# 移動 `tianxia/features/travel/`

- **做什麼**：移動（全部拆包第 47、48 批「移動一」「移動二」）：**選單**（站著的「前往 相鄰地點」，照主畫面選的走法〔步行、疾行；舊的趕路只認得、不再給〕寫時間與體力、體力不夠灰掉）、**路上那串**（折返、路上小事三樣：邊走邊想、沿途打聽、路邊採集；做過的灰掉、收穫每個遊戲日有上限）、**路上見聞**（抵達一站時抽一則）、**喊停**、**安排前往**（大地圖的按鈕，`Game.travel`／`travel_refusal`）、`POST /api/travel`；第 48 批再加**出發**（`depart`：收店、散掉答應了卻先走的結伴、扣體力、排抵達時刻）、**抵達的補算**（`arrivals`、`arrive`，`arrive` 是事件 `arrive` 的發布點）、**在路上那一行字**（`journey_line`）、**結伴同行**（答應、跟著的人照抄一趟、路上小事分收穫、分道揚鑣、拱手作別）、`POST /api/party/leave`。`_arrivals` 每次 `sync`、`advance` 都叫，位置一個都不動。
- **導覽**：`docs/guide/行動與地盤.md` 的「移動」那一條。
- **設計稿**：都沒有版本號（手冊之前的稿）——地圖擴充設計 `docs/superpowers/specs/2026-10-03-地圖擴充與移動-design.md` 3.2、3.3（出發、喊停）；路上設計 `docs/superpowers/specs/2026-10-03-路上-design.md` 第三～五節（折返、路上小事、路上見聞；企劃者 2026-10-03 同一天拍板）、第四節的每天收穫上限（企劃者 2026-10-03）；結伴同行是玩家互動第二層（企劃者 2026-10-08；沒有另寫設計稿，規則寫在 `docs/guide/散人與玩家互動.md`「玩家之間的互動」那一條），結伴騎馬（整隊照帶頭的人的坐騎走、體力各照自己的坐騎算）是裝備四欄設計 `docs/superpowers/specs/2026-10-10-裝備四欄-design.md` 5.8；計畫 `docs/superpowers/plans/2026-11-06-移動包-第1批.md`、`docs/superpowers/plans/2026-11-07-移動包-第2批.md`；搬包照手冊 `docs/superpowers/specs/2026-10-30-開發模式-design.md` 3.1～3.11、第十五節與總表 `docs/superpowers/plans/2026-10-31-全部拆包-總表.md` 第 47、48 列。
