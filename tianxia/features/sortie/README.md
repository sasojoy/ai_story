# 出陣 `tianxia/features/sortie/`

- **做什麼**：投靠了陣營的人在領地爭奪的區塊上出陣——別人的、中立的攻（打一場，推那一塊的進度），自家的守（零風險，把對面的進度拉下來）；出陣時撞上對面剛在這一塊推過的人是混戰（本人對本人，贏了推得多、輸了白跑）；打完那一下在「剛剛」底下多一塊出陣回報（進度條、一句話、小籤）。減法季的約戰開著的季（`season21`、`week7`；`duel_rules.on`＝減法季的 `sortie_duel` 子開關＋出陣＋領地爭奪），出陣換成貼一張約戰：封三招、10 分鐘的窗裡對面同一區的人應戰、同袍同去，窗滿了結算（推或拉那一塊的進度、戰報、紀錄、冷卻），沒人應由對面的假人補位、連假人都沒有由守軍迎戰，季終作廢退次數與體力。出陣沒有自己的開關：地盤（領地爭奪）開著就有。行動列那一格（`act:train`）整格是這一包的：地盤開著是出陣（序章是雪恥：照寫好的打草廬的斷眉），地盤關著的季（不帶設定、測試內容）是舊遊歷（打這裡的對手一場，必敗先問、打完有機會接戰後事件；遇上自己陣營的隊伍改操練：不會輸、拿三成心得經驗、推大勢照季長縮放）；還有守勢行動（`act:duty`：巡哨、傳道、保境安民，推所在戰線、算守城，出陣開著時佔一次出陣，約戰開著時收進此地、一天記一點貢獻；記過之後鈕灰掉寫「今天巡過了／傳過了／做過了」、按不下去不扣體力〔`duel_actions.duty_done_today`、`train_actions.DUTY_DONE`，Joy 2026-11-11 PR #232〕；守城已發而此刻沒得守時這一下另外替守城記一次〔`orders.DUTY_IDLE`，PR #234〕）與遊歷推大勢（打贏或操練推地點寫的那幾條線，照陣營的目標換方向）。主動搬六包第 1 批（出陣本體、混戰、出陣回報）、第 2 批（出陣約戰）、全部拆包第 17 批（出陣三：舊遊歷、序章雪恥、操練、守勢、遊歷推大勢，`act:train` 整格）搬進來。
- **導覽**：`docs/guide/行動與地盤.md` 講出陣、出陣回報、混戰、出陣約戰的那幾段（約戰的結算與戰報在 `docs/guide/戰鬥.md` 的出陣約戰）；第 17 批收進來的那一半也在同一份：「行動」那一節的「**遊歷**」（沒有地盤的季的舊遊歷、跟自家隊伍操練、遊歷推大勢、操練照季長縮放）、「**出陣約戰**」底下的「巡哨、傳道、保境安民」（約戰開著時的守勢），「領地爭奪（第 38 項改版，第一批）」那一節的「**守勢行動**」（不是自家的區塊灰掉、佔一次出陣）；序章（草廬，雪恥是其中一步）在 `docs/guide/核心與存檔.md`「模組」那一節的「新手引導重做」。核心與功能包的關係見 `docs/guide/核心與存檔.md` 的「核心、功能包、FEATURES、掛鉤、服務清單」。
