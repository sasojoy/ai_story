# 出陣 `tianxia/features/sortie/`

- **做什麼**：投靠了陣營的人在領地爭奪的區塊上出陣——別人的、中立的攻（打一場，推那一塊的進度），自家的守（零風險，把對面的進度拉下來）；出陣時撞上對面剛在這一塊推過的人是混戰（本人對本人，贏了推得多、輸了白跑）；打完那一下在「剛剛」底下多一塊出陣回報（進度條、一句話、小籤）。減法季的約戰開著的季（`season21`、`week7`；`duel_rules.on`＝減法季的 `sortie_duel` 子開關＋出陣＋領地爭奪），出陣換成貼一張約戰：封三招、10 分鐘的窗裡對面同一區的人應戰、同袍同去，窗滿了結算（推或拉那一塊的進度、戰報、紀錄、冷卻），沒人應由對面的假人補位、連假人都沒有由守軍迎戰，季終作廢退次數與體力。出陣沒有自己的開關：地盤（領地爭奪）開著就有。主動搬六包第 1 批（出陣本體、混戰、出陣回報）、第 2 批（出陣約戰）搬進來。
- **導覽**：`docs/guide/行動與地盤.md` 講出陣、出陣回報、混戰、出陣約戰的那幾段（約戰的結算與戰報在 `docs/guide/戰鬥.md` 的出陣約戰）；核心與功能包的關係見 `docs/guide/核心與存檔.md` 的「核心、功能包、FEATURES、掛鉤、服務清單」。
- **設計稿**：沒有版本號，四份（都在 `docs/superpowers/specs/`）：`2026-10-14-出陣探索與地盤-design.md` 第二節（出陣本體）；`2026-10-20-輿圖簡化-design.md` 4.3（混戰、翻地與爭搶）；`2026-10-24-減法季-整合設計.md` 4.3（減法季的出陣與約戰；接線計畫 `docs/superpowers/plans/2026-10-24-減法季-主機側實作計畫.md` 第四節）；`2026-10-28-出陣約戰網頁-草圖/`（約戰的網頁，企劃者 2026-10-28 選丙）。出陣回報是企劃者 2026-10-23 在草稿上選的「寫數字」、2026-10-26 小籤改「寫字」。
