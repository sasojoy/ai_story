# 探索 `tianxia/features/explore/`

- **做什麼**：減法季的「探索」那一格——**探索一顆**（出門一趟只碰上一件事：遭遇、事件、素材、感悟，照地點的表抽；三道閘的前兩道；頭目擋路；自家營寨跟同袍比劃；城裡的地痞）與**走一趟**（按一次探索走一、三、五段，每一段就是一次探索一顆；停在要選的事上、選完接著走；打輸、氣血見底、體力不夠回頭；走完留一句〔預設三句免費、自己寫的用一張題壁墨；題壁墨寫的不被預設句擠掉、換季帶到下一季，PR #117〕、遊記；路上看到別人的留言與揮手；撿到稀世的東西、以弱勝強記一則行狀）。開關：減法季的 `explore_one`、`outing` 兩個子開關（`rules.jianfa`；season21、week7 開，不帶設定、weekend、測試內容關）。主動搬六包第 3＋4 批（企劃者 10/31「趕快拆」，兩批合成一批）搬進來；**探索三選一**與找素材「自己說」（模組與 Game 上它們的方法）全部拆包第 13 批整套拿掉，還活著的小工具（`find_rng`、`one_of`、`gather_finds`、`home_gather`）搬進這一包。
- **導覽**：`docs/guide/行動與地盤.md` 的「減法季探索一顆」那幾段（模組那一節的 `explore_one`／走一趟兩條、行動那一節的「減法季探索一顆」）、`docs/guide/戰鬥.md` 的「減法季三道閘」；核心與功能包的關係見 `docs/guide/核心與存檔.md` 的「核心、功能包、FEATURES、掛鉤、服務清單」。
- **設計稿**：沒有版本號，兩份：探索一顆是 `docs/superpowers/specs/2026-10-24-減法季-整合設計.md` 4.1（4.2 三道閘）；走一趟是企劃者 2026-10-29～30 的設計稿（artifact，網址在 `outing_rules.py` 開頭；不在 specs/），之後 Joy 10/30～31 的幾輪改字、改結算卡照江湖紀錄與程式裡的註記。
