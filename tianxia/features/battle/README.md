# 全服決戰 `tianxia/features/battle/`

- **做什麼**：官軍、黃巾兩軍在一個大區集結、一回合一回合地打（散人、豪強臨時投效），收場之後每個人下一次同步把那一場補到自己手上。主動搬六包第 5 批搬進「看」的那一半——場景、戰局條、攻城條、一回合一段的戰況、收場補送（戰報、江湖紀錄、軍餉、行狀、戰功）、補回被洗掉的戰報、放手一搏的輸入框與鎖外三段式、補劇情。全部拆包第 6 批接著搬「打」那一半的頭一段——管理者的決戰工具（立刻開戰的選單、立刻開戰、取消決戰、三場大戲那三顆鈕）與攻城（好幾場並存的那一串、推一場、收兵、取消、收場、守城軍令、這一場的定義）。「打」的其餘（集結、投效、挑同伴、推進、結算）還在 `Game`，第 7、8 批搬（批次表 `docs/superpowers/plans/2026-10-31-主動搬六包-批次.md`；計畫 `2026-10-31-決戰包-第1批.md`、`2026-11-01-決戰包-第2批.md`）。
- **導覽**：`docs/guide/戰鬥.md` 全服決戰那幾段（戰鬥的演出與大場面、全服決戰、戰記）與末尾「全服決戰（功能包）」那一節；核心與功能包的關係見 `docs/guide/核心與存檔.md` 的「核心、功能包、FEATURES、掛鉤、服務清單」。
- **設計稿**：沒有一份決戰的總稿、都沒有版本號，散在：`docs/superpowers/specs/2026-09-27-天下大勢-design.md`（全服決戰）、`2026-10-02-第一季黃巾之亂-design.md`（時刻表決戰）、`2026-10-05-武學與成長-design.md`（戰鬥過程）、`2026-10-20-輿圖簡化-design.md` 4.4（攻城戰）；其餘是試玩修正——Joy 2026-10-10（戰局條、個人戰功、掛機、點名與顯眼）、10-13（放手一搏只評成功率、劇情回合結算後整批寫）、10-14（一回合一段、完整戰報、決戰戰報不被洗掉）、10-30（一軍的戰法摺成一列）、PM 2026-10-15（再失手就倒下那一句）。管理者的決戰工具：管理者觸發鈕（企劃者 2026-10-07）第 3 組「三場大戲」、第一季計畫 T8（立刻開戰照時刻表開）、T10（取消決戰）、FB-099（開打後被取消、還沒有結果）、FB-563（取消的不上輿圖）；攻城：領地爭奪第二批（Task 10 好幾場並存、Task 11 收場、裁決 14、19、22、23）、FB-605（守城軍令）。
