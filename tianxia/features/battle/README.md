# 全服決戰 `tianxia/features/battle/`

- **做什麼**：官軍、黃巾兩軍在一個大區集結、一回合一回合地打（散人、豪強臨時投效），收場之後每個人下一次同步把那一場補到自己手上。主動搬六包第 5 批搬進「看」的那一半——場景、戰局條、攻城條、一回合一段的戰況、收場補送（戰報、江湖紀錄、軍餉、行狀、戰功）、補回被洗掉的戰報、放手一搏的輸入框與鎖外三段式、補劇情。全部拆包第 6 批接著搬「打」那一半的頭一段——管理者的決戰工具（立刻開戰的選單、立刻開戰、取消決戰、三場大戲那三顆鈕）與攻城（好幾場並存的那一串、推一場、收兵、取消、收場、守城軍令、這一場的定義）。全部拆包第 7 批接著搬「打」那一半的第二段——集結、加入、晚到、臨時投效、改投、挑同伴（隨你出陣、打完回江湖）、在不在場、假人趕路、出招的分派，並拿了 `battle:` 前綴（假人的分數在 `bots.py`）。全部拆包第 8 批搬「打」的最後一段——推進與結算（我在哪一場、一回合一回合推〔回合首功包在外面〕、收兵、收場與論功、只能觀戰與整個取代畫面、份量快照補上）與龍頭上陣（`tianxia/generals.py` 整個搬進包；挑法 `on`、`pick` 留在共用規則層 `tianxia/chiefs.py`），收季的收兵接成接縫掛鉤 `on_season_close`（批次表 `docs/superpowers/plans/2026-10-31-主動搬六包-批次.md`；計畫 `2026-10-31-決戰包-第1批.md`、`2026-11-01-決戰包-第2批.md`、`2026-11-01-決戰包-第3批.md`、`2026-11-01-決戰包-第4批.md`）。
- **導覽**：`docs/guide/戰鬥.md` 全服決戰那幾段（戰鬥的演出與大場面、全服決戰、戰記）與末尾「全服決戰（功能包）」那一節；核心與功能包的關係見 `docs/guide/核心與存檔.md` 的「核心、功能包、FEATURES、掛鉤、服務清單」。
- **設計稿**：沒有一份決戰的總稿、都沒有版本號，散在：`docs/superpowers/specs/2026-09-27-天下大勢-design.md`（全服決戰）、`2026-10-02-第一季黃巾之亂-design.md`（時刻表決戰）、`2026-10-05-武學與成長-design.md`（戰鬥過程）、`2026-10-20-輿圖簡化-design.md` 4.4（攻城戰）；其餘是試玩修正——Joy 2026-10-10（戰局條、個人戰功、掛機、點名與顯眼）、10-13（放手一搏只評成功率、劇情回合結算後整批寫）、10-14（一回合一段、完整戰報、決戰戰報不被洗掉）、10-30（一軍的戰法摺成一列）、PM 2026-10-15（再失手就倒下那一句）。管理者的決戰工具：管理者觸發鈕（企劃者 2026-10-07）第 3 組「三場大戲」、第一季計畫 T8（立刻開戰照時刻表開）、T10（取消決戰）、FB-099（開打後被取消、還沒有結果）、FB-563（取消的不上輿圖）；攻城：領地爭奪第二批（Task 10 好幾場並存、Task 11 收場、裁決 14、19、22、23）、FB-605（守城軍令）。集結與加入（第 7 批）：總設計「全服決戰」、第一季設計（時刻表決戰）、FB-009（集結時照常遊玩）、FB-028（晚到當回合就能出手）、FB-030（加入與改選各一則）；臨時投效：試玩回饋 2026-10-08（散人）、Joy 2026-10-13（豪強）、FB-273（先投效再選邊）；挑同伴：`2026-10-18-歷史武將同行-design.md` 第五、六節（9.3 沒有預設值、9.6 情誼減半、FB-361）；在場：地圖擴充設計第六節；趕路：地圖擴充設計 3.4；好幾場並存：領地爭奪第二批 Review Focus 4、FB-566。推進與結算（第 8 批）：第一季設計（時刻表決戰 T8 三場大戲、T10 管理者救場）、戰鬥系統設計 4.1～4.3（勝負、伏筆鎖定只在收場看）、FB-015／FB-035（季終收兵、不算勝負）、FB-027（收場補送）、FB-113（序章裡不畫戰場）、FB-109（整個取代畫面）、FB-173（只剩掛機的人）、試玩回饋 2026-10-08（最有戲的放手一搏、結算不在鎖內等模型）、Joy 2026-10-10（論功）、Joy 2026-10-17 第 2 條（龍頭上陣）、Joy 2026-11-03（回合首功）、Review Focus 2（時間到了在等前一場打完的決戰）。都沒有版本號。
