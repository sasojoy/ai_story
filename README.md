# 天下大勢（原型）

一個由玩家寫下結局的文字武俠江湖。設計文件見 `docs/superpowers/specs/2026-09-27-天下大勢-design.md`。

## 安裝與執行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe app.py
```

打開 http://127.0.0.1:7861 ，輸入名號即可開始；同一個名號會自動讀取存檔（`saves/`）。

右上方的「主線與目標」區塊會告訴你這一季的主線、可能的結局與下一步。左欄最上面是場景列：左邊是所在地點或眼前的事件，右邊是所在大區的小地圖（只標出區內摸清的地點、你的位置，以及往相鄰大區的方向）。點小地圖、它下方或右欄的「大地圖」按鈕，會打開整頁的「江湖輿圖」：可以切換局勢（各大區的大勢與龍頭人物常出沒處）、敵情（危險度與最難對付的對手的勝算）、劇情（★ 這一幕主線的目標、✦ 最近 3 天的大事與傳聞）、路線（走過去最省的體力）四個圖層；在圖上點地點或從右邊的下拉選單選地點，會列出它的詳情，按「安排前往」就沿最省體力的路一站一站走過去（體力不夠時停在半路），按「返回江湖」回到原本的畫面。看不見也沒去過的地點只畫輪廓與「？」。開局前幾步由老說書人帶路。場景列與選項按鈕下方是「剛剛」卡片（剛才那次行動的結果、敘事與數值增減，綠增紅減），再往下是「江湖紀錄」：最近 5 次行動一則一列（點一下可以展開那次的敘事），更早的收在「展開更早的紀錄」裡（最多保留 30 則）。連續在「門下」做的調整併成一則；時間流逝中發生的江湖大事與主線變化也會記成一則「江湖大事」。

戰鬥是三對三全自動：你和兩名同伴一隊。會開打的按鈕上寫著對手與勝算（穩勝、有把握、五五波、凶險、必敗，依目前的陣容、配置與內力模擬而得）；打完後「剛剛」卡片換成戰鬥卡片（結果、關鍵時刻、獲得與損失），同一次行動裡卡片沒寫到的事（例如完成新手引導與它的獎勵）列在卡片底下。按右欄的「戰報」或戰鬥卡片的「看完整戰報」，會打開整頁的戰報：左邊是最近 20 場的列表，右邊是選中那一場的完整內容（陣容、結果、關鍵時刻、獲得與損失、我方表現、逐回合戰報）；按「返回江湖」回到原本的畫面。劇情裡跟蹤、打聽、救人這類「辦事」由隊中該項屬性最高的人出手；服藥、聽禪、領悟這類「修行」只看本人。戰前按右欄的「門下」打開整頁的隊伍與武學配置：上方是每個人的人物卡（等級、內力、屬性、資質）與本命、自選1、自選2 三個武學欄；下方左邊是武學庫，右邊是選中武學的白話說明（何時發動、每成的數字、相剋、誰用最順手、配在哪裡）。點一個自選欄再選一門武學就能「配置到」那一欄，也可以「卸下」、用心得「升一成」或「散功」；按「返回江湖」回到原本的畫面。閉關可以得到心得。

## 測試與平衡

```bash
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/simulate.py 30
```

## 修改內容

所有地點、事件、武學、人物、敵方隊伍、大勢線都在 `content/` 的 JSON 裡，改完重啟 `app.py` 即可。內容寫錯時，啟動會直接列出是哪個 id 出錯。
試玩時可以在「設定」分頁快轉時間，或把 `content/config.json` 的 `time_scale` 調大。
