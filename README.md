# 天下大勢（原型）

一個由玩家寫下結局的文字武俠江湖。設計文件見 `docs/superpowers/specs/2026-09-27-天下大勢-design.md`。

## 安裝與執行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe app.py
```

打開 http://127.0.0.1:7861 ，輸入名號即可開始；同一個名號會自動讀取存檔（`saves/`）。

右上方的「主線與目標」區塊會告訴你這一季的主線、可能的結局與下一步。左欄最上面是場景列：左邊是所在地點或眼前的事件，右邊是以你為中心的小地圖（從大地圖截出你附近的一塊：摸清的地點寫名字，沒摸清的只畫輪廓與「？」或淡點；視窗外、兩站路以內的摸清地點在邊緣標出方向，例如「↘ 無錫」）。點小地圖、它下方或右欄的「大地圖」按鈕，會打開整頁的「江湖輿圖」：可以切換局勢（各大區的大勢與龍頭人物常出沒處；龍頭人物是江湖上會自己行動的人物，選到他常出沒的地點，詳情會說明他是誰、現在推著哪條大勢往哪走、最近有什麼傳聞）、敵情（危險度與最難對付的對手的勝算）、劇情（★ 這一幕主線的目標、✦ 最近 3 天的大事與傳聞）、路線（走過去最省的體力）四個圖層；在圖上點地點或從右邊的下拉選單選地點，會列出它的詳情，按「安排前往」就沿最省體力的路一站一站走過去（體力不夠時停在半路），按「返回江湖」回到原本的畫面。看不見也沒去過的地點只畫輪廓與「？」。開局前幾步由老說書人帶路。場景列與選項按鈕下方是「剛剛」卡片（剛才那次行動的結果、敘事與數值增減，綠增紅減），再往下是「江湖紀錄」：最近 5 次行動一則一列（點一下可以展開那次的敘事），更早的收在「展開更早的紀錄」裡（最多保留 30 則）。連續在「門下」做的調整併成一則；時間流逝中發生的江湖大事與主線變化也會記成一則「江湖大事」。

戰鬥是三對三全自動：你和兩名同伴一隊。會開打的按鈕上寫著對手與勝算（穩勝、有把握、五五波、凶險、必敗，依目前的陣容、配置與內力模擬而得）；打完後「剛剛」卡片換成戰鬥卡片（結果、關鍵時刻、獲得與損失），同一次行動裡卡片沒寫到的事（例如完成新手引導與它的獎勵）列在卡片底下。按右欄的「戰報」或戰鬥卡片的「看完整戰報」，會打開整頁的戰報：左邊是最近 20 場的列表，右邊是選中那一場的完整內容（陣容、結果、關鍵時刻、獲得與損失、我方表現、逐回合戰報）；按「返回江湖」回到原本的畫面。劇情裡跟蹤、打聽、救人這類「辦事」由隊中該項屬性最高的人出手；服藥、聽禪、領悟這類「修行」只看本人。戰前按右欄的「門下」打開整頁的隊伍與武學配置（「名冊・隊伍」分頁）：上方是隊伍切換與選中那一隊的三欄，每欄是一個人的人物卡（品階、統御、等級、內力、屬性、資質）與本命、自選1、自選2 三個武學欄；中間是名冊；下方左邊是武學庫，右邊是選中武學的白話說明（何時發動、每成的數字、相剋、誰用最順手、配在哪裡）。點一個自選欄再選一門武學就能「配置到」那一欄，也可以「卸下」、用心得「升一成」或「散功」；按「返回江湖」回到原本的畫面。閉關可以得到心得。

門下有名冊與隊伍。名冊是這一季入門的所有人，依品階（天、地、玄、黃）排列，點名字看人物卡；天品另有不佔武學欄、不能升級或散功的「特性」，黃品沒有本命武學。每個人都有自己的統御，一隊的總統御不能超過上限（開季 15、第二幕 18、第三幕 20），超過時換不進去並寫明「統御 17／15」；隊伍數也依主線幕數開放（開季 2 隊、第二幕 3 隊、第三幕 4 隊，還沒開放的寫「第二幕開放」）。本隊一定有你、你固定是隊長，歷練、探索、交遊、劇情戰與檢定都由本隊出手，經驗也只給本隊；第二隊起的派遣隊目前只能編隊，之後才會出門。每欄上方的「換人」可以把候補或別隊的人換進來、或空出這一位（被換下的人回到候補）；同一門武學同時只能配給一個人，某人的本命不能再配給他同一隊的人。

新人從各隊成員中最低的等級起算、先列候補，每次入門都記一筆江湖紀錄（例如標「地品・入門」）：在城鎮或門派可以「收徒」（40 兩、5 體力，每天最多 2 次，黃品四分之三、玄品四分之一，有人只在自己的門派收得到；收完了寫「此地已無可收之徒」）；交遊與奇遇事件可能「結識」玄品到天品；打贏水寨頭目、藏龍洞守墓人可能「招降」；第 2 天起第一次交遊必定遇上一名地品的新立門戶「福緣」，到第 7 天結束還沒遇上就直接送上門；兩名福緣的地品都已經（用招賢）請進門時，福緣改送一份賀禮（心得 +50，不算招賢心得，江湖紀錄記「福緣」、標「賀禮」）。劇情萬一又給了已經入門的人，就改給心得。

門下頁的「招賢」分頁用元寶招人（原型不接金流：在右欄「設定」分頁按「測試：領取 1000 元寶」）：單抽 100、十連 1000 元寶。機率公開寫在分頁上：天 3%、地 12%、玄 35%、黃 50%，同品階的人平均分配；連續 40 抽沒出天品，第 40 抽必得天品（分頁上一直顯示「再 N 抽必得天品」），十連至少一名地品以上，兩種保底分開算。卡池是人物資料標了「招賢」的人（開局的韓鐵、小墨與只能招降的人不在裡面），每人標出品階與機率。抽到新人照入門規則先列候補；抽到已經入門的人換成心得（黃 10、玄 20、地 50、天 100），但本季招賢換到的心得超過 150 之後減半、最多 300，滿了改給銀兩。抽完在分頁上排出一排結果卡（名字、品階、流派、統御、本命，以及「新入門」或「重複 → 心得 +50」），江湖紀錄記一則「招賢・十連」。元寶與保底計數跨季保留，其他照舊每季清空。

## 測試與平衡

```bash
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/simulate.py 30
.venv/Scripts/python.exe scripts/simulate.py 30 3000
```

模擬器讓機器人玩完整季，印出結局、大勢、名冊人數與整季拿到的心得；第二個參數是付費機器人開季先花在招賢的元寶，另外印出它的統計，以及付費方與免費方的本隊在開季、第二幕、第三幕交手的勝率（設計文件的目標是不超過 70%、60%、55%）。

## 修改內容

所有地點、事件、武學、人物、敵方隊伍、大勢線都在 `content/` 的 JSON 裡，改完重啟 `app.py` 即可。內容寫錯時，啟動會直接列出是哪個 id 出錯。
同伴在 `content/characters.json` 寫統御 `command`、取得管道 `sources`（可選 `recruit_at` 限定收徒地點、天品寫特性 `trait`），結識事件的效果寫 `recruit`、條件用 `members_none` 排除已入門的人，敵方隊伍用 `surrender` 寫可能投效的人；品階的範圍（統御、本命品質、資質）、免費管道與「寫了管道就要有事件或隊伍帶得來」都會在載入時檢查。收徒、招降、福緣、統御上限與隊伍數的數字在 `content/config.json`。
招賢的價格、機率、保底、重複換算與付費心得護欄也在 `content/config.json`（`gacha_*`、`duplicate_xinde`、`test_yuanbao`）；其中價格、重複換算與護欄是暫定值（另談），名稱列在 `provisional`，改數字不用改程式。
試玩時可以在「設定」分頁快轉時間，或把 `content/config.json` 的 `time_scale` 調大。
