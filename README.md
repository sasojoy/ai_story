# 天下大勢（原型）

一個由玩家寫下結局的文字武俠江湖。設計文件見 `docs/superpowers/specs/2026-09-27-天下大勢-design.md`。

## 安裝與執行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe app.py
```

打開 http://127.0.0.1:7861 ，輸入名號即可開始；同一個名號會自動讀取存檔（`saves/`）。

右上方的「主線與目標」區塊會告訴你這一季的主線、可能的結局與下一步；左上方「場景／地圖」分頁中的地圖顯示你看得見、去過與尚未摸清的地點。開局前幾步由老說書人帶路。

戰鬥是三對三全自動：你和兩名同伴一隊。會開打的按鈕上寫著對手與勝算（穩勝、有把握、五五波、凶險、必敗，依目前的陣容、配置與內力模擬而得）；打完後場景上方出現戰鬥卡片（結果、關鍵時刻、獲得與損失），按「看完整戰報」或右欄的「戰報」分頁，可以看最近 20 場的逐回合戰報與我方每人表現。劇情裡跟蹤、打聽、救人這類「辦事」由隊中該項屬性最高的人出手；服藥、聽禪、領悟這類「修行」只看本人。戰前按右欄的「門下」打開整頁的隊伍與武學配置：上方是每個人的人物卡（等級、內力、屬性、資質）與本命、自選1、自選2 三個武學欄；下方左邊是武學庫，右邊是選中武學的白話說明（何時發動、每成的數字、相剋、誰用最順手、配在哪裡）。點一個自選欄再選一門武學就能「配置到」那一欄，也可以「卸下」、用心得「升一成」或「散功」；按「返回江湖」回到原本的畫面。閉關可以得到心得。

## 測試與平衡

```bash
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/simulate.py 30
```

## 修改內容

所有地點、事件、武學、人物、敵方隊伍、大勢線都在 `content/` 的 JSON 裡，改完重啟 `app.py` 即可。內容寫錯時，啟動會直接列出是哪個 id 出錯。
試玩時可以在「設定」分頁快轉時間，或把 `content/config.json` 的 `time_scale` 調大。
