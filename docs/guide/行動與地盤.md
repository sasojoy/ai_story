## 模組

- `tianxia/territory.py`：地盤易手（`docs/superpowers/specs/2026-10-14-出陣探索與地盤-design.md` 第四節；`Config.territory`）：戰線地點（`line_of`：`train_trend` 寫了戰線；寫 `front` 的照大區，洛陽兩處不算）、大本營（`bases`，含不在戰線上的投靠點）、拔河（門檻 `threshold`、±`band`）、割據佔地、大事指定（`assign`，`TimetableOutcome.control`、`TerritoryState.pinned`）、控制方（`controller`，存在 `WorldState.territory`，None 照規則現算）、站的隊伍（`squads_at`，`Scenario.territory.garrison`）、價錢倍數（`price_factor`）。`rules.change_trend` 動了就 `update`（決戰結果直接寫進季、`world.advance_world_state` 也叫）；第一次算不發天下大事；`open_season` 清成 None。規則關著的季拔河看黃巾聲勢（三條線一起動）、沒有割據佔地。見「規則速查」的「地盤易手」。
- `tianxia/conquest.py`：領地爭奪（第 38 項改版；`Config.conquest`，開季蓋章 `WorldState.conquest_on`，判斷走 `conquest.on(content, world)`）：區塊（`blocks`、`start_kind`、`capturable`、`adjacent`、`targets`）、此刻歸誰（`holder`，存在 `TerritoryState.control`）、大勢值＝基準＋偏移（`base`、`value`、`reweigh`、`apply_push`、`set_control`、`assign`、`update`，`territory.update`／`assign`／`controller`、`rules.change_trend` 開著時改叫這裡）、中立駐軍（`neutral_squads`）、出陣對手與進度（`sortie_foes`、`progress_*`、`push_progress`）、自家領地（`home`、`is_home`）。見「地盤易手」底下的「領地爭奪」。只 import calendar、rules、territory；territory、rules、sortie、works、orders 反過來在函式裡延後 import 它。
- `tianxia/sortie.py`：出陣的純規則（開關 `on`、次數 `left_today`／`spend`、攻守攪局 `mode`、推多少 `pushes`、字；`Config.sortie`）。選項 id 照留 `act:train`；`Game._sortie` 打或不打、`_sortie_rewards` 三成、`_sortie_hold` 守與攪局；守勢行動也扣次數（`Game._duty_option`）。見「規則速查／行動」的「出陣」。
- `tianxia/explore_modes.py`：探索三選一的純規則（`Config.explore_modes`；id `explore:gather|seek|sense`、找素材 `gather_finds`、撞怪 `encounter_due`、自己的亂數 `rng_for`〔季數｜名號｜`PlayerState.explore_seq`｜用途〕）。`act:explore` 是展開的入口（`IDLE_MARK` 照舊認它）：開關開著時按了不花體力、只回 `PICK`，鈕上不寫體力，三顆都按不下去時入口也灰；`Game._explore_mode` 分給 `_gather`／`_seek`／`_sense_here`。見「規則速查／行動」的「探索」。找素材分支（第 32 項）的純規則也在這裡：開關 `branches_on`（另要 `precise.on`）、這裡有哪幾條 `branches_here`、有沒有分支層 `layered`（兩條以上）、分支給哪幾種屬性 `branch_attributes`、「自己說」可挑的屬性 `say_choices`、深入悟意境 `deep_insight`、寫得好多給的 `say_bonus`、單子 `GatherTextRequest`；`gather_finds` 多一個 `attributes`（只換屬性的池子）。
- `tianxia/gather_llm.py`：找素材「自己說」的 B 段（鎖外）：`score(client, req)` 只回成算（0～100）與從清單挑的屬性（轉繁體再比，清單外是 None），短提示、`num_predict` 32；叫不動回（40, None）。不碰狀態。
- `tianxia/clinic.py`：醫館（療傷只在帶「醫館」標籤的地點）：在不在醫館（`here`，在路上不算）、最近的一家（`nearest`）、不在醫館那一句（`problem`）；`Game.heal`、`act:heal`、`skillview.heal_button` 與機器人的繞路都問它。只 import models、state、atlas。
- `tianxia/ambush.py`：設伏劫道（後期體力玩法第一批，Joy 2026-10-16；`Config.ambush`）的純規則：設得了伏的路（`road_ok`：兩頭都不是城鎮類、不是序章專屬）、路段鍵（`key`）、某一刻有效的埋伏（`active`、`end_of`）、不讀存檔先篩敵我（`maybe_hostile`，照設伏那一刻的 `Ambush.side`）與真的判（`hostile`）、記下與收起（`place`、`lift`、`prune`）。打在 `Game._ambush_check`／`_ambush_fight`（`_arrivals` 每換一段查一次）。見「規則速查」的「後期體力玩法」。
- `tianxia/works.py`：修築工事（`Config.fortify`，工事存在 `TerritoryState.forts`，效果在 `territory.fort_level`／`fort_extra`／`_tug`）與屯糧練兵（`Config.stockpile`，`WorldState.supply`，開集結那一刻 `on_muster` 換成起點的偏移，`world._open_claimed` 叫）。

## 屬性、威力與氣血

- **醫館**（企劃者 2026-10-12「療傷我認為不能隨地療傷，應該去城鎮有醫館的地方讓玩家不能無腦打怪升級」；`tianxia/clinic.py`、`Config.heal_at_clinic`，預設開、測試內容關著）：療傷（`team.heal`）只在帶「醫館」標籤的地點做得了：潁川郡（陽翟，序章出來的第一站）、汝南、宛城、涿郡、下曲陽、白馬寺（洛陽那一區沒有城鎮），每個大區至少一處；載入時檢查開著就要有一家。不在醫館時修練頁的療傷鈕灰掉、第二行寫「這裡沒有醫館，最近的在X。」（`skillview.heal_button` 的 `clinic`，`clinic.nearest` 先照摸清的路找（全圖開放時就是所有已開放的地點）），按下去也只回這一句；在路上不算在醫館。在醫館而且有內傷時「此地還能做」多一顆「醫館療傷（內傷 N・M 兩）」（`act:heal`，同修練頁那一顆、不花體力）。銀兩不夠全治時能治多少治多少（PM 2026-10-12；`team.heal_plan`，每一兩治 2 點），鈕上寫「治 N 點・M 兩（還剩 K 點）」（`skillview.heal_note`，醫館那一顆與修練頁共用）；一兩都沒有才灰掉。內傷沒有上限，可以疊過氣血上限。氣血隨時間回、閉關、吸取、回春都只回到「上限−內傷」，內傷只有醫館治得好。整季機器人與假人內傷到氣血上限的 `bot.CLINIC_AT`（15%）、付得起時往最近的醫館走（`bot.clinic_hop`；整季機器人排在 `pick` 前面，假人 `bot_policy.CLINIC_MOVE_SCORE` 20；內傷到 `bot.CLINIC_URGENT`（25%）以上時往醫館走與療傷都給 `CLINIC_URGENT_SCORE` 100，排在軍令、召見前面，PM 2026-10-12），走進醫館就療傷（`bot.wants_heal` 要人在醫館）；付不起全治時手上至少 `bot.CLINIC_MIN_SILVER`（20）兩才去、才治一部分。內傷到 25% 以上又湊不出這筆錢的假人不遊歷、不挑戰本人（`bot_policy._crippled`），去探索、做事件攢錢：氣血只剩一成上下，打一場輸一場、越輸越窮。醫館標籤不是地形（`sensing.place_tags` 不寫）。

## 後期體力玩法（第一批，Joy 2026-10-16；2026-10-16 合進 main〔ff60ed83〕，正式內容三個開關都關著，數字等 21 天的季一起定）

- **設伏劫道**（`ambush:set:<另一頭>`、`ambush:lift`）：花 `Config.ambush.stamina`（80）守在這一站往某一站的那段路上 `hours`（3）個世界小時；兩頭都不是城鎮類才設得了（正式內容 19 段）。守著的時候本人不能移動（`atlas.travel_block`、`_move_option` 灰掉），下線照守；同一段路可以有幾個人各自埋伏（不擋，擋了等於告訴人那裡有伏兵）。敵對的人（照截殺：兩邊不同一方，或伏兵揭了通緝他）走過那一段（步行、疾行都算，照抵達那一站的時刻判）就打一場（本人對本人，同截殺；亂數「設伏|伏兵|路人|時刻」，不動 `Game.rng`）：贏的拿走輸的 `silver_share`（一成，最多 40 兩）與 `materials`（2）個素材（手上最多的、一階先），輸的扣氣血上限的 `hp_loss`（一成，乘 1−防具）。雙向：伏兵輸了賠的是自己的東西，埋伏也散了。保護照截殺：雙方過了新手期、同一對人 `pair_cooldown_seconds`（跟截殺共用 `WorldState.raids`）、剛被截過的護身（`raided`）。一段只打一場（先設的先打）。散人沒揭通緝、新手期的人沒有設伏鈕。收了、過了時刻的紀錄留 `keep_hours`（24），下線的人回來補算路程時照「當時」判。戰報 kind `ambush`（「設伏」）。
- **修築工事**（`works:fortify`）：自家控制、拔河也是自家的可易手戰線地點，花 `Config.fortify.stamina`（50）加 `per_press`（10）點、最多 `cap`（100）；每個世界小時壞 `decay_per_hour`（8）。工事讓守著的一方多撐：對方要把線推過門檻＋band＋工事÷cap×`band`（10）才翻得過來；易手就沒了。豪強割據佔的地點這一批不修。
