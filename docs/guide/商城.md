## 規則速查

- **開關** `Config.mall.enabled`：模型預設關、測試內容明寫關、正式內容與 `week7` 開。關著時不發元寶、不讀不寫三張表（月卡不加上限）、API 都 404，其餘一個字都不變。設定覆寫檔是淺合併：覆寫檔寫 `mall` 就要整個寫（`week7` 寫 `{"enabled": true, "beta_grant": 5000}`）。
- **錢包的主人**是角色名號的 casefold（`characters.name_key`，同 `characters.key`、真人的 `accounts.character_key`）。真人的帳號與角色一對一、綁了不換；假人沒有帳號（`bot_runner` 只建角色）也有錢包，管理者查帳時真人假人長得一樣。換季角色重來，`characters` 那一列留著，錢包跟著跨季。【開發，PM 待確認；另一條是掛 `accounts.id`、假人沒有錢包】
- **餘額＝帳的加總**（不另存）；餘額不能是負的。每一筆帶不重複的編號：封測發放 `grant:beta:<主人>`、購買 `buy:<主人>:<網頁的編號>`、退款 `refund:<購買 id>`、管理者 `admin:<伺服器的編號>`。原因：`grant` 封測發放、`buy` 購買、`refund` 退款、`reissue` 補發、`revoke` 扣回、`topup` 儲值（留給之後的金流，表的 CHECK 已經收）。
- **封測發放** `Config.mall.beta_grant`（預設 0、`week7` 5000【預設】）：本人那一輪（`Game.own_turn_checks`：伺服器的 `mark_seen`、假人程式自己那一輪）錢包還沒發過就發，寫一則「商城」江湖紀錄；暫停中照發。之後再開新的一季、換一份設定都不會再發。沒建角色的帳號要等建了角色、第一次進來才發。
- **購買**（`mall.buy`，一筆交易）：查重（同一個編號回「這一筆已經買好了」，不扣不發）→ 上架（季的清單、日期含頭尾；沒上架回「沒有這件商品」，不露之後要賣什麼）→ 限購（每天照台灣日、每季照季數、每個帳號照全部；數的是沒退的購買）→ 餘額 → 寫購買紀錄 → 扣元寶 → 發貨（先寫月卡、最後才把回體丹加進 `PlayerState.stamina_pills`）。伺服器在行動鎖裡做，出錯整筆撤回。一次買一件。籌備中、休季、序章裡都能買；賽季時鐘暫停中照其他動作擋。成了寫一則「商城」紀錄（變化寫「元寶 -N」與拿到的東西）。
- **月卡**：每天回體丹上限 +`Config.mall.card_pill_bonus`（1；平常 2→3、新手期 5→6；不限照舊不限），加在 `Game.pill_cap` 這一個地方（`pills_left_today`、服滿那一句、狀態列跟著變；加的那一份是 `Game._pill_card_bonus`，點體力條看的說明也照它寫兩個上限與「月卡多 N 顆」〔`howto.stamina_lines` 的 `card`，FB-480〕）。存在 `mall_entitlements`（`kind='card'`、`key='pill_cap'`、開始日～到期日不含）。買的那一天算第一天（台灣 23:59 買也算）；還沒到期再買從到期日往後接、開始日不動，過期了從今天起算。
- **管理者**（`Game.is_admin`；帳跟季無關，籌備中、休季、暫停中都做得了）：補發、扣回（原因必填；扣回不能扣到負的）、退一筆購買（元寶全退；回體丹收回手上還有的、用掉的不追；月卡扣回那一張的天數，那一張屬於已經過期的舊卡就不動；一筆只能退一次）、查帳（名號或帳號都找得到；帳多寫編號與經手的管理者，玩家自己看的不寫）。每一筆寫進帳（誰、何時、為什麼），管理者自己的江湖紀錄記一則「商城」〔管理者〕。設定頁的表單見「畫面」。
- **玩法說明**（設定抽屜的「玩法說明」最後一節「商城」，`howto.mall_lines`；第三批）：入口、元寶只能儲值取得、不能拿銀兩換也換不成銀兩（`MALL_COIN`）、封測發放（`beta_grant` 是 0 不寫）、月卡（架上有月卡、回體丹一天有上限才寫，上限照 Config：「平常 2 → 3、新手期 5 → 6」）。不看個人；這個人此刻的上限寫在點體力條看的那幾句（FB-480 的「月卡多 N 顆」）。商城關著時整段沒有、玩法說明一個字都不提元寶。字待 joy 潤。
- **假人**不買東西（設計 4.8，這一版沒有外觀，別人看不到誰買了什麼）：`bot_policy`、`bot`、`bot_runner` 都沒有叫 `mall_buy` 的路，只在自己那一輪照樣拿封測發放。任何畫面與回話不寫誰是假人：別人看得到的（「此地還有」、玩家卡、傳聞、江湖史、大事、榜單、戰報、行狀）與假人程式的主控台輸出都沒有元寶、商城、購買的字樣（`tests/mall/test_mall_bots.py` 守）。擂台形象（2026-10-31）也不買：假人照名號穿一套（見「擂台形象」），別人看不出誰是買的。
- **形象、通行證**：形象（`kind` `look`）見下面「擂台形象」；通行證的種類留著（`MallItem.kind`、`mall_entitlements.kind`），允許表裡沒有它的效果，這一版寫不出商品。
