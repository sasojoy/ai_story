## 模組

**地圖**
- `tianxia/atlas.py`：大地圖的資料（純資料與文字）：摸不摸清只由 `location_view` 判斷——全圖開放（`Config.open_map`，企劃者 2026-10-15，預設開、測試內容關著）時已開放的地點全部算摸清（名字、敵情、勝算、詳情都看得到，都能直接安排前往，路線照全部已開放的地點算最短的），沒有視野這件事；劇情還沒開放的地點（`unlock_flag` 沒立起來、序章專屬）照舊完全不畫、不能去。開關關著是舊規則（視野 `vision_base` 兩站、名望 `vision_fame` 多看一站、去過、留意地形與召見摸清的路才算摸清，沒摸清的只畫輪廓與「？」）。大區歸屬（地點座標落在哪個大區多邊形，區外歸最近的大區）、最省體力的路線與三種走法的時間與體力（騎著馬：本來就收 state 的 `route_stamina`／`route_text`／`travel_options`／`detail_text` 自己照 `mounts` 算；純函式 `travel_seconds`／`mode_when`／`arrival_times` 的 `pace`、`travel_stamina` 的 `saving`、`mode_text` 兩個都是**必填**的關鍵字參數；體力兩段進位 `foot_stamina` → `ride_stamina`〔.5 進位、不用 round〕，`route_foot_stamina` 給結伴同行各付各的；`road_spot` 讀 `Journey.pace`）、四個圖層要標的東西（含局勢層的打擊記號 `strike_marks`）、地點詳情與「安排前往」的條件；勝算只在敵情層與詳情欄才算。
- `tianxia/mapview.py`：把 atlas 的資料畫成 SVG：大地圖（江湖輿圖，四個圖層）與場景旁以你為中心的小地圖（從大地圖截一塊，畫法與視野同大地圖，視窗外兩站以內的摸清地點在邊緣標方向）。全圖開放時已開放的地點都畫全彩、都寫名字，圖例的狀態那一句只剩「紅旗：所在地」（`LEGEND_STATES_OPEN`）、打擊記號那一句不寫「還沒摸清時標在大區」（`LEGEND_STRIKE_OPEN`）。小地圖的名字壓到別的地點圓盤的地方只准變少（`tests/test_real_content.py::MINI_DISC_OVERLAPS_OPEN`，上限 1 處；輿圖重製第 1 批〔新天下〕之後量到 0 處）。局勢層照控制方給地點的圓盤上色（地盤易手，`CONTROL_DISC`，圖例多一句 `LEGEND_CONTROL`）；地點包在 `<g data-loc>` 裡給網頁認點擊。圖例不畫進 SVG：`legend_data()` 把圖例當資料（六個圖示的小 SVG 與幾行說明，字全在 `LEGEND_*` 常數）交給網頁，網頁在地圖框左下角疊一層半透明、可收合、不跟著平移縮放的圖例（`web/app.js` 的 `legendHtml`，收合記在這個瀏覽器的 localStorage）；小地圖沒有圖例；路線層的分鐘數乘 `mounts.pace`（騎著馬時跟詳情欄、選單寫的步行時間對得上，圖例照舊寫「步行要幾分鐘」）。
- `tianxia/mapdata.py`：輿圖的資料（`/api/map/base`、`/api/map/state`）。底圖（`base`，伺服器照開放的地點 `base_key` 全服快取）多一份 `world`＝天下圖要的（輿圖重製第 2 批，`world()`）：取景框 `frame`（開放的地點外框加 `WORLD_MARGIN`）、州（`regions`：輪廓、圈 `ring`、州名可以擺的幾處 `spots`）、地面格（`cells`：每一州只拿自己州裡的**區塊**分地面〔`ground_places`：劇本寫了 `territory.blocks` 就只拿區塊，鄉里結社、草廬、南華觀這類不是區塊的不分地面；沒寫區塊的劇本拿全部開放的地點〕）、相鄰的邊（`edges`：`clip` 是州 id＝同一州裡兩格的邊、要用那一州的輪廓裁，None＝兩州相接的那一段，兩邊各是哪一格）、劇本的每一方（`sides`＝`side_inks`：`FactionDef.ink` 的顏色、地面色、大區色、一個字、輿圖上的名字；沒寫照 `FALLBACK_INKS`）、沒人佔的顏色（`MapLayout.unheld`）、「璽」標在哪一州（碎片開著〔`seal.on`〕時劇本 `ring: core` 的那一州）。幾何只看內容與開放的地點，照內容雜湊另外快取（`_WORLD_CACHE`）。疊層（`state`）每個地點多 `rich`（高級資源地＝開季中立的區塊，`conquest.start_kind`；領地爭奪關著的季照內容的區塊表），繩多 `low`／`high`（`territory.sides`，網頁不寫死官軍、黃巾），另有 `geju_side`。
- `tianxia/worldgeo.py`：天下圖的純幾何（輿圖重製第 2 批）：每個種子在整張地圖方框裡的凸格（`cells`，半平面交；邊帶「跟哪一個種子共用」）、同一組種子兩兩共用的邊（`inner_edges`）、兩州共線重疊的那一段（`shared_borders`，沿地圖外緣的零面積折返不算）、跨州的邊照兩邊的凸格切開（`cross_edges`）、州名擺哪（`label_spots`：〔州 ∩ 取景框〕裡離邊與地點都遠的幾處，左右的距離打折、彼此隔開）、取景框（`frame`）、SVG 的 d（`path`）。州是凹的：格子一律算成凸的、畫的時候用州的輪廓裁（網頁的 clipPath），不做多邊形布林運算。不 import 內容與狀態。
- `tianxia/mapart.py`：輿圖的畫法零件（設色山水）：配色、座標寫法、路的二次曲線、河與山脊的平滑線、大區削角、照標籤的地點圖示、紅旗、外框與指北針，以及地形（山頭與樹讓開地點、路與河；只跟內容有關，每份內容算一次快取）。只 import `models`、不看視野；mapview 只管組合、視野狀態與名字避讓。

## 介面（`web/`）

- 伺服器只給資料、畫面自己做：沒有建置步驟的原生 JavaScript（`web/app.js` 一個檔）。底部五個分頁 **江湖／修練／煉製／輿圖／見聞**（見聞＝戰報、大勢、傳聞、江湖史〔最上面是七格玉璽，底下接神器譜，神器與名將的本命兵器都在這一本〕、紀錄、行狀、榜單〔六張榜的籤兩排三個，一次看一張，`boardsHtml`〕），設定與管理者工具收在右上角齒輪。頂上狀態列（體力、氣血兩條＋銀兩、心得；兩條上的「體力」「氣血」兩個字包成 `.lbl`，數字放得下就寫全、放不下才讓開〔FB-135、FB-198：`fitBars` 每次畫狀態列、視窗換寬度、字型載入完量一次，條上那一行字的字尾碰到丹的鈕或「傷 N」先 `.snug` 字小一號、兩個字照寫，還碰到才 `.tight` 拿掉兩個字；`topHtml` 從不帶這兩個 class〕；點名號展開：名號獨佔一行、頭銜第二行〔一段一個 `.who-seg`，不能叫 `seg`〕、屬性、「可配 N 點」與五顆＋鈕、隊伍）。
- 登入狀態是 cookie（`tx_session`），伺服器記憶體裡對應帳號；**重開伺服器要重新登入**。前端每 10 秒打 `/api/main`，分頁在背景時不打、上一次還沒回來不打、內容沒變不重畫。手指按在畫面上時輪詢不重畫江湖頁，放開才補（不然按下去的那一顆被換掉、click 落空）。
- **送出指令的回饋**（Joy 2026-10-12，`web/app.js` 的「送出指令的回饋」那一段）：走 `busy()` 的動作一律一樣——按下去那一顆標 `.sending`（掃光、不能再按），1.5 秒沒回來畫面底下浮一行等候的話（照行動換句，`WAIT_LINES`／`waitLineFor`：探索「四下探看，尚無動靜……」、開爐「爐火正旺，靜待出爐……」，其他「墨跡未乾，江湖尚未回音……」；Joy 要符合世界觀的句子，字是 PM 給的）、12 秒改寫「路遠消息遲，再等片刻……」；上一個還沒回來時再按別的，浮「前一道號令尚未回音」（以前一聲不響地丟掉）。動作（POST）最多等 90 秒（`ACTION_TIMEOUT_MS`），逾時與沒送出去都說「鴻雁折返，訊息未達——再試一次」，逾時另重抓一次畫面，按鈕還原。測試切 busy 一律用 webharness 的 `busyKit()`。
- **登入頁的宣傳影片**（企劃者 2026-10-12「我要在我們登入頁面加這個主要宣傳影片」；`promoHtml`／`promoSound`）：登入、註冊頁最上面貼齊頂端與兩側的主視覺 `web/promo.mp4`（原檔 3.3MB 壓成約 1MB 的 h264＋aac，原檔不進 repo），靜音、自動播放、循環、playsinline，首格 `web/promo-poster.jpg` 在影片載入前先顯示，右下角「開聲音／關聲音」；偏好減少動態效果的人只看首格。登入、註冊切換時 `renderGate` 把同一支影片搬回去（不從頭播、聲音不被關）。建角色畫面與登入後都沒有。測試用的 Chromium 沒有 h264，截圖時要換成 webm。
