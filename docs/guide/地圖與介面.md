## 模組

**地圖**
- `tianxia/atlas.py`：大地圖的資料（純資料與文字）：摸不摸清只由 `location_view` 判斷——全圖開放（`Config.open_map`，企劃者 2026-10-15，預設開、測試內容關著）時已開放的地點全部算摸清（名字、敵情、勝算、詳情都看得到，都能直接安排前往，路線照全部已開放的地點算最短的），沒有視野這件事；劇情還沒開放的地點（`unlock_flag` 沒立起來、序章專屬）照舊完全不畫、不能去。開關關著是舊規則（視野 `vision_base` 兩站、名望 `vision_fame` 多看一站、去過、留意地形與召見摸清的路才算摸清，沒摸清的只畫輪廓與「？」）。大區歸屬（地點座標落在哪個大區多邊形，區外歸最近的大區）、最省體力的路線與三種走法的時間與體力（騎著馬：本來就收 state 的 `route_stamina`／`route_text`／`travel_options`／`detail_text` 自己照 `mounts` 算；純函式 `travel_seconds`／`mode_when`／`arrival_times` 的 `pace`、`travel_stamina` 的 `saving`、`mode_text` 兩個都是**必填**的關鍵字參數；體力兩段進位 `foot_stamina` → `ride_stamina`〔.5 進位、不用 round〕，`route_foot_stamina` 給結伴同行各付各的；`road_spot` 讀 `Journey.pace`）、四個圖層要標的東西（含局勢層的打擊記號 `strike_marks`）、地點詳情與「安排前往」的條件；勝算只在敵情層與詳情欄才算。
- `tianxia/mapview.py`：把 atlas 的資料畫成 SVG：大地圖（江湖輿圖，四個圖層）與場景旁以你為中心的小地圖（從大地圖截一塊，畫法與視野同大地圖，視窗外兩站以內的摸清地點在邊緣標方向）。全圖開放時已開放的地點都畫全彩、都寫名字，圖例的狀態那一句只剩「紅旗：所在地」（`LEGEND_STATES_OPEN`）、打擊記號那一句不寫「還沒摸清時標在大區」（`LEGEND_STRIKE_OPEN`）。小地圖的名字壓到別的地點圓盤的地方只准變少（`tests/test_real_content.py::MINI_DISC_OVERLAPS_OPEN`，現在 1 處：洛陽官道看出去，嵩山腳貼著視窗右緣、壓到嵩山深處圓盤的一角）。局勢層照控制方給地點的圓盤上色（地盤易手，`CONTROL_DISC`，圖例多一句 `LEGEND_CONTROL`）；地點包在 `<g data-loc>` 裡給網頁認點擊。圖例不畫進 SVG：`legend_data()` 把圖例當資料（六個圖示的小 SVG 與幾行說明，字全在 `LEGEND_*` 常數）交給網頁，網頁在地圖框左下角疊一層半透明、可收合、不跟著平移縮放的圖例（`web/app.js` 的 `legendHtml`，收合記在這個瀏覽器的 localStorage）；小地圖沒有圖例；路線層的分鐘數乘 `mounts.pace`（騎著馬時跟詳情欄、選單寫的步行時間對得上，圖例照舊寫「步行要幾分鐘」）。
- `tianxia/mapart.py`：輿圖的畫法零件（設色山水）：配色、座標寫法、路的二次曲線、河與山脊的平滑線、大區削角、照標籤的地點圖示、紅旗、外框與指北針，以及地形（山頭與樹讓開地點、路與河；只跟內容有關，每份內容算一次快取）。只 import `models`、不看視野；mapview 只管組合、視野狀態與名字避讓。
