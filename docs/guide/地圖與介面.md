## 模組

**地圖**
- `tianxia/atlas.py`：大地圖的資料（純資料與文字）：摸不摸清只由 `location_view` 判斷——全圖開放（企劃者 2026-10-15）：已開放的地點全部算摸清（名字、敵情、勝算、詳情都看得到，都能直接安排前往，路線照全部已開放的地點算最短的），沒有視野這件事；劇情還沒開放的地點（`unlock_flag` 沒立起來、序章專屬）照舊完全不畫、不能去。舊的摸清規則（視野、名望多看一站、留意地形、召見摸清路、出師那一步的 `survey` 清單，沒摸清的畫輪廓與「？」）2026-10-27 連開關一起拿掉（企劃者選「拿掉舊玩法和它的測試」）。大區歸屬（地點座標落在哪個大區多邊形，區外歸最近的大區）、最省體力的路線與三種走法的時間與體力（騎著馬：本來就收 state 的 `route_stamina`／`route_text`／`travel_options`／`detail_text` 自己照 `mounts` 算；純函式 `travel_seconds`／`mode_when`／`arrival_times` 的 `pace`、`travel_stamina` 的 `saving`、`mode_text` 兩個都是**必填**的關鍵字參數；體力兩段進位 `foot_stamina` → `ride_stamina`〔.5 進位、不用 round〕，`route_foot_stamina` 給結伴同行各付各的；`road_spot` 讀 `Journey.pace`）、四個圖層要標的東西（含局勢層的打擊記號 `strike_marks`）、地點詳情與「安排前往」的條件；勝算只在敵情層與詳情欄才算。
- `tianxia/mapview.py`：把 atlas 的資料畫成 SVG：大地圖（江湖輿圖，四個圖層）與場景旁以你為中心的小地圖（從大地圖截一塊，畫法同大地圖，視窗外兩站以內的已開放地點在邊緣標方向）。已開放的地點都畫全彩、都寫名字，圖例的狀態那一句只有「紅旗：所在地」（`LEGEND_STATES`）、打擊記號那一句不寫「還沒摸清時標在大區」（`LEGEND_STRIKE`）。小地圖的名字壓到別的地點圓盤的地方只准變少（`tests/season/test_real_content.py::MINI_DISC_OVERLAPS_OPEN`，現在 1 處：洛陽官道看出去，嵩山腳貼著視窗右緣、壓到嵩山深處圓盤的一角）。局勢層照控制方給地點的圓盤上色（地盤易手，`CONTROL_DISC`，圖例多一句 `LEGEND_CONTROL`）；地點包在 `<g data-loc>` 裡給網頁認點擊。輿圖的底圖（`render_base`）把路包成一組 `<g class="tx-roads">`（不烤進點陣；區圖照 CSS 換成一種淡實線，輿圖第三版第 4 批）。圖例不畫進 SVG：`legend_data()` 把圖例當資料（六個圖示的小 SVG 與幾行說明，字全在 `LEGEND_*` 常數）交給網頁，網頁在地圖框左下角疊一層半透明、可收合、不跟著平移縮放的圖例（`web/app.js` 的 `legendHtml`，收合記在這個瀏覽器的 localStorage）；小地圖沒有圖例；路線層的分鐘數乘 `mounts.pace`（騎著馬時跟詳情欄、選單寫的步行時間對得上，圖例照舊寫「步行要幾分鐘」）。
- `tianxia/mapdata.py`：輿圖的資料（`/api/map/base`、`/api/map/state`）。底圖（`base`，伺服器照開放的地點 `base_key` 全服快取）多一份 `world`＝天下圖要的（輿圖第三版第 3 批，`world()`；環形版 `dev/map-2` 的畫法搬回真實地形）：取景框 `frame`（開放的地點外框加 `WORLD_MARGIN`）、大區（`regions`：輪廓 `d`、面積 `area`、大區名可以擺的幾處 `spots`；沒有「圈」）、地面格（`cells`：每一個大區只拿自己大區裡的**區塊**分地面〔`ground_places`：劇本寫了 `territory.blocks` 就只拿區塊，鄉里結社、曹氏莊院、豪族塢堡、草廬、南華觀這類不是區塊的不分地面；沒寫區塊的劇本拿全部開放的地點〕；地點落在大區輪廓外〔官軍大營〕照樣是那一區的一格）、相鄰的邊（`edges`：`clip` 是大區 id＝同一區裡兩格的邊、要用那一區的輪廓裁；None＝兩個大區相接的那一段——真實地形的五個大區互不相接，沒有這種邊）、劇本的每一方（`sides`＝`side_inks`：`FactionDef.ink` 的顏色、地面色、大區色、一個字、輿圖上的名字；沒寫照 `FALLBACK_INKS`）、沒人佔的顏色（`MapLayout.unheld`）。幾何只看內容與開放的地點，照內容雜湊另外快取（`_WORLD_CACHE`）。疊層（`state`）每個地點多 `rich`（高級資源地＝開季中立的區塊，`conquest.start_kind`；領地爭奪關著的季照內容的區塊表），繩多 `low`／`high`（`territory.sides`，網頁不寫死官軍、黃巾），另有 `geju_side`。「正在翻」「激戰」「冷卻」：領地爭奪開著時每一塊區塊多三個鍵（`flip_marks`，第 3 批收尾）——不另寫判斷，照翻地那一份畫面資料 `conquest.block_view`（`main_view["conquest"]["blocks"]` 同一個函式、同一個四捨五入）換名字：`tug`＝`bars`（`{攻方: 進度 0～100}`，只列寫出來不是 0 的；沒有是 None）、`melee`＝`clash`、`cool`＝`cooling`（剛易手還要幾分鐘；沒在冷卻是 None）。領地爭奪關著的季、不是區塊的地點沒有這三個鍵，網頁就不畫（`tests/core/test_world_map.py` 守：三種季疊層沒有這三個鍵、每一塊跟 `conquest_view` 一樣）。疊層每一處另有 `yield`（卡上「今日產出」那一句，`yield_line`：站在那裡的隊伍〔`territory.squads_at`〕打贏有機會掉的最高那一階，照 `materials.possible_drops`〔跟真的擲骰讀同一份表、不擲骰〕；寫了掉落表的寫素材名、照預設表的寫幾品素材；剛易手的中立地照 `conquest.drop_cap` 只算一階；沒有是空字串；輿圖第三版第 4 批）。版圖變化每一週的 `changed` 與每一處的 `flips` 把沒人佔↔有人佔也算（`from`／`to` 是 None；FB-632：開季中立的地第一次被佔下），網頁寫「中立 → 官軍」（`NEUTRAL_WORD`）。
- `tianxia/worldgeo.py`：天下圖的純幾何（環形版 `dev/map-2` 寫的，輿圖第三版第 3 批搬過來；程式裡的「州」就是劇本的大區）：每個種子在整張地圖方框裡的凸格（`cells`，半平面交；邊帶「跟哪一個種子共用」）、同一組種子兩兩共用的邊（`inner_edges`）、兩州共線重疊的那一段（`shared_borders`，沿地圖外緣的零面積折返不算）、跨州的邊照兩邊的凸格切開（`cross_edges`）、州名擺哪（`label_spots`：〔州 ∩ 取景框〕裡離邊與地點都遠的幾處，左右的距離打折、彼此隔開）、面積（`area`）、取景框（`frame`）、SVG 的 d（`path`）。州是凹的：格子一律算成凸的、畫的時候用州的輪廓裁（網頁的 clipPath），不做多邊形布林運算。不 import 內容與狀態。
- `tianxia/weekcard.py`（減法季批 1，整合設計 6.1、3.4）：江湖頁最上面的本週卡（`week_card`：第 N 週／段、兩軍態勢、`Scenario.week_themes` 照季長切前中後三段的主題一句、「你這一步」的候選照託付→軍令→懸賞→伏筆〔`foreshadow.next_step`〕→新手目標→去投靠排）與三方卡（`sides_card`：官軍、黃巾各一欄，減法季四個勝利條件開著才多地方豪強；規則關著、有割據線的季照舊三方）。只讀、只組字；`server.main_view` 送成 `week_card`、`sides_card`，事件選項的樣子另走 `Game.event_option_view`（`event_opts`：動作、圖示的屬性鍵、沒把握才有的心裡話；選單標籤不改，假人照舊讀它）。序章裡、休季兩張卡都不送。
- `tianxia/mapart.py`：輿圖的畫法零件（設色山水）：配色、座標寫法、路的二次曲線（官道雙線的芯是 `class="rd-core"`，區圖藏起來）、河與山脊的平滑線、大區削角、照標籤的地點圖示、紅旗、外框與指北針，以及地形（山頭與樹讓開地點、路與河；只跟內容有關，每份內容算一次快取）。只 import `models`、不看視野；mapview 只管組合、視野狀態與名字避讓。
