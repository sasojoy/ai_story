# 店面寬度上線：電腦上店面照遊戲那一欄（給 joy，2026-10-14）

- 對象：joy（部署測試版的人）。PM 轉交。
- 這一版：GitHub 最新的 main。店面寬度的合併 commit 是 `eee47b8f`（接在丁批 `e53a4639` 後面）。
- 比較的基準：分支 `fb-shop-width` 從 main `6ac202b8` 開，修正一個 commit：FB-225 `52ac3696`。
- 部署完請回報部署的 commit（`git log -1` 那一串）。

## 一、這一版改了什麼

- **FB-225 店面在桌機上跑版，寬度沒照遊戲的版面框架**：企劃者在桌機（約 2000px 寬）打開鐵匠鋪的打造頁，整個店面蓋滿螢幕，主料、輔料兩格各拉成半個螢幕寬，素材格四欄拉滿，字顯得很小，掌櫃那一句擠在左上角；企劃者：「最主要是寬度的設計沒有照著 UI 框架延續」。PM 定只修寬度與版面框架，店面的暗色爐火配色不動。
  - 遊戲本體在電腦上是一欄 640px（`.shell`、底部分頁列 `.tabs-inner`）。現在店面也照這一欄：圖層照舊蓋滿畫面（擋住底下的頁面），可是店的底色（鐵匠鋪的爐火、馬市的土黃、懸賞榜的木紋）只畫在中間 640px，欄外是遊戲本來的頁面底色（`--paper`）。從江湖頁進店、出店，欄的左右邊不跳，欄外也不變色。
  - 欄裡的東西照欄排：招牌那一列、店內分頁（架上、打造、淬煉與修、裝備庫）貼齊欄邊；掌櫃話照手機往裡縮 14px；出爐的麻布、出爐卡（含神器定名表單）連同後面那一層暗幕都在欄裡、在欄的正中間；懸賞榜放大的那張紙貼在欄的下緣、左右各縮 12px。
  - 捲的那一層（`.shop-body`）照舊整片寬：滑鼠在欄外滾輪也捲得動，捲軸在畫面最右邊（跟遊戲本體一樣）；兩邊各留一條捲軸寬的溝（`scrollbar-gutter: stable both-edges`），內容才正好在中間、跟 `.shell` 對齊，換到不必捲的那一頁也不左右跳。捲的內容包在新的 `.shop-col` 裡（`max-width: 616px` 置中，等於欄寬減手機上左右各 12px）：馬廄那一排、素材格、貨卡、裝備庫的每一列都在欄裡。
  - 同一個問題順便掃了別的全畫面圖層（1280、1920 寬）：**武學譜、鑄譜那本書**（`.book-layer`；店裡的鑄譜鈕也開它）返回列與封面原本拉滿整個螢幕（題簽在畫面最右邊、月亮在最左邊），**遊戲裡讀傳那一層**（`.zhuan-layer`）的返回列與篇名那一塊也拉滿；兩個照同一套改，書頁與漆木底只畫在欄裡。讀傳那一段只掛在 `.zhuan-layer` 底下，公開頁（`/zhuan/<代碼>`，`zhuan_html.py`）一個字都沒動。設定抽屜、確認框（`.ask`）、玩家卡原本就是 640 置中、跟欄對齊，沒動。
- **手機一個像素都不變**：新的規則全部在 `@media (min-width: 641px)` 裡（欄寬 640 加一）；`.shop-col` 在手機上沒有任何樣式。

## 二、部署要注意的

1. **先備份資料庫**（照慣例）。資料庫維持第 5 版，不升版；存檔、內容 JSON、`content/config.json`、規則程式都沒動，只動網頁檔與文件。
2. **`server.py` 要重開**：網頁檔（`web/app.js`、`web/style.css`、`web/zhuan.css`）的版本號在 `server.py` 啟動時算，重開之後手機與電腦才會換新的。`run_bots.py` 沒動，照慣例一起重開也可以（同一個資料庫、同一份設定；週末的季兩個都帶 `TIANXIA_PROFILE=weekend`）。

## 三、改到你們程式的地方

- `web/style.css`：懸賞榜那一段後面新的一段「電腦上的店面與武學譜那本書（FB-225）」，整段包在 `@media (min-width: 641px)`：三間店的底色照欄寬畫（`background-size: min(100%, 640px) 100%`、置中、不重複、`background-color: var(--paper)`）；`.shop-layer > .shop-bar`、`> .shop-tabs` 的左右外距、`> .shop-line` 的左右外距、`> .reveal-layer` 的 `left`／`right`、`.shop-board .board-sheet` 的 `left`／`right` 都照 `50% − 320px` 算；`.shop-layer > .shop-body` 加 `scrollbar-gutter: stable both-edges`；`.shop-layer .shop-col { max-width: 616px; margin: 0 auto; }`；`.book-layer` 的底色照欄寬畫、加捲軸溝，`.book-bar`、`.book-cover` 的左右外距。
- `web/zhuan.css`：遊戲裡那一段後面同一套，只掛 `.zhuan-layer`、`.zhuan-layer > .zh-bar`、`.zhuan-layer > .zh-head`。
- `web/app.js`：`smithHtml`、`marketHtml`、`boardHtml` 的 `.shop-body` 裡面多包一層 `<div class="shop-col">`。**之後店裡新加的頁（或第四間店）也要包這一層**，不然電腦上會拉滿。
- 新的測試 `tests/test_shop_width.py`：CSS 照原字查（欄寬照 `.shell` 與 `.tabs-inner` 的 `max-width` 算，兩個要一樣；這一段每一條都只掛在店面、書、讀傳底下）；三間店的畫面 `.shop-body` 裡第一層是 `.shop-col`。
