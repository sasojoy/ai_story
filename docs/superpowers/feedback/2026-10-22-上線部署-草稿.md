1. **季中可以換**（跟上一次不同）：這一版不改資料庫結構（還是第 6 版）、不改季曆。預演把舊程式季中的存檔（集結中、開打中、打完之後三種）換給新程式：伺服器與假人程式都不印 ⚠、沒有錯誤；每個人的季曆時刻、下一件大事、決戰時刻表、銀兩、元寶、等級、江湖紀錄都跟舊程式一字不差；打到一半的決戰照樣打完、發戰報。休季換也可以。

## 步驟

指令都在線上主機的 PowerShell 打。程式資料夾是 `C:\Users\User\Documents\ai_story-tianxia`，資料庫是 `saves\tianxia.db`。**這個視窗不要設 `TIANXIA_DB`**（`echo $env:TIANXIA_DB` 要是空的）。

0. **先看一眼看守的設定**（只看不改）：`C:\Users\User\tianxia-ops\start_server.cmd` 與 `start_bots.cmd` 都要是 `TIANXIA_PROFILE=week7`，資料庫指同一份。不是的話先停下來問 PM。

1. **暫停看守、停伺服器與假人**（監控頁與隧道不用停）：

   ```powershell
   New-Item C:\Users\User\tianxia-ops\PAUSED -ItemType File
   Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object CommandLine -match 'server\.py|run_bots\.py' | ForEach-Object { taskkill /PID $_.ProcessId /T /F }
   ```

   停完再跑一次第二行的前半段（拿掉 `| ForEach-Object …`），確認沒有東西了。

2. **手動備份**：

   ```powershell
   cd C:\Users\User\Documents\ai_story-tianxia
   .venv\Scripts\python.exe scripts\backup_db.py --dest <你平常放手動備份的資料夾>
   ```

   要印「已備份：…（結構第 6 版、帳號 N、角色 N、季 N、江湖史 N）」。檔名與數字記下來，旁邊寫「1022 上線前」。

3. **換程式**：

   ```powershell
   git status
   git log -1 --oneline
   git fetch origin
   git checkout main
   git pull --ff-only origin main
   git log -1 --oneline
   ```

   - `git status` 只能看到 `saves\` 這類沒進版控的東西；有改過的程式檔就先不要換，跟 PM 說。
   - 第一個 `git log -1` 是**上線前的 commit**，記下來。最後一個要印 `3e69e094` 或更新的。

4. **開服務**：

   ```powershell
   Remove-Item C:\Users\User\tianxia-ops\PAUSED
   Start-ScheduledTask -TaskName tianxia-watchdog
   ```

   等一兩分鐘，看伺服器與假人的 log（`start_*.cmd` 導出去的 `*_out.log`、`*_err.log`）：
   - 兩邊都印「資料庫：…saves\tianxia.db」與「設定：week7（第一季濃縮版規則開啟、季長 7 天、人數上限 20）」，而且一樣。
   - **不能有 `⚠` 開頭的那一行**（預演季中、休季、籌備中都沒有印）。
   - `*_err.log` 不能有 `內容檔有誤`、`資料庫結構是第`、`Traceback`。

5. **自己登入看一眼**：
   - 「輿圖」分頁一打開是天下圖（幽州、冀州、洛陽、潁川汝南、南陽五個大區），點一個大區會進那一區的區圖。
   - 季曆、下一件大事跟換之前一樣（季中換的話）。
   - 休季中換的，照平常「⚠ 開啟下一季」就好（預演開過，正常）。

## 出事怎麼回去

**換回舊程式**（資料庫結構沒改，舊程式讀得了新程式寫的存檔）：

1. 照第 1 步建 `PAUSED`、停伺服器與假人。
2. **先跑這一行**（有沒有人用過碎片獨門行動都跑；沒有的話印 `removed 0`，什麼都不動；跑兩次也沒關係）：

   ```powershell
   .venv\Scripts\python.exe -c "import sqlite3,json;c=sqlite3.connect(r'saves\tianxia.db');d=json.loads(c.execute('select data from world where id=1').fetchone()[0]);h=d['seal']['history'];d['seal']['history']=[e for e in h if e.get('kind')!='use'];c.execute('update world set data=? where id=1',(json.dumps(d,ensure_ascii=False),));c.commit();print('removed',len(h)-len(d['seal']['history']))"
   ```

   它只拿掉全服碎片紀錄裡「起用獨門行動」那幾筆（舊程式不認得這一種，不拿掉的話舊程式一開就停，`*_err.log` 會有 `seal.history … input_value='use'`）。
3. `git checkout --detach <第 3 步記下的上線前 commit>`。
4. 刪 `PAUSED`、`Start-ScheduledTask -TaskName tianxia-watchdog`，照第 4 步看 log。

換回去的代價（預演實測）：資料、元寶、等級、季曆都在；碎片行動用過幾次、正在生效的行動會不見（之後再換回新程式，每片又是一季 2 次）；被「引將」引走的大勢人物會留在被引去的地方，舊程式不會送他回去（要不要管理者處理，問 PM）。

**或還原備份**：照主機端操作文件「怎麼還原」，用第 2 步的備份。回到換之前那一刻，之後的進度都沒有。

**季中換了才發現時刻表或季曆不對**：先「⏸ 暫停賽季時鐘」，再找 PM（預演沒有遇到）。

  - 引將（玄紐）：挑一位大勢人物，引到你所在之地坐鎮一日；頒詔（雲篆）：一日之內人人靜心感悟、衝絕學的機會變高；承露（承露）：你所在的大區一日之內體力回得快、醫館療傷不收錢；傳檄（赤璋）：一條戰線一日之內那一軍推得多；收心（歸心）：一位人物一日之內情誼漲得快、求見不看門檻。
