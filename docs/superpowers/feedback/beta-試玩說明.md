# 《天下大勢》第一次 beta 試玩說明

給一起來玩的朋友。這是很早期的版本，會有不順、會有錯，你們的回報就是這次 beta 最重要的東西。

## 怎麼進來

1. 打開企劃者給你的網址（`https://….trycloudflare.com`），手機、電腦都可以。網址不要外流：有網址的人都進得來。
2. 選「註冊」，設定帳號和密碼：
   - 帳號：英文字母、數字、底線，3～20 字。
   - 密碼：至少 6 字。
3. 取一個名號，這就是你在江湖上的名字：
   - 最多 16 字。
   - 不能跟別人重複，也不能用三國名人的名字（例如曹操、張角）。
4. 一個帳號只有一個角色。重新整理頁面不用重新登入。

### 網址打不開時

伺服器開在企劃者的電腦上，所以：

- **伺服器每次重開，網址都會換。** 打不開時，先問企劃者有沒有新網址。
- 用新網址進來後要**重新登入一次**。帳號、角色和進度都還在，不用重新註冊。
- 企劃者的電腦關機或斷網時，大家都連不上，等一下再試。

## 這一季在玩什麼

- 第一季是「黃巾之亂」。每個人一開始都是散人，可以到各陣營的投靠點投靠官軍、黃巾或地方豪強，也可以一直當散人。
- 畫面下方有五個分頁：
  - **江湖**：主要的地方，探索、交遊、歷練、移動都在這裡。
  - **修練**：練功、療傷、閉關，也可以換上別的功法。
  - **煉製**：把撿到的素材兩兩放進爐裡，煉出新功法。全服第一個煉出某個配方的人，替大家取了那門功法的名字。
  - **輿圖**：大地圖，可以選步行、趕路或疾行前往遠方。
  - **見聞**：戰報、大勢、傳聞、江湖史和你的紀錄。
- 體力會隨時間慢慢回來。累了就在江湖頁按「打坐」，回得比較快。
- 黃巾聲勢夠高時會開打全服決戰，人要在戰場那一帶才能加入。

## 先知道：一季可能一兩天就結束

**這是已知的，而且這次刻意不調。**

- 目前的數值下，黃巾在自家地盤操練幾乎沒有風險。模擬時，4 季裡有 3 季不到一天半，黃巾就稱霸、整季結束。
- 一季結束後，畫面會停在「休季中」，等企劃者在 ⚙（齒輪）的管理者區按「開啟下一季」。等一下就會開新的一季。
- 換季時，帳號、江湖史、跟同伴的交情都會留著；屬性、銀兩、武學、陣營等等會重新開始。

## 請你回報什麼

回報請直接貼在 **Discord 或 LINE 群組**（企劃者拉你進的那一個），截圖也丟那裡，企劃者會看。

**最重要的：一季多快結束、結束的當下你在做什麼。** 這是這次 beta 最想收的資料，請盡量寫：

- 這一季從開始到結束大概多久（現實時間，或遊戲裡顯示的第幾天幾點）。
- 結束那一刻你在做什麼：在哪裡、正準備做什麼，有沒有覺得「怎麼突然就結束了」。
- 你投靠了哪一邊，這一季大部分時間在做什麼（歷練、操練、煉製、交遊、趕路……）。

其他任何覺得不對、卡住、看不懂、不好玩的地方也都歡迎回報。每一則最好寫出這四件事：

1. **在哪裡**：哪個分頁、哪個地點。
2. **做了什麼**：按了哪個按鈕、打了什麼字。
3. **看到什麼**：畫面上出現什麼。能截圖最好。
4. **你原本以為會怎樣**。

想到什麼就說，不用整理好，也不用確定是不是錯誤。
