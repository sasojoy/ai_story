## 一、玩家會看到什麼

- **輿圖整頁都是地圖**：夾在狀態列與底部分頁列之間，上面一條「找地點、找人物」、一排五顆濾鏡（勢力、軍令、敵情、路程、劇情；手機 375 寬一排放得下），右上角四顆鈕（我在哪、放大、縮小、⏱ 版圖），底下是抽屜（收著 230px、點了地點 240px，拖把手拉高、拉到全開）。原本的圖層分段、選地點的下拉選單、說明卡、圖例都拿掉了：濾鏡本身就是圖例（每顆前面一個色點）。
- **底圖換成精緻設色山水**：絹紋、四角壓暗、點劃線的州界、官道雙線、大區名寫在地圖上（跟著縮放）。地點是一個圓盤寫一個字（城、營、寺、渡、山、野），外圈照誰佔著上色，字與圓盤不管放多大縮多小，螢幕上一樣大。
- **勢力**：每個有控制方的地點一圈淡淡的暈色、大區照多半歸誰淡淡著色；兩頭歸不同人的路畫紅色鋸齒（前線），短的路中間一個 ⚔。濾鏡開了軍令、敵情、路程、劇情，地點名字底下掛小牌子（令／賞、勝算、幾分鐘、★主線／✦傳聞）。
- **看大局**：縮到 0.62 倍以下只剩點、大區名、三色長條與「官 N・巾 N・豪 N」；上方浮一條「天下 官 N 巾 N 豪 N」，比第一筆記到的那一週多幾處少幾處。
- **抽屜**：
  - 總覽：「今天去哪裡出陣」打得過的最多三處（軍令 +100、懸賞 +50、穩勝 30／有把握 20／五五波 10，減路上分鐘），勝算必敗的照樣列、排在後面、整列淡一點（打得過的已經有三處時留分數最高的一處，多一列），每處寫出陣是攻、守或攪局與理由；三條戰線（拔河的繩、繩上的可易手地點、比上一週往哪邊推了多少）、割據、本週大事。
  - 點一個地點：印、名字、危險度；三格（誰佔著、打得過嗎、多遠）；步行（幾分鐘）、疾行（體力）兩顆；就站在那裡時是「出陣・攻／守」「探索」，回江湖頁按。拉高看得到軍令懸賞、地盤（自家或別人的地盤價錢差幾成、這一季每一週誰佔著的一條色帶、哪一週易手）、站在這裡的隊伍與人物、醫館鐵匠鋪馬市、劇情。
  - 找地點：照大區分組、近的在前；打地名、大區名、人物名（例：打「波才」找到黃巾別部營寨）都找得到。
  - **安排前往之後留在輿圖**：抽屜第一行「往 X・還有 N 分鐘・下一站 Y」與「喊停」（就是江湖頁那一顆）；有事擋著路時寫是哪一則、給「回江湖」。路上的事照舊在江湖頁處理。
- **⏱ 版圖變化（天下怎麼變）**：右上角第四顆鈕。手機上抽屜 320 高、地圖縮到抽屜上面整張看得到（年表往下捲），抽屜裡一張曲線（三條戰線、割據、大事 📜）、三方各佔幾處、年表（一列一個可易手的地點、一格一週，白點是那一週易手），點週次或曲線換看那一週（地圖跟著照那一週上色、那一週易手的地點閃一圈、上方寫「正在看第 N 週」），▶ 播放從第 1 週放到現在，「回到現在」，✕ 收起回到原本的視圖。
- **桌機（寬 900 以上）**：地圖佔滿左邊，抽屜是右邊 360px 一欄（輿圖這一頁不受 640 欄限制）。手機 375 寬是主要的版面。
- **江湖頁的小地圖**：點到一個地點就打開輿圖、選好它、對準它；點空白照舊只是打開輿圖。
- 偏好減少動態效果的人：地點與你的那一圈不閃、抽屜不滑。

## 二、部署要注意的

1. **先備份資料庫**（照慣例）。**資料庫維持第 5 版，不升版**。新的欄位 `TerritoryState.weeks`（每一週週末的地盤）放在季的 JSON 裡、有預設值，舊存檔照讀。
2. **`server.py` 要重開**（網頁檔的版本號在啟動時算）。`run_bots.py` 沒動，照慣例一起重開也可以（同一個資料庫、同一份設定）。
3. **這一季中途上線**：每週的快照從上線之後第一次重算地盤（推動大勢、推進時間）才開始記。年表上線以前的週畫成虛線空格，曲線從有資料的那一週畫起，「天下」那一條寫「比第 N 週」（N 是第一筆記到的那一週）。下一季從第 1 週就完整。
4. 兩個新端點：`GET /api/map/base`（底圖 SVG 加地點、路、大區的清單，約 110KB；照開放的地點快取，劇情開放了新地點才換一份）、`GET /api/map/state`（疊層 JSON，週末設定一份約 16KB）。網頁一次載入只抓一次底圖，疊層在打開輿圖、輿圖開著時每 30 秒（在路上每一輪）、做了動作之後重抓。兩個都只讀、不存檔。舊的 `GET /api/map` 還在（還開著舊網頁的分頁用得到），新網頁不再叫它。

## 三、改到你們程式的地方

- `tianxia/territory.py`：`_snapshot`（`update`、`assign` 最後各叫一次，把「這一週」那一格蓋成此刻的樣子）、`week_at(world, week)`（沒記到的週照前一週補）。

- `web/style.css`：輿圖那一段換掉（`.mapx` 整頁一層、`.mdrawer`、`.map-chips`、桌機 `@media (min-width: 900px)`），拿掉 `.travel-row`、`.map-legend`、`.legend-*`、`.map-tools`。

## 五、QA 要驗的（設計第十二節）

- **手機 375×812**（淺色、深色各一次）：
  - 打開輿圖：地圖夾在狀態列與分頁列之間，頁面本身不捲；拖、捏、滾輪、右上三顆鈕照舊。
  - 點一個地點：不捲動就看得到名字、誰佔著、勝算、分鐘與「步行／疾行」；地圖不動（地點不從手指底下跑開）。點空白收回總覽。
  - 拉遠到看大局：每一區誰佔幾處、上方「天下」那一條。
  - 濾鏡一顆一顆開關：小牌子跟著出現消失。
  - 找地點：打地名、大區名、人物名；點一筆飛過去、抽屜換成那個地點。
  - 步行出發：還在輿圖、抽屜第一行寫往哪裡還有幾分鐘、地圖上的你畫在路上；喊停按得下去；抵達之後那一行消失。疾行到了之後站在新的地點。
  - 「⏱ 版圖變化」：整張地圖與年表同時看得到；點週次、點曲線、播放、回到現在、✕ 收起回到原本的視圖。
  - 江湖頁的小地圖點一個地點：打開輿圖、那個地點選好了。
- **桌機 1280×800**：地圖佔滿左邊、右欄是抽屜，抽屜內容長的時候自己捲、底部不被分頁列蓋住。
- **開關關著**（地盤、出陣，或散人）：輿圖照樣能用；沒有地盤就不畫暈色與前線、版圖變化寫「這一季沒有地盤易手」；沒有出陣（散人）就不畫「今天去哪裡出陣」。
- 疊層的 JSON 一次不到 40KB；底圖一次載入只抓一次（開發者工具的網路那一頁看 `/api/map/base` 只出現一次）。
