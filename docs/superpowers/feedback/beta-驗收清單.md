- **整體版面**：

  - 第一行：名號，後面小字「陣營・第N級」；右邊是 ⚙。
  - 第二行：「📍地點　第N天 時刻」。
  - 第三行：體力條、氣血條（有內傷時疊斜紋並寫「傷 N」）、銀兩、心得。
  - 點名號會展開名望、善惡、四項屬性與隊伍。
- **⚙ 抽屜**：
  - 一般玩家：匿名行走、略過新手引導、修改密碼、登出。
  - 管理者多一區「管理者」：開季、開啟下一季、+1／+8／+24 小時、立刻開戰、觸發、推動、重設密碼。
- **江湖頁的輪盤**（sasojoy PR #7，企劃者 2026-10-04 同意「歷練」改名「遊歷」、「交遊」改名「交友」）：
  - 閒著的時候，行動是一個輪盤：上探索、右遊歷、下打坐、左交友，中間的羅盤是移動。點一格先出說明卡，再按卡上的按鈕才做。
  - 這裡沒有交友事件、但有人物可以求見時，左邊那格變「求見」。
  - 只在此地才有的行動（投靠、求見、加入決戰…）排在輪盤下面的「此地」印章列。
  - 事件、對話、路上、決戰開打後的選單，照舊是一排按鈕。
- **煉製頁的輪盤**：上剛、右快、下柔、左慢（相剋的面對面），中間是「太極火爐」（sasojoy PR #8）：太極外面一圈火舌，左右兩格是放素材的位置，點有東西的那格拿出來；放滿兩樣火舌竄高、字變「點爐開火」，點爐身開爐，等結果時整座爐子晃動。點一格只列那種屬性的素材。四格不動，只有外圈和太極在轉。
- **結果與錯誤**：都用畫面底部跳出的提示顯示，幾秒後消失。
- **自動更新**：每 10 秒向伺服器要一次最新狀態，有變化才重畫。
- **登入狀態**：用 cookie 保持登入。重新整理頁面不用重新登入；伺服器重開後要重新登入。
