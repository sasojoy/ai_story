### 新網頁的樣子（對照用）

- **整體版面**：
  - 不分手機、電腦，都是單欄，最寬 640px 置中。
  - 狀態列黏在頂端，五個分頁固定在底部：**江湖、修練、煉製、輿圖、見聞**。
- **狀態列**：
  - 第一行：名號，後面小字「陣營・第N級」；右邊是 ⚙。
  - 第二行：「📍地點　第N天 時刻」。
  - 第三行：體力條、氣血條（有內傷時疊斜紋並寫「傷 N」）、銀兩、心得。
  - 點名號會展開名望、善惡、四項屬性與隊伍。
- **⚙ 抽屜**：
  - 一般玩家：匿名行走、略過新手引導、修改密碼、登出。
  - 管理者多一區「管理者」：開季、開啟下一季、+1／+8／+24 小時、立刻開戰、觸發、推動、重設密碼。
- **結果與錯誤**：都用畫面底部跳出的提示顯示，幾秒後消失。
- **自動更新**：每 10 秒向伺服器要一次最新狀態，有變化才重畫。
- **登入狀態**：用 cookie 保持登入。重新整理頁面不用重新登入；伺服器重開後要重新登入。

- [ ] 錯誤訊息逐一試過，文字要一字不差：

  | 帳號格式錯（3～20 字，英數與底線） | 帳號只能用英文字母、數字、底線，3～20 字。 |

  | 兩次密碼不同 | 兩次輸入的密碼不一樣。 |
  | 帳號重複（不分大小寫） | 這個帳號已有人使用。 |
  | 帳號不存在 | 帳號或密碼不對。 |
  | 密碼錯 | 帳號或密碼不對。 |
