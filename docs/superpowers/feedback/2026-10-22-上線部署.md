## 先講結論（六件事）

1. **企劃者定的做法**：線上這一季**用現在的舊程式「⚠ 立刻收季」** → 停機、**手動備份** → 換程式 → **當天「⚠ 開啟下一季」**。領地爭奪是開季那一刻蓋在季上的章：**只有換程式之後新開的季才有**；正在跑的這一季就算不收、換了程式也照舊沒有。

## 步驟

指令都在線上主機的 PowerShell 打。程式資料夾是 `C:\Users\User\Documents\ai_story-tianxia`，資料庫是 `saves\tianxia.db`。**這個視窗不要設 `TIANXIA_DB`**（`echo $env:TIANXIA_DB` 要是空的）。

0. **先看一眼看守的設定**（只看不改）：`C:\Users\User\tianxia-ops\start_server.cmd` 與 `start_bots.cmd` 都要是 `TIANXIA_PROFILE=week7`，資料庫指同一份。不是的話先停下來問 PM。

1. **用現在的舊程式立刻收季**（伺服器還開著）：管理者帳號登入 → 右上 ⚙ →「管理者工具 ↓」→「⚠ 立刻收季」→ 問句「立刻收季：這一季馬上結束、算出結局與武學榜，全服進入休季……」→「確定收季」。
   - 江湖頁會出現「══ 賽季落幕：…… ══」與善人榜、惡人榜、名人榜、宗師榜、天下武學榜，管理者工具改寫「休季中」。
   - **避開時刻表決戰正在集結或開打的時候**（week7 是那幾天的 20:00 前後）：沒打完的決戰會直接收掉、不算結果。

2. **暫停看守、停伺服器與假人**（監控頁與隧道不用停）：

   ```powershell
   New-Item C:\Users\User\tianxia-ops\PAUSED -ItemType File
   Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object CommandLine -match 'server\.py|run_bots\.py' | ForEach-Object { taskkill /PID $_.ProcessId /T /F }
   ```

   停完再跑一次第二行的前半段（拿掉 `| ForEach-Object …`），確認沒有東西了。

3. **手動備份**（舊程式還在的時候做）：

   ```powershell
   cd C:\Users\User\Documents\ai_story-tianxia
   .venv\Scripts\python.exe scripts\backup_db.py --dest <你平常放手動備份的資料夾>
   ```

   要印「已備份：…tianxia-manual-…db（結構第 6 版、帳號 N、角色 N、季 N、江湖史 N）」。檔名與數字記下來，旁邊寫「1022 上線前（已收季）」。

4. **換程式**：

   ```powershell
   git status
   git log -1 --oneline
   git fetch origin
   git checkout main
   git pull --ff-only origin main
   git log -1 --oneline
   ```

   - `git status` 只能看到 `saves\` 這類沒進版控的東西；有改過的程式檔（包括 `content\config.json`）就先不要換，跟 PM 說。
   - 第一個 `git log -1` 是**上線前的 commit**，記下來。最後一個要印 `ae6bb9ee` 或更新的。

5. **開服務**：

   ```powershell
   Remove-Item C:\Users\User\tianxia-ops\PAUSED
   Start-ScheduledTask -TaskName tianxia-watchdog
   ```

   等一兩分鐘，看伺服器與假人的 log（`start_*.cmd` 導出去的 `*_out.log`、`*_err.log`）：
   - 兩邊都印「資料庫：…saves\tianxia.db」與「設定：week7（第一季濃縮版規則開啟、季長 7 天、人數上限 20）」，而且一樣。
   - **不能有 `⚠` 開頭的那一行**（預演休季換、季中換都沒有印）。
   - `*_err.log` 不能有 `內容檔有誤`、`資料庫結構是第`、`Traceback`（`Ollama 暖機失敗` 是模型沒開，跟這一次無關）。

6. **當天開下一季**：管理者帳號登入 → ⚙ →「管理者工具 ↓」→「⚠ 開啟下一季」→「確定開啟下一季」。
   - 跟平常換季一樣：同伴重獲自由、玩家等級武學歸零、要重新投靠；碎片跟著人走。開季那一天是第 1 天。

7. **確認領地爭奪有開**（只要看到下面任一樣就是有開；舊的季、沒蓋章的季都沒有）：
   - 設定頁「管理者工具」裡、「玉璽」那一組的**上面**多一組「**領地爭奪**（救場；易手的天下大事照自然發生寫，不寫管理者）」。
   - 底部「聞」（見聞）那一排多一顆「**形勢**」。
   - 「輿圖」點進一區、點一處中立地（例：潁川汝南的荒丘、汝南荒野），卡上寫「**中立・高級資源領地，還沒有人佔**」（沒有領地爭奪的季，同一處寫「不在戰線上」）。
   - 玩法說明（⚙ → 玩法說明）「地盤」那一節第一句是「地圖分三種：官軍的領地、黃巾的領地，和中立地。……」
   - 或直接在主機上查（只讀，伺服器開著也可以）：

     ```powershell
     .venv\Scripts\python.exe -c "import sqlite3,json;c=sqlite3.connect('file:saves/tianxia.db?mode=ro',uri=True);n,d=c.execute('select number,data from seasons order by number desc limit 1').fetchone();print('season',n,'conquest_on',json.loads(d).get('conquest_on'))"
     ```

     要印「season N conquest_on True」（N 是新開的那一季）。印 `False` 就是這一季沒蓋到章（例如在換程式之前就開了季），照第 1 步再收一次、開下一季。

## 出事怎麼回去

**A. 換回舊程式**（資料庫結構沒改，舊程式讀得了新程式寫的存檔；FB-695 已修，不必先跑任何指令）：

1. 照第 2 步建 `PAUSED`、停伺服器與假人（**一定要先停**）。
2. `git checkout --detach <第 4 步記下的上線前 commit>`。
3. 刪 `PAUSED`、`Start-ScheduledTask -TaskName tianxia-watchdog`，照第 5 步看 log。

預演實測（`54802f52`、`3e69e094`、`1d12fa6c` 三種舊程式都換回去過，伺服器與假人程式都開得起來、0 錯，角色、元寶、等級、季曆都在）。換回去的代價：

- **開著領地爭奪的季**（換程式之後新開的那一季）：舊程式沒有領地爭奪，地盤照舊規則（戰線拔河）重算一次——天下大事會跳出兩三則「某地落入某某之手」，輿圖上只剩戰線上的十幾處有主，其他的變成沒人佔；正在集結的攻城戰從畫面上消失（不會打）；翻地進度、戰書、分紅帳留在存檔裡但沒人讀。
- 碎片的獨門行動：起用過的次數與正在生效的那一筆不見（再換回新程式時每片又是一季 2 次）；被「引將」引走的大勢人物留在被引去的地方。
- **退回去之後這一季別再換回新程式**（FB-706）：預演在退回 3 分鐘後再換回來，38 塊地有 23 塊變成沒人佔（連官軍、黃巾的城都是），正在集結的攻城戰變成攻自己的地。要再上新程式，就先「⚠ 立刻收季」→（換程式）→「⚠ 開啟下一季」，或還原第 3 步的備份。

**B. 還原備份**：照主機端操作文件「怎麼還原」，用第 3 步的備份（先停機，`.venv\Scripts\python.exe scripts\restore_db.py <備份檔>`）。回到「舊程式剛收完季、休季中」那一刻，之後新開的季與進度都沒有。程式要不要一起換回去照 A 的第 2 步：換回舊程式再開下一季，就是沒有領地爭奪的季；不換程式、用新程式再開下一季，就是重開一次有領地爭奪的季。

**C. 只把領地爭奪關掉（緊急開關，程式不退）**：

1. 停伺服器與假人（第 2 步）。
2. 改 `content\config.json`：把 `"conquest": {"enabled": true}` 改成 `"conquest": {"enabled": false}`（只改這一個字）。
3. 開服務（第 5 步）。兩個程式都要重開才讀得到。

關掉之後（預演實測，同計畫 `2026-10-22-打開領地爭奪.md` 第六節 6.7）：蓋了章的季當場照「沒有領地爭奪」走，地盤照戰線拔河重算一次（天下大事兩三則「落入」）、設定頁的「領地爭奪」一組與見聞的「形勢」消失、出陣照舊規則；伺服器與假人都沒有錯。**同一季不要再打開**（同 A 的最後一條）；要恢復就等收季、開下一季（開下一季之前先把這一行改回 `true`，不然下一季也沒有）。下次換程式之前先 `git checkout -- content\config.json` 把改的這一行還原，不然 `git pull` 會卡住。只在真的出事時用。

**季中換了才發現時刻表或季曆不對**：先「⏸ 暫停賽季時鐘」，再找 PM（預演沒有遇到）。

## 玩家看得到的變化

### 開了新季之後，玩家第一次會碰到的（領地爭奪；預演實機看過）

- **地圖分三種**：官軍的領地、黃巾的領地、中立地。中立地 9 塊（荒丘、汝南荒野、南陽官道、南陽郊野、淯水河畔、綠林山寨、白馬津、下曲陽、拒馬河畔）開季沒人佔，站著比較強的對手（例：汝南荒野的潰營悍卒），掉的東西也好；剛開季的新角色在那裡按出陣會寫「必敗」，要先練起來。
- **出陣推地**：投靠之後，在別人的地方、中立地按「出陣・攻」，在自家的地方是「出陣・守」（行動列底下那一行寫「這裡還沒有人佔：打一場，打贏推這一塊的進度、記貢獻……」）。打贏一場，戰報結果寫「你在汝南荒野替官軍推進了 2，進度 2／100。」；打輸不推。守勢行動（巡哨、傳道、保境安民）只在自家的地方按得下去，別處灰著寫原因。
- **翻地**：一塊地的進度推滿 100 當場易手——天下大事「汝南荒野落入官軍之手」、江湖史「甲客率先攻入汝南荒野」，推過的人照出力分紅（預演一個人推滿：銀兩 +200、經驗 +300、名望 +20）。剛易手的地 60 分鐘內兩邊都推不動，卡上寫「剛易手，58 分後才能再推、加成暫停」；沒人推的地每天往回 10。
- **輿圖**：天下圖的地面、區圖名字框的顏色是此刻誰佔著；正在翻的地，區圖名字框底下多一條進度，點開卡有「正在翻　官軍 60／100　官軍 1 人正在攻（甲客 +2）」。
- **戰書要第 4 階**：一塊地自己那一邊推到 60，這一段**在任的第 4 階**才看得到「下戰書」（一邊一天一張，挑 12:00～21:00 最近的整點或半點）；其他人只會在天下大事看到「黃巾軍定於第 1 天 15:20 攻南陽郊野」「攻城・南陽郊野：黃巾軍的集結號角吹響了，開打前趕到南陽就能加入」。7 天的季第 4 階門檻高（計畫寫 870 貢獻），季初幾天可能沒有人下得了戰書。
- **攻城戰**：開打前 30 分鐘集結，人要在那個大區，江湖頁有攻城卡（「攻城・白馬津｜守方：津口惡霸（守將）」、戰局條、你的職位、集結還剩幾分）。輿圖上，戰書下了、還沒開集結時區圖名字框旁蓋一枚紅框的「戰」、天下圖那一格紅虛線框；集結與開打時天下圖那一格泛紅光。攻方贏了直接易手（預演「黃巾軍大勝，拿下南陽郊野」），輸了進度砍半；散人可以臨時投效一邊或助守（「你助守南陽郊野，只算這一場」）。
- **見聞多「形勢」**：每天 22:00 一篇〈天下形勢〉（例「是日：官軍拿下汝南荒野。」），模型寫不出來照固定段，玩家看不出差別。
- **決戰開集結多一句起點說明**（例「長社火攻開集結：戰局起點照潁川汝南此刻的戰況往官軍偏了 7 點……潁川汝南一帶的地盤此刻官軍佔 8 處、黃巾軍佔 5 處、2 處還沒人佔。」）。
- **自家領地的好處**：療傷、打造、買馬九折（敵方的地貴兩成），找素材有機會多撿一份，靜心感悟比較容易抓住。
- **玉璽碎片**：不再從宛城現世，改成開季藏一片在中立地、探索才撿得到（開季擲，不一定有）；螭首「鎮地」、金角「補缺」這一季起用得了（上一季灰著）。
- 玩法說明「地盤」一節整個換成這一套。
