## 一、人物 【定＋預設】

人物（本人、同伴、敵人）共用同一種資料：

| 欄位 | 說明 |
|---|---|
| 名號、品階 | 天／地／玄／黃（敵人另有「頭目」標記） |
| 四項屬性 | 臂力（攻）、根骨（防與氣血）、身法（速度）、悟性（絕招發動率與控制命中） |
| 屬性成長 | 每升一級各屬性增加的量，依品階不同 |
| 流派適性 | 剛柔快巧各一格：S／A／B／C，影響使用該流派武學時的效果（S 1.2、A 1.0、B 0.85、C 0.7）【預設】 |
| 本命武學 | 固定一門（黃品沒有）；本人的本命是骨架＋詞條（1b） |
| 自選武學 | 兩格，可裝任何已習得的武學 |
| 出身門派 | 決定吃哪一派的加成（1c） |
| 統御消耗 | 天 7、地 5、玄 3、黃 2；本人 5 |
| 人物特性 | 天品獨有、地品可能有（1c） |

- **人物等級**：1～30，靠戰鬥經驗提升，每季歸零重練；等級提供屬性成長。【預設】
- 屬性量級改為三戰式的數十到百餘（例：玄品初始 50～70），以便百分比效果有意義。原本事件中「臂力 ＋1」這類獎勵改為「＋3」或改發心得。【預設】

## 二、武學 【定＋預設】

| 欄位 | 說明 |
|---|---|
| 類型 | 心法（被動）、絕招（主動）、連招（突擊）、流派奧義（兵種，一隊一個）【定】；陣法、號令留待第二階段 |
| 流派 | 剛柔快巧（心法可為「無」） |
| 品質 | 下／中／上 |
| 門派 | 所屬門派（用於門派加成與取得管道；**任何人都能使用**）【定】 |
| 發動率 | 絕招、連招才有；成數提高時上升 |
| 準備回合 | 絕招可有 0～2 回合「蓄勢」 |
| 特效清單 | 見下 |

**特效種類（第一階段）**【預設】：傷害（倍率、目標數）、回復、屬性增減（攻防速，百分比，持續 N 回合）、控制（點穴／卸兵／封脈，機率＋持續回合）、閃避、減傷、發動率增減。

**成數效果**：第 1 成到第 10 成，傷害倍率、發動率、持續回合等依成數線性提升（每門武學定義「第 1 成值」與「第 10 成值」）。【預設】

- 原有 12 門武學全部改寫成新格式（名稱不變）。

## 三、全自動戰鬥 【定＋預設】

- **三人一隊**（隊長＋兩名隊員），**隊長倒下即敗退**。【定】
- 最多 **8 回合**；8 回合後雙方都未敗退＝**平手**（無獎懲）。【預設】
- **戰前**（準備回合）：心法 → 流派奧義。**每回合**：依身法決定行動順序；每人行動時：絕招（機率，準備中則蓄勢）→ 否則普攻 → 普攻後連招（機率，可多個）。【定】
- **控制**：點穴（本回合不能行動）、卸兵（不能普攻 → 連招也不觸發）、封脈（不能發絕招）。【定】
- **相剋**：剛剋巧、巧剋快、快剋柔、柔剋剛（沿用），剋制方傷害 ×1.25。
- **目標選擇**：普攻與單體絕招優先打**血量比例最低**的敵人，但每場至少有 30% 機率改打隊長（避免永遠不打隊長）。【預設】
- **血量池（兵力／內力通用）**【定】：戰鬥引擎的血量池同時支援兩種語意——個人層的**內力**（第一階段）與勢力層的**部眾**（第二階段）。**傷害隨剩餘量下降**：造成傷害 × (0.5 ＋ 0.5 × 剩餘／上限)。【預設公式】
- **戰報**：每回合列出誰發動了什麼、造成多少傷害或什麼狀態，最後寫勝負與原因（例：「隊長 Rayal 倒下，敗退」）。畫面上顯示摘要，可展開完整戰報。

### 3.1 兵力的兩層對應 【定：C】
| 層 | 血量池 | 戰後 | 回復 |
|---|---|---|---|
| **個人層**（本人遊歷的打鬥；本人＋身邊同伴參戰） | **內力** | 內力保持戰後剩餘值，**不會讓本人不能行動**，只是繼續打比較吃力 | 隨時間調息回滿（約 2 小時）；閉關時回復加倍【預設】 |
| **勢力層**（地圖上的小隊出征，**第二階段**） | **部眾**（門人弟子人數，例「Rayal 率門人 600」） | 戰損分**輕傷**（約七到八成，休養回來）與**折損**（要招募） | 輕傷隨時間休養；折損到城鎮或門派招募門人（花銀兩與時間）；帶兵上限隨人物等級提升 |

- **新手期**（一脈第一季前 3 天）：內力與部眾回復速度加倍、招募門人免費。【定】
- 呼應企劃者「不做重傷休養」的決定：戰敗只降低血量池，不會讓本人無法行動。

## 四、心得、境界與世界進度 【定＋預設】

- **心得**：共用資源，自由分配給任何武學提升成數；**散功**返還 80%；季末歸零。【定】
- **升級成本**【預設】：第 n 成升到第 n＋1 成需要 `20 × n` 心得（第 1→2 成 20、第 9→10 成 180；單門練滿共 900）。
- **來源比例**【定】：歷練 35%、閉關 25%、主線與目標 20%、奇遇與事件 10%、重複人物 10%（第一階段無重複人物，先由收徒相關事件補足）。
- **境界**（1b）：成數上限＝ min(依天數與歷練的個人境界, 世界進度上限)。個人境界【預設】：開季第 3 成；之後每滿「1.5 天且累積 8 場歷練」提升 1 成。世界進度上限【預設】：第一幕 5 成、第二幕 8 成、第三幕 10 成。

## 五、主角本命（1b）【定＋預設】

- **出身**【預設內容】：四種基本出身全開放——**世家子弟**（揚州起步，偏剛／柔）、**寺院俗家**（金山寺起步，偏剛，心法強）、**江湖浪子**（瓜洲渡起步，偏快）、**市井遊俠**（蘇州起步，偏巧）。每種出身：屬性分配不同（總量相同）、2 名玄品初始同伴、3 個骨架可選。特殊出身（門望解鎖）第一階段不做。
- **骨架**：一門完整的中品武學，第一天即可用。
- **領悟**：第 3／6／9 成各一次；到達後需**閉關悟道 2 小時**，出關三選一並附悟道文字。【定】
- **詞條池**：下／中／上三級對應第 3／6／9 成；五類（傷害、控制、生存、節奏、協同）；三選一必來自三個不同類別；控制類最多 1 個；相衝互斥；須與骨架類型相容。經歷只提高出現機率。【定】第一階段每級每類先準備 3～4 個詞條。【預設】
- **重悟**：單格、每季 2 次、花心得（該級升級成本的一半）＋閉關 2 小時。【定＋預設】
- 本命不能散功，骨架整季固定。【定】

## 六、門下與門派（1c）【定＋預設】

- **取得**：出身初始 2 名玄品；**收徒**（城鎮或門派，黃／玄，花銀兩，每天最多 2 次）；交遊結識（玄／地）；奇遇結識（地／天）；招降（擊敗頭目時機率收服）。【定】
- **新立門戶福緣**：前 7 天內保證結識一名地品。【定】
- **統御上限**：每隊開季 15，第二幕起 18、第三幕起 21。【預設】
- **門派三件式**【定】：① 本派武學效果 ＋15%；② 專屬特效（棲霞「以柔化剛」：受剛派攻擊傷害 −20%；玄鐵「百煉」：被控制持續 −1 回合）；③ 同門共鳴（2 人／3 人全隊加成）。
- **散人「博采眾長」**【定】：三門武學分屬三種不同類型時，全部效果 ＋10%；散人限定取得的武學只有散人拿得到。
- 第一階段人物名冊【預設】：約 16 名同伴（黃 4、玄 6、地 4、天 2），分布在出身、收徒、事件與頭目之中。

## 七、對現有系統的影響

| 現有 | 改為 |
|---|---|
| 內功／外功／外功／輕功 四格 | 每人：本命 1 ＋ 自選 2；每隊：流派奧義 1 |
| 單人自動戰鬥＋關鍵戰回合選擇（強攻、巧取…） | 3 對 3 全自動戰鬥＋戰報；**移除**關鍵戰戰術按鈕；內力跨戰鬥保留並隨時間回復 |
| 武學經驗（練哪門升哪門） | 心得（自由分配）＋散功 |
| 閉關：替一門武學加經驗 | 閉關：產生心得；到達領悟門檻時閉關＝悟道 |
| 敵人：單一數值 | 敵人：一隊 1～3 名人物（含武學） |
| 事件選項 `combat: 敵人 id` | `combat: 敵方隊伍 id` |
| 介面「武學」分頁 | 「門下」分頁：隊伍、人物、武學配置、心得分配、散功；「戰報」分頁 |

大勢、主線、地圖、引導、事件系統維持不變。
