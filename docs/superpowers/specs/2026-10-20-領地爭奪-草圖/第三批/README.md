先看 `對照-形勢.png`（並排、縮成一倍）。

| | 怎麼放 | 圖 |
|---|---|---|
| **甲** | 一篇一張卡、新的在上、整篇攤開：時刻（最新一篇標「新」）、粗體的「是日：…」、全文 | `形勢-甲-一篇一張卡.png` |

- 兩種都一樣：見聞多了第九顆籤，375 寬一排放不下，最後的「名帖匣」被切成「名帖」（那一排會橫捲）。做的時候要處理（例：籤分兩排，或跟官方攻略的籤一起重排）。
- **推薦乙，最新一篇預設攤開**（就是「點開一篇」那一張）：每天只要讀今天那一篇，舊的當目錄掃「是日」就夠。
