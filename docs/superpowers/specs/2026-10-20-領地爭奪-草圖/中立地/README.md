# 領地爭奪：輿圖上的中立地怎麼畫（對比圖，2026-10-20）

計畫 `docs/superpowers/plans/2026-10-20-領地爭奪.md` Task 6 末尾：輿圖「勢力」濾鏡（局勢層）上，中立地出兩種畫法給企劃者挑。**程式先用甲**（`dev/conquest-1`），挑了乙就套 `乙.patch`。

- 真的網頁截圖：本機預覽（`conq1.localhost:7884`，21 天季設定、領地爭奪只在預覽那個行程裡打開、暫存資料庫），一個官軍角色在潁川郡。為了看得到「被佔下的中立地」，先用管理者那一套把荒丘給官軍、南陽郊野給黃巾，其餘中立地沒人佔。
- 每一種四張：`X-375-淺色.png`、`X-375-深色.png`（手機 375×812，抽屜收起、縮小一格）、`X-1280-淺色.png`（電腦 1280×800）、`X-375-近看.png`（點了官軍大營、放大一格，抽屜寫「無人・中立地」）。
- `對照-375-淺色.png`、`對照-375-深色.png`、`對照-375-近看.png`：甲乙同一塊並排（截地圖中間那一塊，原尺寸）。先看這三張。
- 深色主題時地圖本身照舊是紙色（輿圖一直是這樣），變的只有上面的狀態列、濾鏡、抽屜。

## 兩種

| | 還沒人佔的中立地 | 被佔下的中立地 | 看大局（縮到最小） |
|---|---|---|---|
| **甲** | 灰白圓盤＋灰色**虛線圈**（外圈離圓盤遠一點、粗一點） | 跟一般地點一樣，照佔領方的顏色，看不出開季是中立地 | 灰點、虛線邊 |
| **乙** | 灰白圓盤＋**細金邊**（外圈、圓盤邊都是細金線） | 照佔領方的顏色，外面多**一圈淡金**（「開季是中立地，好獵場還在」） | 灰點、金邊；被佔的外面一圈淡金 |

（截圖裡南陽官道、嵩山深處、官軍大營、綠林山寨、白馬津是還沒人佔的中立地，荒丘是被官軍佔下的中立地，南陽郊野是被黃巾佔下的中立地。）

## 好壞

- **甲**
  - 好：「虛線＝沒人佔」一眼就懂，跟官軍藍、黃巾金、豪強綠三種實線不會搞混；375 寬、縮小一格也看得出是斷的。
  - 壞：被佔下之後看不出它原本是中立地（設計 3.3「好東西留著、變成佔領方的好獵場」在地圖上沒有記號），要點開抽屜看「中立地」那一格。
- **乙**
  - 好：被佔下的中立地外面留一圈淡金，地圖上就看得出哪些是好獵場、哪些是一般的地盤。
  - 壞：細金邊跟黃巾的金黃色很近（對照圖裡南陽官道與南陽黃巾營擺在一起時最明顯），還沒人佔的中立地容易看成「淡淡的黃巾地」；淡金外圈在藍色的官軍地盤上看得清楚（荒丘），在黃巾的地盤上跟金黃的圓盤與暈色貼在一起、淡很多（電腦那一張的南陽郊野）。
- 建議：甲。乙的「被佔下也留記號」值得要的話，可以把乙那一圈淡金換成甲的灰色虛線外圈（被佔下了照佔領方的顏色、外面再一圈淡灰虛線），兩邊的好處都留；要的話再出一張。

## 怎麼換成乙

`乙.patch` 是 `web/app.js` 的差異（只動 `marksParts` 那一段，多一個 `wasNz`），`git apply` 套上就是乙的畫法；`tests/test_conquest_mapview.py::test_web_marks_draw_unheld_neutral_as_grey_disc_with_dashed_ring` 要跟著改（甲那一條驗的是虛線）。顏色都待 joy 對（`NEUTRAL_INK`、乙的金 `#B8902F`）。
