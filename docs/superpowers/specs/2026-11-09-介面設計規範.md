> 在這之前沒有成文的規範，散在 Joy 的回饋裡（11/6 不重複、說明收起來、能做的排前面；11/7 按完不跳頂）與幾個做得好的頁（傳承與識海 `web/legacy.css`、列傳、決戰面板、此地圓章）。這份把它們寫成一份，**之後新畫面、改畫面一律照這份做，給 Joy 看之前照第八節自己驗一次**。
> 跟程式對不上時照程式；這份跟 Joy 當下說的不一樣時照 Joy，並回來改這份。

## 一、三句話

1. **水墨**：紙、墨、朱印、楷書。底是宣紙色，字是墨，重點用朱紅（印）與金（匾、帖邊）；有場景就放圖（我們自己的水墨插畫），不用表情符號當圖示、不用預設的灰框表格。
2. **操作友善**：手機一隻拇指能用。點得到的東西至少 44px 高；一張卡最多一顆主鈕；能做的排前面；按完留在原處；輪詢重畫不掉狀態。
3. **有質感**：每一塊都要有「這是什麼東西」的樣子——武譜像一頁譜、殘頁像撕下來的紙、結義像金蘭帖、門派頂上是山門與匾。一個 `<ul>` 加一行灰字不算畫完。

## 二、色票（只用 `web/style.css` 的 `:root`）

| 名字 | 淺色 | 用在 |
|---|---|---|
| `--paper` | #f4ede0 宣紙 | 頁底 |
| `--card` / `--card-2` | #fbf7ef / #efe6d5 | 卡、卡裡的次一層（收起來的說明、殘頁） |
| `--ink` / `--ink-2` | #2a241d / #6b6155 | 正文 / 次要字（不要再自己寫灰） |
| `--line` | #ddd1bc | 邊線、虛線分隔 |
| `--accent` | #a8322a 朱 | 主鈕、朱印、序號直條、要緊的提醒 |
| `--gold` | #b7862b | 名望、小點綴（條列的「・」） |
| `--gang --kuai --rou --man` | 剛快柔慢 | 武學與意境的屬性色籤，一律照這四色 |
| `--ok` / `--bad` | 綠 / 紅 | 狀態（身在山門、失敗） |

- 深色模式由 `@media (prefers-color-scheme: dark)` 換同一組名字：**用了色票就自動有深色**。寫死的顏色只准用在「本身就是一件東西」的面上（匾額的木色、金蘭帖的朱紅、殘頁的紙），而且兩種模式都要看過。
- 場景圖在深色模式壓暗一點（`filter: brightness(.78) saturate(.85)`），不要整張白亮。

## 三、字

| 字型 | 用在 |
|---|---|
| `--kai`（霞鶩文楷，`index.html` 已載 400、700） | 名字：門派名、武學與意境名、人名、段標題、落款、一句氛圍話 |
| `--serif`（Noto Serif TC） | 大標題、大數字（傳承頁的值） |
| `--sans` | 規則、數字、按鈕、提示——要讀清楚的東西 |

- 段標題：楷書 18px、字距 .12em、左邊一筆 3px 墨線（`.zm-sec-hd h4`）。
- 名字 16～19px 楷書粗；說明 13～14px；最小 11px（只用在名帖底下的「你」這種標記）。
- 一行說明不超過手機一行半；長的收進「？」。

## 四、版面

- **手機先**：以 390px 寬設計（也看 360px），左右留白跟著頁面的卡；不准橫向捲動。
- 間距只用 4／6／8／10／12／14／16。卡圓角 10～14px（`--radius` 14），陰影用 `--shadow`。
- 一頁由上到下：**這是哪裡（頁首）→ 現在能做的 → 看的（清單）→ 收起來的說明**。
- 分頁（`hero-tabs`）一頁一件事：功能包自己有一整塊畫面、跟別的放一起會混的，開自己的分頁（例：「師門」不跟「同伴」放一起，Joy 11/9）；只在有東西時才出現那一顆分頁。

## 六、操作

- **44px**：所有點得到的（含「怎麼來」「？」這種文字鈕）。
- **一張卡一顆主鈕**；選一樣東西去做，八樣以內畫成卡、每張自己一顆鈕，**不用 `<select>`**。
- **不可逆的要確認一次**（`ask(...)`；割袍斷義、熔掉、放走同伴），可逆的不問。
- **按完不跳頂**（Joy 11/7）：俠客頁的切換用 `heroStay(() => …; renderPage())`。
- **輪詢重畫不掉狀態**：攤開、挑到一半都記在 `S.<名字>`，不靠原生 `<details>`（重畫就收起來）。
- **做不了的不要每一列都寫為什麼**：同一個原因（例：不在山門）在頁首說一次，列上只是沒有鈕。
- 結果寫在按的那一塊附近（`mxNote` 那一套），不要只在頁頂。

## 七、內容

- **一件事一頁只出現一次**（Joy 11/6「你這邊是胡亂設計的嗎」）。
- **說明預設收起來**，一行提示就好；門檻、來源、規則放「？」後面。
- **能做的排前面**，做不了的在後面；跟這一頁無關的不放（11/6「你有在認真檢查嗎」）。
- 寫給玩家看的新字在程式旁註 `// 待 joy 潤`（Joy 不潤字，但要找得到）；不露機器的數字（戰況照 `rules.humanize`）。
