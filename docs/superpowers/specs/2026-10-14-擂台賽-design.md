# 擂台賽（隨時挑擂）設計

2026-10-14，PM 派工；Joy 的原話：「我再想開一個擂台賽，讓他們可以報名，然後可以對戰，但是如何對戰我還沒想好，因為很難兩個人都同時在線」。
Joy 在選擇卡選了「隨時挑擂」：報名的人留下一份守擂的分身，別人隨時來挑，對的是分身，照積分排名。

數字都在 `Config.arena`（`ArenaTuning`），規則在 `tianxia/arena.py`，接到 Game 的在 `engine.py` 的「擂台」那一段。全部【預設】，試玩後再調。

## 一、報名與分身

- 在城鎮（懸賞榜那一種城鎮，`bounties.is_town`）的「此地還能做」裡有「擂台」（`act:arena`），打開第二層選單（`PlayerState.picking_arena`），不花體力。
- 「報名守擂」（`arena:join`）：把此刻的身手抄成分身，記在這一季的 `WorldState.arena`（名號鍵 → `ArenaEntry`）。
  分身是：武學威力、三招的份量（同頭目戰，不算騎兵與部下：`_battle_scores(mounted=False)`）、職位、氣血上限、身上兩門武學的名字。
  報過了再按是「更新守擂分身」：重抄一次，積分與戰績不動。
- 要報名得有武學（威力是 0 的報不了），季要在跑、不在序章。
- 只算這一季：`WorldState` 換季整個重來，積分、戰績、分身一起清。

## 二、挑擂

- 選單上列其他守擂的人（積分高的先，最多 `list_max` 8 人；多的收成一行），每一顆寫積分、勝負、身手比你強或弱（同奪璽單挑 `foe_line` 的字）、體力。
- 擋：自己要先報名；付得起 `stamina`（10，比照截殺）；同一個人挑同一個人有冷卻 `pair_cooldown_seconds`（3 小時世界秒）；
  一個人一個遊戲日最多被挑 `defend_per_day`（6）場（保護上限）。擋的那一顆灰掉寫原因。
- 按下去：付體力、記冷卻與被挑的次數，開一場（`PlayerState.arena`，`ArenaFight`）。挑的人用此刻的身手（同報名的抄法），
  守的人用他的分身；兩邊的氣血池都從滿的開始，打完不扣回角色、不磨兵器防具。
- 打到一半不能安排前往、閉關、做別的事（同頭目戰：`_idle`、`atlas.travel_block`）。

## 三、一場怎麼打

照頭目戰與奪璽單挑的純函式（`duel.push_of`、`harm_of`、`gamble_roll`、`verdict_at`）：

- 一場 `rounds`（5）回合。每回合你出三招之一，或在輸入框寫 20 字放手一搏（走頭目戰同一個輸入框與 `/api/do/duel_text`，三段式；
  模型只評成功率、寫成敗兩版，評不到 40；不限次數），或「認輸下台」（算落敗）。
- 分身的招照奪璽單挑的代打（份量^`proxy_power` 加權），回合開始時你看得到他的架勢（`DuelTuning.tell_truth` 六成是真的）。
- 兩邊都出招：推力照 `push_of`（兩邊的份量、剋、運氣、參謀），兩邊各扣自己的池子（`harm_of`）。你放手一搏：分身的招不算、他不扣血。
- 勝負（你的角度）：你的池子見底或氣勢 ≤ 10 落敗；他的池子見底大勝；氣勢 ≥ 90 提前大勝；打滿照氣勢分大勝、險勝、僵持、落敗。
- 亂數全用自己的（「擂台|季|名號|場次|回合」），不碰 `Game.rng`。

## 四、積分

- Elo：起始 `start_rating`（1000），K＝`k`（32）。挑的人贏（大勝、險勝）得 1 分、僵持 0.5、落敗 0；守的人照反過來。
  兩邊都改，守的人不在線也照算（寫在 `WorldState.arena`）。
- 戰績：勝、負、和、連勝（挑與守都算，輸了歸零）、最長連勝。
- 守的人下次同步補一份戰報（`kind="arena"`）與一則江湖紀錄「守擂・挑的人」（積分怎麼變）；挑的人當下就有。
- 爆冷門（挑的人贏、照積分算的勝率 ≤ `upset_expect` 0.25）、連勝到 `streak_news`（5）的倍數：天下大事一句。
- 最精彩的一搏照決戰的做法：那一場成了的放手一搏裡挑最有戲的（`battle_instance.more_dramatic`），成功率 ≤ `highlight_rate`（30）
  就上天下大事（具名），那個人名望 +`highlight_fame`（1）。

## 五、季末

- 收季那一刻（`world.end_season`）至少打過一場的人照積分排，前三名寫進江湖史與天下大事。
- 獎勵（`prizes`）：第一名名望 30・回體丹 3 顆，第二名 20・2 顆，第三名 10・1 顆。回體丹換季帶著走，所以選它。
  休季時那個人同步就補（`WorldState.arena` 的那一筆記 `prized`）；休季一次都沒上線的人只有江湖史那一行，拿不到丹（新的一季讀不到上一季）。

## 六、假人與機器人

- 伺服器假人走同一條路（`bot_policy`）：在城鎮、還沒報名、有武學就報名；分身比現在弱了一截（威力差 15% 以上）就更新；
  手上體力夠時每一輪 `ARENA_CHANCE` 擲一次挑擂，挑看得到的人裡積分最近的；打的時候看架勢出剋它的招（同頭目戰 `DUEL_READ`）、不寫放手一搏、不認輸。
- 畫面上沒有任何一處透露誰是假人（名單、榜、天下大事都一樣寫）。
- 整季機器人不碰擂台（`bot.pick` 排除 `act:arena`、`arena:yield`）。

## 七、擂台榜

- `arena.board(world)`：打過至少一場的人照積分排，前 10 名（名次、名號、積分、勝負和、連勝）。
- 放進介面 thread 正在做的見聞「榜單」分頁，那一頁合進 main 之後由這邊接上去（已跟介面 thread 對過）。在那之前，打開擂台時第一句寫你的積分與名次、前三名。
