## 產生器（`tools/`）

- `prep.py`：暫存資料庫開一季（season21、領地爭奪開著）、一個官軍角色站在潁川郡、荒丘給官軍、南陽郊野給黃巾。`serve.py`：預覽伺服器（埠 7892）。`patch_app.py`：第一輪暫時改 `web/app.js`（三版用網址參數切換；拍完 `git checkout -- web/app.js`）；`示意-appjs.patch` 是那一次的 diff。
- `fetch.js`：登入後抓 `/api/map/base`、`/api/map/state` 存成 `map_base.json`、`map_state.json`（草圖都讀這兩份真資料；這裡沒附，自己跑一次）。
- `mock.py`（三種風格）、`mock2.py`（古輿圖加料）、`mock3.py`（收線）、`mock4.py`（清甲＋清乙的框）、`mock5.py`（大改兩方案）、`mock6.py`（天下圖的地面與前線）、`mock7.py`（重排）、`mock8.py`（新地理甲乙）：吐 `mocks/*.html`，用 `python -m http.server` 開著、`shot2.js` 拍；`shot.js` 是拍真畫面（會登入）的版本；`compose*.py` 並排（PIL，字型 `C:\Windows\Fonts\msjh.ttc`）。
- 都是草圖用的臨時腳本，路徑寫死在設計 session 的 scratchpad，拿來用要改路徑。
