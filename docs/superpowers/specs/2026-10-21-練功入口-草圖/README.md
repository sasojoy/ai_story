## 三個做法

### 甲：城裡的灰鈕換成一顆亮著的「往某地練功」

城裡練功灰著（「…最近的在潁水河畔」）時，第四顆換成 `→ 往潁水河畔練功（步行約 3 分鐘）`，按了就是移動那一條「前往 潁水河畔」（實測上路，week7 現實約 3 分鐘到），到了再點探索→練功。

- 好：改動最小（網頁一處）；城裡也有一顆按得下去、指向經驗的鈕。
- 壞：
  - 還是要先點探索才看得到；還是排第四顆，375×812 點開時**下半截被分頁列蓋住**（順帶發現 1 不修的話，企劃者那一句「看不到第四顆」照樣成立）。
  - 到了還要再點兩下（探索→練功）；野外跟現況一樣。
  - 草圖只認隔壁那一條「前往」：官軍與散人灰著的 17 處裡有 5 處（大將軍府、汝南學宮、汝南集市、譙縣、曹氏莊院）最近的練功點隔兩站以上，那幾處退回原本的灰鈕。要做到底得讓引擎給目的地、走輿圖的多站前往；那樣就是新加一顆「永遠按得下去」的選項，`bot.py::pick()` 要一併改。

### 乙：練功排第一顆、灰著時字不淡、底下一行小字

探索卡上練功排第一；城裡灰著時只有鈕灰（底色換成 `--card-2`、虛線框），字照常深，「最近的在潁水河畔」拆到底下一行小字「城外才有對手：最近的在潁水河畔」；野外亮著也排第一。

- 好：點開探索第一眼就是練功、不會被分頁列蓋住；只動網頁（正式做時引擎可以把那一行放進 `Option.note`，不必解析標籤）。
- 壞：
  - 沒點探索還是看不到；城裡還是按不下去，要自己去「移動」找潁水河畔。
  - 探索那一格的小字與底下那一行仍寫「三選一」「點開三選一：找素材、找事件，或靜心感悟」，卡上其實有四顆（甲也一樣）。
  - 「灰著但字不淡」是全站唯一的一顆，跟其他灰鈕不一致。

### 丙：行動列多一格「練功」

行動列變五格：探索、**練功**、出陣、交友、移動。野外亮著，小字「不限次數」，第二行照勝算上色（穩勝綠，同遊歷／出陣）；按了直接練功，不經過探索。城裡灰著，小字「城外才有」，行動列底下多一行「**練功** 城外才有對手，最近的在潁水河畔（步行約 3 分鐘）」。練功從探索卡拿掉，探索卡回到真的三選一（格子的「三選一」與底下那一行都對了）。

- 好：
  - 不用點開就在第一屏，名字就叫「練功」，經驗的大宗跟出陣、交友平起平坐。
  - 選項 id 不變（`explore:practice`），假人、整季機器人、`bot.pick` 都不受影響。
  - 「三選一」的字跟實際一致。
- 壞：
  - 五格變窄：375 寬每格 79→62 px，320 寬 51 px。灰格小字的上限從六個字降到約四個字（「城外才有」「不在戰線」40 px 剛好）；現在就超長的交友灰格更擠（順帶發現 2）。
  - 城裡那一格是灰的，深色模式下很暗（所有灰格本來就這樣），要靠底下那一行。
  - 要跟著改的說法多：玩法說明「練功（在探索裡，體力 6）」、行動列底下練功那一行（引擎的 `action_notes` 現在沒有練功）、導覽〈地圖與介面〉行動列那一段、〈行動與地盤〉探索那一段；序章／初入江湖要不要亮這一格（草圖照探索那一格一起亮）。

### 丙帶路：丙的城裡那一格也亮著、按了帶你去

丙的另一種城裡畫法：那一格亮著，小字「往潁水河畔」，按了就是隔壁那一條「前往」（實測上路）；底下那一行「**練功** 城裡沒有對手：按一下走到潁水河畔（步行約 3 分鐘），到了再按練功」。

- 好：新手站在城裡一按就往練功的地方走；深色模式也看得見。
- 壞：格子寫「練功」，按下去是走路（底下那一行說了）；「往汝南荒野」這種五個字在 320 寬剛好貼著格子兩邊（50 px／51 px）；隔兩站以上的 5 處同甲，退回灰格「城外才有」。

## 推薦：丙＋帶路

企劃者的兩個卡點是「看不到」與「城裡練不了」。甲、乙都還藏在探索裡：甲解決城裡按不下去、沒解決看不到（第四顆還在分頁列底下）；乙解決點開後看不到、沒解決沒點開與城裡按不下去。丙把練功放上行動列，沒點任何東西就看得到，城裡那一格帶路，一按就往練功的地方走；選項 id 不變，假人與整季機器人不必動，探索也回到名副其實的三選一。代價是五格變窄，現有的格子小字都在四個字內放得下（交友那一格的長原因本來就超過，另修）。

## 要企劃者定的

1. 丙的城裡那一格：灰著寫「城外才有」（丙），還是亮著帶路「往潁水河畔」（丙帶路）。
2. 練功那一格排哪：探索右邊（草圖），或出陣右邊。
3. 亮著時的小字：「不限次數」（照派工），第二行要不要照樣寫勝算（草圖有）。
4. 帶路遇到最近的練功點隔兩站以上（大將軍府、汝南學宮、汝南集市、譙縣、曹氏莊院）：退回灰格（草圖），還是讓引擎走輿圖的多站前往（要改引擎與 `bot.pick`）。
5. 字待 joy 潤：「城外才有」「不限次數」「往潁水河畔」、底下那兩句。
6. 順帶發現 1、2 要不要各開一張單。

## 順帶發現（現況就有，不論挑哪個）

1. **點開探索之後第四顆被分頁列蓋住**：375×812、潁川郡，探索卡底在 797 px、分頁列頂在 756 px，練功那一顆在 721～784 px，下半截在分頁列底下；網頁點開後會叫 `revealMoveCard()`（`scrollIntoView({block: "nearest"})`，卡上有 `scroll-margin-bottom: 64px`），但卡本身沒超出視窗時 Chromium 不捲（`scrollY` 一直是 0；卡超出視窗時才捲，而且捲到卡底在 748 px，這時有算那 64 px）。無頭 Chromium 1208 與桌面 App 的瀏覽器窗格（Chrome 152、手機模擬）都量到同樣的結果。野外的練功（721～769 px）也有一截被蓋住。修法可以是自己量：卡底超過「視窗高 − 64 − 安全區」就 `scrollBy` 差的那一段。
2. **交友灰格的原因被切**：「交友（這裡沒有能說上話的人）」那一格的小字是整句（10 個字、100 px），四格時 79 px 的格子只看得到「裡沒有能說上話的」，丙五格時更少。超過行動列灰格「最多六個字」的規矩。
