## 一 問題在哪

## 二 方案：桌上一塊沙盤（企劃者挑的）

整張輿圖是**一塊木托盤裝的沙盤**：地是沙、山是浮雕、河是刻槽、每一處地點是一枚棋子、誰佔了哪裡就是棋子的顏色、本週目標插一面旗、寶是一錠金、你是一枚紅棋。沒有「畫出來的景」，只有桌上的東西；所以不怕密、也不怕空——空著的沙地就是沙地，不是「沒畫完」。

草圖第 2 輪三種風格裡我自己傾向木刻古輿圖（記號式的、跟文字遊戲的紙墨同一套）；企劃者挑沙盤，理由他沒說，看第 3～5 輪他挑的都是「把翻地當主角」的那一邊——棋子的顏色就是戰況，一眼就是誰佔了哪裡。

### 2.2 三層：燈下 → 全區 → 天下

四層變三層（舊的「點一處」不是一層，是任何一層裡點一枚棋子）。上面右邊三顆木牌就是三層，亮著的是現在這一層；左邊一顆是區名▾（現在的 `select.r-pick`，換到別區看的是那一區的全區）【設計】。每次打開輿圖分頁回到燈下（`mapFirst` 照舊）。

#### 燈下（第一層，打開第一眼）——企劃者定「兩步」

沙盤上一盞燈只照你腳下：

- **亮的**＝你＋路網上 `lamp_hops`【預設 2】步以內的地點（照 `base.edges` 算步數，不分區；洛陽官道在洛陽區也亮）。亮的才畫成棋子、才有名字牌；名字牌後面直接帶步行幾分（「潁水河畔・3分」，`state.places[].minutes`）。
- **暗的**＝圖框內其餘地點：只剩一顆小釘（r 5～6、歸屬色、55% 透明、沒字、沒旗沒金）。它們在，但不跟你搶眼睛。
- **圖框**照亮的那一圈 fit（四邊留約 46 地圖單位），不拖不縮。
- **燈**：以你為中心的徑向漸層，亮圈外暗 30%；亮圈內的路粗（2.6px），外面細且淡。
- **指針**：亮圈外、跟你有關的，掛在托盤內緣朝那一處的方向，一顆深色膠囊寫「為什麼・地名・N分」，尾巴往外一撇：
  - 哪些算有關：本週目標（不限距離，紅底）、正在翻（`tug`／`melee`）、有寶（`rich`）、有賞（`bounty`）。
  - 只掛步行 ≤ `pointer_minutes`【預設 15】分的，最多 `pointer_max`【預設 3】個，近的先；本週不受這兩條限制。
  - 兩顆撞在一起就上下錯開 22px。按一顆＝點那一處（見 2.3）。
- **底下的面板叫「當下」**（待 joy 潤）：第一列是本週軍令（紅底一條：「本週」章、地名、軍令的內容、步行 N 分 ›），接著是腳下走得到的每一條路（棋色點、地名、多半・勝算、步行 N 分 ›），本週那一處不重複列。在路上時第一列換成現在的 `journeyHtml`【設計】。
- 草圖：`第5輪-全套/1-燈下兩步.jpg`。

#### 全區（第二層）

全亮：這一區每一處都是棋子、都有名字牌；面板是「令牌」（待 joy 潤）：腳下走得到的路，跟燈下的「當下」少了本週那一列【設計：全區是「看整區」，當下的提醒留在燈下】。草圖：`4-全區.jpg`。

#### 天下（第三層）

整張沙盤：五個區各是一塊壓出來的盤（你在的那一塊亮一點 `#E6DAB8`，其餘 `#DCCDA8`），山水照 2.1 但縮小；每一處一枚小棋（r 4.2，大地方 5.5；顏色＝歸屬、沒棋面字），你是紅棋（r 9、「你」）、本週插旗、寶一錠金；區名是木牌；路 0.9px。面板是**三條戰線**：每一條一根繩（左端「官」章、右端「黃」章、繩從官色漸到黃色、米白珠子停在值的位置；右上寫 ▲N／▼N／持平），下面一行「寶在 …」（天下有寶的地名）。點區名木牌→那一區的全區；點小棋不反應【設計】。草圖：`5-天下.jpg`。

### 2.3 點一處（任何一層）

- **點亮的棋子**：那一枚抬起（半徑 +3px、影子加深加長、外面一圈米白）、名字牌翻成米白底深字；從你到那裡的路點亮成米白粗繩（照 `state.places[].path` 一段段沿路畫，底下襯一條半透明深色）；其餘棋子與名字牌退淡到 72%；面板換成**卡**。草圖：`2-點亮的.jpg`。
- **點暗釘**（燈下才有暗釘）：那一枚先點亮成棋子＋名字牌，**圖框重新 fit 把它包進來**（亮圈不變、只是多包一枚），其餘同上。草圖：`3-點暗的.jpg`。
- **卡**（底下面板）：第一行棋色點、地名（全名）、歸屬・地形（「官軍地・野外」「正在翻・野外」「無主・山野」）、右上 ✕；第二行多半・勝算 詞・今日產出；兩顆鈕：**「步行 N 分／沿路可以做小事」**（淺木、主鈕）、**「疾行／立刻到・體力 M」**（深木）；接著「此地的對手」一行（對手名＋勝算詞）、`fierce`＋`price` 一行。**卡的其餘內容照現在的 `placeCard`（往上拉：能悟、對手、人物、今日產出、軍令、截殺…）原樣搬進來，不增不減**【設計】——這一份只重畫卡的頭與兩顆鈕。
- ✕、再點同一枚、點空的沙地：收卡、回到原本那一層的面板。

### 2.4 名字牌怎麼擺（全區、燈下共用）

照重要度排隊，每一塊挑一個**不壓棋子、不壓別的牌、不出托盤**的位置：

1. 排隊：你 → 點了的那一處 → 腳下的路與本週 → 大地方、有寶、正在翻 → 其餘。
2. 每一塊依序試：下、上、右、左、右下、左下、右上、左上、再下一格、再上一格（棋子半徑 + 牌半高 + 3px）。
3. 都被佔了：往外一圈一圈找（半徑每 9px、每 30°），找到了就從棋子拉一條 1px 細線到牌。
4. 還是找不到（理論上不會）：放在正下方，QA 要抓得到（見第七章）。

草圖的 `tools/board.js::placeLabels` 是這一條的最簡單寫法；正式做可以更聰明，但**結果要滿足第七章的量法**。
