# 《天下大勢》大地圖與場景小地圖 — 設計

> 來源：試玩回饋。「場景」和「地圖」兩個分頁差別不大；現在的地圖像網路遊戲的小地圖，但少了一個能看整個江湖局勢的大地圖。
> 本文件取代現行的左欄「場景／地圖」分頁設計；戰鬥、檢定、門下、戰報、江湖紀錄的規則與畫面不變。

## 一、目標

1. **大地圖（整頁）**：一眼看出整個江湖的局勢、敵情、劇情與路線，並能直接安排前往。
2. **場景小地圖**：只給粗略方向感（我在哪一區、往哪邊是哪一區），不重複前往按鈕的內容。
3. **左欄更單純**：拿掉「場景／地圖」分頁，場景一直看得到。

## 二、大地圖整頁

### 2.1 入口與版面
- 入口：
  - 右欄「門下」「戰報」旁多一個「大地圖」按鈕。
  - 點場景小地圖，或它下方的「大地圖」按鈕，也會打開。
- 版面：和門下、戰報同一種整頁模式，打開時隱藏主畫面。
  - 上方：標題「江湖輿圖」、目前時間與體力、「返回江湖」。
  - 下方左邊：大地圖，佔大部分寬度。
  - 下方右邊：地點詳情欄。
- 圖層按鈕：局勢／敵情／劇情／路線，一次顯示一層，預設「局勢」。
- 圖例（所在地、看得見、去過、未知、城鎮、門派、野外等說明）放在大地圖頁，隨圖層顯示該層用到的記號。

### 2.2 選地點
- 點地圖上的地點，或從詳情欄上方的下拉選單選，被選的地點在圖上加粗標示。
- 兩種方式都要有。
- 預設選中所在地。

### 2.3 視野
- 沿用現行規則（`mapview.visible_locations` 與已去過地點）。
- 看不見、沒去過的地點只顯示輪廓與「？」，詳情欄只寫「尚未摸清」。
- 敵情、勝算、路線體力只對看得見或去過的地點顯示。

### 2.4 安排前往
- 詳情欄最下方有「安排前往（約 N 體力）」按鈕。所在地、看不見的地點、未開放的地點不顯示此按鈕。
- 路線：在「看得見或去過、且已開放」的地點之間，以 `move_cost` 找最省體力的路。
- 執行：
  - 一站一站移動，每站照常扣體力、觸發新手引導的移動步驟與門檻檢查。
  - 下一站體力不夠就停下，停在已抵達的地方。
- 條件：有待處理事件、閉關中、賽季已結束時不能安排前往，按鈕改為說明原因。
- 紀錄只寫一筆：
  - 抵達：「前往 高郵湖（途經 揚州城郊）」。
  - 中途停下：「前往 太湖水寨（體力不足，停在 鎮江渡口）」。
- 走完回到主畫面，場景顯示抵達的地點。

## 三、四個圖層

### 3.1 局勢
- 每個大區依它對應的大勢上色，數值越危險越紅，區名旁標出大勢名稱與數值。沒有對應大勢的區保持原色。
- 門派所在地標門派記號。
- 龍頭人物在他們「常出沒」的地點插旗，旗旁寫名字與「常出沒」。
- 隱藏大勢，以及只在隱藏劇情揭露後才活動的人物，要等揭露後才顯示。

### 3.2 敵情
- 地點依危險度上色（一到三顆星）。
- 標籤寫最難對付的敵人和勝算，例如「最險：水寨頭目 必敗」。
- 勝算沿用戰前勝算：同一套模擬、快取與六種勝算詞。只在切到敵情層時才計算，平常重畫不做。

### 3.3 劇情
- ★ 目前這一幕主線的目標地點。
- ✦ 最近 3 天有江湖大事或傳聞的地點。選到該地點時，詳情欄列出那些事。
- 隱藏劇情的地點，揭露後才標。

### 3.4 路線
- 從所在地出發，每個看得見或去過的地點旁標出最省體力的走法要花多少體力。
- 未開放的地點標「未開放」。

### 3.5 詳情欄
被選的地點同時列出四方面資訊：
- 局勢：所屬大區與大勢、常出沒的人物
- 敵情：可能遇到的敵人各自的勝算
- 劇情：主線目標、最近的大事與傳聞
- 路線：體力與途經地點

最下面是「安排前往」按鈕。

## 四、要補的內容資料（只補「在哪裡」，不改規則與數值）

| 資料 | 放在哪 | 說明 |
|---|---|---|
| 大區代號與對應大勢 | `content/map.json` 的 `regions` | 每區加 `id`，以及 `trends: [trend id]`（可空）。預設：江北、太湖一帶 → 太湖寇亂；金陵一帶 → 前朝寶藏（揭露後才顯示）。 |
| 地點屬於哪一區 | 不用填 | 載入時依地點座標落在哪個大區多邊形內自動判斷。落在所有大區外的地點，歸給最近的大區。 |
| 龍頭人物常出沒處 | `content/scenario.json` 的 `sim_players` | 加 `haunts: [location id]`。固定不動，不影響世界模擬與亂數。 |
| 主線目標地點 | `storylines[].acts[]` | 加 `places: [location id]`（可空）。 |
| 江湖大事發生地 | `world_events`、`thresholds` | 加 `location`（可空）。 |
| 傳聞發生地 | 狀態 `Rumor` | 加 `location`（可空）。玩家在某地觸發的傳聞記在當時所在地點；龍頭人物的傳聞記在他們的第一個常出沒處。 |

- 載入時檢查：所有 id 都要存在，寫錯要指出是哪一筆。
- 舊存檔的傳聞沒有地點，一樣可以讀取。

## 五、場景小地圖與左欄

### 5.1 小地圖
- 只畫所在大區的輪廓。
- 區內看得見或去過的地點畫成小點，只有城鎮等重要地點標名字。沒摸清的地點畫成淡點或不畫。
- 不畫路，也不放危險、敵人、體力等數字。
- 所在地用醒目記號標出。
- 輪廓邊緣標出相鄰大區的方向，例如「↓ 金陵一帶」「↘ 太湖一帶」。方向由大區中心點的相對位置決定。
- 事件進行中也照常顯示所在位置。
- 點小地圖或它下方的「大地圖」按鈕，會打開大地圖。

### 5.2 左欄
由上到下：
1. 場景列：左邊是地點或事件文字，右邊是小地圖
2. 選項按鈕
3. 「剛剛」卡片
4. 江湖紀錄

- 拿掉「場景／地圖」分頁。
- 新手引導「看地圖」那一步改成「按『大地圖』看看」，打開大地圖就算完成。`content/tutorial.json` 的文字同步修改。

## 六、不在這次範圍
- 多人玩家的位置與勢力範圍（第四階段）。
- 龍頭人物隨時間移動、追蹤行蹤。
- 行程耗時：移動仍只花體力、不花遊戲時間，和現在一樣。
- 地圖美術風格大改：沿用現有 SVG 畫法與配色，只加圖層記號。

## 七、測試
- 規則引擎：
  - 大區歸屬，含座標落在區外的地點
  - 最省體力路線，只走看得見或去過、且已開放的地點
  - 安排前往：逐站扣體力、體力不足停下、事件中或閉關中不可前往、紀錄一筆
  - 各圖層資料：大區大勢值、常出沒、主線目標、最近 3 天大事與傳聞、敵情最險對手、未摸清地點不洩漏資訊
  - 隱藏大勢與隱藏人物在揭露前後的差別
  - 傳聞地點的記錄
  - 內容驗證（id 寫錯要報錯並指出 id）
  - 舊存檔讀取
- 介面：
  - 大地圖開關與三個整頁互斥
  - 圖層切換
  - 選地點（下拉與點圖）
  - 安排前往後回到主畫面
  - 小地圖只畫所在大區
  - 左欄沒有分頁
  - 新手引導打開大地圖即完成
  - 輸出數量與順序一致
- 效能：敵情層第一次計算和已快取時的耗時都要量，平常重畫不做勝算模擬。
- 真實內容：機器人跑完整季不出錯。
