## 三、A 大圖加抽屜：玩家怎麼用

**畫面**：
- 最上面一行是狀態（名號、陣營、時刻、體力），底下整頁都是地圖，最下面是原本的五個分頁。
- 地圖左上：一條搜尋框，下面一排濾鏡。
- 地圖右上：三顆鈕，◎ 回到自己、＋、－。
- 地圖底部：一個可以拉高拉低的抽屜。

| 想做的事 | 怎麼做 |
|---|---|
| 看地圖 | 一指拖；兩指捏合、或滾輪縮放；也可以按右上的 ＋／－ |
| 看大局 | 一直拉遠（或按 －）：地名收起來，只剩每個大區的名字、誰佔幾處（例「官 3・豪 1・巾 1」）、前線的紅色鋸線 |
| 看一個地點 | 點它。抽屜升到半開，第一行是名字、誰控制、危險度，第二行就是「步行 N 分／疾行（體力 M）」；地點不會移位 |
| 看完整細節 | 抽屜往上拉（或點把手）：地盤（誰控制、這一季的易手、在這裡療傷打造買馬便宜還是貴）、敵情與勝算、龍頭人物、醫館鐵匠鋪馬市、劇情 |
| 安排前往 | 在抽屜第一行按「步行」或「疾行」。之後留在輿圖，抽屜第一行變成「往 X・還有 N 分鐘・喊停」（草圖沒有畫這一格） |
| 出陣、探索 | 點自己所在的地點（或按 ◎），抽屜第一行變成「出陣・攻／守（今日還能 N 次）」與「探索（找素材・找事件・靜心）」 |
| 疊資訊 | 點上面的濾鏡。「勢力」預設開著；「敵情」在地名底下多一行勝算，「路程」多一行幾分鐘，「劇情」在地名前面加 ★、✦。可以同時開幾個 |
| 找自己 | 按右上的 ◎：飛回你所在的地點、選好它 |
| 找地點、找人 | 點搜尋框：抽屜拉到全開，結果照大區分組，寫誰佔著與幾分鐘。可以打地名、大區、人物（打「波才」找到黃巾別部營寨）。點一筆就飛過去、選好它 |
| 看三條戰線 | 抽屜收著時就是三條小橫條。往上拉，每條戰線一條繩子：可易手的地點排在門檻上，黑線是戰況；旁邊寫這一週往哪邊走（例「▶ 黃巾推進 6」） |
| 去出陣 | 抽屜收著時的第二行「⚔ 出陣：今日還能 3 次・最近的是 X（攻／守）」，點了飛過去 |
| 看這一季的版圖變化 | 按「⏱ 版圖變化」：<br>- 地圖自動拉到整張，抽屜變成一排 1～12 週，有易手的週次右上角有小點；<br>- 點一週、拉滑桿、或按「▶ 從頭看」（每 0.8 秒一週）；<br>- 地圖照那一週重新著色，那一週易手的地點會閃一圈紅；抽屜列出那一週的大事與每一處易手；<br>- 地圖上方一條紅色提示「正在看第 N 週的版圖・回到現在」 |
| 桌機 | 輿圖這一頁不受 640 欄的限制：地圖佔滿左邊，抽屜變成右邊固定的一欄 |

## 七、推薦：A，並從 B 借年表

**推薦 A 大圖加抽屜**，理由：

1. **量到的十五個問題，A 幾乎全部直接解掉**（P10 部分）。最痛的三個是：點了看不到（P1、P2）、地圖框太小（P3）、看不到大局（P5）。A 的解法最直接：抽屜、整頁地圖、拉遠變大局。
2. **留住已經做好的東西**：
   - 企劃者 10/4 從三個方向裡挑了設色山水，`mapart.py` 的地形、圖示、外框都還用得上；
   - 玩家已經學會的手勢（拖、捏、點）不用重學。
   - B 與 C 都等於丟掉那張圖重來。
3. **工程量最小**：
   - 伺服器的 `mapview` 照留，只要多送一份小的 JSON（控制方、勝算、分鐘數），網頁自己疊上去，換濾鏡、點地點就不必再抓整張圖（P7）；
   - 網頁的輿圖頁重寫成整頁加抽屜。
   - B、C 每個大區都要一份新的排法（可以自動推開再手調），C 的美術要全換。
4. **地盤易手的規則在 A 裡看得到**：抽屜的三條繩子就是 B 的拔河繩，門檻、亂局、這一週往哪走都在上面。

**從 B 借年表**：
- A 的「版圖變化」現在是一排週次加滑桿，看得到一週，看不出一整季。
- B 的年表（一列一個地點、一格一週）一眼看出「汝南荒野整季換了三手」。
- 建議 A 的版圖變化抽屜拉高時，滑桿下面接一張 B 那樣的年表。

**C 值得留著的**：水墨與印章是三個方向裡最有味道的，可以拿「印」的畫法給 A 的地點用（勢力用一顆小印取代暈開的顏色），看企劃者喜不喜歡。

## 八、選定之後要補的東西

- **地盤的歷史**：三個方向的「版圖變化」都要知道每一週的控制方。
  - 現在 `WorldState.territory` 只存此刻。
  - 要在換週（或易手）時存一份快照；放在季的 JSON 裡，結構版本不動。
  - 草圖裡的歷史是照規則算的假資料。
- **輿圖的資料改成兩層**：
  - 底圖（山水、路、地點）一季只抓一次；
  - 疊層（控制方、勝算、分鐘數、劇情記號、你在哪）是一份小的 JSON。
  - 這是 P7 的解法，A、B、C 都需要。
- **找地點**：伺服器給一份「地點、大區、常出沒的人物、幾分鐘」的清單，網頁自己搜尋。
- **安排前往之後留在輿圖**（P12）：現在是跳回江湖頁，改了要先跟企劃者確認（江湖頁的路上選項也要能從輿圖做）。
- 顏色（官軍藍、黃巾黃、豪強綠）、字句（「此刻由誰控制」「朱批」等）都待 joy 潤。

## 九、草圖的假資料怎麼來的
