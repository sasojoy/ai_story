## 零、一句話

三個陣營各三次晉升，每次都由一位大勢人物召見、親自出面；你得走到他面前，演完這場戲才算晉升。戲裡的選擇不決定升不升，決定的是他怎麼看你，有兩則還暗暗牽動時刻表上的大事。

---

## 一、共通規則 【定】

| 題目 | 決定 |
|---|---|
| 怎麼觸發 | 個人隱藏進度跨過門檻（第 3、4 階還要完成機緣）時，收到一道**召見**（「皇甫嵩召你到長社營中」）。沒有期限 |
| 什麼時候晉升 | **要親自走到那個地點、演完奇遇才晉升**。召見之後進度照樣累積，只是身份要等奇遇演完才改 |
| 第 4 階 | 奇遇在**取得資格時**發生（機緣完成、召見、演完），劇本的用詞配合「候缺」；每週上任另外發一則陣營軍情，不再演一次（5.4） |
| 選項 | **奇遇是儀式，不是考試**：每個選項都會晉升，差別在情誼、小獎勵與伏筆 |
| 部下 | 在奇遇裡交到你手上：第 2 階 2 人、第 3 階 3 人、第 4 階 4 人，都是原創的無名人物（5.5） |
| 時局 | 選項的後果照**抵達當下**的時局算（例：第 8 週以後才去見何進，拒賄就不再影響盧植） |
| 人物不在 | 每則寫主版與**接手版**：出面的人退場、重創、下獄或離開時，由接手那條戰線的同陣營大勢人物出面，劇情骨架不變、只換人與幾句話。召見發出後人物才不在的，召見自動改由接手的人發 |
| 叛投 | 取消還沒去的召見；身份歸零，在新陣營重新晉升，看到的是新陣營的奇遇 |
| 傳聞 | 照第一季設計 5.3：升第 2 階的每天彙整成一則陣營軍情；升第 3、4 階的每次單獨一則、寫名字。在演完奇遇的那一刻發 |

## 二、官軍 【定】

### 2.1 升第 2 階（屯長）：長社考校

- **出面**：皇甫嵩，在長社。
- **接手版**：朱儁（皇甫嵩重創或離開潁川時）。朱儁出身寒門，最在意實在；三個選項的反應改成他的口吻，最好的仍是第二個。
- **場景**：「長社營中。皇甫嵩不問你殺過幾個賊，只指著轅門外跪著的一個鄉勇：『他偷了百姓一隻雞。往後你就是屯長了，你怎麼處置？』」
- **選項**

| 選項 | 反應 | 效果 |
|---|---|---|
| 「按軍法，斬。」 | 「軍法是要守的，但為一隻雞斬一個兵，下一仗誰替你衝？」 | 皇甫嵩情誼 +3 |
| 「杖二十，賠雞，再罰他替那戶人家挑一個月的水。」 | 皇甫嵩微微一笑。（他治軍嚴明又愛惜士卒） | 皇甫嵩情誼 +10 |
| 「一隻雞而已，放了吧。」 | 「營規鬆一寸，賊就近一丈。」 | 皇甫嵩情誼 −3 |

- **結尾**：兩個鄉勇被叫到你面前：「從今天起，他們跟你。」晉升屯長，得到 2 名部下，解鎖「招募鄉勇入隊」「招降黃巾散兵」（5.5）。

### 2.2 升第 3 階（軍司馬）：盧中郎的奏表

- **出面**：盧植，在盧植營（冀州）。
- **跨兩個地點**：在盧植營領到奏表，**送到洛陽宮城才算晉升**。
- **場景**：「盧植把一卷竹簡交給你：『廣宗旦夕可破，只缺雲梯與糧。這份奏表，你親手送進宮去。』」
- **送到宮門**：守門的黃門伸手要竹簡，說奏表要先過他們的手。

| 選項 | 結果 | 效果 |
|---|---|---|
| 「照規矩交給黃門」 | 奏表照常遞上去，石沉大海 | 無 |
| 「轉去大將軍府，請何進代呈」 | 外戚樂得讓宦官難看，奏表很快遞上 | 冀州戰況往官軍偏 1【預設】 |
| 「塞錢給黃門，請他快些」 | 奏表遞上了；盧植事後知道 | 銀兩 −20；盧植情誼 −10（他寧可功虧一簣也不肯低頭） |

- 「轉去大將軍府」要多走一站（宮城到大將軍府）。
- **結尾**：晉升軍司馬，得到 3 名部下，解鎖「向大勢人物請命、接機密軍令」（5.5）。
- **接手版**：盧植第 8 週下獄或退場後，改由**董卓**在盧植營召見。他託你送進大將軍府的不是奏表，是一份厚禮：

| 選項 | 效果 |
|---|---|
| 「照送」 | 董卓情誼 +5 |
| 「勸他別送」 | 董卓情誼 −5；旁白：「董卓瞇起眼看了你半晌，把禮收了回去。」 |
| 「私下扣下來」 | 銀兩 +30；董卓情誼 −15 |

- 這個接手版順便示範董卓「貪功跋扈的苗頭」，以及人物誌寫的性情漂移：玩家多數「照送」，就是在助長他。

### 2.3 升第 4 階（校尉，候缺）：校尉印綬

- **出面**：何進，在大將軍府。
- **場景**：「何進親手把校尉的印綬放進你掌心：『本將軍向來賞罰分明。等有了缺，你就領兵。』出了府門，一個小黃門跟上來，笑著說印綬要在宮裡『登記』，才算數。」
- **選項（第 8 週以前）**

| 選項 | 效果 |
|---|---|
| 「給他。」 | 銀兩 −50；盧植下獄的機率 +5% |
| 「拒絕。」 | 盧植**不**下獄的機率 +5% |
| 「回府告訴大將軍。」 | 同拒絕；何進情誼 +5，但他只說「此事……容後再議」（優柔寡斷） |

- **這是一般伏筆**【定；數字預設】：每人只算一次，全服合計上限 ±20%，只影響第 8 週「盧植下獄」照百分比結算的那次擲骰；有人鎖定關鍵伏筆時不起作用（伏筆文件 4.4）。
- **第 8 週以後的變體**：小黃門照樣索賄，但盧植的事已經定了，選項只剩銀兩與情誼的差別。拒絕時多一句旁白：「你想起廣宗城下那個寧可下獄也不肯低頭的人。」
- **結尾**：取得第四階資格（候缺），得到 4 名部下；每週照最近一週的貢獻排名上任（5.4），上任後解鎖戰略方針與會戰時指揮一條戰線（5.5、第六節）。
- **接手版**：何進重創時，改由潁川或冀州的官軍主將（皇甫嵩、朱儁）在營中授印；索賄的換成一位來營中的監軍宦官，選項不變。
