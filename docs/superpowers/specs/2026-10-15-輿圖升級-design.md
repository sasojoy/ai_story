# 輿圖升級（A 優化版）設計

**企劃者 10/15：「A 優化版，先用這版試試」。** 這一份把草圖 `2026-10-15-輿圖升級-草圖/a2.html` 寫成要做進遊戲的樣子；畫風用 a2 預設的**甲 精緻設色山水**（乙、丙先不做，之後要換再說）。草圖 README 的「A 優化版改了什麼」是同一件事的說明，問題清單（P1～P16）在 README 第一節。

範圍：輿圖的**操作**（拖、縮放、點地點、詳情、安排前往、濾鏡、找自己、找地點、圖例、小地圖、手機單手）與**美術**，加上**勢力版圖**與**這一季的版圖變化**。規則面（地盤易手、全圖開放、出陣、探索三選一）照它們的設計文件，這一份不改任何規則與數值。

---

## 一、畫面（手機 375 寬為主）

- **輿圖這一頁整頁都是地圖**：
  - 頂上照舊是遊戲的狀態列；
  - 現在地圖上面的「⏳ 時刻・體力」卡、圖層分段、地點下拉選單、地圖下面的詳情卡都拿掉；
  - 地圖從狀態列底下一路到底部分頁列。
- **地圖左上**：一條搜尋框「🔍 找地點、找人物」，底下一排濾鏡：勢力、軍令、敵情、路程、劇情、「⏱ 版圖變化」。
- **地圖右上**：三顆鈕：◎ 我在哪、＋、－。
- **底部抽屜**：疊在地圖上、可以拉高拉低，有四種高度：
  - 收著（約 230px）；
  - 半開（約 240px，點地點時）；
  - 拉高（可用高度的六成）；
  - 全開（九成多，找地點時）。
  - 把手拖了放開吸到最近的高度；點一下把手在「收著或半開」與「拉高」之間切。
- **手勢照舊**：一指拖、兩指捏、滾輪縮放；點一下選地點（不移動視圖）；倍率從整張的三成到 2.2 倍。
- **圖例拿掉**：濾鏡本身就是圖例（每顆濾鏡前面一個色點，跟地圖上的小牌子同色）。

## 二、美術（甲 精緻設色山水）

現在的設色山水（`mapart.py`）往上一層：

| 東西 | 現在 | 改成 |
|---|---|---|
| 紙 | 平的紙色 | 加絹紋（雜訊濾鏡）、四角壓暗 |
| 山 | 一層青綠山頭 | 兩層：後面一座淡的遠山、前面深的近山，山脊一筆亮線 |
| 河 | 一條色線 | 外深內淺兩層（黃河照舊土黃） |
| 官道 | 粗虛線 | 雙線（褐色外框、紙色內芯） |
| 州界 | 虛線 | 點劃線（長、空、點、空） |
| 大區名 | 只在角落 | 寫在地圖上（大字、拉開字距、半透明），跟著縮放 |
| 地點 | 照標籤的小圖示 | 圓盤裡寫一個字（城、營、寺、渡、山、野），雙圈；外圈照控制方上色 |

地點的字照地點標籤挑：城鎮「城」、營寨「營」、寺院書院道觀「寺」、渡口「渡」、山林「山」，其餘「野」。現在的小圖示（城牆、營帳、屋頂…）不再用在輿圖上，小地圖照舊。

## 三、地圖上的記號

- **勢力**（濾鏡「勢力」，預設開）：
  - 每個有控制方的地點底下一圈那一方顏色暈開；
  - 大區照「這一區最多地點歸誰」淡淡著色；
  - 兩方地盤相接的路畫成紅色鋸線，短的路（200 以內）中間加 ⚔。
- **地點**：圓盤、字、地名（地名在圓盤右邊，13px）；你所在的地點後面加「（你）」，插一面紅旗、外面一圈紅色會慢慢擴散。
- **濾鏡疊成地名底下一排小牌子**，一種一個顏色：
  - 軍令（預設開）：「令 守城」紅、「賞 討伐」橘；
  - 敵情：勝算（穩勝、有把握綠，五五波、難分勝負黃，凶險、必敗紅）；
  - 路程：「N 分」灰；
  - 劇情：「★主線」「✦傳聞」紫。
  - 可以同時開好幾個。你所在的地點不掛小牌子。
- **選取**：點了的地點外面一圈黑框。
- **字的大小固定**：縮放時字、圓盤、小牌子在螢幕上大小不變（照倍率反算）。

## 四、看大局（拉遠）

倍率低於 0.62 時換成「看大局」：
- 地名收起來，地點變成那一方顏色的小點；
- 每個大區寫名字（大字）、一條三色長條（官、巾、豪各佔幾處）與「官 3・巾 1・豪 1」；
- 地圖上方浮一條「天下」：官、巾、豪各佔幾處，比開季多幾處少幾處。

## 五、抽屜

### 收著：今天去哪裡出陣

1. **今天去哪裡出陣**：最多三個建議。
   - 候選是你此刻能出陣的戰線地點（`sortie.mode` 不是 None）。
   - 排法：有你這一週的軍令在那裡記功的 +100、有你揭著的懸賞在那裡交差的 +50、勝算（穩勝 30、有把握 20、五五波 10、其餘 0）、減去步行分鐘數。
   - 每一個寫：地名、出陣・攻／守／攪局、為什麼（軍令・X、懸賞・X、勝算）、幾分鐘；點了飛過去、選好它。
   - 沒有任何候選時（散人、出陣關著）這一段不畫。
   - 第一行寫「今日還能 N 次・你在 X（誰的地盤）」。
2. **三條戰線**：
   - 每條一根繩：左官軍、右黃巾，斜線是亂局，黑線是戰況；
   - 繩上那一線可易手的地點畫成小方印（誰佔著）；
   - 繩名旁寫這一週往哪邊推（「▶ 黃巾推進 6」「◀ 官軍推進 3」「持平」）；
   - 底下一行寫割據。
   - 第一季規則關著的季沒有三條戰線，這一段只寫黃巾聲勢一根。
3. **本週大事**：這一週時刻表上的大事（第一季才有）。

### 點一個地點：先看三格

- **第一行**：控制方的小印、地名、大區、危險度。
- **三格**：
  - 誰佔著（可易手／大本營）；
  - 打得過嗎（勝算；出陣是攻還是守）；
  - 多遠（步行分鐘；疾行的體力）。
- **動作一排**：
  - 不在這裡：「步行 N 分」「疾行（立刻到・體力 M）」，照 `travel_options`，被事件擋著時照現在的寫法（灰的那顆寫是哪一則，旁邊一顆「回江湖」）。
  - 在這裡：「出陣・攻／守（今日還能 N 次）」與「探索」，都是回江湖頁按（按鈕跳到江湖頁、展開那一格）。
- **拉高才看的細節**，照順序：
  - 軍令與懸賞；
  - 地盤（誰控制、在這裡療傷打造買馬便宜還是貴、一條 12 格的色帶是這個地點整季每一週誰佔著、易手的週次）；
  - 站在這裡的隊伍與勝算、常出沒的人物；
  - 此地有什麼（醫館、鐵匠鋪、馬市）；
  - 劇情（主線目標、最近的大事與傳聞）。

### 找地點、找人物

點搜尋框，抽屜拉到全開：
- 一個輸入框；結果照大區分組（由北到南）、組裡近的在前；
- 每一筆寫控制方的小印、地名、常出沒的人物、步行幾分鐘（你在這裡寫「你在這裡」）；
- 可以打地名、大區名、人物名；
- 點一筆飛過去、選好它。

### 在路上

安排前往之後**留在輿圖**（企劃者 10/15 同意照草圖做）：
- 抽屜第一行變成「往 X・還有 N 分鐘・喊停」，「喊停」就是江湖頁那一顆（`act:halt`）。
- 地圖上照現在畫你在路上的位置。
- 江湖頁照舊能處理路上的事（邊走邊想、沿途打聽、折返……）。

## 六、天下怎麼變（版圖變化）

按「⏱ 版圖變化」：
- 搜尋框與濾鏡收起來，勢力打開，地圖拉到整張、放在抽屜上面那一塊；
- 地圖上方一條「正在看第 N 週」；
- 抽屜（約可用高度的六成）由上往下：
  1. 標題「天下怎麼變・第 N 週週末」，右邊「▶ 播放」「回到現在」「✕」。
  2. **天下大勢曲線**：
     - 三條戰線與割據，一週一點；
     - 斜線帶是亂局，還沒到的週打灰；
     - 有時刻表大事的週次上面一個 📜，紅色直線是正在看的那一週；
     - 點曲線選週。
  3. **各方地盤數**：三個色塊，寫那一週官、巾、豪各佔幾處、比開季加減多少。
  4. **年表**（B 的）：
     - 一列一個可易手的地點（照戰線分組，廣宗另一組），一格一週；
     - 顏色是那一週誰佔著，白點是那一週易手，還沒到的週打斜線；
     - 點表頭的週次或任何一格選週，點地名在地圖上框出來。
  5. **那一週**：時刻表的大事、每一處易手（從誰到誰）。
- 選了別的週：整張地圖照那一週的控制方重畫，那一週易手的地點外面一圈紅色會閃。
- 「▶ 播放」從第 1 週每 0.9 秒走一週走到現在；「回到現在」回到這一週；「✕」收起。

規則關著的季（沒有三條戰線）：曲線只畫黃巾聲勢；地盤開關關著時沒有年表，這一塊只寫「這一季沒有地盤易手」。

## 七、桌機

輿圖這一頁不受遊戲 640px 那一欄的限制：
- 地圖佔滿左邊，抽屜變成右邊固定一欄（360px，整欄高、自己捲），沒有把手；
- 版圖變化時地圖照樣拉到整張。
- 寬度不到 900px 時照手機的排法。

## 八、其他

- **江湖頁的小地圖**：點小地圖上的某個地點，打開輿圖、選好那個地點（P14）；點其他地方照舊只打開輿圖。
- 網頁一打開輿圖、每 30 秒（輿圖這一頁開著時）、做了任何動作之後，重抓一次疊層；底圖一次載入期間只抓一次（開放的地點變了才重抓）。
- 偏好減少動態效果的人：不閃、不飛（直接跳過去）、抽屜不滑。

## 九、資料與伺服器

- **底圖**（`GET /api/map/base`）：一張 SVG，只有紙、大區、山、河、路、大區名，不畫地點與字。
  - 照「這一季開放的地點」快取，劇情開放了新地點才換；
  - 另附地點（id、名字、座標、字、是否大地點、大區）、路、大區（名字、中心）的清單給網頁畫記號；
  - 回應帶一個 `key`，網頁照它判斷要不要重抓。
- **疊層**（`GET /api/map/state`）：一份 JSON，網頁自己畫記號、抽屜與年表：
  - 每個地點：控制方、可易手／大本營、勝算、出陣是哪一種、步行分鐘與疾行體力、軍令與懸賞、主線與傳聞、常出沒的人物、醫館鐵匠鋪馬市、地盤福利那一句、站的隊伍；
  - 你：在哪、在路上的話往哪、還有幾分鐘、出陣今天還剩幾次；
  - 三條戰線、割據、各方地盤數、本週大事；
  - 今天去哪裡出陣（伺服器排好的三個）；
  - 版圖變化要的每一週（下一條）。
- **地盤每一週的快照**：
  - `TerritoryState.weeks`（週次 → 那一週的控制方、三條戰線的值、割據），存在季的 JSON 裡，資料庫結構不動（第 5 版）；
  - `territory.update` 每次重算時把「這一週」那一格蓋成此刻的樣子，所以一週結束時就是週末的樣子；
  - 沒記到的週（舊存檔、那一週什麼都沒動）照前一週補；
  - 開季（`open_season` 清地盤）一起清。
- **安排前往**（`POST /api/travel`）照舊，網頁出發之後留在輿圖、重抓疊層。
- **舊的** `GET /api/map`（整張 SVG＋詳情文字）網頁不再用，保留一版給相容，之後拿掉。
- 引擎裡新的模組 `tianxia/mapdata.py` 組這兩份資料（純資料，不 import 網頁框架、不讀時鐘）；底圖的 SVG 由 `mapview.render_base` 畫。

## 十、不做的

- 乙（印與旗）、丙（古輿圖）兩種畫風。
- 戰線走勢箭頭畫在地圖上（只在繩名旁寫這一週往哪邊推）。
- 在輿圖上直接按出陣、探索（按鈕帶你回江湖頁）。

## 十一、待 joy 潤、待對

- 三方的顏色：官軍藍、黃巾黃、豪強綠，地盤暈色與色帶。
- 字句：「今天去哪裡出陣」「天下怎麼變」「正在看第 N 週」「往 X・還有 N 分鐘」、三格的標題、濾鏡名。
- 地點的一個字（城、營、寺、渡、山、野）。

## 十二、驗收

- **手機 375×812**：
  - 點一個地點，不捲動就看得到名字、誰佔著、勝算、分鐘與「步行／疾行」，地點不會從手指底下移開；
  - 拉遠看得到每一區誰佔幾處；
  - 「⏱ 版圖變化」整張地圖與年表同時看得到。
- **桌機 1280×800**：地圖佔滿左邊、右欄是抽屜。
- 安排前往之後還在輿圖、抽屜寫還有幾分鐘、喊停按得下去。
- 開關關著（地盤、出陣）時輿圖照樣能用：沒有勢力就不畫暈色與前線，沒有出陣就不畫「今天去哪裡出陣」。
- 疊層的 JSON 一次不到 40KB；底圖一次載入只抓一次。
