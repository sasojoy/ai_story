## 一、定位

**一句話**：一個由玩家寫下結局的文字武俠江湖。每個賽季都是一段新的江湖史，你的名字可能就寫在其中。

**設計來源**：
- 取自《三國志・戰略版》的三個優點 **【定】**：
  1. 策略大於操作（自動戰鬥、配置決勝）
  2. 賽季制（定期重來、每季不同）
  3. 適合上班族的節奏（體力制、零碎時間）
- 取自《金庸群俠傳 Online》的世界模式 **【定】**：玩家就是一名俠客，在開放的江湖中自由遊歷。

**主軸** **【定】**：以「江湖大勢」（世界進度）為心臟。幫派爭霸是集體推動大勢的主要舞台，個人奇遇讓小人物也能改變江湖。

**目標玩家**：喜歡策略遊戲但沒空長時間在線的成年玩家；喜歡武俠小說與文字冒險、重視故事與想像空間的玩家。

**形式** **【定】**：純文字。省下美術成本，專注在世界觀與玩法。

## 二、世界觀

- **背景** **【定】**：虛構朝代「大胤」末年，朝廷衰弱、無力管轄江湖，各方勢力趁勢而起。每個賽季都是「亂世中的一段江湖」，不受任何原著約束。
- **版權原則** **【定】**：
  - 地理使用傳統地名（中原、江南、蜀中、西域、塞北、荊楚、閩粵、關中、齊魯……）。
  - 門派可用傳統通用名稱（少林、武當、峨嵋、丐幫……）。
  - **武學、人物、秘笈名稱全部原創**，不得使用金庸等作品的專有名詞。
- **調性** **【定】**：寫實江湖——刀劍無眼、人心險惡，但有俠義與情誼。
- **文字風格** **【定】**：近似武俠小說旁白，簡潔、有畫面感。每則事件一到兩百字，適合手機閱讀。

## 三、核心循環

### 3.1 循環

```
體力（隨時間恢復）
  → 選擇行動（移動、歷練、探索、交遊……）
  → 文字事件，2～4 個選項
  → 每個選擇讓數值增減（屬性、武學熟練、聲望、善惡、金錢、世界進度……）
  → 機率觸發奇遇；個人累積推進全服的江湖大勢
```

### 3.2 體力 **【預設】**
- 上限 150，每 5 分鐘恢復 1 點（約 12 小時回滿）。
- 目的：公平（限制肝度）、節奏（每天幾次零碎時間）、控制世界進度的推進速度。

### 3.3 行動 **【預設】**
| 行動 | 消耗 | 效果 |
|---|---|---|
| 移動 | 體力（依路況） | 前往相鄰地點 |
| 歷練 | 體力 | 戰鬥與磨練，提升屬性，**累積當地的大勢進度** |
| 探索 | 體力 | 搜索當地；事件與奇遇的主要來源 |
| 交遊 | 體力 | 拜訪 NPC、門派任務、結交同伴 |
| 閉關 | 時間（不耗體力） | 指定時數修練武學，期間不能行動 |
| 派遣 | 不耗 | 派同伴辦事，一段時間後回報 |

### 3.4 文字事件 **【定】**
- 每個選項都要有**取捨**，不能有明顯的最佳解。
- 選項可以要求特定屬性、武學或身份才會出現。
- 選項可以開啟後續事件（事件鏈）。

範例：
```
【瘦西湖畔】
一名醉漢跌跌撞撞撞上了你，懷中掉出一塊刻著狼頭的鐵牌。
他慌忙撿起，眼神閃過一絲驚恐。

  1. 一把扣住他的手腕，逼問鐵牌來歷（膽識＋，可能開戰）
  2. 裝作沒看見，暗中跟蹤（消耗 10 體力，觸發追蹤事件）
  3. 扶他起身，順手摸走鐵牌（身手判定，惡名＋1）
  4. 不予理會，繼續賞景
```

### 3.5 戰鬥 **【定】**
- **一般遭遇**：自動結算，只顯示簡短結果。
- **關鍵戰鬥**（強敵、奇遇、大勢事件）：回合選擇式。每回合從「強攻、以巧破力、固守、施展絕招、撤退」等選項中挑一個；結果由屬性、武學、陣法、選擇與隨機共同決定，以文字描述過程。

### 3.6 一天的典型節奏
- 早上 5 分鐘：用體力歷練或探索，派同伴跑商。
- 午休 10 分鐘：處理事件，回應幫派集結，看江湖傳聞。
- 晚上 15 分鐘：主要探索與關鍵戰鬥；睡前閉關 8 小時。

## 四、江湖大勢與賽季（主軸）

### 4.1 賽季結構 **【定】**
- 一季 **11～13 週**，每季完全重來（跨季保留見第十節）。
- 每季抽一個**主題劇本**，劇本內有**骨架**，**走向由玩家推動**。

```
序幕：風起（約 2 週）     開荒、拜師、認識江湖；大勢線緩慢起步
第二幕：群雄（約 4 週）   幫派成形、爭奪據點；第一批門檻事件觸發
第三幕：決戰（約 4 週）   大勢線對抗，高層區與秘境開啟
終局（約 1～2 週）         結局收束、結算、寫入江湖史；選擇遺志、退隱
```
- 大勢推進得快，決戰可能提早到來，因此季長有彈性。
- 每次換幕都要有明顯的世界變化（新區域、新勢力），緩解中段疲乏。

### 4.2 大勢線 **【定】**
- 每個劇本有 3～5 條大勢線，各有 0～100 的進度值。
- 大勢線分為**公開**與**隱藏**。隱藏線要等某位玩家觸發特定奇遇後才會浮現。

範例劇本「魔教復起」：
| 大勢線 | 公開／隱藏 | 推進方式 |
|---|---|---|
| 魔教勢力 | 公開 | 在西域歷練並選擇邪道事件；魔教陣營幫派佔領據點 |
| 正道聯盟 | 公開 | 剿滅魔教分舵；門派掌門結盟 |
| 前朝寶藏 | 隱藏 | 有玩家以極低機率拿到第一片藏寶圖殘卷後才浮現 |

### 4.3 推進方式 **【定】**
- **累積**：每次歷練、選擇、佔領都讓相關大勢線小幅前進（所有人都能參與）。
- **躍進**：稀有奇遇讓進度一次大幅跳升（「一個人改變江湖」的時刻）。
- **對抗**：大勢線之間可互相拉扯（例如魔教上升壓制正道）。

### 4.4 門檻事件 **【定】**
- 大勢線達到門檻時觸發全服世界事件，例如「魔教勢力達 30 → 光明頂開放，高層區解鎖」。
- **哪條線先到門檻，決定下一幕的方向**，所以同一劇本每季走向都不同。

### 4.5 江湖傳聞與江湖史 **【定】**
- 重大事件全服廣播為「江湖傳聞」。觸發者可選**具名或匿名**。
- 賽季結束時，依各線最終狀態產生**結局**，連同關鍵人物寫入永久的**江湖史**。

## 五、地圖

### 5.1 結構 **【定】**
- 7～9 個大區，分為三個層級：高層區 1～3、中等區 1～3、新手區 2～6。**各層數量每季可不同**。
- 每個大區底下有 **30～100 個有名字的地點**，全圖約 300～800 個地點。
- 新手區在外圍，高層區在核心。

### 5.2 規則與呈現 **【定】**
- **底層規則仿沙盤**：每個地點都是可佔領的領地；**連地**——幫派只能攻打與己方領地相鄰的地點；關隘與渡口是咽喉要道；地點有等級與產出。
- **表面用文字呈現**：

```
【揚州城】 屬：江南・由「青龍幫」控制
城中繁華，運河上船隻往來不絕。
近日傳聞：黑風寨的人在城外劫了一趟鏢。

相鄰地點：
  → 鎮江渡口（無主）
  → 瘦西湖（青龍幫）
  → 黑風寨（赤焰盟）⚔ 交戰中
```

### 5.3 區域開啟途徑 **【定】**
| 途徑 | 例子 |
|---|---|
| 武力 | 幫派攻破劍門關，蜀中對所有人開放，但關隘由該幫控制 |
| 世界進度 | 藏寶圖湊齊，「崑崙秘境」出現，全服傳聞 |
| 個人奇遇 | 某玩家發現秘道，只有他和他告訴的人知道（資訊即資源） |

### 5.4 內容撰寫分級 **【預設】**
- **重要地點**（每區 5～10 個）：手寫完整描述、專屬奇遇與人物。
- **一般地點**：範本加參數產生描述（例如「山林、險峻度高、有獸類出沒」）。
- 開發時以 AI 輔助產生初稿，人工修飾後存入設定檔（見第十一節）。

## 六、武學系統（三層結構）**【預設】**

企劃者尚無具體想法，先採用以下結構，原型後再調整。

**第一層：個人武學**
- 欄位：內功 1、外功 2～3、輕功 1、心法 1。
- 屬性相剋：內功分陰陽剛柔，招式分快慢虛實，形成相剋關係。沒有無敵的配置。
- 武學有「成數」（第一成～第十成）作為熟練度。

**第二層：流派套裝**
- 湊齊同一流派的武學觸發額外效果。
- 散人混搭有「雜學」優勢，與入派者形成不同的強項。

**第三層：陣法**（企劃者提議）
- **陣位**：陣眼、攻位、守位，各有效果與需求（例如陣眼須內力最深者擔任）。
- **規模**：小陣 2～3 人（自己加同伴）、中陣 5～7 人（組隊、強敵）、大陣數十人（幫派戰、守關）。
- **陣法相剋**；某些武學專門破陣（攻擊陣眼）。
- 門派有專屬陣法；散人可從奇遇學得奇門陣法。

配置示意（武學名稱皆為原創範例）：
```
【你】 內功：玄陽心經（陽・剛）  輕功：追風步
       外功：流雲劍法、綿掌      心法：以柔化剛
       → 觸發「流雲真傳」：柔性招式威力提升
【同伴・峨嵋女俠】 內功：金頂心法  外功：拂柳手 ……
```

## 七、門派與幫派

### 7.1 門派 **【定】**（混合制）
- **入門派**：穩定學到完整武學體系，有門派任務、資源與同門支援；須守門規，也會捲入門派恩怨。
- **當散人**：自由、不受約束、什麼都能學，但武學要自己一門門去找。
- **叛出師門**：可以，但會被追殺。
- **偷學**：可以偷學他派武功，被發現後果嚴重。

### 7.2 門派與幫派的關係 **【定】**
- **分工**（第一版）：門派是 NPC 組織（NPC 掌門、長老）；幫派是玩家組織。一人可同時屬於一派一幫，兩者可能產生矛盾。
- **門派內晉升**（賽季內目標）：外門 → 內門 → 真傳 → 長老；**掌門之位由玩家競爭**，掌門能影響門派立場。
- **開宗立派**（長期夢想，後期實作）：幫派累積到一定程度可自創門派、編寫武學套路、收徒。

### 7.3 幫派 **【定】**
- 相當於三戰的同盟，是地盤爭奪與集體推動大勢的單位。
- **跨季存續**：名號、成員、歷史、階級保留；地盤、資源、庫存每季歸零。新季整幫「遷入」新江湖。

## 八、同伴 **【定】**

- 來源：奇遇、結交、收徒。每位同伴有個性與專長。
- **二選一**：帶在身邊一起戰鬥（可布陣），或派出去辦事（打探、押鏢、採集、經營）。
- 派遣中的同伴可能觸發自己的奇遇，回來帶回消息或事件。
- 同伴名冊跨季保留（見第十節）。

---

## 九、玩家互動（重度）**【定】**

包含幫派、地盤爭奪、PK、搶奪與恩怨。與體力制、上班族節奏的衝突用以下方式調和 **【預設】**：
- **離線防守**：玩家預設防守策略，被攻擊時由系統代打。
- **攻擊有代價**：PK 消耗體力；殺人累積惡名；惡名高會被官府通緝，正派玩家可領賞追殺。
- **損失有上限**：被擊敗只掉部分身上物品；有新手保護期與城鎮安全區。
- **恩怨紀錄**：誰殺過你、誰救過你都會留下紀錄，可能觸發專屬的復仇奇遇。
- **善惡與聲望** **【預設】**：行為累積善名／惡名，影響 NPC 態度、門派接納與可觸發的事件。

## 十、跨季傳承 **【定】**

**原則：收集跨季（寬度），培養當季（高度）。** 老玩家的優勢是選擇多、懂搭配，而不是數值碾壓。

| | 跨季保留（收集） | 每季重來（培養） |
|---|---|---|
| 武學 | 武學圖鑑（學過或見識過的） | 修練成數 |
| 陣法 | 陣譜 | — |
| 同伴 | 同伴名冊 | 好感度、實力 |
| 角色 | 族譜、稱號、江湖史 | 屬性、財產、身份與地位 |
| 幫派 | 名號、成員、歷史 | 地盤、資源、庫存 |

**遺志**：
- 預設每季可帶一項「遺志」給下一代角色，例如一門武學從第三成開始，或一位同伴帶著好感度加入。
- 遺志的優勢有上限，大約一個月內會被追平。
- 部分劇本是**無傳承的純公平季**。

**避免新手被擋在門外**：
- 收集來自遊戲本身而非抽卡；新手收集快、老手收集邊際遞減，差距會收斂。
- 強弱由相剋決定而非稀有度，基礎武學也有用。
- **新手福緣**：首季角色的奇遇機率較高。

**留存動力**：企劃者玩三戰的持續動力是「收集與培養」和「同盟的人」，對應本作的「圖鑑、名冊、族譜」與「幫派跨季存續」。

## 十一、AI 的角色 **【定】**

**規則引擎為主，AI 為輔。**
- **規則引擎決定一切數值**：體力、數值增減、大勢進度、戰鬥結果。原因是多人賽季遊戲必須公平、可平衡、快速，不能讓 LLM 的隨機性決定獎勵。
- **事件骨架寫在設定檔**：觸發條件、選項、數值增減、後續事件。
- **AI 的兩個用途**：
  1. **開發期**：大量產生地點描述與事件初稿，人工修飾後存入設定檔。
  2. **遊戲中（選用）**：把戰報、傳聞改寫得更生動；逾時或失敗時直接使用原始文字。
- 可沿用 `ai遊戲` 的 Ollama 經驗，但遊戲流程**不得依賴** LLM 的即時回應。

## 十三、原型（B）範圍

### 13.1 要驗證的三個問題
1. **體力 × 事件選擇的循環好不好玩？** 選擇有沒有取捨感、會不會膩？
2. **推動大勢有沒有「我改變了世界」的感覺？** 傳聞與門檻事件有沒有衝擊力？
3. **關鍵戰鬥的選擇有沒有張力？**

### 13.2 內容範圍
- **1 個大區**（江南），約 20～30 個地點，其中 5～8 個重要地點手寫。
- **行動**：移動、歷練、探索、交遊、閉關。
- **事件**：約 30～50 則手寫事件（含事件鏈與奇遇），加上一般地點的範本事件。
- **大勢**：1 條公開線 + 1 條隱藏線，含 2～3 個門檻事件、江湖傳聞與簡易的賽季結局。
- **戰鬥**：一般遭遇自動結算；關鍵戰鬥用回合選擇。武學只做第一層（欄位與簡化相剋）。
- **門派**：1～2 個可拜入的門派，含入派與散人的差異。
- **模擬玩家**：數名 NPC「虛擬玩家」按時間推動大勢線並產生傳聞，營造「別人也在改變江湖」的感覺。**不做真正的多人連線。**

### 13.3 測試用機制
- **時間快轉**：體力恢復速度、閉關時長與虛擬玩家的行動頻率可由設定檔調整，並提供除錯指令一次快轉數小時，讓試玩者不必真的等待。
- **存檔**：單機存檔即可。

### 13.4 技術方向 **【預設】**
- **Python**，沿用 `ai遊戲` 熟悉的技術：Pydantic 定義資料模型，Gradio 做網頁介面。
- **規則引擎與介面完全分離**：規則引擎是不依賴 UI 的純 Python 模組，之後產品階段換成真正的伺服器時可以重用。
- **內容放設定檔**（JSON）：地點、事件、武學、大勢線、劇本，方便不寫程式也能新增內容。
- **原型不接 LLM**；AI 輔助只用於開發期撰寫內容。
- 避免重蹈 `ai遊戲` 的上帝物件問題：狀態、規則、內容載入從一開始就分模組。

### 13.5 原型不做（留待試玩後）
幫派、地盤爭奪、PK、陣法、流派套裝、同伴與派遣、門派晉升與掌門、跨季傳承、多大區與區域層級、真正的多人連線、遊戲中的 LLM 改寫。
