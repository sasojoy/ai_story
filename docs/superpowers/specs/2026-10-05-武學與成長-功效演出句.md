## 一、佔位與寫法

| 佔位 | 換成 | 說明 |
|---|---|---|
| `{who}` | 出手的人的名號 | 功效只算你自己身上那兩門（13.1），所以一定是玩家本人；跟回合句型裡我方的出手者一樣寫名號 |
| `{art}` | 帶著這個功效的那一門的名字（不含括號） | 句子裡自己寫成「【{art}】」。內功、武學兩門都帶同一個功效時，由開發挑一門（例：層數多的那門） |
| `{foe}` | 對手的名字 | 可能是一個人（波才），也可能是一群人（黃巾散兵），句子兩種都要通 |

- **只在功效真的改到結果時才演**（13.6）。所以句子可以寫「破開了守勢」「撐成了僵持」這種有結果的話，不用像回合句型那樣兩頭都要通。
- **建議畫面**：一句獨立成行，前面標功效名，例：「〔先手〕沈浪搶得先機，【穿林腿】出手在前。」讓玩家看得出是哪個功效起了作用。
- **建議放的位置**寫在每節的表頭（開打前、受傷時、結果出來時、戰鬥外）；照開發的實作調整。
- 不寫數字（「兩次」「半步」「四平八穩」這類字也避開），約 22 字以內，繁體中文，不用別的作品的專有名詞。
- 每個功效三句，隨機挑或固定挑都可以。

## 二、八個一般功效（13.2）

### 2.1 開打前或第一回合前：先手、穩、破甲、險

| 功效 | 屬性 | 演出句 |
|---|---|---|
| 先手 | 快 | {who}搶得先機，【{art}】出手在前。 |
| 先手 | 快 | {foe}還沒站穩，{who}已經搶攻上去。 |
| 先手 | 快 | {who}起手極快，【{art}】先聲奪人。 |
| 穩 | 慢 | {who}以【{art}】步步為營，不給{foe}可乘之機。 |
| 穩 | 慢 | {who}沉住了氣，【{art}】守得滴水不漏。 |
| 穩 | 慢 | 任{foe}怎麼變招，{who}的【{art}】都不亂。 |
| 破甲 | 剛 | 【{art}】勢大力沉，硬是破開了{foe}的守勢。 |
| 破甲 | 剛 | {who}一記重手，打散了{foe}的架子。 |
| 破甲 | 剛 | {foe}的防備，在【{art}】面前像紙糊的。 |
| 險 | 虛 | {who}兵行險著，【{art}】專走險路。 |
| 險 | 虛 | {who}把勝負押在這一下，賭得極大。 |
| 險 | 虛 | 【{art}】出手大起大落，是福是禍全看這一下。 |

- 穩、險改的是運氣的起伏，可能幫上忙也可能幫倒忙，所以句子只寫打法，不寫賭贏賭輸。

### 2.2 受傷的那一回合：化勁、厚

| 功效 | 屬性 | 演出句 |
|---|---|---|
| 化勁 | 柔 | {who}以【{art}】卸去來勢，傷得輕了。 |
| 化勁 | 柔 | {foe}的力道撞上【{art}】，被化開了不少。 |
| 化勁 | 柔 | {who}順勢一讓，把勁力引到了一旁。 |
| 厚 | 實 | {who}帶著傷，【{art}】的架勢卻一點不散。 |
| 厚 | 實 | 傷得不輕，{who}的【{art}】仍然穩穩當當。 |
| 厚 | 實 | 氣血見底，{who}靠著深厚的底子硬撐。 |

### 2.3 打贏之後：乘勝、吸取

| 功效 | 屬性 | 演出句 |
|---|---|---|
| 乘勝 | 陽 | {who}越打越順，這一仗收穫格外多。 |
| 乘勝 | 陽 | 【{art}】打出了氣勢，{who}從中得益不少。 |
| 乘勝 | 陽 | 勝得痛快，{who}心中豁然開朗。 |
| 吸取 | 陰 | {who}趁勢運轉【{art}】，回了些氣血。 |
| 吸取 | 陰 | {foe}散逸的氣勁，被【{art}】收了過來。 |
| 吸取 | 陰 | 打完這一仗，{who}的氣血回補了些。 |

## 三、七個特別功效（13.4）

### 3.1 開打前或回合中：連環、借力

| 功效 | 演出句 |
|---|---|
| 連環 | {who}一招未盡，【{art}】又接上了後招。 |
| 連環 | 【{art}】招招相連，{foe}剛擋下就又來了。 |
| 連環 | 前招落空，{who}的後招已經到了。 |
| 借力 | {foe}越是兇猛，【{art}】越借得上力。 |
| 借力 | {who}借著{foe}的來勢，反手送了回去。 |
| 借力 | {foe}的勁力，被【{art}】一併借了過來。 |

### 3.2 受傷的那一回合：不動

| 功效 | 演出句 |
|---|---|
| 不動 | {who}運起【{art}】硬受了下來，臟腑卻沒傷著。 |
| 不動 | 皮肉雖痛，{who}的內息紋風不動。 |
| 不動 | 【{art}】護住心脈，這一場沒有留下內傷。 |

### 3.3 結果出來時：護命、悟招、回春

| 功效 | 演出句 |
|---|---|
| 護命 | 眼看要敗，{who}以【{art}】護住要害，撐成了僵持。 |
| 護命 | {who}守住最後一口氣，{foe}終究沒能拿下。 |
| 護命 | 緊要關頭，【{art}】替{who}擋下了要命的一下。 |
| 悟招 | {who}從這一仗裡又悟出些門道。 |
| 悟招 | 對拆之間，{who}對【{art}】又多懂了一層。 |
| 悟招 | {foe}的路數，被{who}記在了心裡。 |
| 回春 | 打完之後，{who}運轉【{art}】，氣血慢慢回了過來。 |
| 回春 | 喘息之間，【{art}】替{who}補回了些氣血。 |
| 回春 | 不論輸贏，{who}收功時氣色好了不少。 |

- 回春不論勝負都會回，所以句子不寫打贏。

### 3.4 戰鬥外：輕身

遊歷少花體力，是唯一在戰鬥外生效的（13.4）。建議接在遊歷的結果裡；沒有對手，所以只用 `{who}`、`{art}`。

| 功效 | 演出句 |
|---|---|
| 輕身 | {who}腳下輕快，這一趟省了些力氣。 |
| 輕身 | 【{art}】身法輕靈，走得比平常省力。 |
| 輕身 | 一路健步如飛，{who}還留著不少體力。 |

## 四、組出來的樣子

打贏的一場：

> 〔先手〕沈浪搶得先機，【穿林腿】出手在前。
> 第1回合　沈浪以【穿林腿】身形一晃，搶到側面出手，對手氣勢 -34；黃巾散兵掄起兵刃猛砸過來，你氣血 -12。
> 〔化勁〕黃巾散兵的力道撞上【基礎吐納】，被化開了不少。
> 〔乘勝〕沈浪越打越順，這一仗收穫格外多。

本來要輸的一場：

> 第3回合　山匪頭目嘶吼著迎頭撞來，你氣血 -40；沈浪以【坐山拳】穩穩踏前一步，招式沉而不亂，被對方架開。
> 〔護命〕眼看要敗，沈浪以【坐山拳】護住要害，撐成了僵持。
