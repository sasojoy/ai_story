# 輿圖簡化：真實地形、翻地與爭搶、兩層輿圖（設計）

**企劃者與設計討論 session 談的（2026-10-20 晚，三版）。** 起因是領地爭奪第一批的「輿圖中立地甲乙對比圖」：企劃者「我不太滿意，我覺得這個輿圖資訊以及表達的涵義太過複雜」。談到後來不只是記號太多——企劃者要的是**輿圖整個大改**。中間走過「三圈同心的天下」（第二版），企劃者仔細想過之後**退回**：「不應該切成一個環形的方式設計地圖，應該復原之前的仿造真實地形的方式。只是這樣就需要再思考以及設計翻地的原理以及如何吸引玩家進行互相爭搶領地的設計。」所以這一份寫三件事：**地理照舊是仿真實地形**（第三章）、**翻地與爭搶怎麼設計**（第四章）、**輿圖怎麼畫**（第五章：兩層、不自由縮放）。草圖與每一輪挑的圖在 `2026-10-20-輿圖簡化-草圖/`（環形那兩輪留著當紀錄，已作廢）。

跟程式對不上時以程式為準；數字凡是標【預設】的都是待調的佔位，不是定案。字一律待 joy 潤。

## 零、一句話

地圖照舊仿真實地形；一塊地白天誰都能推、推滿當場翻、翻了冷卻一小時；兩邊推到同一塊就是混戰（撞上就打）、約好一起推有集火加成、攻下與守住都分紅；輿圖只畫兩張不縮放的圖——天下圖看形勢、前線與正在翻的地，區圖看腳下這一區，其他的全收進點了才攤開的卡。

## 一、企劃者定的【企劃者】

照談的順序，原話在引號裡：

1. **輿圖第一眼只答兩件事**：「先是要能清楚知道自己在哪裡，這個點的資訊可能領悟的意境，或者打怪的經驗之類的。再來是要能清楚分辨現在是屬於哪塊陣營的領地，是基礎資源領地還是高級資源領地這些」。
2. 現在的問題是「第一眼看到資訊很混亂，搞到分不清那些資訊是代表什麼含意」。
3. 風格：三種風格草圖（古輿圖、戰棋版圖、極簡節點）裡「一比較符合，但我覺得有點太陽春了」；加料三版裡選「**一甲的山水＋一乙的印章框與羅盤**」（現在遊戲裡的設色山水當底，大城地名加印章框，左下角羅盤）；再收線之後選「**清甲＋清乙的框**」，然後改成「**平時清乙，多一個塗層濾鏡，打開的時候變成清甲**」（平常沒有領地淡彩、誰的領地看地名框的顏色；一顆「塗層」濾鏡開了才多一層融成一片的淡彩）。
4. 「但老實說這樣看起來線條跟圓圈感覺又太多，很容易看不出資訊」→「但其實我更希望的是輿圖能大改」→ 兩個大改方案裡選**方案一「兩層輿圖」**（天下圖＋區圖），不選行軍卷；天下圖「大區要能看出前線在哪」。
5. 「整個地圖設計要稍微調整，你看這些灰色沒人的地方有些根本只有連接在黃巾軍」——中立地的擺法要讓兩邊都碰得到。
6. 三圈同心（參考三國志戰略版）談了一輪之後**退回**：「仔細想了之後我們不應該切成一個環形的方式設計地圖，應該復原之前的仿造真實地形的方式。只是這樣就需要再思考以及設計翻地的原理以及如何吸引玩家進行互相爭搶領地的設計。」
7. 「所有季共用一張輿圖。錯的，不共用～只有設計的理念是通用的～但整個輿圖的地點以及圓形這些都有可能搭配劇本～變成多方陣營（三～四）～調整」——通用的是理念與畫法，地理跟著劇本（3.3）。
8. 翻地：對「每天投票、晚上一場攻城戰太像排程，白天看不到地在動；搶到了也沒什麼好處」的診斷：「你說的都很對」。「**推滿當場翻是好的**，但本來是想類似小決戰這樣能製造多人混戰，但單人累積貢獻計算好像也不錯，讓大家能分工或者集合火力」。
9. 混戰要不要真的打到人：選 **(b) 撞上就打**（出陣時對面剛好有人在推這一塊，照截殺的規則跟他打一場）。
10. 「如果是隨時都可以推的話，那就會變成剛被翻掉的領地可能要過一個小時之類的時間才能重新被翻，這段時間領地內的加成會先暫停，等時間過了才開始啟用」——翻地後的冷卻與加成暫停。

## 二、目標、不做、反目標

- **目標**：玩家打開輿圖的那一刻，一眼知道（a）我在哪、這裡給我什麼（悟什麼、對手是誰），（b）這裡是誰的領地、基礎還是高級；再多看一眼知道天下打成什麼樣、前線在哪、哪一塊正在翻、寶在哪。每一次出陣都看得到地在動；搶到一塊地有名有利；兩邊推到一起就打起來。
- **不做**：不改地理的畫法（仿真實地形照舊）；不定數字（都是【預設】）；不動戰鬥、懸賞、軍令本身——只動它們在輿圖上怎麼呈現與翻地怎麼接。
- **反目標**：又長出一排濾鏡或一堆小牌子；為了「資訊完整」把拿掉的東西塞回地圖；翻地變成排程（投票、等公告、等晚上）；地名或記號在 375 寬互相壓到、要縮放才看得清；把地圖切成環形棋盤。

## 三、地理：仿真實地形（環形作廢）

### 3.1 照舊

- 地圖照現在的仿真實地形（`content/map.json`、`locations.json`、`mapart.py` 的山水）：五個大區（幽州、冀州、洛陽、潁川汝南、南陽）、42 處地點、現有的路。三圈同心、青州東郡陳留鹿台這些新州新地點**作廢**；出生點照舊（兩軍出序章都在潁川郡）；投靠點照舊（第二版「投靠點只在外圈」作廢）。
- 區塊種類照領地爭奪設計 3.1：陣營區塊（基礎資源、開季就是自家）、中立區塊（高級資源、開季中立、搶下留著）；哪幾處是哪一種照設計 4.1 與計畫 2.1，**但要照 3.2 重排**。
- 玉璽碎片照領地爭奪設計 3.9 與裁決第 13 條：藏在開季中立的區塊（第二版「核心機率最高」作廢，沒有核心）。

### 3.2 中立地要讓兩邊都碰得到

企劃者看到的問題（第一章第 5 條）：幽州、冀州的灰地只貼著黃巾。解法不是環形，是**在真實地形上重排區塊表**：每一個中立區塊都要有一條路從官軍開季持有的領地走得到、也有一條路從黃巾的走得到（不穿過不是區塊的地點，照設計 3.2「相連」的定義），而且兩邊開季碰得到的中立地數量相近（裁決第 2 條「目標各 6～7 塊」）。做法是調整開季的歸屬與連線（例如把幽州、冀州那幾處貼著黃巾的中立地換成黃巾的陣營區塊、把兩軍之間的地點改成中立），不是搬地理。重排後的名單列給 PM 對。寫一條測試守住：每個中立區塊兩軍各至少一條路走得到。

### 3.3 地理跟著劇本（通用的只有理念）

- **通用的**：兩層輿圖（天下圖＋區圖、不自由縮放）、一張卡、塗層濾鏡、翻地的規則——這是畫法與玩法，哪一個劇本都一樣。
- **跟著劇本的**：地點、大區、連線、每一塊是哪一種區塊、誰的投靠點、幾方陣營、每一方的顏色——都是劇本的內容資料（`content/scenario.json`、`map.json`、`locations.json`）。這一季（三國篇第一季黃巾之亂）是官軍、黃巾兩方；之後的劇本可能是三～四方。
- **程式不能寫死**：陣營數、每一方的顏色、「官巾」、「藍黃灰」——一律從劇本讀。天下圖的地面顏色與前線照劇本的陣營畫：一方一色、沒有控制方一色；任兩方相接就是前線。區圖的印章框顏色同一套。翻地的規則（第四章）對任何兩方都成立。
- 同一個劇本裡規則開關不同的季（領地爭奪關著、地盤關著、14 天只有黃巾聲勢）也用新畫法（5.6）；不是「所有季共用一張地圖」。

## 四、翻地與爭搶

取代領地爭奪設計 3.6、4.3、4.4 裡「每天投票選目標、22:00 公告、晚上一場攻城戰才易手」那一套（第一章第 8 條，企劃者同意診斷）。規則對任何兩方都成立（3.3）。

### 4.1 推滿當場翻

- 每一塊**碰得到**的敵方或中立區塊（跟自家此刻持有的領地相連，設計 3.2）一條進度 0～100（第一批已經有：`conquest` 的攻城目標進度，往攻方為正）。沒有目標清單、沒有投票：相連的每一塊都隨時能推。
- 推：出陣・攻推進度，出陣・守拉回。一下推多少照第一批的公式（計畫 2.3：`progress_scale` × 攻 1／守 `hold_share` ÷ √人數），次數照出陣的一天 `per_day` 次；貢獻照舊記。
- **進度到 100 當場易手**：天下大事一句、江湖史一筆、地圖立刻變；進度歸零、換守方。不等晚上。
- **翻地後的冷卻**【企劃者】：剛翻的地〔預設 1 小時現實時間〕內不能再被推（進度鎖住、鈕上寫「剛易手，N 分後才能再推」）；這段時間**這塊地的領地加成暫停**（設計 4.5 的探索、療傷、打造加成；中立地的高階回饋、碎片照設計 3.3 留著但同樣等冷卻過），時間到了才啟用。
- 沒人推的地每個季曆日往守方回〔預設 10〕，免得半推的地擺著不動【我替他定的】。
- 大本營打不下來、廣宗照時刻表（裁決照舊）。

### 4.2 看得見誰在推、集火有加成

- 區圖點一塊，卡上列「正在推這裡的人」：「官軍 3 人正在攻（映雪 +12、…）、黃巾 2 人在守」——同「此地還有」的名單（`presence_seconds` 之內出陣過這一塊的人、各推了多少）。分工自然發生：一眼知道哪裡缺人。
- **集火**：同一塊地〔預設 1 小時〕內每多一個人推，每一下多〔預設一成、最多五成〕；守方同樣算。約好一起推比各推各的快，這就是「集合火力」的理由。

### 4.3 混戰：撞上就打【企劃者選 (b)】

- 出陣時對面剛好有人在推這一塊（〔預設 10 分鐘〕內對這一塊出陣過攻或守），就照**截殺的規則**跟他打一場（`Game.raid` 那一套：本人對本人單次判定、新手期、同一對冷卻、被截過的護身都照舊）：贏的那一下推得多〔預設乘 1.5〕、輸的這一下白跑（體力照扣、不推）。
- 只撞得到**正在推**的人（10 分鐘內有出陣紀錄），下線的、站在那裡沒推的不會被撞——這跟截殺「下線也殺得到」不同，混戰是戰場上的事。
- 城鎮類地點也打【我替他定的】：對方是在出陣，不是躲在城裡；截殺「城鎮不能動手」那條只管截殺。
- 兩邊同時在推的塊在天下圖上標「激戰」（紅光一閃一閃）、進度條兩頭拉。這就是原本想用小決戰做的多人混戰——不用排時間，誰在線誰就在戰。

### 4.4 攻城戰留著當大招

- 進度到門檻〔預設 60〕時攻方主將（照領地爭奪 3.6 的主將定義）可以**下戰書**：當晚攻城時段（避開時刻表決戰前 30 分、後 45 分，裁決第 6 條）一場攻城戰（第二批 Task 11 的那一套：留守、守將、軍餉）。打贏直接翻（冷卻照 4.1）、打輸進度砍半。沒人下戰書就照推。
- 投票（裁決第 9 條的加權投票）與每天 22:00 的公告結算**不再需要**；每天的鐘只剩攻城時段這一件。這一條動到裁決第 9、11 條，列在第八章給 PM。

### 4.5 爭搶的動機

- **攻下分紅**：易手那一刻，這一輪（上一次歸零之後）推過進度的人照貢獻比例分銀兩、經驗、名望〔預設一塊地總額：中立地 銀 200・經驗 300・名望 20，陣營區塊減半；都待調〕；推最多的那個記一筆江湖史與行狀「某某率先攻入荒丘」（`annals` 的種類加一個）。個人的名字掛在地圖事件上。
- **守城功**：守方把進度從五成以上拉回零，同樣分紅（總額〔預設〕同攻下的一半）；拉回最多的記江湖史。
- **今日產出**：區圖每一塊的卡上寫一句「今日產出：玄鋼骨 ×1」這類（內容待 joy；資料來源是那一塊的掉落表與中立駐軍的高階回饋），讓人一眼知道搶這塊是為了什麼。高級資源地的強對手、高階回饋、碎片、站在自家領地的加成（設計 3.3、4.5）照舊。
- 軍令的攻城、守城照裁決第 11 條改讀：攻城＝這一邊此刻進度最高的那一塊，守城＝自家此刻被推得最高的那一塊【我替他定的】。

## 五、輿圖：兩層、不自由縮放

拿掉一張可以無限縮放的地理圖，換成兩張各自固定取景的圖。沒有捏合縮放、沒有看大局那一套（倍率 0.62 以下換畫法）、沒有圖例。

### 5.1 天下圖（打開輿圖第一眼）

整張天下一屏看完（現在的五個大區）。畫的東西，一樣一個意思：

| 記號 | 意思 |
|---|---|
| 大區的輪廓（不規則）＋底下淡淡的山水 | 天下的樣子 |
| 大區裡的地面：一方一色＋沒人佔一色（這個劇本：藍官軍、黃黃巾、灰沒人佔） | 照「離哪個地點最近」分給那個地點的佔領方；顏色與幾方從劇本讀（3.3）。草圖用小六角格拼，正式做法開發定：Voronoi、模糊暈色都可以，要求是一眼分得出每一種地面 |
| 一塊地的地面兩色拔河 | **正在翻**：進度幾成，攻方的顏色泛進來幾成（4.1） |
| 紅光一閃一閃 | **激戰**：兩邊同時在推（4.3） |
| 紅線 | **前線**：任兩方的地面相接的那一道 |
| 細墨線 | 有主與沒人佔相接的邊 |
| 金點（實心／空心） | 高級資源地（實心＝有人佔、空心＝沒人佔） |
| 大區名＋「官 N・巾 N・寶 N」 | 這一區幾處歸官、幾處歸巾、幾處高級資源（陣營數照劇本） |
| 紅點＋旗 | 你在哪 |

- 點一區進區圖。上面一排：「天下」、搜尋框、「⏱ 版圖」。
- 抽屜收著時一行：「你在 潁川汝南・潁川郡」＋「進入此區 ›」；拉開是你腳下這一處的卡（5.3）。
- 版圖變化（⏱）在天下圖上播：整張照那一週的佔領重畫，年表、曲線照輿圖升級設計第六節；規則面不動。

### 5.2 區圖（點一區、或從抽屜「進入此區」）

只畫這一區的地點，固定取景，所以圖示、字、框都可以比現在大。畫的東西：

| 記號 | 意思 |
|---|---|
| 現在遊戲裡的設色山水當底（`mapart.py`），線收掉 | 底圖。大區界的點劃線不畫；三種路（官道虛線、雙線大路、小路）統一成一種淡淡的實線 |
| 地點的墨筆小圖（城、營、寺、渡、山、野） | 地點是什麼（取代圓盤裡的一個字） |
| **印章框**：每個地名裝在一個框裡，框的顏色＝誰的（一方一色、沒人佔一色，顏色從劇本讀）；大城的框粗一點 | 誰的領地 |
| 印章框底下一條細進度條（攻方的顏色） | 正在翻、幾成（4.1）；剛易手的灰掉寫冷卻 |
| 朱印「寶」在名字旁 | 高級資源領地（開季中立的），不管此刻誰佔著 |
| 名字底下用意境的顏色寫「風」「火」（最濃的在前，最多兩個） | 這裡悟得到什麼 |
| 朱圈＋旗 | 你在哪 |
| 通到鄰區的路畫到邊上，寫「→ 南陽」 | 往哪裡出區 |
| 左下角羅盤 | 裝飾（企劃者挑的） |
| 上面一排：「‹ 天下」、大區名下拉、「⏱ 版圖」 | 切區、回天下圖 |

### 5.3 抽屜：一張卡

一打開就是你腳下這一處；點別處是同一張卡。由上往下：

1. 控制方的小印、地名（你在這裡加「（你）」）、右邊「★高級」（高級資源地才有）與距離（不在這裡時寫「步行 N 分」）。
2. 一句話：「官軍的基礎資源領地」「中立・高級資源領地，還沒有人佔」「官軍佔下的高級資源領地」「官軍大本營」「不在戰線上」；剛易手的接「剛易手，N 分後才能再推、加成暫停」（字待 joy 潤）。
3. **正在翻**（碰得到的敵方或中立區塊才有）：進度條、「官軍 3 人正在攻（映雪 +12、…）、黃巾 2 人在守」、集火加成幾成（4.2）。
4. 「此地能悟」：意境的牌子（現在的 `insightRow`）。
5. 「此地的對手」：站在這裡的隊伍與勝算；人物另一行。
6. 「今日產出」一句（4.5）。
7. 動作一排：在這裡是「出陣・攻／守（今日還能 N 次）」與「探索」；不在這裡是「步行 N 分」「疾行（體力 M）」；被事件擋著照現在的寫法；主將在門檻以上的塊多一顆「下戰書」（4.4）。
8. 拉高才看：軍令與懸賞、這一季誰佔過（色帶與易手）、地利、此地有什麼（醫館鐵匠鋪馬市）、劇情（主線目標、大事傳聞）。

輿圖升級設計第五節的「今天去哪裡出陣」三條建議、三條戰線的繩、本週大事：挪到這張卡底下、拉高才看【我替他定的】。「找地點、找人物」照舊是搜尋框全開。在路上：抽屜第一行照舊寫「往 X・還有 N 分鐘・喊停」。
