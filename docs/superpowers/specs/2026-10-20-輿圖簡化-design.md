# 輿圖簡化：三圈天下＋兩層輿圖（設計）

**企劃者與設計討論 session 談的（2026-10-20 晚）。** 起因是領地爭奪第一批的「輿圖中立地甲乙對比圖」：企劃者「我不太滿意，我覺得這個輿圖資訊以及表達的涵義太過複雜」。談到後來不只是記號太多——企劃者要的是**輿圖整個大改**，連地理都「可以打掉重新來過」。所以這一份寫的是兩件事：**天下怎麼重排**（三圈同心的概念）與**輿圖怎麼畫**（兩層、不自由縮放）。草圖與每一輪挑的圖在 `2026-10-20-輿圖簡化-草圖/`。

跟程式對不上時以程式為準；這一份不改任何數值。字一律待 joy 潤。

---

## 零、一句話

天下重排成三圈——外圈出生州（基礎資源、開季就是自家）、內圈中原（高級資源、開季中立、兩軍從外往裡搶）、核心藏玉璽；輿圖只畫兩張不縮放的圖——天下圖看形勢與前線、區圖看腳下這一區，其他的全收進點了才攤開的卡。

## 一、企劃者定的【企劃者】

照談的順序，原話在引號裡：

1. **輿圖第一眼只答兩件事**：「先是要能清楚知道自己在哪裡，這個點的資訊可能領悟的意境，或者打怪的經驗之類的。再來是要能清楚分辨現在是屬於哪塊陣營的領地，是基礎資源領地還是高級資源領地這些」。
2. 現在的問題是「第一眼看到資訊很混亂，搞到分不清那些資訊是代表什麼含意」。
3. 風格：三種風格草圖（古輿圖、戰棋版圖、極簡節點）裡「一比較符合，但我覺得有點太陽春了」；加料三版裡選「**一甲的山水＋一乙的印章框與羅盤**」（現在遊戲裡的設色山水當底，大城地名加印章框，左下角羅盤）；再收線之後選「**清甲＋清乙的框**」，然後改成「**平時清乙，多一個塗層濾鏡，打開的時候變成清甲**」（平常沒有領地淡彩、誰的領地看地名框的顏色；一顆「塗層」濾鏡開了才多一層融成一片的淡彩）。
4. 「但老實說這樣看起來線條跟圓圈感覺又太多，很容易看不出資訊」→「但其實我更希望的是輿圖能大改」→ 兩個大改方案裡選**方案一「兩層輿圖」**（天下圖＋區圖），不選行軍卷；天下圖「大區要能看出前線在哪」。
5. 「整個地圖設計要稍微調整，你看這些灰色沒人的地方有些根本只有連接在黃巾軍」「這個整體設計要重新改過」「可以參考三國志戰略版的地圖設計概念，出生州是外圍一圈，高級資源地才是內圈」；「現在的地理也可以打掉重新來過」；出生點「確定整個地圖之後再來想想」。
6. 新地理兩個提案裡選**甲「同心圓天下」**，加兩條：「也要讓出生區直接相連」「出生地點就可以直接用選的」。
7. 最後：「不要真的弄成圓形那麼單調，概念上是這樣就可以了」——三圈是**概念**，畫出來照舊是不規則的州郡與山水，不是幾何圖。

## 二、目標、不做、反目標

- **目標**：玩家打開輿圖的那一刻，一眼知道（a）我在哪、這裡給我什麼（悟什麼、對手是誰），（b）這裡是誰的領地、基礎還是高級；再多看一眼知道天下打成什麼樣、前線在哪、寶在哪。領地爭奪的「搶中立地」在地圖上看得出為什麼要搶、往哪裡搶。
- **不做**：不改領地爭奪的規則數字；不在這一份定出生點的細節以外的序章改法（只寫「要搬」）；不動戰鬥、懸賞、軍令本身——只動它們在輿圖上怎麼呈現。
- **反目標**（做成這樣就是失敗）：又長出一排濾鏡或一堆小牌子；為了「資訊完整」把拿掉的東西塞回地圖；畫成一個正圓的棋盤（企劃者明說太單調）；地名或記號在 375 寬互相壓到、要縮放才看得清。

## 三、天下：三圈同心（概念）

### 3.1 圈與州

| 圈 | 誰的 | 州（現有的、新的） | 地點的性質 |
|---|---|---|---|
| **外圈・出生州** | 官軍（西半邊） | 洛陽、南陽 | 陣營區塊・基礎資源，開季就是自家 |
| | 黃巾（東半邊） | 冀州、青州〔新〕 | 同上 |
| **內圈・中原** | 開季中立 | 潁川、東郡〔新〕、陳留〔新〕、汝南 | 中立區塊・高級資源：強對手、高階回饋；被佔下留著、變成佔領方的好獵場（領地爭奪設計 3.3） |
| **核心** | 開季中立 | 鹿台〔新〕；嵩山深處、南華觀搬進來 | 高級中的高級；玉璽碎片**最可能**藏在這裡 |

- **玉璽碎片**【企劃者，審稿後定】：照領地爭奪設計 3.9 與裁決 13，所有開季中立的區塊（中原十二處加核心）都可能藏碎片，**核心的機率最高**；天下圖的朱印「璽」標的是「最可能的地方」，不是「只在這裡」。第三批 Task 14 的藏法照這條（機率在 4.8，核心加權）。
- **投靠點只在外圈**【企劃者，審稿後定】：官軍在洛陽、南陽各一處，黃巾在冀州、青州各一處。現在六個投靠點裡四個不在自家外圈，這樣搬：長社（官軍）與黃巾別部營寨（黃巾）改成中原的高級資源地（長社火攻照舊在長社打）；盧植營搬到東郡靠冀州那一側、南陽黃巾營搬到汝南靠南陽那一側（都是中原的中立地，當兩軍的前哨舊址，名字照留）。人物的開季站位（皇甫嵩、朱儁、傅燮、盧植、張曼成、趙弘、韓忠）、序章第十步「看投靠點」、宛城之戰與廣宗決戰的敵方主將所在都跟著搬——列在批 1。留著當飛地不行：開季兩軍就從飛地往對方家裡推，三圈與裁決第 2 條第一天就破。
- **每一個內圈郡都夾在一個官軍州和一個黃巾州之間**：潁川夾在洛陽與南陽之間（官軍近）、東郡夾在洛陽與冀州之間、陳留夾在冀州與青州之間（黃巾近）、汝南夾在青州與南陽之間。兩邊都碰得到、只是遠近不同——這就解掉了企劃者看到的「灰色沒人的地方有些根本只有連接在黃巾軍」，也自然滿足領地爭奪裁決第 2 條「開季兩邊碰得到的目標要差不多」。
- 幽州（涿郡、樓桑里、鄉里結社：桃園起點）併進冀州的最外側；豪強的三個據點照所在的圈歸屬（曹氏莊院在中原、鄉里結社與豪族塢堡在黃巾外圈）【我替他定的，見第七章】。

### 3.2 路

- **外環路**：四個出生州沿外環直接相連（洛陽↔冀州、冀州↔青州、青州↔南陽、南陽↔洛陽）【企劃者：「也要讓出生區直接相連」】。官巾相接的兩個口子（洛陽↔冀州、青州↔南陽）就是外圈的前線。
- **內環路**：中原四郡相連。
- **輻路**：每個出生州兩條往內（到它兩邊的內圈郡），每個內圈郡一條往核心。從任何出生州走到核心都是三步（州 → 郡 → 核心）。
- 「相連＝有路直通」照領地爭奪設計 3.2 的定義不變：能挑成目標的是跟自家此刻持有的領地相連的區塊。

### 3.3 地點

- 現有 42 個地點**留大半**，照新的圈歸屬；新加東郡、陳留、青州三個州與鹿台一處核心（地名在草圖裡標「（新）」，都是佔位，待 joy）。每州幾處、每郡幾處是【提案、目標不是硬砍】：出生州各 5、內圈郡各 3、核心 3；**序章、時刻表、伏筆鏈、門派、人物站位用到的地點一律留**（冀州＋幽州現在 12 處、潁川 12 處，多就多），地點 id 不刪（舊存檔站在消失的地點會炸），只搬座標與歸屬。最後名單由 PM 與 joy 對（領地爭奪裁決第 1 條的做法）。
- **州＝引擎的大區（`MapRegion`）一對一**：新地理是 9 個大區——洛陽、南陽、冀州（含幽州）、青州、潁川、東郡、陳留、汝南、核心。決戰集結的 `BattleDef.region`、伏筆片段的 `region`、人物 haunts、風聞、路上見聞、懸賞掛單都讀大區，所以潁川汝南拆開時這些都要跟著改（長社火攻改成 `yingchuan`）。核心自己一區，不是任何一條戰線的集結地。每個地點的 `train_trend`／`BlockDef.line` 在批 1 先照「最近的內圈郡」暫填（3.6 的線 PM 定了再改），批 1 不等它。
- 內圈與核心的地點全部是高級資源地（開季中立）；外圈全部是基礎資源地（陣營區塊）；大本營（投靠點）在外圈、打不下來（裁決照舊）。

### 3.4 出生州與出生點

- **出生點用選的**【企劃者】：建角色時在自己陣營的兩個出生州裡挑一個；散人在四個出生州任選【我替他定的】。
- 序章跟著搬到出生州（現在兩軍出序章都在潁川郡，那是未來的中原正中央）。序章內容怎麼搬、新手期在敵方領地療傷的那一條（裁決第 4 條）要不要留，等出生點定了再談——企劃者說「出生點確定整個地圖之後再來想想」。

### 3.5 畫出來不是圓

三圈是概念。天下圖照舊是不規則的州郡輪廓、山水、河、路（企劃者：「不要真的弄成圓形那麼單調」）。草圖裡的正圓只是說明圈怎麼分。

### 3.6 跟領地爭奪的接縫

- 區塊表（領地爭奪設計 4.1、計畫 2.1、`content/scenario.json` 的 `territory.blocks`）照第三章重寫：外圈 `guan`／`huang`、內圈與核心 `neutral`。
- **三條戰線的大勢值**（領地爭奪 4.7：每條線的值＝佔領的基準＋偏移）現在是潁川汝南、南陽、冀州三條；新地理沒有「三條線」這種形狀。【待 PM 定】：改成照四個內圈郡各算一條、或兩個半邊各算一條、或整個中原算一個總值。這一份只標出衝突，不定。
- 時刻表三場決戰的地點【我替他定的】：長社火攻留在潁川（中原、搶地的高潮）、宛城之戰在南陽（官軍外圈、黃巾打進家門）、廣宗決戰在冀州（黃巾外圈、官軍打進家門）。
- 中立地的「甲／乙畫法」（領地爭奪第一批 Task 6 末尾的對比圖）**作廢**：新輿圖沒有圓盤與虛線圈，高級資源地用朱印「寶」（區圖）與金點（天下圖）標，不管誰佔著都有。

## 四、輿圖：兩層、不自由縮放

拿掉一張可以無限縮放的地理圖，換成兩張各自固定取景的圖。沒有捏合縮放、沒有看大局那一套（倍率 0.62 以下換畫法）、沒有圖例。

### 4.1 天下圖（打開輿圖第一眼）

整張天下一屏看完。畫的東西，一樣一個意思：

| 記號 | 意思 |
|---|---|
| 州郡的輪廓（不規則）＋底下淡淡的山水 | 天下的樣子 |
| 州郡裡的地面：藍／黃／灰 | 照「離哪個地點最近」分給那個地點的佔領方：藍官軍、黃黃巾、灰沒人佔（草圖用小六角格拼，正式做法開發定：Voronoi、模糊暈色都可以，要求是一眼分得出三種地面） |
| 紅線 | **前線**：官與巾的地面相接的那一道 |
| 細墨線 | 有主與沒人佔相接的邊 |
| 金點（實心／空心） | 高級資源地（實心＝有人佔、空心＝沒人佔） |
| 朱印「璽」 | 核心：玉璽碎片**最可能**藏的地方（所有中立地都可能，見 3.1） |
| 州郡名＋「官 N・巾 N・寶 N」 | 這一州幾處歸官、幾處歸巾、幾處高級資源 |
| 紅點＋旗 | 你在哪 |

- 點一州進區圖。上面一排：「天下」、搜尋框、「⏱ 版圖」。
- 抽屜收著時一行：「你在 潁川・潁川郡」＋「進入此區 ›」；拉開是你腳下這一處的卡（4.3）。
- 版圖變化（⏱）在天下圖上播：整張照那一週的佔領重畫，年表、曲線照輿圖升級設計第六節；規則面不動。

### 4.2 區圖（點一州、或從抽屜「進入此區」）

只畫這一州的地點，固定取景，所以圖示、字、框都可以比現在大。畫的東西：

| 記號 | 意思 |
|---|---|
| 現在遊戲裡的設色山水當底（`mapart.py`），線收掉 | 底圖。州界的點劃線不畫；三種路（官道虛線、雙線大路、小路）統一成一種淡淡的實線 |
| 地點的墨筆小圖（城、營、寺、渡、山、野） | 地點是什麼（取代圓盤裡的一個字） |
| **印章框**：每個地名裝在一個框裡，框的顏色＝誰的（藍官軍、黃黃巾、灰沒人佔）；大城的框粗一點 | 誰的領地 |
| 朱印「寶」在名字旁 | 高級資源領地（開季中立的），不管此刻誰佔著 |
| 名字底下用意境的顏色寫「風」「火」（最濃的在前，最多兩個） | 這裡悟得到什麼 |
| 朱圈＋旗 | 你在哪 |
| 通到鄰州的路畫到邊上，寫「→ 南陽」 | 往哪裡出州 |
| 左下角羅盤 | 裝飾（企劃者挑的） |
| 上面一排：「‹ 天下」、州名下拉、「⏱ 版圖」 | 切州、回天下圖 |

- **塗層**濾鏡一顆（名字待 joy 潤）：平常關著；開了多一層照歸屬融成一片的淡彩（草圖「清甲」：暈色半徑大、邊緣模糊，看起來是一片不是一顆顆圓）。
- 點一個地點：抽屜半開、那一處的卡（4.3）；地圖不移動。

### 4.3 抽屜：一張卡

一打開就是你腳下這一處；點別處是同一張卡。由上往下：

1. 控制方的小印、地名（你在這裡加「（你）」）、右邊「★高級」（高級資源地才有）與距離（不在這裡時寫「步行 N 分」）。
2. 一句話：「官軍的基礎資源領地」「中立・高級資源領地，還沒有人佔」「官軍佔下的高級資源領地」「官軍大本營」「不在戰線上」（字待 joy 潤）。
3. 「此地能悟」：意境的牌子（現在的 `insightRow`）。
4. 「此地的對手」：站在這裡的隊伍與勝算；人物另一行。
5. 動作一排：在這裡是「出陣・攻／守（今日還能 N 次）」與「探索」；不在這裡是「步行 N 分」「疾行（體力 M）」；被事件擋著照現在的寫法。
6. 拉高才看：軍令與懸賞、這一季誰佔過（色帶與易手）、地利、此地有什麼（醫館鐵匠鋪馬市）、劇情（主線目標、大事傳聞）。

輿圖升級設計第五節的「今天去哪裡出陣」三條建議、三條戰線的繩、本週大事：挪到這張卡底下、拉高才看【我替他定的】。「找地點、找人物」照舊是搜尋框全開。在路上：抽屜第一行照舊寫「往 X・還有 N 分鐘・喊停」。

### 4.5 風格

企劃者一路挑下來：古輿圖（紙本、墨筆記號）> 現在的設色山水當底（一甲）> 印章框與羅盤（一乙）> 線收掉（清甲／清乙）。所以區圖的底就是 `mapart.py` 現在畫的那一套山水，只動記號那一層與路的畫法；天下圖是同一套山水淡淡地襯在底下、上面蓋州郡地面。深色主題時地圖本身照舊是紙色（輿圖一直是這樣）。桌機照輿圖升級設計第七節（不受 640px 那一欄限制）。

### 4.6 開關關著的季也是這一張（一套輿圖，不留舊的）

新輿圖取代**所有季**的輿圖，不只領地爭奪開著的季（裁決第 15 條：三批做完才在 `season21.json` 開，上線初期跑的多半是關著的季；兩套並存等於 `MAP_CHIPS`、看大局、視野那一套都要繼續養）。地面的顏色一律讀 `territory.controller`：官軍藍、黃巾黃、豪強綠（7 天測試季拔河加割據會有）、沒有控制方灰（`Config.territory` 關著時整張灰）；紅線只畫官巾相接，其餘相接畫細線；沒有三條線的季（14 天只有黃巾聲勢）天下圖照樣畫，區名底下的數字照控制方算。4.4 那一表的東西真的刪，不留給別的季。
