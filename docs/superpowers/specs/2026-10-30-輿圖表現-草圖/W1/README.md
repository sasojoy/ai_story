## 跟丙差在哪

1. **W2 的部分都還沒有**：打開的倍率（1.15，不是 1.5）、上面還是 Joy 的搜尋列與篩選籤、沒有區名 chip、🔍 圓鈕、小地圖、箭頭牌、底條（抽屜照舊是「從某處出發」那一排卡）；每一處都寫名字（丙只寫兩步內／要地／本週／寶／正在翻），名字是全名「潁川郡（陽翟）」，後面沒有「N 分」。
2. **危險度徽中景也掛**：W1 照派工單「近中景」都掛；設計 2.2 的密度（中景不掛）在 W2 照新的三段門檻做。
3. **沒有地塊的地點是一個圓**（設計 2.1「沒有地塊的地點」）：官軍大營、綠林山寨的座標落在所屬區外（地塊裁到區界會裁光），南華觀、曹氏莊院、鄉里結社、豪族塢堡不是區塊、沒有地塊——都拿半徑 60 的圓當地。丙的時候官軍大營沒有地，現在是一個藍色的圓；圓不裁區界、不算戰線，點圓也開那一處的卡。
4. **正在翻的中立地，內框是淡灰細線**：丙（`tools/slg5.js`）在這種地塊描紅框，跟「你的那一塊」的紅框太像；W1 照「內框是自己的顏色」，沒有主人就是沒人佔的那一種。
5. **可出陣的橘框全是淡的**：開季的新角色每一處出陣都是必敗（引擎的勝算），照設計畫淡一半；打得過的地方是實的（單元測試有）。
6. **地是向量的 SVG，不是 Joy 的點陣**：見下一節。

## 地為什麼改回向量（給 Joy 看）

Joy 2026-10-30 把地面畫成點陣（`#mk` 是一張 canvas），理由是水暈的濾鏡很重、大圖層上的混色讓 Safari 拖縮時破圖。第二版的地兩樣都沒有（不混色、沒有濾鏡），而地常駐之後近看也要畫：點陣是地圖的兩倍大，近看（倍率 1.5～2.4、手機兩三倍像素）要放大兩三倍，橘框、紅框的線會糊。所以 `#mk` 改回一張向量的 SVG，只在換了疊層、週次、倍率差過三分之一級時重寫一次，拖縮照舊只換 `#mvw` 的 transform。點一塊地照座標算是哪一處（`landAt`），這一層不收點擊。

量了一次（無頭 Chromium、375×812 兩倍像素、CPU 降速 4 倍，用 rAF 一幀一幀 `camSet` 模擬拖 120 幀、捏 160 幀，各跑三次；不是手機，只看相對）：

| 版本 | 拖：平均／p95／超過 33ms 的幀 | 捏：平均／p95／超過 33ms 的幀 |
|---|---|---|
| W1（向量的地，近看也畫） | 6.8／12／1 | 10.0／48～61／8～9 |
| S1（Joy 的點陣，近看不畫） | 6.4～7.2／6～12／1～2 | 9.5～10.1／30～42／7～8 |
| S1 開著塗層（點陣近看也畫） | 6.6～6.7／6～12／1 | 10.4～10.9／36～48／9～10（最長一幀 158ms） |

拖一樣；捏跟「塗層開著」的點陣差不多（捏的時候字那一層照舊會重排，兩版都有）。真的手機（尤其 iPhone Safari）要 Joy 或 QA 拿手機拖拖看；真的卡，退路是把 `groundSvg` 的輸出照舊烤成點陣（函式沒變，只換 `groundShow`），點地的熱區照座標算，不受影響。
