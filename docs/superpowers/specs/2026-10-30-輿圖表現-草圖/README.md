## 產生器（`tools/`）

- `compose_now.py`：把 `現況/` 的四張並排成 `現況-四層.png`（PIL，字型 `C:\Windows\Fonts\msjh.ttc`）。
- `compose_round.py <輪的資料夾名>`：把那一輪的幾張並排、上面寫甲乙丙丁與一句話，吐 `../<資料夾名>.png`；每一輪的面板寫在檔裡的 `ROUNDS`。
- `styles.js`：第 2 輪的三種風格。在登入後的輿圖分頁載入它（草圖時是用 scratchpad 裡的 `python -m http.server 8158` 餵給頁面，`<script src="http://127.0.0.1:8158/styles.js">`），再 `txMock('ink'|'board'|'text')` 就把地圖區整個蓋掉重畫，`txMockOff()` 還原。拿真的 `/api/map/base`、`/api/map/state`；山水（嵩山、桐柏山、伏牛山、潁水、一片林）是手填的座標，只為草圖；地名框互推（`relax`）是最簡單的那種，正式做要另外想。
- `board.js`：第 3 輪，沙盤這一套的三個畫面。載法同上，`txBoard('region')`、`txBoard('region', '<地點 id>')`（點一處）、`txBoard('world')`（天下），`txBoardOff()` 還原。山、林、河從 `/api/map/base` 的 `svg` 裡照顏色挑（峰 `fill="#557D69"`、林 `fill="#8FA877"`、河 `stroke="#6FA0C2"` 與黃河 `#C9A867`），名字牌的擺法在 `placeLabels`。
- 第 1 輪的乙、丙、丁是在真畫面上用瀏覽器 JS 改 DOM 截的（乙：藏 `g.n-faint`、`.tx-world-map` 的 transform 往右 60px、`g.n-label[data-id=luoyang_road]` 上移 50、`text.n-you-name` 改到城圖上面；丙：按 `.r-top [data-act="map-full"]`；丁：乙的那幾下再加藏 `text.n-sub`、圖往上 205px、`position:fixed` 的清單面板），沒有改任何程式檔。
- 預覽伺服器與資料庫的準備腳本在討論 session 的 scratchpad（`maptalk/prep.py`、`serve.py`：week7、埠 8157、`map.localhost`、`ollama_url` 指 `127.0.0.1:9`），做法同 `../2026-10-20-輿圖簡化-草圖/tools/`。
