## 修正輪（W2 審查 2026-10-31）

三位審查員對 `c4140079` 的發現，這一輪修的（測試先寫、修之前是紅的；改壞會紅的另外用變異試過）：

- **選中的名字不被自己那一圈擋住**（should）：選的、滑到的、下一站、終點那一圈照舊佔位、別的名字讓開，它自己的名字從「小圖連圈」的外框擺起。打開的取景裡兩步內每一處輪流當選中的（375、320），都是原本的字級、不壓圈（`test_w2_a_selected_name_is_not_crowded_out_by_its_own_ring`）。
- **收回底條時抽屜捲回頂上**（should）：收回一行那一格一律回頂、換到一排卡那一格也回頂；全開照留、一處的卡照 Joy 的（`test_w2_folding_the_drawer_back_to_the_tray_scrolls_it_to_the_top`；實機 W2-12）。
- **點擊範圍至少 40**（should）：見「跟丙差在哪」第 5 條（`test_w2_the_hud_and_the_tray_are_big_enough_to_tap`；實機每一張的 `reach`）。
- **名字掃描帶本週、翻、激戰，讓步上限分寬、分段**（should）：見上一節。拿掉旗的框、墨筆小圖框改回 y − 15、箭頭牌照 24 高排、區名 chip 的框改回 34 高，掃描都會紅。
