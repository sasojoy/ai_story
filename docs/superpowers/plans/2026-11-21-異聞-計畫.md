## 全域限制（每一批都照）

- 數值全由引擎決定：模型只寫兩段字、三個做法、一份帳；順逆、獎勵、足跡、定論、兆頭、對誰有利都是引擎。模型回的東西一律過程式檢查，不合格換引擎的替身句。
- 慢的模型呼叫不在行動鎖裡：三段式 A（鎖內只讀＋開單）→ B（鎖外 `shell.screen_text`、`shell.model_call`）→ C（鎖內重驗再套用）。鎖內不叫模型（不用 `_quick_client`）。
- 資料庫第 9 版不升；正文與樹在旁檔 `<db stem>-yiwen.sqlite`，表都是 `CREATE TABLE IF NOT EXISTS`，之後加表不 `ALTER` 舊表。
- 包只 import 核心（`MODULES`、`tianxia/core/`）、共用層（`SHARED`：`speech`、`zh`、`renown`、`ollama_client`……）、自己；不 import 探索包、商城包、江湖錄包（`tests/core/test_feature_boundaries.py`）。
- 開關 `Config.yiwen.enabled` 預設關（`tianxia/core/tuning/yiwen.py`）＋開季蓋章 `WorldState.yiwen_on`；判斷一律 `rules.on(content, world)`＝開關開著且這一季有章。季中打開下一季才有；季中關掉：撞見、開路、定論都停，眼前那一則的選單接管放手（見異聞一）。
- 新欄位一律 `Field(<預設>, json_schema_extra=QUIET)`，空的不寫鍵（`test_shell_stays_thin` 的 QUIET 名單會擋）。
- 包的路由第一行是開關的 gate，關著回 404（先於登入與參數解析，範本 `tianxia/features/mail/routes.py::_gate`）。
- 假人不撞見、不走、不開路、不買、足跡不算；任何畫面、傳聞、江湖史、API 回應、主控台輸出都分不出誰是假人（`web/` 連註解都不寫那三個詞，`tests/bots/test_server_bots.py` 掃）。總數不分真假。

- 這一包的世界那一格跑在 `catch_up_season` 的全服交易裡：讀寫旁檔的地方一律包住例外、記一行、下一步再試，**不准讓旁檔的錯撤回全服時鐘**（異聞四）。

- 設計稿不改 content JSON，開發照設計稿第三節的表轉檔進 `tianxia/features/yiwen/content/`（正式檔先放五句樣例）。
