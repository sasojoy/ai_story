> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 拿到第四階資格（計畫丙一的 `PlayerState.qualified`）的人，每週一照**上一週**的貢獻排名，前幾名上任（席次照伺服器人數上限換算，`factions.rank4_seats`）；上任的人是第 4 階（頭銜「校尉」「大方渠帥」「一方之主」），其他人保留資格、頭銜寫候缺、權限照第 3 階。有空缺時，剛拿到資格的人當下就補上。每週上任名單發一則陣營軍情，補缺的人另發一則。

**Architecture:** 新模組 `tianxia/seats.py`。排名要讀每個有資格的人上一週的貢獻，可是週一的掛鉤（`world.WEEK_HOOKS`）只拿得到共用的賽季、讀不到別人的存檔；所以每個有資格的人做完行動（`Game.choose`）與同步（`Game.sync`）時，把自己每週的貢獻抄一份到共用賽季的帳（`WorldState.seat_ledger`），週一的掛鉤照這本帳排。貢獻只會從自己的行動或同步時的結算來，所以帳不會落後。`ranks.rank_of` 在第一季照席次回 4。

## Global Constraints

- 開關：一律 `rules.season_one(content, world)`；開關關著時沒有席次，`rank_of` 照舊。
- 席次：每陣營 `factions.rank4_seats(content.config)`（人數上限 × `rank4_seat_ratio`，四捨五入，最少 1）。
- 每週一 00:00（季曆）照上一週（`week − 1`）的貢獻排名，前 N 名上任；同分時先拿到資格的人優先。上一週一點貢獻都沒有的人也排得進去（席次沒坐滿時，有資格就上任）。
- 資格整季有效；沒上任的人保留資格，下週再爭；掉出席次只是降回第三階的權限，不是懲罰（設計 5.4）。
- 有空缺時當下補上：拿到資格（或下一次行動）時，自己陣營的席次沒坐滿，就上任到下週一。這一條與「同分時先拿到資格的人優先」，企劃者 2026-10-06 同意。
- 上任的人：`ranks.rank_of` 回 4，頭銜是第 4 階的；沒上任的人照丙一寫「{第 3 階}（{第 4 階}候缺）」。
- 傳聞（傳聞分層 4.1）：每週上任名單一則陣營軍情（名單有變才發）；補缺的人一則。名字用存在帳上的顯示名（匿名寫「某位少俠」）。
- 叛投：從舊陣營的帳與席次拿掉（`defection.defect` 呼叫 `seats.leave`）；新陣營要重新晉升（`qualified` 計畫丙一已經清掉）。
- 換季：帳與席次跟著賽季清空（存在 `WorldState`）。
- 第 4 階的權限（戰略方針、占據郡縣、會戰指揮）不在這份，讀 `rank_of == 4` 的是計畫戊、庚。

## Review Focus

1. **不在線的人**：甲上週貢獻最高，但週一 00:00 他不在線，他上一週的帳在最後一次行動時就抄好了，照樣上任（Task 2 `test_rotation_reads_the_ledger_not_the_saves`）。

5. **開關關著**：`rank_of`、頭銜照舊，帳一筆都不寫（Task 1 `test_switch_off_no_ledger`）。

"""第四階席次與每週輪替（第一季設計 5.4；計畫 2026-10-06-第一季正式版-丁）。

有資格的人（PlayerState.qualified，計畫丙一）每週一照上一週的貢獻排名，前 N 名上任（N＝factions.rank4_seats）。
排名要讀每個人上一週的貢獻，可是週一的掛鉤只拿得到共用的賽季：所以有資格的人每次行動、同步時把自己每週的貢獻
抄進 WorldState.seat_ledger（report），週一照這本帳排（rotate）。有空缺時當下補上。只有第一季的規則開著才有。"""
from __future__ import annotations

import random

from . import factions
from .models import Content
from .rules import add_rumor, display_name, season_one
from .state import GameState

TITLES_RANK = 4


def _title(faction: str) -> str:
    from .ranks import TITLES  # noqa: PLC0415  ranks → seats：在函式裡 import，避免循環

    return TITLES.get(faction, ["", "", "", "", ""])[TITLES_RANK]


def seated(state: GameState) -> bool:
    """自己此刻在任嗎：有陣營、在那個陣營這一週的名單上。"""
    p = state.player
    return p.faction is not None and p.name in state.world.seats.get(p.faction, [])


def report(state: GameState, content: Content) -> list[str]:
    """抄帳（Game.choose、Game.sync 的最後呼叫）：有資格的人把每週的貢獻抄進共用賽季的帳、記下顯示名；
    自己陣營的席次沒坐滿、自己又還沒在任時當下補上，發一則陣營軍情、回傳給自己的那一句。"""
    p, w = state.player, state.world
    if not season_one(content, w) or p.faction is None or not p.qualified:
        return []
    w.seat_ledger.setdefault(p.faction, {})[p.name] = dict(p.contrib_weeks)
    w.seat_shown[p.name] = display_name(state)
    held = w.seats.setdefault(p.faction, [])
    if p.name in held or len(held) >= factions.rank4_seats(content.config):
        return []
    held.append(p.name)
    title = _title(p.faction)
    add_rumor(state, f"{display_name(state)}補上了{title}的缺。", content=content, layer="faction", faction=p.faction)
    return [f"你補上了{title}的缺，到下週一為止。"]

def rotate(state: GameState, content: Content, week: int) -> list[str]:
    """週一 00:00（world.WEEK_HOOKS）：每個陣營照上一週（week − 1）的貢獻排名，前 N 名上任；同分照帳上的先後（先拿到資格
    的優先）。名單有變才發一則陣營軍情「本週在任的校尉：甲、乙。」。帳上沒有人的陣營名單清空、不發字。"""
    w = state.world
    if not season_one(content, w):
        return []
    n = factions.rank4_seats(content.config)
    for faction, ledger in w.seat_ledger.items():
        order = list(ledger)
        ranked = sorted(order, key=lambda name: (-ledger[name].get(week - 1, 0), order.index(name)))
        holders = ranked[:n]
        if holders != w.seats.get(faction, []):
            names = "、".join(w.seat_shown.get(name, name) for name in holders)
            add_rumor(state, f"本週在任的{_title(faction)}：{names}。", content=content, layer="faction", faction=faction)
        w.seats[faction] = holders
    return []

def rank_of(state: GameState) -> int:
    """此刻的階：散人 0；投靠了就至少第 1 階（存檔裡記的是晉升過的階，投靠本身不寫）；有第四階資格而且這一週
    在任（seats.seated）是 4（正式版丁）。"""
    p = state.player
    if p.faction is None:
        return 0
    if p.qualified:
        from . import seats  # noqa: PLC0415
        if seats.seated(state):
            return 4
    return max(p.rank, 1)

```python
def leave(state: GameState, faction: str) -> None:
    """叛投時（defection.defect）：從舊陣營的帳與這一週的名單拿掉自己；空出來的席次，下一個有資格的人下次行動就補上。"""
    w, name = state.world, state.player.name
    w.seat_ledger.get(faction, {}).pop(name, None)
    if name in w.seats.get(faction, []):
        w.seats[faction].remove(name)
```
