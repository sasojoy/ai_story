# 傳聞分層（三）：刺探 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 別的陣營的機密只有打聽才拿得到（傳聞分層 4.2）。第一季裡，有陣營的人站在別的陣營的據點（投靠點）或別的陣營的大勢人物身邊，選單上多一個「打聽軍情」（體力 5、身法檢定 6）；成功時探到那一方這一週的一件機密——本週的主攻戰線、集中打擊的大勢人物、某道軍令的總額度湊到哪裡——這一週自己人還沒報過的，寫成一則自己陣營的軍情「【探子回報】{名號}在{地點}打聽到：…」；在那個大區有自家伏筆鏈「打聽」來源的片段時，有機會聽到一片（伏筆文件原本寫「刺探」、濃縮版先改成「行動」的那兩片換回來）。S1 的刺探軍令要用的兩個接口一併留好：個人部分 `orders.credit(kind="spy")`、達成時 `spying.report(..., spy=None)`。

**Architecture:**
- 新模組 `tianxia/spying.py`（純規則、只讀寫狀態，不 import engine、world、atlas）：`secrets`（機密＝被打聽那一方這一週還沒達成的軍令；來源是 `SOURCES` 裡的函式，一種機密一個，之後的計畫往裡加）、`spied_on`（在哪裡打聽得到哪幾方）、`report`（報回自己陣營的軍情；同一週、同一個陣營、同一件事只報一次，記在新欄位 `WorldState.spy_reports`，只留這一週的）、`odds`（成功率）。
- **「誰聽得到」不另寫一條規則**：機密平常就只在那一方自己的「本週軍令」與陣營軍情裡，1a 的 `rules.audible` 讓別的陣營、散人聽不到；帶回來的敵情是一則**自己陣營**的陣營軍情（`layer="faction"`），一樣照 `audible` 的陣營規則走——被打聽的那一方、散人都聽不到。1a 在 `rules.Ears` 留給 1c 的位置因此用不到（理由見「與其他計畫並存」）。陣營軍情的「要點」（`rumor_view.FACTION_KEYS`）多一個 `orders.SPY_REPORT`，所以「你不在的時候」也列刺探帶回的敵情（傳聞分層第八節第 2 項）。
- 引擎：`Game._spy_options`／`Game._spy`，走既有的 `_cost_option`（標籤寫體力與成算）、`roll_check`、`check_result_line`（跟事件的檢定同一套）。成功時呼叫 `orders.credit(kind="spy")`：現在沒有任何軍令認這個種類，什麼都不記；S1 的刺探軍令模板接上它就記得到。
- 伏筆：`FsSource` 多 `"spy"`；`foreshadow.hear_after_spy`（打聽成功才抽，機率是行動的 4 倍）；`content.validate` 檢查 spy 片段的大區真的打聽得到；`content/foreshadows.json`（不在 `content/events/` 底下）兩片的 `source` 換回 `"spy"`，文字一個字都不動。
- 假人：`bot_policy.ACT_SCORES["spy"] = 0.4`（低於探索、交友與遊歷的基本分：強度旋鈕挑最高分時輪不到，隨手挑時才偶爾打聽）；整季機器人（`bot.py`）照樣隨機挑。
- **第一季開關**：全部掛在 `rules.season_one(content, world)` 後面；關著（或這一季開季時沒蓋章）時沒有這個選項、沒有機密、`report` 回空、伏筆本來就不跑——beta 一個字都不變（每個任務都有開關關著的測試）。

**Tech Stack:** Python 3.14、pydantic、pytest。**不改網頁、不改 `server.py`**：新選項照既有的規矩收在江湖頁的「此地還能做 N 件事」摺疊裡（`web/app.js` 的 `actionBar`：不是那五格的選項都進摺疊），伺服器照選單送。

    if faction is None:

def spied_on(state: GameState, content: Content, loc_id: str) -> list[str]:
    """在這個地點打聽得到哪幾方的機密（劇本的順序）：這裡是那一方的據點（投靠點），或那一方在場的大勢人物此刻在這裡。

    faction = state.player.faction
    if faction is None or not active(state, content):

def report(
    state: GameState, content: Content, faction: str | None, about: list[str], rng: random.Random | None, *,
    spy: str | None = None, place: str = "",
) -> list[str]:
    """替 faction 探到 about 那幾方的一件機密，報回 faction 的陣營軍情（傳聞分層設計 4.2「帶回的敵情發在自己陣營的軍情」）。
    挑法：這一週 faction 還沒報過的機密裡隨機一件（rng 是 None 時照 SOURCES 的順序取第一件）；全都報過了，就從全部裡挑一件
    給打聽的人看，不再發一則（同一週同一件事只報一次：三千人時不會把軍情洗掉）。報過的記在 WorldState.spy_reports
    （「週:陣營:種類:軍令 id」，只留這一週的）。
    spy 是打聽的人的名號：給了就寫進那一則軍情，回傳寫給他看的幾行（探到什麼、報回去了沒）。不給（刺探軍令達成時，
    S1 的計畫呼叫）就發「【探子回報】{機密}」、回傳那一則的全文；沒有新的可報是空的。開關關著、散人回空的。"""
    if faction is None or not active(state, content):
        return []
    found = [secret for side in about for secret in secrets(state, content, side)]
    if not found:
        names = "、".join(faction_name(content, side) for side in about) or "對方"
        return [NOTHING.format(about=names)] if spy is not None else []
    w = state.world
    week = orders.week_of(state, content)
    w.spy_reports = [key for key in w.spy_reports if key.startswith(f"{week}:")]  # 只留這一週的：舊週的機密早就過時了
    prefix = f"{week}:{faction}:"
    fresh = [secret for secret in found if prefix + secret.key not in w.spy_reports]
    pool = fresh or found
    secret = pool[0] if rng is None else rng.choice(pool)
    seen = [FOUND.format(secret=secret.text)] if spy is not None else []
    if not fresh:
        return (seen + [KNOWN]) if spy is not None else []

    def _spy_options(self, loc: Location) -> list[Option]:
        """打聽軍情（傳聞分層設計 4.2；軍令文件 4.1 的「打聽」）：第一季、有陣營、這裡是別的陣營的據點或站著別的陣營的

        return [self._cost_option("act:spy", spying.OPTION, c.config.spy_stamina, note=rate_words(rate))]

    state: GameState, content: Content, region: str | None, rng: random.Random, world: WorldStateStore | None = None,
) -> list[str]:
    """打聽軍情成功之後（Game._spy 呼叫）：在打聽的那個大區，做得了、還沒聽過、來源是 spy 的自家片段裡隨機一則，
    機率 spy_fragment_chance（伏筆文件 2.2 第 4 條：在敵方地盤打聽到的是自家陣營鏈的片段，不會揭露敵方的伏筆）。

    if region is None:
        return []
    pool = [
        (c, i, f) for c in _capable_chains(state, content) for i, f in enumerate(c.fragments)

        return []
    c, i, f = rng.choice(pool)
    _mark_heard(state, c.id, i)
    return [fragment_line(_fragment_text(state, content, c, f, world))]
