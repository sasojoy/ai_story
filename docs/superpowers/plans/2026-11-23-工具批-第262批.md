**純函式**（wave_gate.py，放在 `compare_extra` 附近）：
- `js_rerun_plan(compare_text: str, name_status: str) -> dict`：回 `{"rerun": bool, "why": str, "tracks": [...], "profiles": [...], "files": [...], "first": {(軌,設定): [hb, hh]}}`。
  - (a) 解析所有「不一樣」的列（整段或半舊半新任一不一樣都算紅）；有紅的假人列、`Traceback`、沒有任何紅列、或紅列的軌不全在 `JS_TRACKS` → 不再跑，why 寫原因。
  - (b) `name_status` 是 `git diff --name-status base head`：`web/` 底下 `.js` 的行**全部是 `M`**（有 `A`/`D`/`R`/`C` → 不再跑，why「多了／少了 js 檔，script 清單會變」），至少一支 `M`。
  - 別的檔（tianxia/、index.html、css……）有差不擋 (b)：再跑時它們都留 base 的，若它們動到 facade 輸出，再跑照樣不一樣 → 紅。
- `js_rerun_verdict(plan, rerun_text) -> dict`：再跑的每一個 (軌,設定) 都「一樣」（半舊半新也一樣），而且再跑的 head 雜湊等於第一次的 head 雜湊（PM 認定：雜湊等於閘門裡 head 的那一個）→ `{"ok": True}`；否則 ok False、寫哪一格。
- `js_rerun(py, script, base_dir, head_root, tmp, plan, extra_flags, out_txt)`：`shutil.copytree(base_dir, tmp/"base_js")`，`plan["files"]` 每一支從 head_root 抄過去，跑 `same_behavior.py compare --base base_js --head head_root --tmp ... --tracks <plan.tracks> --profiles <plan.profiles> --no-bots`，加原本那次的 `--new`、`--also-existing`、`--crossover`（從 `compare_extra` 的結果挑這三個，不帶 `--cache`、`--covers`、`--bot-covers`），輸出寫 `compare_js.txt`，回文字。**不開伺服器、不用埠**（TestClient）。
**接在 main()**：`wait(running…)` 之後、compare 的 red 算完之後、`git worktree remove` 之前：`result["compare"]["code"] != 0` 才判；
`name_status = git(repo, "-c", "core.quotepath=off", "diff", "--name-status", base, head)`。plan 不再跑 → `result["compare"]["js_rerun"] = {"ran": False, "why": ...}`，照舊紅。
再跑 → `result["compare"]["js_rerun"] = {"ran": True, "tracks", "profiles", "files", "first": {"facade season21": [hb, hh]...}, "rerun": {...}, "ok"}`；
ok → `result["compare"]["code_first"] = 原碼`、`code = 0`；compare.txt 檔尾附一段「js 再跑：軌、換進的檔、第一次雜湊、再跑雜湊、結論」（把 compare_js.txt 接上）。不 ok → 照舊紅，兩份 txt 都留。
explore-compare 不受影響（不讀 js）。檔頭說明第 4 點後補一段「第 262 批」。

## 三、②走查：頁面外、固定定位、自己捲的層捲著拍

改法：**先找頁面外的層**：`document.body` 底下、`!el.closest("#app")`、`getComputedStyle(el).position === "fixed"`、`overflowY` 是 auto/scroll、`scrollHeight > clientHeight + 2`、visibility 不是 hidden、有寬高在畫面內。

不寫死 `#yw-pop`。建議把 SCROLLER 搬進 `snippets.mjs` 匯出（driver import），才測得到；搬時字串原樣。
