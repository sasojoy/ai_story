## 要 PM 定的

1. **FB-131：有好幾個字可選的種類，引擎接哪一個字**（槍或矛、棍杖錘、弩或弓、拳套護手拳；防具甲鎧袍衫）。
   - 建議：**兵器一律接 `weapons.NOUNS[種類]`（劍、刀、槍、棍、弩、拳套）；防具照這一件的屬性查表**：剛、柔 → 甲，快、虛 → 衫，慢、陰 → 袍，陽、實 → 鎧（`armor.FORGE_NOUNS`，待 joy 潤）。Task 1、2 照這個寫。
   - 理由：兵器有挑種類那一步，鈕上寫的就是 `NOUNS`（「棍」「弩」「拳套」），架上的現成兵器、退路字表、懸賞第二批的 `bounties._noun` 也都用這一個字；挑「棍」打出「…錘」、挑「弩」打出「…弓」會讓人以為打錯了（FB-133 已經在抱怨同一樣東西兩個叫法）。防具沒有挑種類那一步，字照屬性挑才有意思，而且架上四件已經是這個對法（鐵葉甲剛、軟皮甲柔、輕綃衫快、厚氈袍慢）；四個字都用得到（陽、實是兩個硬屬性合的，配「鎧」）。取名提示會先告訴模型最後接的是哪個字，模型可以照這個字湊前段。
   - 另兩種讀法：(乙) 照「天機|配方鍵」的雜湊從可選的字裡挑一個——一律、簡單，可是兵器會出現「挑棍得錘」，防具會出現慢屬性的「…衫」；(丙) 兵器也照屬性查表（例：棍的剛、實、慢接「錘」）——有味道，可是同樣有「挑棍得錘」，而且要再寫一張 joy 要潤的表。
   - PM 選乙或丙：只改 `weapons.noun_for`（多收配方鍵或屬性）、`armor.noun_for`、`smithing.noun_for` 的呼叫與 `content.validate` 驗兵器退路名的那一圈（要把每個可能接上的字都驗過），測試裡寫死「接 NOUNS」的那幾行跟著改。

2. **模型沒照提示寫的前段怎麼接**：寫了全名、前段本來就以「像兵器或衣物」的字結尾、或前段只有一個字。FB-131 記的失敗輸入正好是這一類：gemma4:26b 替棍取「重岩杵」、qwen 替劍取「斷霜刃」「寒霜刃」。只看「結尾是不是這一種的字、不是就接」會接出「重岩杵棍」「斷霜刃劍」「落星箭弩」「金縷衣鎧」這種兩個名詞疊在一起的名字（「刃」「杵」「箭」「衣」都不在字表裡）；前段只有一個字（「雷」→「雷劍」）、或兩個字而且本來就以同一種的字結尾（替拳套取「鐵拳」、替袍取「金甲」）會登記成兩個字的名字。這些都過得了 `name_problem`（2～6 字）；疊字的那幾個以前是退回字表，照「不是就接」會變成怪名字**永久**進全服登記表（兩個字的「雷劍」「鐵拳」現在的 `kind_problem` 就收，這一批一起擋）。
   - 建議（甲）：
     - **接字**（`weapons.finish_name`／`armor.finish_name`；接過的再接一次一樣，C 段 `recheck` 重跑不會變）：前段結尾已經是這一種的字（兵器 `WEAPON_WORDS[種類]`、防具甲鎧袍衫）就照它（「裂雷矛」「金縷衫」照收，同一種的別的字不硬換）；結尾是「看起來像別的兵器或衣物」的字（兵器 `weapons.LOOKALIKE_TAILS`：刃杵棒箭矢戟斧鉞鞭鐧；防具 `armor.GARMENT_TAILS`：衣裳服褂冑盔氅襖裙；兩張都待 joy 潤）就把那一個字換成引擎的字（「重岩杵」→「重岩棍」、「斷霜刃」→「斷霜劍」、「落星箭」→「落星弩」、「金縷衣」→「金縷鎧」）；其餘接在後面。
     - **檢查**（`weapons.kind_problem`／`armor.word_problem`，接好之後才跑）：最後那個字前面至少兩個字（`weapons.HEAD_SHORT`／`armor.WORD_SHORT`：「雷劍」「鐵拳」「金甲」退回字表）；前面那一段不能又以同一種的字或表裡的字結尾（`weapons.DOUBLE_NOUN`／`armor.WORD_DOUBLE`：模型自己寫了「重岩杵棍」「裂矛槍」「金甲袍」也退回）；防具名字的前段除了兵器的字，也不能有 `LOOKALIKE_TAILS` 的字（`WORD_CLASH`：「斷刃衫」）。
   - 理由：FB-131 的病是「好好的名字只差一個字就整個退回字表」；「重岩杵」「斷霜刃」換一個字就是好名字，比整個退回字表更接近模型的意思。疊字與兩個字的名字讀起來像取壞了，名字又是永久的，寧可退回字表（字首＋中間字＋兵器或防具字，一定是三個字）。「鋒」不放進表：架上就有「輕鋒劍」，「寒鋒劍」也是好名字。表外的字照舊接在後面；兵器那邊也不看衣物的字（防具的字本來就可以在兵器名字裡，「破甲槍」），替兵器寫「金縷衣」會接成「金縷衣劍」照收——都算少見。`try_gear_names.py` 分開數「模型自己寫了全名」「換了最後一個字」「疊字退回」「太短退回」，Task 9 照實報，漏網的字交 joy 補進表。
   - 另兩種讀法：(乙) 像兵器、衣物的字結尾不換字、直接退回字表：更保守，FB-131 的三個例子仍然拿不到模型的名字；(丙) 原本那一版：結尾不是這一種的字就一律接、不擋疊字與兩個字，會登記「重岩杵棍」「雷劍」。
   - PM 選乙：`finish_name` 拿掉換字那一支（只剩照收與接），兩張表只給檢查用；Task 1、2 的接字測試改期望值（「重岩杵」→「重岩杵棍」，被 `DOUBLE_NOUN` 擋下）。選丙：拿掉兩張表與四個新原因，接字與檢查的測試照「結尾是這一種的字就照收、不是就接」改。「杵」「棒」要不要直接算棍（`WEAPON_WORDS`）仍然交給 Joy（FB-131）：算了的話「重岩杵」照收，從 `LOOKALIKE_TAILS` 拿掉。

3. **FB-134（防具頁「換上」沒有上限）這一批要不要一起做**。FB-134 自己寫明「防具打造那一批之後才常見」：一階工錢 20 兩比架上 40 兩便宜、同一個配方可以一直打、整季機器人也會打；這一批又把「淬煉」「打造防具…」排在那串「換上」的前後，裝備庫防具一多，打造入口就被擠出 375×812 的第一屏，QA 要看的入口位置也跟著變。
   - 建議：**一起做**（Task 5 Step 4）：防具頁的「換上」最多列 `equipment.DISMANTLE_LIST`（8）件，照修好之後的減損（`armor.fresh_cut`）由高到低、同分 id 大的先（跟 `armor.wanted` 挑「換上」的鍵一樣，所以整季機器人與假人要按的那一顆一定在上面），多的收成一行灰掉的說明「還有 N 件，到修練頁的裝備庫換」（`equipment.WIELD_MORE`，待 joy 潤）；兵器頁的「換上」照舊（只列配得上身上武學的）。
   - 理由：拆解已經是同一個做法（8 顆＋一行說明），玩家看得懂；最好的先列，真的會想換的都在上面。代價：同名同階的仍然可能列好幾顆（FB-134 提的「同名同階同耐久的合成一顆」沒做：一顆鈕代表好幾件時要另外決定換上哪一件）。
   - PM 要延後：Task 5 拿掉 `WIELD_MORE`、排序與上限那幾行和 `test_the_armor_page_lists_at_most_eight_to_wield_best_first`；交接與 QA 寫明「裝備庫防具多時，打造入口在一整串換上的後面」，FB-134 狀態照舊。

```python
def kind_problem(kind: str, name: str) -> str | None:
    """兵器配方的名字對不對得上種類（附帶決定 c；naming.NamingRequest.check 跑它）。FB-131 之後名字一律是「前段＋這一種的字」：

    結尾（疊字）、不能跟架上的現成兵器（shop_name）同名——不然買的跟打的分不出來。None＝可以。已經登記的配方不重驗
    （查表照著打的人拿登記在案的名字）。"""
    words = WEAPON_WORDS.get(kind, ())
    tail = _tail(name, words)
    if tail is None:
        return KIND_MISSING
    head = name[: -len(tail)]
    if len(head) < 2:

        return KIND_CLASH
    if head.endswith(words + LOOKALIKE_TAILS):
        return DOUBLE_NOUN
    if name in _SHOP_NAMES:

    return None
```

```python
FORGE_PREFIX = "鎧|"  # 防具配方鍵的開頭：前綴就是欄位，跟兵器的「兵|」共用 gear_recipes；不用「甲|」（「甲:N」是防具的 id 開頭，3.1）
FORGE_WORDS = ("甲", "鎧", "袍", "衫")  # 防具配方的名字一定以其中一個字結尾（4.7）

GARMENT_TAILS = ("衣", "裳", "服", "褂", "冑", "盔", "氅", "襖", "裙")
WORD_MISSING = "名字看不出是防具"  # 待 joy 潤
WORD_SHORT = "名字太短"  # 待 joy 潤：防具字前面不到兩個字（「金甲」）
WORD_CLASH = "名字像是兵器"  # 待 joy 潤

SHOP_CLASH = "跟鐵匠鋪架上的防具同名"  # 待 joy 潤


def recipe_key(main: str, aux: str) -> str:
    """防具配方鍵（4.7）：「鎧|主料+輔料」。沒有種類；主輔不交換（同兵器 4.4）。"""
    return f"{FORGE_PREFIX}{main}+{aux}"


def recipe_parts(key: str | None) -> tuple[str, str] | None:
    """recipe_key 拆回（主料, 輔料）；不是防具欄的配方鍵（兵器的「兵|」、None）回 None。"""
    if not key or not key.startswith(FORGE_PREFIX):
        return None
    main, plus, aux = key[len(FORGE_PREFIX):].partition("+")
    return (main, aux) if plus and main and aux else None


def recipe_text(content: Content, key: str | None) -> str | None:
    """配方寫給玩家看（修練頁的裝備庫）：「精鐵砂＋驚羽」（主料在前）；不是自己打的（買的）是 None。"""
    parts = recipe_parts(key)
    if parts is None:
        return None
    name = lambda mid: content.materials[mid].name if mid in content.materials else mid  # noqa: E731
    return f"{name(parts[0])}＋{name(parts[1])}"


def noun_for(attribute: str) -> str:
    """接在防具名字最後的那個字（FB-131）：照這一件的屬性查 FORGE_NOUNS；認不得的屬性接「甲」。"""
    return FORGE_NOUNS.get(attribute, "甲")


def finish_name(attribute: str, head: str) -> str:
    """FB-131：模型給的前段接成整個名字（同 weapons.finish_name；「要 PM 定的」第 2 條）。前段已經是防具的字結尾（模型還是寫了全名）
    就照它；以衣物的字（GARMENT_TAILS）結尾就把那個字換成 noun_for（「金縷衣」→「金縷鎧」）；其餘接上 noun_for。接過的再接一次一樣。
    接好之後照樣過 naming.name_problem 與 word_problem（太短、疊字、兵器的字在那裡擋）。"""
    if head.endswith(FORGE_WORDS):
        return head
    if head.endswith(GARMENT_TAILS):
        return head[:-1] + noun_for(attribute)
    return head + noun_for(attribute)


def word_problem(name: str) -> str | None:
    """防具配方的名字對不對（4.7；naming.NamingRequest.check 跑它）：要以防具的字結尾、那個字前面至少兩個字、前段不能有任何兵器的字
    （weapons.WEAPON_WORDS）或像兵器的字（weapons.LOOKALIKE_TAILS）、前段不能又以防具字或衣物的字結尾（疊字）、不能跟架上的防具同名。
    防具的字在前段中間照收（「玄甲雲紋鎧」）。None＝可以。"""
    if not name.endswith(FORGE_WORDS):
        return WORD_MISSING
    head = name[:-1]
    if len(head) < 2:
        return WORD_SHORT
    if any(word in head for words in weapons.WEAPON_WORDS.values() for word in words) or any(
        ch in head for ch in weapons.LOOKALIKE_TAILS
    ):
        return WORD_CLASH
    if head.endswith(FORGE_WORDS + GARMENT_TAILS):
        return WORD_DOUBLE
    if name in SHOP_NAMES.values():
        return SHOP_CLASH
    return None


def fallback_name(content: Content, key: str, attribute: str, salt: int = 0, tianji: int = 0) -> str:
    """防具配方的退路名字（模型叫不動、取壞了）：字首＋craft_names.armor 的一個字＋防具字（noun_for），一定以防具的字結尾。
    種子同 naming.fallback_name（配方鍵＋這一季的天機，加鹽），同一個配方同一季永遠組出同一個名字。"""
    names = content.craft_names
    seed = key if tianji == 0 else f"{tianji}|{key}"
    digest = hashlib.sha256(f"{seed}#{salt}".encode()).digest()
    return names.prefixes[digest[0] % len(names.prefixes)] + names.armor[digest[1] % len(names.armor)] + noun_for(attribute)
```

```python
def forge(
    state: GameState, content: Content, world: WorldStateStore, client: OllamaClient | None,
    kind: str, main: str, aux: str, proposed: tuple[str | None, str] | None = None, rng: random.Random | None = None,
) -> tuple[Equipment | None, list[str]]:
    """C 段（鎖內）：打一件（兵器 4.2～4.4；防具 4.7 照同一套，kind 是 ARMOR_KIND）。回（那一件, 訊息）；打不成回 (None, [原因])，
    什麼都不收、不登記。配方這一季沒人打過：proposed 是鎖外先取好的（名字, 說明），再過一次 naming.recheck（先接字，FB-131）與這一欄的
    名字檢查；沒給（整季機器人、腳本、測試）才在這裡叫模型（client 是 Game._quick_client 的複本）；過不了走退路字表，claim_weapon_recipe
    原子登記，名字撞到就換下一個。品質照 forge_odds 擲（rng：兵器 Game.rng、防具 own_rng，由呼叫端給；沒給是下品）；收工錢與兩樣素材、
    熟手 +1、放進身上或裝備庫，別人首創的記首創名望回饋。"""
    problem = forge_problem(state, content, kind, main, aux)
    if problem is not None:
        return None, [f"（{problem}。）"]
    key = recipe_key(kind, main, aux)
    slot = slot_of(kind)
    tier = tier_of(content, main)
    attribute = attribute_of(world, content, kind, main, aux)
    odds = forge_odds(state, content, world, kind, main, aux)
    setting = setting_points(state, content, attribute, slot)
    recipe, first = world.lookup_weapon_recipe(key), False
    if recipe is None:
        tianji, _ = fusion.recipe_seed(world, key)
        check, finish = _name_rules(kind, attribute)
        if proposed is not None:
            name, note = naming.recheck(content, proposed, person=world.is_character_name, check=check, finish=finish)
        else:
            name, note = naming.propose(
                client, content, _messages(content, kind, main, aux, attribute, tier), person=world.is_character_name,
                check=check, finish=finish,
            )
        for candidate in _candidates(content, world, key, kind, attribute, tianji, name):
            draft = WeaponRecipe(
                name=candidate, key=key, kind="" if slot == "armor" else kind, slot=slot, attribute=attribute, tier=tier,
                main=main, aux=aux, creator=state.player.name, creator_shown=state.player.name,
                note=note if candidate == name else "",
            )
            recipe, first = world.claim_weapon_recipe(key, draft)
            if recipe is not None:
                break
        if recipe is None:
            return None, [FIZZLE]
    quality = fusion.roll_quality(odds, rng)
    p = state.player
    used = Counter([main, aux])
    for mid, n in used.items():
        p.materials[mid] -= n
        if not p.materials[mid]:
            del p.materials[mid]
    cost = price(content, tier, slot)
    p.stats["silver"] -= cost
    p.forge_counts[key] = p.forge_counts.get(key, 0) + 1
    m, a = content.materials[main], content.materials[aux]
    what = f"兩份{m.name}" if main == aux else f"{m.name}與{a.name}"
    if slot == "armor":
        item = armor.new_armor(state, name=recipe.name, attribute=recipe.attribute, tier=tier, quality=quality, recipe=key)
        head = ARMOR_FORGED.format(what=what, name=recipe.name, attribute=recipe.attribute, grade=equipment.grade(item))
    else:
        item = weapons.new_weapon(state, name=recipe.name, kind=kind, attribute=recipe.attribute, tier=tier, quality=quality, recipe=key)
        head = FORGED.format(what=what, name=recipe.name, kind=kind, attribute=recipe.attribute, grade=weapons.grade(item))
    msgs = [head + _arrival(state, recipe, first)]
    msgs += setting_line(content, setting, slot)
    msgs.append(f"銀兩 -{cost}")
    msgs += [f"{content.materials[mid].name} -{n}" for mid, n in used.items()]
    msgs.append(equipment.store(state, item))
    fusion.echo(state, content, recipe, first, made="打")
    return item, msgs
```

```python
def temper_material(state: GameState, content: Content, slot: str = "weapon") -> str | None:
    """淬身上那一件（slot 那一欄）要用的素材：階不低於那一件的、最低階的先（最便宜），同階數量多的先，再照 id；沒有是 None。"""

def temper_problem(state: GameState, content: Content, slot: str = "weapon") -> str | None:
    p = state.player

def temper(state: GameState, content: Content, slot: str = "weapon") -> list[str]:
    """淬煉身上那一件（兵器 4.7、防具 4.1）：用一個同階以上的素材（＋那一階的工錢），淬煉次數 +1（兵器的加成、防具的減損每次

    item = equipment.worn(p, slot)

    cost = temper_price(content, material, slot)
    p.materials[mid] -= 1

    item.tempers += 1
```

```python
def _pick_pair(
    state: GameState, content: Content, prefer: str | None, mine: list[Equipment],
    ok: Callable[[str, str], bool] | None = None,
) -> tuple[str, str] | None:
    """整季機器人一爐挑哪兩樣（兵器、防具共用）：主料挑背包裡最高階的（同階先挑屬性是 prefer 的、再挑最多的、再照 id）；輔料先挑同一種
    （夠兩個時），不然挑跟主料最近一階、數量最多的。素材不到兩個、或 mine（身上與裝備庫裡算數的那幾件）裡已經有一件階比主料高、
    或同階而且是自己打的，是 None（不然每次路過都打一件）。ok 給了就跳過它說不行的組合（防具：合出來會被內功剋的），照同樣的順序
    試下一個輔料、再試同階的下一個主料，都不行是 None；沒給（兵器）就是第一個組合，跟抽出來之前的 forge_plan 一模一樣。"""
    mats = content.materials
    held = {mid: n for mid, n in state.player.materials.items() if n > 0 and mid in mats}
    if sum(held.values()) < 2:
        return None
    top = max(mats[mid].tier for mid in held)
    if any(item.tier > top or (item.tier == top and item.recipe is not None) for item in mine):
        return None
    mains = sorted((mid for mid in held if mats[mid].tier == top), key=lambda mid: (mats[mid].attribute != prefer, -held[mid], mid))
    for main in mains:
        auxes = ([main] if held[main] >= 2 else []) + sorted(
            (mid for mid in held if mid != main), key=lambda mid: (top - mats[mid].tier, -held[mid], mid))
        for aux in auxes:
            if ok is None or ok(main, aux):
                return main, aux
    return None


def forge_plan(state: GameState, content: Content, world: WorldStateStore, art) -> tuple[str, str, str] | None:
    """整季機器人要打哪一把：身上那門武學配得上的種類；主料、輔料照 _pick_pair（同階先挑跟武學同屬性的）。手上或裝備庫已經有一把
    配得上、階比主料高、或同階而且是自己打的，就不打。打不成（forge_problem）是 None。"""
    if art is None or not weapons.smith_here(state, content):
        return None
    kind = weapons.art_weapon(art.id, content, world)
    if kind is None:
        return None
    mine = [w for w in [state.player.weapon, *equipment.in_slot(state.player, "weapon")] if weapons.usable(w, art, content, world)]  # 裝備四欄 3.3
    pair = _pick_pair(state, content, art.attribute, mine)
    if pair is None:
        return None
    main, aux = pair
    return (kind, main, aux) if forge_problem(state, content, kind, main, aux) is None else None


def armor_plan(state: GameState, content: Content, world: WorldStateStore, neigong) -> tuple[str, str, str] | None:
    """整季機器人要打哪一件防具（照兵器的 forge_plan）：主料、輔料照 _pick_pair（同階先挑跟身上內功同屬性的：防具對上內功，裝備四欄 4.2），
    **跳過合出來會被內功剋的組合**（attribute_of 照天機算；不然主料只剩一個時配到剛＋柔挑成剛之類，打出一件比身上還差的）。
    身上或裝備庫已經有一件不被內功剋的防具階比主料高、或同階而且是自己打的，就不打（被內功剋的那幾件不算：不然打出一件相剋的就
    再也不打那一階）。防具關著、打不成是 None。"""
    if not armor.smith_here(state, content):
        return None
    mine = [a for a in [state.player.armor, *equipment.in_slot(state.player, "armor")]
            if a is not None and not armor.clashes(a.attribute, neigong)]
    pair = _pick_pair(
        state, content, neigong.attribute if neigong is not None else None, mine,
        ok=lambda main, aux: not armor.clashes(attribute_of(world, content, ARMOR_KIND, main, aux), neigong),
    )
    if pair is None:
        return None
    main, aux = pair
    return (ARMOR_KIND, main, aux) if forge_problem(state, content, ARMOR_KIND, main, aux) is None else None
```

```python
這一種的字結尾）、換了最後一個字（前段以像兵器或衣物的字結尾）；退回的裡面疊字、太短、其他（計畫「要 PM 定的」第 2 條）。
要先開 Ollama（模型照 content/config.json，--model 可換）。只量不改、不寫資料庫、不開世界。照伺服器同一個格式問（naming.HeadReply），

用法：.venv/Scripts/python.exe scripts/try_gear_names.py [--times 4] [--model gemma4:26b]
"""
from __future__ import annotations

import argparse
import io
import os
import sys
import tempfile
from pathlib import Path

sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))
os.environ.setdefault("TIANXIA_DB", str(Path(tempfile.gettempdir()) / "try_gear_names_unused.db"))  # 不開世界，保險起見

from collections import Counter  # noqa: E402

from tianxia import armor, naming, smithing, weapons  # noqa: E402
from tianxia.content import load_content  # noqa: E402
from tianxia.models import WEAPON_KINDS  # noqa: E402

# 兵器一律精鐵砂＋驚羽；防具四個字各一爐：剛（甲）、快（衫）、慢（袍）、剛＋快＝陽（鎧）
ARMOR_ORDERS = [("gang_1", "gang_1"), ("kuai_1", "kuai_1"), ("man_1", "man_1"), ("gang_1", "kuai_1")]
DOUBLE = (weapons.DOUBLE_NOUN, armor.WORD_DOUBLE)  # 疊字退回
SHORT = (weapons.HEAD_SHORT, armor.WORD_SHORT, f"長度要 {naming.NAME_MIN_CHARS}~{naming.NAME_MAX_CHARS} 個字")  # 太短退回


def ask(client, content, kind: str, main: str, aux: str, times: int, tally: Counter) -> None:
    """問 times 次，印每一次，數進 tally（took／full／swapped／double／short／other）。天機當 0（屬性照天機 0 的種子）。"""
    attribute = smithing.attribute_with(content, 0, kind, main, aux)
    messages = smithing._messages(content, kind, main, aux, attribute, smithing.tier_of(content, main))
    check, finish = smithing._name_rules(kind, attribute)
    for _ in range(times):
        try:
            reply = client.chat_structured(messages, naming.HeadReply, required_fields=["head"])
        except Exception as exc:  # noqa: BLE001  連不上、逾時：照實印
            print(f"  {smithing.noun_label(kind)}・屬{attribute}：叫不動模型（{type(exc).__name__}）", flush=True)
            tally["other"] += 1
            continue
        head = naming.clean_name(reply.head)
        name = finish(head)
        problem = naming.name_problem(name, content) or check(name)
        how = "full" if name == head else "appended" if name.startswith(head) else "swapped"  # 照收、接在後面、換了最後一個字
        if problem is None:
            tally["took"] += 1
            tally[how] += 1
            verdict = "收" + {"full": "（模型自己寫了全名）", "swapped": "（換了最後一個字）"}.get(how, "")
        else:
            tally["double" if problem in DOUBLE else "short" if problem in SHORT else "other"] += 1
            verdict = f"退回字表（{problem}）"
        print(f"  {smithing.noun_label(kind)}・屬{attribute}：前段「{reply.head}」→【{name}】{verdict}　{reply.description}", flush=True)


def main() -> None:

    client = OllamaClient.from_config(content.config)
    if args.model:
        client.model = args.model
    print(f"模型 {client.model}，每一爐問 {args.times} 次（照 smithing._messages 的單子；模型只取前段、引擎接字，FB-131）", flush=True)
    orders = [(kind, "gang_1", "kuai_1") for kind in WEAPON_KINDS] + [(smithing.ARMOR_KIND, m, a) for m, a in ARMOR_ORDERS]
    tally: Counter = Counter()
    for kind, main, aux in orders:
        ask(client, content, kind, main, aux, args.times, tally)
    total = len(orders) * args.times
    print(f"合計 {total} 次，收 {tally['took']} 次（模型自己寫了全名 {tally['full']} 次、換了最後一個字 {tally['swapped']} 次）、"
          f"退回字表 {total - tally['took']} 次（疊字 {tally['double']} 次、太短 {tally['short']} 次、其他 {tally['other']} 次）",
          flush=True)


if __name__ == "__main__":
    main()
```
