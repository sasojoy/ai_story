**Goal:** 把引擎的存取層從「JSON 檔＋跨程式檔案鎖」換成 SQLite：時間一律由外面傳入；全服狀態、角色存檔、帳號都進同一個資料庫；小的資料整份覆寫，會長大的資料（傳聞、江湖史、戰鬥回合、配方）一筆一筆加；換季不刪資料，江湖史跨季保存。規則與數值一個都不改，既有測試照過。

**Architecture:**
- 新的 `tianxia/database.py` 管 SQLite 連線、資料庫結構與交易。**一個動作＝一筆交易**（`BEGIN IMMEDIATE`…`COMMIT`，出錯 `ROLLBACK`）。第 1 期仍是兩支程式（`app.py` 與 `run_bots.py`）寫同一個檔案，SQLite 的寫入權取代原本的檔案鎖：伺服器等到拿到為止、假人等不到就跳過。
- `tianxia/world_state.py` 只剩資料模型與 `WorldStateStore` **介面**（`typing.Protocol`）；實作是新的 `tianxia/sqlite_world.py::SqliteWorldStore`。第 2 期的世界主迴圈會換成「記憶體裡一份＋每個動作寫進資料庫」，介面不變。
- 角色存檔換成 `tianxia/characters.py::CharacterStore`（取代 `save.py`），**不再夾帶賽季**（`GameState.world` 只留在記憶體）。帳號（`tianxia/accounts.py`）改存資料庫，帳號密碼成為帳號上的一種登入方式。
- 引擎不再讀電腦時鐘：`Game.now` 由 `sync(now)` 設定，開戰、集結與回合逾時都用它。

**Tech Stack:** Python 3.14（內建 `sqlite3`，SQLite 3.50）、Pydantic v2、Gradio（只在 `app.py`）、pytest

**Spec:** `docs/superpowers/specs/2026-10-02-線上架構-design.md`（第三、四節，第十節第 1 期）；傳聞的資料表照 `docs/superpowers/specs/2026-10-02-傳聞分層-design.md`（第二、七節）。

## Global Constraints

- `tianxia/` 不得 import gradio。`engine.Game` 仍是唯一對外門面。
- 玩家看得到的文字、程式註解、docstring 用繁體中文，風格比照周圍程式碼。
- **規則與數值一個都不改**。這一期只換「時間從哪裡來」與「資料存在哪裡」。
- **引擎不讀電腦時鐘**：做完 Task 1 之後，`tianxia/engine.py`、`world.py`、`bot.py`、`world_state.py`、`sqlite_world.py` 都不得 import `time`。現在時間一律從 `Game.sync(now)`、或明確傳進來的 `now` 參數拿。例外只有兩個，都是「由外面注入、預設值是 `time.time`」的時鐘：`accounts.AccountStore(clock=...)`（擋猜密碼）、`bot_runner.BotRunner(clock=...)`（假人程式本身就是伺服器端）。`database.py` 用 `time.monotonic()` 算等寫入權的期限，那不是遊戲時間。
- **存資料的原則**（線上架構設計 3.1）：
  - 小的整份覆寫：全服的小資料一列（`world` 表）、每一季一列（`seasons` 表）、每個角色一列（`characters` 表）。
  - 會長大的一筆一筆加：傳聞、江湖史、戰鬥回合、武學、配方、投靠名冊只 `INSERT`／`UPSERT` 單一列，**不整份重寫**，也**不在每次讀取時全部讀回記憶體**。
  - 換季不刪資料：賽季編號加一，舊的一季整份留著。
- **資料庫結構**：記在 `PRAGMA user_version`，這一期是第 1 版。第 1 期做完之前還沒有任何正式資料庫，所以各任務要改結構就**直接改 `database.SCHEMA`**，版本號維持 1；第 1 期合進主線之後，再改結構就要加版本號與搬資料的步驟（設計 8.2）。
- **不搬舊資料**（企劃者 2026-10-03 決定）：舊的 `saves/*.json`、`saves/world/state.json`、`saves/accounts/accounts.json` 不讀、不刪、不轉換。換版後從零開始。
- 假人看不出來：`characters.is_bot` 只給假人程式挑人用，任何畫面、榜單、主控台輸出都不能顯示（伺服器假人設計第五節）。
- 介面名稱不改：其他模組的型別標註繼續寫 `WorldStateStore`（現在它是介面）。要建一個實體，一律用 `sqlite_world.open_world(...)`。
- **永遠不要讀、寫、執行任何東西去碰真正的 `saves/` 與 `.local/`**：`C:/Ray/專案/ai遊戲` 正在跑朋友試玩的伺服器。在 worktree 裡實作；測試一律用 `tmp_path`（`tests/conftest.py` 會把預設資料庫指到暫存檔）；**不要啟動 `app.py` 或 `run_bots.py`**（它們用固定的 7861 port 與預設資料庫）。
- 指令裡的 `$PY` 指這個 checkout 能用的 Python：有 `.venv` 就用 `.venv/Scripts/python.exe`，worktree 沒有 `.venv` 時用主 clone 的（例如 `C:/Ray/專案/ai遊戲/.venv/Scripts/python.exe`）。測試：`$PY -m pytest -q`（在 worktree 根目錄執行）。
- 每個任務結束時，**全部測試都要通過**。測試只在三種情況可以改：(a) 測的是被換掉的儲存實作本身（檔案鎖、檔案被占用時重試、JSON 檔格式）——刪掉或換成資料庫版本；(b) 機械式的介面改名（建構方式、時間由外面傳入）；(c) 斷言讀的欄位搬進了資料表——改成讀新的方法。斷言的**行為**不能改。
- Commit：只 commit、不 push；`git add` 用明確路徑；訊息用 Write 工具寫進暫存檔再 `git commit -F <檔案>`（PowerShell 的 `Set-Content` 會加 BOM，不要用）。訊息格式：英文祈使句標題、空行、內文，最後一行一字不差 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。串接 git 指令時每一步都檢查結果，失敗就停。

- Produces（`tianxia/database.py`）：
  - `DEFAULT_PATH: Path`（`saves/tianxia.db`）、`ENV_VAR = "TIANXIA_DB"`、`SCHEMA_VERSION = 1`、`SCHEMA: tuple[str, ...]`
  - `default_path() -> Path`——設了環境變數 `TIANXIA_DB` 就用它，否則 `DEFAULT_PATH`（呼叫當下才讀，測試可以 monkeypatch）。
  - `class Database(path: Path)`：
    - `transaction(timeout: float | None = None)`——context manager，給出 `sqlite3.Connection`。最外層 `BEGIN IMMEDIATE`、成功 `COMMIT`、出錯 `ROLLBACK`；同一個執行緒裡巢狀呼叫併進最外層那一筆。`timeout=None` 等到拿到寫入權為止；給秒數時等不到丟 `TimeoutError`。在 `snapshot()` 裡呼叫丟 `RuntimeError`。
    - `snapshot()`——context manager，給出 `sqlite3.Connection`；不在交易裡時開一筆唯讀交易（幾句 `SELECT` 看到同一個時間點）；已經在交易或快照裡時直接用那一筆。
    - `close()`——關掉這個資料庫開過的所有連線。
    - 連線的 `row_factory` 是 `sqlite3.Row`（可以用欄位名稱取值）。
  - `open_database(path: Path | None = None) -> Database`——同一個檔案在同一個程式裡共用一個 `Database`（同一個執行緒因此共用同一條連線、同一筆交易）。
  - `close_all() -> None`——關掉 `open_database` 開過的所有資料庫（測試結束時用）。

```python
def default_path() -> Path:
    """預設的資料庫檔：設了環境變數 TIANXIA_DB 就用它，否則 saves/tianxia.db。呼叫當下才讀。"""

    return Path(override) if override else DEFAULT_PATH


class Database:
    def __init__(self, path: Path):
        self.path = Path(path)
        self._local = threading.local()
        self._connections: list[sqlite3.Connection] = []
        self._connections_lock = threading.Lock()
        try:
            self._ensure_schema()
        except BaseException:
            self.close()  # 版本不對時也要把剛開的連線關掉
            raise

    def _thread(self) -> threading.local:
        """這個執行緒的連線與交易狀態；第一次用時開連線。"""
        local = self._local
        if not hasattr(local, "conn"):
            self.path.parent.mkdir(parents=True, exist_ok=True)
            conn = sqlite3.connect(self.path, timeout=BUSY_SLICE, autocommit=True, check_same_thread=False)
            conn.row_factory = sqlite3.Row
            conn.execute("PRAGMA journal_mode = WAL")
            conn.execute("PRAGMA synchronous = NORMAL")
            conn.execute("PRAGMA foreign_keys = ON")
            local.conn, local.depth, local.reading = conn, 0, False
            with self._connections_lock:
                self._connections.append(conn)
        return local

    @contextlib.contextmanager
    def transaction(self, timeout: float | None = None) -> Iterator[sqlite3.Connection]:
        local = self._thread()
        if local.reading:
            raise RuntimeError("讀取快照裡不能寫入：先離開 snapshot() 再開交易")
        if local.depth:
            local.depth += 1
            try:
                yield local.conn
            finally:
                local.depth -= 1
            return
        self._begin(local.conn, timeout)
        local.depth = 1
        try:
            yield local.conn
        except BaseException:
            local.depth = 0
            local.conn.execute("ROLLBACK")
            raise
        local.depth = 0
        local.conn.execute("COMMIT")

    def _begin(self, conn: sqlite3.Connection, timeout: float | None) -> None:
        deadline = None if timeout is None else time.monotonic() + timeout
        while True:
            wait = BUSY_SLICE if deadline is None else max(0.0, deadline - time.monotonic())
            conn.execute(f"PRAGMA busy_timeout = {int(wait * 1000)}")
            try:
                conn.execute("BEGIN IMMEDIATE")
                return
            except sqlite3.OperationalError as exc:
                if exc.sqlite_errorcode & 0xFF not in (sqlite3.SQLITE_BUSY, sqlite3.SQLITE_LOCKED):
                    raise
                if deadline is not None and time.monotonic() >= deadline:
                    raise TimeoutError(f"等不到資料庫的寫入權：{self.path}") from exc

    @contextlib.contextmanager
    def snapshot(self) -> Iterator[sqlite3.Connection]:
        local = self._thread()
        if local.depth or local.reading:
            yield local.conn
            return
        local.conn.execute("BEGIN")  # DEFERRED：第一句 SELECT 才拿讀取的快照，不擋寫入的人
        local.reading = True
        try:
            yield local.conn
        finally:
            local.reading = False
            local.conn.execute("COMMIT")

    def _ensure_schema(self) -> None:
        with self.transaction() as conn:  # 拿到寫入權再看版本：兩支程式同時開新檔也只建一次
            version = conn.execute("PRAGMA user_version").fetchone()[0]
            if version == SCHEMA_VERSION:
                return
            if version != 0:
                raise RuntimeError(
                    f"資料庫結構是第 {version} 版，這版程式只認得第 {SCHEMA_VERSION} 版：{self.path}"
                )
            for statement in SCHEMA:
                conn.execute(statement)
            conn.execute(f"PRAGMA user_version = {SCHEMA_VERSION}")

    def close(self) -> None:
        with self._connections_lock:
            connections, self._connections = self._connections, []
        for conn in connections:
            conn.close()
        self._local = threading.local()


_OPEN: dict[Path, Database] = {}
_OPEN_LOCK = threading.Lock()


def open_database(path: Path | None = None) -> Database:
    """同一個檔案在同一個程式裡只開一個 Database：同一個執行緒因此共用同一條連線、同一筆交易
    （全服狀態、角色、帳號各自的 store 才能在同一個動作裡一起寫進同一筆交易）。"""
    resolved = Path(path if path is not None else default_path()).resolve()
    with _OPEN_LOCK:
        if resolved not in _OPEN:
            _OPEN[resolved] = Database(resolved)
        return _OPEN[resolved]


def close_all() -> None:
    """關掉 open_database 開過的所有資料庫（測試結束時用，Windows 才刪得掉暫存檔）。"""
    with _OPEN_LOCK:
        databases = list(_OPEN.values())
        _OPEN.clear()
    for db in databases:
        db.close()
```

注意兩點：
- `sqlite3.connect(..., autocommit=True)` 是 Python 3.12 起的參數：不會自己開交易，`BEGIN`／`COMMIT` 全部由這個模組下。
- `sqlite_errorcode` 可能是延伸錯誤碼，所以先 `& 0xFF` 再比對。
