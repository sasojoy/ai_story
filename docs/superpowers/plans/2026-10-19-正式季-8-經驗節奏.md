# 正式季第 8 批：經驗節奏（縮小版） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task（PM：一步一步做，不開子代理）。

**Goal:** 各陣營最好的練功點差不到一成；滿級之後的經驗一律 5 換 1 換成心得；21 天季的 30 級以後加陡給一個【預設】，讓最認真、不吃丹的人第 7～8 天滿級。

**Architecture:** 練功點只改內容（`content/scenario.json` 地盤易手的 `garrison`），不改隊伍數字、不改挑法。滿級換心得收成 `team` 一組函式（`maxed`、`as_xinde`、`maxed_xinde`），每一個給本人經驗的地方照它寫得失；第 5 批懸賞那一支改用它，比例從 `Config.season21_daily` 搬到 `Config.maxed_exp_per_xinde`。加陡只寫在 `content/profiles/season21.json`。

**Spec:** `docs/superpowers/specs/2026-10-17-正式季整合-design.md` 3.3、3.5、3.6；12.1 第 16 條。PM 2026-10-19 縮小範圍：20 人三週量表先不跑、週末與 14 天不動、經驗倍數不加。

## Global Constraints

- 只動規則面；量表只用 `scripts/measure_exp_pace.py`，各量一次。
- 不改資料庫結構；新字標「待 joy 潤」；數字標【預設】。
- 只跑 `scripts/test_for.py --base origin/feature/formal-season`。

## Review Focus

1. 滿級換心得只換本人；同伴照拿經驗。沒滿級一個字都不變。
2. 升到 50 級那一下剩下的經驗不換（照舊丟掉）：只在這一筆之前已經滿級時換。
3. 戰報的得失寫心得、不寫「經驗 +0」；江湖紀錄多一句換了多少。
4. 懸賞的賞那一段（`reward_bits`）跟交差時給的一樣，每一種季都換。

### Task 1：量表報各方的練功點
- `measure_exp_pace.py` 每一行多印練功每點體力換幾經驗（練功拿到的經驗 ÷ 花在練功的體力）與常去的練功點。
- 量現在的 season21 新規則，四方各一行，當基準。

### Task 2：黃巾的練功點改駐軍（12.1 第 16 條）
- 照基準挑：官軍控制的地點裡黃巾最好的練功點，把最弱的那一路換成跟黃巾死士同一檔的官軍隊伍（北軍五校 35 經驗、難度 55），`garrison` 一起改。
- 再量一次，四方最好的練功點每點體力差不到一成；不到就再挑一處，照實報。

### Task 3：滿級換心得（3.5）
- `Config.maxed_exp_per_xinde`（5）；`team.maxed(content, member)`、`team.as_xinde(content, exp)`、`team.maxed_xinde(state, content, exp) -> int`（滿級才換、記進心得）。
- `Game._record_exp(record, exp) -> list[str]`：戰報那一筆（打仗、出陣兩種、挑戰本人的僵持、切磋、頭目戰）滿級時經驗寫 0、心得加上換的；回江湖紀錄那一句 `team.MAXED_XINDE`。
- 守、攪局、守勢行動、操練（`_drill_gains`）、決戰軍餉（`_showdown_pay`）、懸賞交差與賞那一段照同一個函式。
- 測試：滿級打一場、守一下、領軍餉、交懸賞都換成心得，同伴照拿經驗；沒滿級不變。

### Task 4：21 天季的加陡【預設】（3.3 甲）
- 量 season21 新規則、不吃丹，官軍與黃巾；照第幾天滿級挑 `late_exp_step`，讓滿級落在第 7～8 天，寫進 `season21.json`、標【預設】。
