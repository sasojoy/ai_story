## 零、一句話

武學、內功練到第十成之後，可以繼續花心得「精研」：一重一重往上，每一重比上一重貴，威力只多一點點，上限很遠——練滿的人永遠有地方花心得，但不會因此變得碾壓別人。

## 二、設計決定

### 2.1 為什麼挑「精研」【PM】【待企劃者：確認方向】

三個候選：

1. **精研（挑這個）**：十成之後花心得一重一重往上，威力每重多一點點。
   - 沒有上限的感覺、越來越貴，正好是「一直有東西花」。
   - 人人都有：散人、沒有門下的人、本命武學的人都用得到（傳功只有帶門下的人用得到）。
   - 規則簡單：一個數字、一個倍數，乘在 `player_art` 一個地方，戰鬥各處自動帶著，不碰戰法、功效、回合。
   - 不改心得收入，也不改任何別的出口。
2. **心得重鑄功效層**（不挑）：功效層有上限（`depth.max_layers` 5）、是有限的出口，花完一樣溢出；又直接動到戰法與絕招的強度（量表 `measure_tactics.py --catch-up` 剛調好的本命對滿配 56%），等於重開平衡；重鑄要擲骰，還會跟合成「拿到新東西」的意義打架。
3. **心得換軍需貢獻**（不挑）：只有投靠了陣營、第一季規則的季才有貢獻，散人沒地方花；貢獻會推晉升與軍餉，跟正式季第 6 批「軍階每週上限」打架；心得是打仗打出來的，換成貢獻等於多一條推線的路，牽動戰線平衡。

### 2.2 玩家看得到什麼

- 修練頁身上那一門練到第十成之後，練成鈕換成「精研第N重・心得 M」（第一次是第一重）。按了扣心得、重數 +1，回一句「【某某】精研至第N重，威力 +X%。」（待 joy 潤）。
- 功法卡威力那一行：練滿之後寫「第十成・精研 N 重，威力 123.4（下一重 124.0）」（待 joy 潤），取代「（已達第十成）」。
- 到上限（見 2.3）寫「精研已到盡頭」（待 joy 潤），鈕灰掉。
- 心得不夠時鈕照舊灰著、寫還差多少（同練成）。
- 玩法說明（`howto` 修練那一段）多一句：第十成之後可以精研、每重多 0.5%、一重比一重貴。
- 不做排行榜、不上江湖史、不上行狀（太頻繁，不算大事）【PM】。

### 2.3 規則怎麼算

- 重數記在 `PlayerState.art_refine: dict[str, int]`（功法 id → 精研了幾重），每一門各自記，改練換下來也留著（同 `art_levels`）。
- 只有第十成才能精研；身上那兩門（內功、武學）才能按，功法庫裡的不能【PM】。
- 價錢：第 n 重（從 1 數）＝ `refine_xinde_step` × n，**60 × n**【預設】。一門累計：10 重 3,300、20 重 12,600、30 重 27,900。
- 威力：玩家那一份的 `base_power`／`top_power` 乘（1＋`refine_power_per` × 重數），**每重 +0.5%**【預設】，跟本命的 `signature.scale` 疊乘。
- 上限：**100 重**（+50%，一門累計 303,000 心得）【預設】：一季攢 5.7～7.7k，兩門分攤的話一季約十來重（+5～7%），一輩子碰不到上限。上限只是保險。
- 不受傷（練成的 `practice_injury_chance` 不擲）、不碰 `Game.rng`【PM】：精研是花錢買小幅成長，不是練功的苦。
- 熔掉那一門：精研花的心得**不退**，`library.remove_art` 連同 `art_refine` 那一筆拿掉【PM】（不然「精研→熔→退心得」變成存錢罐，也免得熔煉價錢再算一套）。求藝交出也一樣（走 `remove_art`）。
- 換季：角色重來，重數歸零（同修練、破境丹的次數）。
- 雲篆（玉璽碎片「練成的心得 ×0.9」）**不打折精研**【PM】：雲篆寫的是練成；精研沒有上限，打折等於永久多一成威力的成長。
- 只算本人，同伴、部下不精研（他們有傳功）。

### 2.4 開關

- `Config.refine_xinde_step: int = 0`（0 是關著）、`refine_power_per: float = 0.005`、`refine_cap: int = 100`，放在 `cultivate_xinde_price` 旁邊（models.py:2814 那一帶），註解寫理由。
- 正式：`content/config.json` 寫 `refine_xinde_step: 60`。測試內容不寫 → 關著。
- 關著時一個字都不變：鈕照舊「練滿了」、威力那一行照舊「（已達第十成）」、`player_art` 不乘、`art_refine` 永遠是空的。
- 不掛第一季開關（同以心得修練，每季都有）。

### 2.5 跟其他系統的接縫

- 江湖水漲（`rise.py`）照全隊威力浮大場面難度，精研多的那一點會被浮回去一部分；一般遊歷、出陣、頭目、擂台、決戰照算。這是預期的：精研是「花不完的心得換一點點」，不該讓挑戰變簡單太多。
- 決戰份量 `battle_instance.strength` 吃威力（夾 400），精研照算進去。
- 勝算（`team.estimate`）走同一個 `player_art`，鈕上的勝算自動對。
- 機器人：`bot.spend_xinde` 最後加一步 `refine`，付完要剩 `REFINE_RESERVE` 200 心得，一次最多 3 重；假人跟整季機器人同一條，不另外設計。

### 2.6 不做

- 不改心得收入、不改其他出口的價錢。
- 不做「精研」以外的第二條新出口（重鑄、換貢獻都不做）。
- 不讓精研改功效、戰法、品質。
- 資料庫結構不動（`art_refine` 在角色那一列的 JSON 裡）。
