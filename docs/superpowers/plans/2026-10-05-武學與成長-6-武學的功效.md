# 武學與成長 6：武學的功效 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每門武學帶功效：八個一般功效（一個屬性一個，一門最多三個，看合成的來路）與偶爾出現的特別功效；功效只算玩家本人身上那兩門，作用在遊歷時的戰鬥，回合裡有一句演出，戰報與功法卡寫得出來。

**Architecture:** 功效的名字、掛點（hook）、每層多少、上限寫在內容 `content/traits.json`，演出句在 `content/trait_lines.json`（S1 寫好的 45 句）。一門武學的一般功效記成**屬性的清單** `MartialArt.traits`（第一個是自己的屬性，後面是傳下來的），特別功效記在 `MartialArt.special`。新模組 `tianxia/traits.py` 算「身上兩門加起來各幾層」（`Loadout`），換算成 `encounter.Mods` 交給遭遇戰；氣血、獎勵、回氣血、體力在 `team`／`engine` 照 hook 接上。功效在程式裡叫 trait，不叫 effect（`models.Effect` 是事件的效果，免得混）。

**Tech Stack:** Python 3／pydantic（`tianxia/`）、FastAPI（`server.py`，這份不用改）、原生 JavaScript（`web/app.js`，這份不用改）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-05-武學與成長-design.md` 第十三節（13.1～13.7）；演出句 `docs/superpowers/specs/2026-10-05-武學與成長-功效演出句.md`。

**開工條件：** 計畫三（回合演出、大場面判讀，分支 `claude/silly-turing-6f37f4`）、計畫二之三（同伴吃屬性加成、身法閃避）、計畫五（武學＋武學、合到舊的）**三份都併進 main 之後**。寫這份時三份都還沒進 main，下表是照它們的計畫與計畫三分支寫的名字；開工時以 main 的實際為準，名字不同就照實際、保持這份要的行為，並在 task 報告寫出差異。

**執行方式：** 子代理逐步做（superpowers:subagent-driven-development：每個 Task 一個新的子代理實作、另一個子代理審過才做下一個，最後整條分支再審一次）。

## Global Constraints

- 功效只算**玩家本人**身上那一門內功、一門武學（13.1）；同伴、部下不算。
- 一般功效：八個，一個屬性一個；一門最多 3 個（自己屬性 1＋傳下來 2），可以重複、重複就疊加；**品質管強度**：下品 ×1、中品 ×1.5、上品 ×2、絕學 ×3（`Config.trait_quality_multiplier`），剛合出來三個就都在。
- 層數＝身上兩門裡這個功效出現的次數 × 那一門（自己那一份）品質的倍數，兩門相加；數字＝每層 × 層數，再套上限（`content/traits.json`）。
- 特別功效：新武學長出來時 5%（`Config.special_trait_chance`）由規則擲（配方加天機的雜湊）；第四格、不分品質、**不傳給後代**；身上兩門相同的只算一次；合到舊的維持那一門原本的。
- 名將本命絕學的獨特特別功效：內容（`SkillDef.special`）指到一個 `pool: false` 的特別功效，一個只能給一門；這份只做欄位與驗證，內容等劇情寫本命絕學時再填。
- **生效的地方**：遊歷時的戰鬥（遭遇戰、劇情戰、挑戰名將；大場面先照規則算，模型推的優勢照計畫三）；「輕身」管遊歷（與挑戰名將）的體力。**全服決戰不在這份**（交戰鬥系統）。
- 勝算（`team.estimate`）含會改到「贏的機會」的功效（先手、穩、險、破甲、厚、連環、借力），**不含**護命與閃避（只把落敗變僵持）。
- 沒有功效的人（開局、只有基礎武學、`traits` 是空的舊資料）打一場，結果與**亂數用法**跟現在一模一樣：只有帶「連環」才多擲一次運氣。
- 數字全由規則引擎決定；模型只取名，取名提示看得到功效。
- 不升 `SCHEMA_VERSION`：`MartialArt` 存成 JSON，多兩個欄位有預設值。
- 演出句照 S1 的檔（`{who}`、`{art}`、`{foe}` 三個佔位），一句一行，前面標〔功效名〕。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

```python
"""武學的功效（武學與成長設計第十三節）：資料與層數。"""
import pytest

from tianxia import traits
from tianxia.martial_arts import ATTRIBUTES, generate_from_name


def _art(name, attribute="快", traits_=(), special=None, kind="武學"):
    return generate_from_name(name, kind, name, attribute=attribute).model_copy(
        update={"origin": "fused", "traits": list(traits_), "special": special},
    )


def test_every_attribute_has_one_general_trait(content):
    assert sorted(t.attribute for t in content.traits.general) == sorted(ATTRIBUTES)
    assert traits.general(content, "快").name == "先手" and traits.general(content, "實").name == "厚"


def test_an_art_without_traits_has_its_own_attribute():
    """Review Focus 4：舊資料、內容寫的武學沒有 traits，當作只有自己屬性那一個。"""
    assert traits.traits_of(_art("舊拳", attribute="剛")) == ["剛"]
    assert traits.traits_of(_art("新拳", attribute="剛", traits_=["剛", "快", "實"])) == ["剛", "快", "實"]


def test_layers_add_up_both_arts_by_quality(state, content, world):
    """身上的武學是上品【破甲｜先手、破甲】、內功是下品【化勁｜破甲】：破甲＝2 層×2＋1 層×1＝5（設計 13.2 的算例）。"""
    outer = _art("裂石拳", attribute="剛", traits_=["剛", "快", "剛"])
    inner = _art("柔息功", attribute="柔", traits_=["柔", "剛"], kind="內功")
    world.claim_skill_name(outer)
    world.claim_skill_name(inner)
    state.player.member.wugong_id, state.player.member.neigong_id = outer.id, inner.id
    state.player.art_quality[outer.id], state.player.art_quality[inner.id] = "上品", "下品"
    lo = traits.loadout(state, content, world)
    assert lo.layers["difficulty_cut"] == 5 and lo.layers["big_win"] == 2 and lo.layers["toll_cut"] == 1
    assert traits.amount(content, lo, "difficulty_cut") == pytest.approx(0.2)  # 5×4% 剛好上限
    assert traits.amount(content, lo, "big_win") == pytest.approx(0.08)
    assert lo.source["破甲"] == "裂石拳"  # 層數多的那一門（演出句的 {art}）


def test_a_special_counts_once_even_on_both_arts(state, content, world):
    a = _art("甲拳", special="lianhuan")
    b = _art("乙功", attribute="柔", special="lianhuan", kind="內功")
    world.claim_skill_name(a)
    world.claim_skill_name(b)
    state.player.member.wugong_id, state.player.member.neigong_id = a.id, b.id
    lo = traits.loadout(state, content, world)
    assert list(lo.specials) == ["double_luck"]


def test_no_arts_no_traits(state, content, world):
    state.player.member.wugong_id = state.player.member.neigong_id = None
    lo = traits.loadout(state, content, world)
    assert lo.layers == {} and lo.specials == {} and traits.amount(content, lo, "big_win") == 0


def test_the_card_line_lists_the_traits_with_this_arts_numbers(content):
    art = _art("裂石拳", attribute="剛", traits_=["剛", "快", "剛"], special="lianhuan").model_copy(update={"quality": "中品"})
```

`tianxia/models.py`：

```python
TRAIT_HOOKS = (  # 一般功效掛在遭遇戰的哪一步（武學與成長設計 13.2）；程式照這幾個實作
    "big_win", "luck_narrow", "difficulty_cut", "toll_cut", "win_reward", "win_heal", "luck_widen", "condition_floor",
)
SPECIAL_HOOKS = (  # 特別功效的掛點（13.4）：新的特別功效用這幾個就只要改內容；要新的掛點才要寫程式
    "double_luck", "no_injury", "no_loss", "win_xinde", "power_from_difficulty", "heal_after", "train_stamina",
)


class GeneralTrait(_Strict):
    """一般功效（content/traits.json，13.2）：一個屬性一個。每層 per_layer、疊加到 cap 為止；desc 的 {value} 換成數字。"""

    attribute: Attribute
    name: str
    hook: Literal[TRAIT_HOOKS]
    per_layer: float = Field(ge=0)
    cap: float = Field(ge=0)
    desc: str


class SpecialTrait(_Strict):
    """特別功效（13.4、13.5）：不分品質、強度固定（amount）。pool 是 false 的只屬於一門內容武學（名將本命絕學），
    合成擲不到。"""

    id: str
    name: str
    hook: Literal[SPECIAL_HOOKS]
    amount: float = Field(ge=0)
    pool: bool = True
    desc: str


class TraitBook(_Strict):
    general: list[GeneralTrait] = Field(default_factory=list)
    special: list[SpecialTrait] = Field(default_factory=list)
```

```python
"""武學的功效（武學與成長設計第十三節）：八個一般功效（一個屬性一個）與特別功效。

| 誰 | 做什麼 |
|---|---|
| 內容（content/traits.json） | 每個功效叫什麼、掛在哪裡（hook）、每層多少、上限、一句說明 |
| 這裡 | 一門武學帶哪幾個（traits_of）、本人身上兩門加起來各幾層（loadout）、換算成數字（amount） |
| encounter／team／engine | 照 hook 把數字用在遭遇戰的各一步 |

一門武學的一般功效記成**屬性的清單**（MartialArt.traits，最多 3 個：第一個是自己的屬性，後面是傳下來的，13.3）；
舊資料與內容寫的武學沒有這個欄位，當作只有自己的屬性。功效只算玩家本人身上那兩門（13.1）。
程式裡叫 trait，不叫 effect：models.Effect 是事件的效果。
"""
from __future__ import annotations

from dataclasses import dataclass, field

from .martial_arts import MartialArt
from .models import Content, GeneralTrait, SpecialTrait
from .state import GameState
from .world_state import WorldStateStore

MAX_TRAITS = 3  # 一門最多帶幾個一般功效（13.3）
PERCENT_HOOKS = {"win_xinde", "train_stamina"}  # 這兩個的數字是點數，其他都是比例


def traits_of(art: MartialArt) -> list[str]:
    return list(art.traits) or [art.attribute]


def general(content: Content, attribute: str) -> GeneralTrait:
    return next(t for t in content.traits.general if t.attribute == attribute)


def special(content: Content, special_id: str | None) -> SpecialTrait | None:
    return next((t for t in content.traits.special if t.id == special_id), None) if special_id else None


def multiplier(content: Content, quality: str) -> float:
    return content.config.trait_quality_multiplier.get(quality, 1.0)


@dataclass
class Loadout:
    """本人身上兩門加起來的功效：一般功效照 hook 記層數（已乘品質），特別功效照 hook 記一個（相同的只算一次）；
    source 是每個功效名對到「帶它、層數最多的那一門」的名字（演出句的 {art}）。"""

    layers: dict[str, float] = field(default_factory=dict)
    specials: dict[str, SpecialTrait] = field(default_factory=dict)
    source: dict[str, str] = field(default_factory=dict)


def loadout(state: GameState, content: Content, world: WorldStateStore) -> Loadout:
    from . import team  # team 會 import 這個模組

    out, best = Loadout(), {}
    if not content.traits.general:
        return out
    for skill_id in (state.player.member.wugong_id, state.player.member.neigong_id):
        art = team.player_art(state, content, world, skill_id)  # 自己那一份：品質照自己修到的
        if art is None:
            continue
        mult, mine = multiplier(content, art.quality), traits_of(art)
        for attribute in dict.fromkeys(mine):
            trait = general(content, attribute)
            layers = mine.count(attribute) * mult
            out.layers[trait.hook] = out.layers.get(trait.hook, 0.0) + layers
            if layers > best.get(trait.name, (0.0, ""))[0]:
                best[trait.name] = (layers, art.name)
        sp = special(content, art.special)
        if sp is not None and sp.hook not in out.specials:
            out.specials[sp.hook] = sp
            best.setdefault(sp.name, (1.0, art.name))
    out.source = {name: art_name for name, (_, art_name) in best.items()}
    return out


def amount(content: Content, lo: Loadout, hook: str) -> float:
    """一般功效的數字：每層 × 層數，套上限；身上沒有是 0。"""
    trait = next((t for t in content.traits.general if t.hook == hook), None)
    if trait is None:
        return 0.0
    return min(trait.cap, trait.per_layer * lo.layers.get(hook, 0.0))


def has(lo: Loadout, hook: str) -> bool:
    return lo.layers.get(hook, 0.0) > 0 or hook in lo.specials


def _value(hook: str, number: float) -> str:
    return f"{number:g}" if hook in PERCENT_HOOKS else f"{round(number * 100):g}%"


def card_line(content: Content, art: MartialArt) -> str:
    """功法卡的一行（13.6）：這一門的每個一般功效（照這一門自己的層數與品質算出來的數字），再加特別功效。"""
    if not content.traits.general:
        return ""
    mult, mine, parts = multiplier(content, art.quality), traits_of(art), []
    for attribute in dict.fromkeys(mine):
        trait = general(content, attribute)
        number = min(trait.cap, trait.per_layer * mine.count(attribute) * mult)
        parts.append(f"〔{trait.name}〕" + trait.desc.replace("{value}", _value(trait.hook, number)))
    sp = special(content, art.special)
    if sp is not None:
        parts.append(f"〔{sp.name}〕" + sp.desc.replace("{value}", _value(sp.hook, sp.amount)))
    return "功效：" + "・".join(parts)
```

```python
def inherit_fuse(base: MartialArt, attribute: str) -> list[str]:
    """武學＋意境（13.3）：新武學的屬性（意境的）排第一；底的功效整串往後推，最多留 2 個，擠掉最舊的。"""
    return [attribute] + traits_of(base)[: MAX_TRAITS - 1]


def inherit_blend(a: MartialArt, b: MartialArt, attribute: str) -> list[str]:
    """武學＋武學（13.3）：新武學的屬性排第一；兩門各傳一個下來——各自屬性的那個（traits_of 的第一個），照 id 排序。"""
    first, second = sorted((a, b), key=lambda art: art.id)
    return [attribute, traits_of(first)[0], traits_of(second)[0]]


def roll_special(content: Content, key: str, tianji: int) -> str | None:
    """長出新武學時擲特別功效（13.4）：配方加這一季天機的雜湊，同一個配方同一季永遠一樣；只從共用清單（pool）挑。"""
    import hashlib

    pool = sorted(t.id for t in content.traits.special if t.pool)
    digest = hashlib.sha256(f"{tianji}|{key}|special".encode("utf-8")).digest()
    roll = int.from_bytes(digest[:8], "big") / 2**64
    if not pool or roll >= content.config.special_trait_chance:
        return None
    return pool[digest[8] % len(pool)]


def naming_note(content: Content, trait_list: list[str], special_id: str | None) -> str:
    """取名的提示裡那一行（13.1：取名時看得到功效，名字要配得上）：只寫名字，不寫數字。"""

        return ""
    names = [general(content, attribute).name for attribute in trait_list]
    sp = special(content, special_id)
    tail = f"，還帶著罕見的「{sp.name}」" if sp is not None else ""
    return f"這門武學的功效是：{'、'.join(names)}{tail}。名字要配得上它的功效。\n"
```

```python
class Mods(BaseModel):
    """這一場本人身上的功效換算成的數字（武學與成長設計 13.2、13.4）。由呼叫端（team.trait_mods）算好傳進來，
```

```python
def condition_of(now: float, cap: float, floor: float = CONDITION_FLOOR) -> float:
    """氣血狀態係數：滿血 1.0，見底 floor（預設五成；本人帶【厚】時高一點，武學與成長設計 13.2）。"""
    if cap <= 0:
        return 1.0
    return floor + (1 - floor) * max(0.0, min(1.0, now / cap))
```

```python
def resolve_encounter(
    our_power: float, difficulty: float, rng: Random, shift: float = 0.0, mods: Mods | None = None,
) -> EncounterResult:
    """shift 是判定差距的平移（大場面的優勢，見 advantage_shift）；平常是 0。mods 是本人的功效（13.2）：破甲讓對手
    當作弱一點（門檻與運氣都照當作的強度算）、借力加威力、穩與險改運氣的起伏、先手降大勝門檻、連環多擲一次運氣取好的。
    沒有連環時照舊只擲一次運氣。"""
    mods = mods or Mods()
    effective = difficulty * (1 - mods.difficulty_cut)
    half = luck_half(effective) * max(0.0, mods.luck_scale)
    luck = rng.uniform(-half, half)
    if mods.double_luck:
        luck = max(luck, rng.uniform(-half, half))
    margin = our_power + abs(difficulty) * mods.power_add - effective + luck + shift
    for tier, threshold in tier_thresholds(effective):
        if tier == "大勝":
            threshold -= abs(effective) * mods.big_win_cut
        if margin >= threshold:
            return EncounterResult(tier=tier, margin=margin, our_power=our_power, difficulty=difficulty)
    return EncounterResult(tier=FALLBACK_TIER, margin=margin, our_power=our_power, difficulty=difficulty)
```

```python
def reference_power(content, level):
    outer = with_quality(content_art("量武學", "量武學", "武學", "實", "下品"), "中品")
    inner = with_quality(content_art("量內功", "量內功", "內功", "柔", "下品"), "中品")

def rates(content, power, squad, mods):
    rng = random.Random(team.ESTIMATE_SEED)
    tiers = Counter(
        encounter.resolve_encounter(power, squad.difficulty, rng, mods=mods).tier for _ in range(team.ESTIMATE_RUNS)
    )
    runs = team.ESTIMATE_RUNS
    toll = sum(content.config.encounter_neili_loss.get(t, 0.0) * n for t, n in tiers.items()) / runs
    return 100 * sum(tiers[t] for t in team.WIN_TIERS) / runs, 100 * tiers["大勝"] / runs, 100 * toll

    squads = [content.squads[s] for s in sorted({s for loc in content.locations.values() for s in loc.enemies})]
    print("一、單一功效（三格、中品；勝率／大勝率／一場扣的氣血 %，對每一支隊伍的平均差）")
    for level in LEVELS:

        base = [rates(content, power, sq, encounter.Mods()) for sq in squads]
        print(f"  第 {level} 級（參考威力 {power:.0f}）")
        for trait in content.traits.general:

            print(f"    〔{trait.name}〕勝率 {win:+.1f}、大勝 {big:+.1f}（{note}）")
        for sp in content.traits.special:

            got = [rates(content, power, sq, team.trait_mods(content, lo)) for sq in squads]
```

## 計畫裡的決定（設計沒寫死、這份替實作選的）

| 題目 | 這份的做法 | 理由 |
|---|---|---|
| 程式裡的名字 | trait（`traits.py`、`MartialArt.traits`、`content/traits.json`） | `models.Effect` 已經是事件的效果，叫 effect 會混 |
| 一般功效怎麼存 | 存屬性的清單（`["剛", "快", "實"]`），功效名照內容的對照表 | 功效是一個屬性一個；改功效名不用動存檔 |
| 數字放哪 | `content/traits.json`（每層、上限、說明） | 設計 13.4：加新的特別功效只改內容；數字都是預設，校準只改內容 |
| 「真的改到結果」怎麼判 | 開打前的功效一帶就演；化勁、厚、不動要真的掉了氣血；打贏才演的三個要打贏；護命要真的改判 | 每一個都對得上 S1 分的時機（開打前、受傷、結果出來、戰鬥外） |
| 乘勝的經驗 | 整隊拿的經驗一起乘 | 經驗本來就是每人拿一樣多（FB-002）；只乘本人要另開一條路 |
| 護命與閃避 | 護命先套，套了就不擲閃避 | 設計 13.4「做好之後蓋過閃避」；也不多用亂數 |
| 勝算 | 含先手、穩、險、破甲、厚、連環、借力；不含護命與閃避 | 勝算是贏的機會（同 14.4 的判斷） |
| 爐子的預覽 | 已知配方寫「會合出【X】」與功效，沒人合過寫「沒人合過」 | 設計 13.6 |
