# 玉璽碎片 1：張角之死、爭奪、持璽勝利與董卓奪璽 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 第一季的「大勢任務：玉璽碎片一」（第一季設計第十節）的第一半：張角一死（第 10 週病逝、廣宗決戰、聲威被打到 0），傳國玉璽的一角流落廣宗、無主，勝利條件全服改寫成「倒數結束時碎片在誰手上，誰就是勝方」；有陣營的人在碎片所在的地點打守衛奪下它（散人奪不了），持有的一方投入守備；第一次被玩家陣營奪下就是全服躍進，開始兩週倒數（季曆），時刻表上剩下的大事壓縮進倒數，季末那一刻持有的陣營以「漢室重光／黃天當立／群雄得璽」收季；每一次易手都是具名的天下大事、寫進江湖史、頒稱號；碎片無主滿 48 個季曆小時，董卓搶走、擁兵自重，在他手上時勝負退回三方態勢，可以奪回。另外把 beta 的舊玉璽鏈在第一季關掉。週末設定這類季程壓縮過的季，碎片的時限與守衛強度照壓縮的倍數換算（企劃者 2026-10-06「照比例調整」，Task 12），完整長度的季照設計的原數字。全部藏在第一季的開關（而且這一季開季時蓋了碎片的章）後面，開關關著時 beta 一個字都不變。

**Architecture:** 碎片的樣子是 `state.ShardState`，存在共用賽季的 `WorldState.shard`（跟著那一季的 JSON 存，換季整個換掉）；開季時 `world_state.stamp_season` 照 `Config.season_one` 與 `shard_quest` 蓋章（`ShardState.on`），這份計畫之前開的季沒有章，碎片的規則不跑。內容在新的 `content/shard.json`（`models.ShardDef`：張角、董卓、廣宗、各陣營收藏碎片的地點與守衛、公告句）。規則在新的 `tianxia/shard.py`：`hour`（每曆時：入口一、董卓來搶）、`guard_squad`／`seize`（奪取）、`guard`（守備）、`start_countdown`（倒數與壓縮時刻表）、`winner`（持璽結局的勝方）、`admin_set`／`stop_countdown`（救場）、`pace`（照比例調整：時限乘這一季的壓縮倍數、守衛強度除以它的平方根，只在這裡換算）。`world.season_hour` 每曆時呼叫 `shard.hour`；`decisive_ending` 在任務推出後暫停；`evaluate_ending` 先看 `shard.winner`；`timetable.when` 讀壓縮過的時間。引擎的選項是 `act:seize`（奪取，打一場單次判定）與 `act:guard`（守備）；碎片的天下大事記成 `ShardNews`，江湖頁小標「大事」點開的本週大事面板與每個人的江湖紀錄照時刻表大事的做法補。

**Tech Stack:** Python 3.14、pydantic、FastAPI、原生 JavaScript、pytest。

## Global Constraints

- `tianxia/` 是純規則引擎，不得 import 任何網頁框架；引擎不讀電腦時鐘；資料庫是唯一的真實來源；數值全部由規則引擎決定（CLAUDE.md「架構」「原則」）。
- **開關**：每一個新行為只在 `shard.active(content, world)` 成立時發生——內容有 `shard.json`、`rules.season_one(content, world)`（`Config.season_one` 開著，而且那一季開季時蓋了「開」的章），**而且那一季開季時 `ShardState.on` 蓋成 True**（`Config.shard_quest`，預設 True）。所以：
  - 開關關著（beta）時：沒有碎片、沒有選項、沒有公告，`shard.winner` 是 None（結局照舊）、`shard.paused` 是 False（決定性勝利照舊）、`timetable.when` 照舊（schedule 裡沒有一般大事的 id）、本週大事面板與江湖紀錄照舊（碎片的公告是空的）。beta 的玉璽鏈照舊（`season_one_off` 在開關關著時是空的）。
  - **熱更新安全**：這份計畫上線前就開的第一季，WorldState 裡沒有 `shard` 這一欄，讀進來是 `ShardState(on=False)`，那一季碎片的規則一律不跑；要等管理者開下一季才有。季中把 `shard_quest` 改掉也不影響正在跑的那一季。
  - 開與關兩邊都有測試（Task 1、2、3、7、9、10）。
- **不改資料表、不升 `SCHEMA_VERSION`**：碎片存在 `seasons` 那一列的 JSON（`WorldState.shard`），守備的每日記號存在角色的 JSON（`PlayerState.shard_guarded`）。
- **新欄位都有預設值**，舊存檔、舊資料庫直接讀得進來：`WorldState.shard`、`PlayerState.shard_guarded`、`Ending.seal`、`SeasonOneOff.world_events`、`TimetableEvent.status_lines`、`Config.shard_*`、`Content.shard`（沒有 `shard.json` 就是 None，測試夾具照舊）、`FigureState.status` 多兩種值。
- **一個動作一筆交易；`mutate` 不能巢狀**：`shard.hour` 在 `world.season_hour` 裡跑（常在 `mutate_season` 裡），只改 `state.world`、不碰 store；跨季的玉璽紀錄（`record_jade_seal_fragment`，本身是一次 `mutate`）只在玩家的奪取動作（`Game._seize`）裡寫，不在任何 `mutate` 裡。
- **假人看不出來**：假人跟真人走同一個 `act:seize`／`act:guard`，公告、江湖史、稱號一律寫名號，真人假人一樣。

```python
def paused(state: GameState, content: Content) -> bool:
    """態勢的勝利條件暫停了嗎（第一季設計 4.4 末段）：大勢任務推出後，決定性勝利與季末比態勢都改看碎片；只有董卓持有的時候
    「勝利條件退回三方比態勢」（10.2 第 2 點）。"""
    w = state.world
    return active(content, w) and launched(w) and w.shard.phase != "rival"


def place_name(content: Content, loc_id: str | None) -> str:
    return content.locations[loc_id].name if loc_id in content.locations else (loc_id or "")


def faction_name(content: Content, faction: str | None) -> str:
    return next((f.name for f in content.scenario.factions if f.id == faction), faction or "")


def fill(content: Content, text: str, **slots: str) -> str:
    """公告句的插槽（ShardLines）：{keeper}、{rival} 照人物表的名字，其餘照呼叫端給的。"""
    sd = content.shard
    slots = {"keeper": figures.name_of(content, sd.keeper), "rival": figures.name_of(content, sd.rival), **slots}
    for key, value in slots.items():
        text = text.replace("{" + key + "}", value)
    return text


def announce(state: GameState, content: Content, title: str, text: str, chronicle: str = "") -> str:
    """碎片的一件天下大事（具名；傳聞分層設計第五節：天下大事人人看得到）：記一筆 ShardNews（江湖頁的公告卡、每個人的
    江湖紀錄由 Game 補）、一則天下大事傳聞（記在碎片所在的地點），有江湖史那一行就寫。回傳那一則的 id。"""
    w = state.world
    news = ShardNews(id=f"shard:{len(w.shard.news) + 1}", time=w.time, title=title, text=text)
    w.shard.news.append(news)
    add_rumor(state, text, w.shard.location, content=content, layer="world")
    if chronicle:
        add_chronicle(state, chronicle)
    return news.id


def hour(state: GameState, content: Content) -> list[str]:
    """每曆時一次（world.season_hour 在季的事之後呼叫）：入口一（持有碎片的人物退場或重創）。
    規則沒開、這一季沒蓋碎片的章、或季已經收了，什麼都不做。回傳「【江湖大事】」開頭的公告。"""
    w = state.world
    if not active(content, w) or w.ended:
        return []
    return _keeper_falls(state, content)


def _keeper_falls(state: GameState, content: Content) -> list[str]:
    """入口一（第一季設計 10.1「張角之死」；伏筆文件 6.3）：持有碎片的人物（張角）退場或重創——時刻表的病逝、廣宗決戰、
    挑戰把聲威打到 0 都算。還沒推出時：碎片流落廣宗、無主，大勢任務推出、勝利條件改寫；碎片本來就在他手上時
    （入口二先發生，第二份計畫）：碎片掉在廣宗、無主（先發生的算數：不再推出一次）。其他時候（已經有人奪下）不管他。"""
    sd, w = content.shard, state.world
    s = w.shard
    if s.phase not in ("hidden", "keeper") or not figures.is_out(state, sd.keeper):
        return []
    first = s.phase == "hidden"
    s.phase, s.holder, s.holder_name, s.location, s.since = "ownerless", None, None, sd.at, w.time
    place = place_name(content, sd.at)
    if first:
        s.launched_at = w.time
        text = fill(content, sd.lines.launch, place=place)
        announce(state, content, sd.lines.launch_title, text, fill(content, sd.lines.launch_chronicle, place=place))
    else:
        text = fill(content, sd.lines.drop, place=place)
        announce(state, content, sd.lines.launch_title, text)
    return [f"【江湖大事】{text}"]
```

```python
# ── 奪取 ─────────────────────────────────────────────────


def guard_strength(state: GameState, content: Content) -> int:
    """守衛強度（第一季設計 10.2 第 4 點「看持有陣營的態勢與投入的守備」）：無主時是 shard_guard_base（廣宗的亂兵）；
    玩家陣營持有時是 base ＋ 那個陣營的態勢 × shard_guard_per_stance ＋ 投入的守備（Task 5），四捨五入成整數。
    張角、董卓持有時不看這個，看他本人的聲威（figures.difficulty，8.4「守衛強度跟著聲威走」）。"""
    cfg, s = content.config, state.world.shard
    if s.phase != "held":
        return cfg.shard_guard_base
    standing = stances(state, content).get(s.holder or "", 0)
    value = cfg.shard_guard_base + standing * cfg.shard_guard_per_stance + s.guard.get(s.holder or "", 0)
    return int(round(value, 6) + 0.5)


def guard_squad(state: GameState, content: Content) -> Squad | None:
    """此刻要奪碎片得打的對手：無主是 guards["ownerless"]、玩家陣營持有是那個陣營的守衛，難度換成守衛強度；張角、董卓持有
    是他本人的隊伍（figures.squad_of，難度照聲威）。還沒現世是 None。"""
    sd, s = content.shard, state.world.shard
    if s.phase == "keeper":
        return figures.squad_of(state, content, sd.keeper)
    if s.phase == "rival":
        return figures.squad_of(state, content, sd.rival)
    key = "ownerless" if s.phase == "ownerless" else s.holder if s.phase == "held" else None
    if key is None:
        return None
    return content.squads[sd.guards[key]].model_copy(update={"difficulty": guard_strength(state, content)})


def seize(state: GameState, content: Content) -> list[str]:
    """（打贏守衛之後）state.player 替自己的陣營奪下碎片（第一季設計 10.2 第 1、4 點）：持有的陣營換成他的、碎片收進他的陣營的
    收藏地點、投入的守備歸零（換人持有就從 0 起）；全服具名廣播（天下大事，奪下的人自己這一則江湖紀錄已經寫了，不再補）；
    稱號（第一季設計 13.3：這一季第一個奪下的人是「奪璽先登」，之後每一次易手是「易璽之人」，江湖史由 honors.grant_now 寫）；
    記貢獻。回傳給奪下的人看的句子（公告全文）。呼叫端（Game._seize）先確定能奪。"""
    sd, w, p = content.shard, state.world, state.player
    s = w.shard
    first = not s.seizers
    s.phase, s.holder, s.holder_name = "held", p.faction, p.name
    s.location, s.since, s.guard = sd.vaults[p.faction], w.time, {}
    s.seizers.append(p.name)
    text = fill(
        content, sd.lines.seize, name=p.name, faction=faction_name(content, p.faction), place=place_name(content, s.location),
    )
    p.events_seen.append(announce(state, content, sd.lines.seize_title, text))
    honors.grant_now(state, content, "s1_shard_seize" if first else "s1_shard_change", p.name, faction=p.faction)
    push.add_contribution(p, calendar.point(w.time, content, w).week, content.config.shard_seize_contrib)
    return [text]
```

```python
# ── 守備 ─────────────────────────────────────────────────


def guard_problem(state: GameState, content: Content) -> str | None:
    """投入守備按不下去的原因（今天守過了、全陣營的守備已經滿了）；None＝可以。呼叫端先確定碎片在自己陣營手上、人在收藏地點。"""
    cfg, w, p = content.config, state.world, state.player
    if w.shard.guard.get(p.faction or "", 0) >= cfg.shard_guard_cap:
        return "守備已經滿了"
    if p.shard_guarded == calendar.point(w.time, content, w).cal_day:
        return "今天已經守過了，明天再來"
    return None


def guard(state: GameState, content: Content) -> list[str]:
    """投入守備（第一季設計 10.2 第 4 點「守衛強度看持有陣營的態勢與投入的守備」）：碎片在自己陣營手上、人在收藏地點的人，
    每個曆日一次，替陣營加 shard_guard_step 點守衛強度（全陣營加到 shard_guard_cap 為止，換人持有就從 0 起），記貢獻。
    體力由呼叫端扣（Game._guard）。回傳給他看的句子。"""
    cfg, w, p = content.config, state.world, state.player
    s = w.shard
    at = calendar.point(w.time, content, w)
    s.guard[p.faction] = min(cfg.shard_guard_cap, s.guard.get(p.faction, 0) + cfg.shard_guard_step)
    p.shard_guarded = at.cal_day
    push.add_contribution(p, at.week, cfg.shard_guard_contrib)
    return [f"你在{place_name(content, s.location)}加派人手，輪班守著碎片。（守備 {s.guard[p.faction]}／{cfg.shard_guard_cap}）"]
```

```python
# ── 倒數 ─────────────────────────────────────────────────


def start_countdown(state: GameState, content: Content) -> float:
    """全服躍進（第一季設計 10.2 第 1、3 點）：從此刻起倒數 shard_countdown_days 個季曆日，倒數結束時碎片在哪一方手上，哪一方勝。
    做法是把季末挪到倒數結束那一刻：時刻表上還沒到、還沒開打的大事（含三場決戰）照時間比例壓縮進這段倒數，順序不變、
    季末照常是下曲陽那一則公告（「時刻表上剩下的大事壓縮進這兩週發生，季提早結束但有完整收尾」）。挪過的記在
    ShardState.moved（管理者停止倒數時還原）。倒數會超過排定的季末時不壓縮，照排定的季末收（待企劃者確認 1）。
    回傳倒數結束的世界秒（記在 countdown_end）。"""
    w = state.world
    s = w.shard
    start = w.time
    end = start + content.config.shard_countdown_days * DAY / calendar.cal_scale(content, w)
    finale_event = next((e for e in content.timetable if e.kind == "finale"), None)
    finale = timetable.when(state, content, finale_event) if finale_event is not None else end
    if end < finale - calendar.EPS_SECONDS:
        ratio = (end - start) / (finale - start)
        for event in content.timetable:
            if event.id in w.timeline or event.id in w.showdowns_opened:
                continue
            at = timetable.when(state, content, event)
            if at <= start + calendar.EPS_SECONDS:
                continue  # 時間已經到了的照舊在這一刻結算
            key = timetable.schedule_key(event)
            s.moved.setdefault(key, at)
            w.schedule[key] = start + (at - start) * ratio
    s.countdown_end = min(end, finale)
    return s.countdown_end
```

```python
# ── 持璽結局 ───────────────────────────────────────────────


def winner(state: GameState, content: Content) -> str | None:
    """持璽結局的勝方（第一季設計 10.2 第 5 點、13.1）：大勢任務推出後，碎片在玩家陣營手上就是那個陣營；在張角手上是張角的
    陣營（「張角若一路守到季末，黃巾以持璽獲勝」）。無主、董卓持有、還沒推出都是 None：退回三方比態勢。
    world.evaluate_ending（收季時挑結局）與世界記憶的 seal_holder 都讀它。"""
    w = state.world
    s = w.shard
    if not active(content, w) or not launched(w):
        return None
    if s.phase == "held":
        return s.holder
    if s.phase == "keeper":
        return content.figures[content.shard.keeper].faction
    return None
```

```python
ADMIN_TARGETS = ("ownerless", "rival")  # 加上劇本的陣營 id


def admin_set(state: GameState, content: Content, target: str) -> list[str] | None:
    """管理者直接定碎片在哪（救場）：target 是陣營 id（收進那個陣營的收藏地點）、ownerless（無主，在廣宗，董卓的時鐘重算）、
    rival（董卓搶走）。效果跟自然發生一樣：還沒推出就先推出（勝利條件改寫的公告照發）；第一次落到玩家陣營手上就開始倒數；
    董卓的狀態跟著換（持璽 rebel_seal、手上沒了 rebel）。公告照發、不寫是管理者；稱號、貢獻、跨季紀錄不發（沒有人真的奪下）。
    state.player 是管理者：公告已經寫進他這一則，同步時不再補。target 認不得回 None。"""
    sd, w = content.shard, state.world
    s = w.shard
    if target not in (*ADMIN_TARGETS, *(f.id for f in content.scenario.factions)):
        return None
    msgs: list[str] = []
    if not launched(w):  # 還沒推出：照入口一推出（碎片先流落廣宗）
        s.phase, s.location, s.since, s.launched_at = "ownerless", sd.at, w.time, w.time
        place = place_name(content, sd.at)
        msgs.append(fill(content, sd.lines.launch, place=place))
        chronicle = fill(content, sd.lines.launch_chronicle, place=place)
        state.player.events_seen.append(announce(state, content, sd.lines.launch_title, msgs[-1], chronicle))
        if target == "ownerless":
            return msgs
    rival = w.figures.get(sd.rival)
    if s.phase == "rival" and rival is not None and rival.status == "rebel_seal":
        rival.status = "rebel"
    if target == "ownerless":
        s.phase, s.holder, s.holder_name, s.location = "ownerless", None, None, sd.at
    elif target == "rival":
        s.phase, s.holder, s.holder_name = "rival", None, None
        s.location = rival.location if rival is not None and rival.location else sd.at
        if rival is not None:
            rival.status = "rebel_seal"
    else:
        s.phase, s.holder, s.holder_name, s.location, s.guard = "held", target, None, sd.vaults[target], {}
    s.since = w.time
    text = fill(content, sd.lines.admin, place=place_name(content, s.location))
    if s.phase == "held" and s.countdown_end is None:
        text += fill(content, sd.lines.countdown, when=calendar.stamp_text(start_countdown(state, content), content, w))
    state.player.events_seen.append(announce(state, content, sd.lines.seize_title, text))
    return msgs + [text]


def stop_countdown(state: GameState, content: Content) -> bool:
    """管理者停止倒數：壓縮過的大事（ShardState.moved）還沒結算、還沒開打的照原本的時間放回去，季末也回到原本排定的時間；
    之後再有人第一次奪下碎片（碎片又落到玩家陣營手上）會重新開始倒數。沒有在倒數回 False。"""
    w = state.world
    s = w.shard
    if s.countdown_end is None:
        return False
    for key, at in s.moved.items():
        if key == timetable.FINALE_KEY or (key not in w.timeline and key not in w.showdowns_opened):
            w.schedule[key] = at
    s.countdown_end, s.moved = None, {}
    return True
```

```python
# ── 照比例調整（企劃者 2026-10-06「照比例調整」）─────────────────────


class Pace(NamedTuple):
    """這一季碎片實際用的時限與難度。設定裡的數字（shard_ownerless_hours、shard_countdown_days、守衛強度的公式）是完整長度的季
    用的；季程壓縮過的季只在 pace 這裡換算，其他地方一律讀這一份。"""

    ownerless_hours: float  # 碎片無主滿幾個季曆小時，董卓來搶
    countdown_days: float  # 第一次被玩家陣營奪下後倒數幾個季曆日（超過排定的季末就照季末，start_countdown）
    guard: float  # 守衛強度的倍數：無主的亂兵、玩家陣營持有時的整條公式都乘它


def compression(content: Content, season: WorldState) -> float:
    """這一季比完整長度的季（DEFAULT_SEASON_DAYS 天）壓縮了幾倍：完整的季是 1，週末設定的 2.5 天是 5.6。
    照這一季開季時蓋的季長（season_length_days）；比完整的季還長的也當 1（不放寬、也不加難）。"""
    return max(1.0, DEFAULT_SEASON_DAYS / season_length_days(season, content))


def pace(content: Content, season: WorldState) -> Pace:
    """照比例調整（k＝compression）：
    - 時限乘 k：時限是留給人行動的時間，而人的行動照現實時間走（體力照現實時間回、路照現實時間走、假人照現實時間一輪一動），
      所以時限在季曆上放長 k 倍，現實長度就跟完整的季一樣（無主 48 季曆小時＝現實 8 小時；倒數兩週＝現實約 2.3 天）。
    - 守衛強度乘 k 的 −shard_guard_pace 次方（預設除以 √k）：戰力也是照現實時間練的，同一個季曆週，壓縮過的季大家只練了
      1/k 的時間。整季模擬量到第 9、10 週假人的戰力：完整的季中位數 28～31、打得過 40 的 15 人裡有 6～7 個；週末設定中位數
      15～17、有 2～3 個——要讓「打得過守衛的人」佔的比例跟完整的季差不多，守衛強度要除以約 √5.6≒2.4（40 → 17）。
    完整長度的季 k＝1，三個數字都是設定的原數字。"""
    k = compression(content, season)
    cfg = content.config
    return Pace(
        ownerless_hours=cfg.shard_ownerless_hours * k,
        countdown_days=cfg.shard_countdown_days * k,
        guard=k ** -cfg.shard_guard_pace,
    )
```
