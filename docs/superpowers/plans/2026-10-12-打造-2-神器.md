**Goal:** 先修 **FB-141**（打造一爐一則紀錄，結果句排在最後，375 寬「剛剛」收著時只看得到挑主料那一行）：開爐成了那一下併進「打造」那一則時只留結果。接著做打造隱藏配方設計第十三節「第二批」。**神器配方**開始挑，每季照天機挑兵器 2、防具 1，這一季全服同一批。企劃者選了 14.1 甲：打中神器配方一爐必出神器，不擲品質。全服第一把是**原品**，名字先寫「無名神器」，打出的人在修練頁定名（同絕學定名：自己打字過 `naming.name_problem`、原子登記、江湖史一行、江湖上傳一句；另有一顆「沿用譜名」；不能跟別種兵器的字、架上的現成貨、一般組合字表組得出的名字同名）。之後照同一個配方打出的都是**仿品**，叫「仿・原品名」，原品還沒定名時叫「仿・無名神器」，定名之後讀檔照全服那一列重寫。原品主人每多一個不同的人打出仿品就多一點首創名望回饋。加成：兵器原品 +26%、仿品 +23%，防具原品 29%、仿品 26%，都算上品。原品不能拆、不能交求兵懸賞（手上那把也排除）。**神器譜**放在見聞→江湖史底下，跨季保留。**三階素材新來源**（兵器設計 4.9）：挑戰大勢人物本人打贏必掉一個三階，屬性照他；大場面對手打贏另擲一次三階。兩種都用自己的亂數，不碰 `Game.rng`（FB-129）。**伺服器假人開始打造**（PM 決定第 3 條）：照整季機器人的挑法打一般組合與名器，打完換上更好的那把；打中神器配方時，過一兩輪按「沿用譜名」定名。假人只走 `Game` 的公開行動，不淬煉。名將本命兵器是第三批，這一份不寫。

**Architecture:** 神器的全部規則掛在第一批的那幾個模組上，不另開模組。
- `forge_secrets.py` 多這幾樣：原品主人在 `new_find` 那一筆裡一起記，照甲首位發現者就是原品主人；`arrival` 寫原品、仿品那一句。`refresh_names(p, content, world)` 讓原品、仿品的名字照全服那一列重寫。定名的檢查有 `table_names`、`divine_name_problem`、`TABLE_CLASH`。`unnamed_originals` 列出還等著定名的原品。另有 `key_for`、`owned_gear`、`what_text`、神器譜 `divine_book` 與 `DIVINE_BOOK`。
- `smithing.forge` 打中神器配方時不擲品質，第一把是原品，之後是仿品，仿品數加一。`smithing.name_divine` 是定名，照 `cultivation.name_mastered` 那一套。`go_option` 對自己鑄譜上打中過的神器配方寫 `DIVINE_HEAD`。
- 全服資料沿用第 4 版的 `gear_recipes`：`GearFind` 多 `divine`、`owner`、`master_shown`、`divine_name`、`copies` 幾欄，舊列讀成名器。新的存取有 `world.add_copy`、`world.name_divine`（原子，定的名字寫進名字欄、佔名字空間）、`world.divine_records`（跨季）。**資料庫不升版**。
- 加成在 `weapons.bonus`／`armor.cut`：原品、仿品的基本值取代階那一格，品質照查表，不另加名器的 2%。階品：`equipment.grade` 多「・神器」「・仿品」。原品不能拆，`equipment.dismantle` 擋；求兵由 `bounties.fit_problem` 擋。
- 三階素材：`materials.tier3_pick` 是純函式，照屬性挑、種子決定。`Game._tier3`、`_figure_tier3` 用自己的 `random.Random(種子)`。
- 假人：`bot.forge_step` 給出單子的下一步，`bot_policy._smith_want` 先問換買修、再問打造。定名在 `bot_policy._name_originals`，整季機器人在 `bot.keep_book_names`。
- 畫面：修練頁那一列底下一張定名表單，`skillview.gear_rows` 給 `divine`；送 `MENXIA_ACTIONS["name_divine"]`。
- FB-141：`journal.add_entry(..., fold=True)`，開爐成了那一下用。

**Tech Stack:** Python 3.12、pydantic、SQLite（不動結構）、pytest（`-n auto`）、原生 JavaScript 網頁（`web/app.js`、node 假瀏覽器測試）。

```python
    """最新的放最前面，只留最近 MAX_ENTRIES 則。
    merge=True 且最新一則是同一類（同標題）時併進那一則：敘事依序接上、數值變化加總、時間與結果標記用新的。

    結果句排第一（375 寬「剛剛」收著時看得到）；數值變化、引導照樣加總。併不進去（標題不同）時 fold 不起作用。"""
    head = _mergeable_head(state, entry) if merge else None
    if head is not None:
        state.journal[0] = _merged(head, entry, _story(entry) if fold else _story(head) + _story(entry))
        return
    state.journal.insert(0, entry)
    del state.journal[MAX_ENTRIES:]
```

```python
TABLE_CLASH = "跟鐵匠鋪尋常打得出的名字同名"  # 待 joy 潤：神器定的名字跟一般組合字表組得出的名字撞了


def what_text(slot: str, kind: str) -> str:
    """寫給人看的「哪一種」：兵器寫兵器字（weapons.NOUNS：劍、拳套），防具寫「防具」。"""
    return weapons.NOUNS.get(kind, kind) if slot == "weapon" else "防具"


def table_names(content: Content) -> set[str]:
    """一般組合的字表組得出來的每一個名字（5.2）：兵器 字首×兵器中間字×兵器字、防具 字首×防具中間字×甲鎧袍衫。用整張字表（不只前
    「素材數」個字），joy 之後在素材表後面加素材也擋得住。約三千個字串，只在定名時現算，不快取。"""
    names = content.craft_names
    made = {p + m + n for p in names.prefixes for m in names.weapon for n in weapons.NOUNS.values()}
    return made | {p + m + n for p in names.prefixes for m in names.armor for n in armor.FORGE_WORDS}


def divine_name_problem(content: Content, slot: str, kind: str, name: str) -> str | None:
    """神器原品定的名字還要過的（5.2；name_problem 另外過）：兵器不能有**別種**兵器的字（不要求帶自己這一種的字，例「斬月」）、
    不能跟架上的現成兵器同名；防具不能有兵器的字、不能跟架上的防具同名；都不能跟一般組合的字表組得出的名字同名
    （不然「仿・X」跟一般組合的「X」並存）。None＝可以。"""
    if slot == "weapon":
        if any(word in name for other, words in weapons.WEAPON_WORDS.items() if other != kind for word in words):
            return weapons.KIND_CLASH
        if name in {weapons.shop_name(k, a) for k in WEAPON_KINDS for a in weapons.ATTR_WORDS}:
            return weapons.SHOP_CLASH
    else:
        if any(word in name for words in weapons.WEAPON_WORDS.values() for word in words):
            return armor.WORD_CLASH
        if name in armor.SHOP_NAMES.values():
            return armor.SHOP_CLASH
    if name in table_names(content):
        return TABLE_CLASH
    return None


def unnamed_originals(state: GameState, world: WorldStateStore) -> dict[str, str]:
    """身上、裝備庫、寄放的神器原品裡還等著你定名的（5.2）：裝備 id → 譜名（「沿用譜名」那一顆寫的字，登記當下記的 GearFind.title）。

    p = state.player
    out: dict[str, str] = {}
    for item in owned_gear(p):
        if not item.original or item.secret is None:
            continue
        find = world.lookup_gear_find(key_for(item.secret))
        if find is not None and find.divine and find.owner == p.name and find.divine_name is None:
            out[item.id] = find.title
    return out
```

```python
    state: GameState, content: Content, world: WorldStateStore, item_id: str, name: str, keep: bool = False,

    pending = forge_secrets.unnamed_originals(state, world)
    if item_id not in pending:
        return False, [NAME_GONE]
    item = next(i for i in forge_secrets.owned_gear(state.player) if i.id == item_id)
    if keep:
        name = pending[item_id]
    else:
        name = naming.clean_name(name)
        problem = naming.name_problem(name, content, world.is_character_name) or forge_secrets.divine_name_problem(
            content, item.slot, item.kind, name)
        if problem is not None:
            return False, [NAME_BAD.format(problem=problem)]
    reason = world.name_divine(forge_secrets.key_for(item.secret), state.player.name, name)
    if reason == "taken":
        return False, [NAME_TAKEN.format(name=name)]
    if reason is not None:
        return False, [NAME_GONE]
    item.name = name
    rule, who = content.config.forge_secrets, state.player.name
    add_chronicle(state, rule.named_chronicle.format(who=who, name=name, what=forge_secrets.what_text(item.slot, item.kind)))
    add_rumor(state, rule.named_rumor.format(who=who, name=name), None, content=content, named=True)
    return True, [DIVINE_NAMED.format(name=name)]
```

```python
def divine_book(records: list[tuple[int, GearFind]]) -> str:
    """神器譜那一段的 Markdown（Game.chronicle_text 接在江湖史後面）：一把一行——第幾季、名字（還沒定名寫「無名神器（劍）」）、

    if not records:
        return ""
    lines = []
    for season, find in records:
        what = what_text(find.slot, find.kind)
        name = f"【{find.divine_name}】" if find.divine_name else f"{DIVINE_UNNAMED}（{what}）"
        copies = f"，仿品 {find.copies} 把" if find.copies else ""
        lines.append(f"- 第 {season} 季　{name}　{what}・屬{find.attribute}　原品在{find.master_shown or find.owner}手上{copies}")
    return f"{DIVINE_BOOK}\n\n" + "\n".join(lines)
```

```python
def tier3_pick(content: Content, attribute: str | None, seed: str) -> str | None:
    """三階素材的新來源（兵器設計 4.9；打造第二批）挑哪一個：剛柔快慢直接對；陰陽虛實是兩個屬性合出來的（insights.PAIR_ATTRIBUTES），
    照種子的 sha256 從兩個來源挑一個（同 equipment.dismantle_material）；沒寫屬性、該屬性沒有三階素材時在全部三階裡照種子挑。
    決定性、不擲 Game.rng。沒有三階素材是 None。"""
    digest = hashlib.sha256(seed.encode("utf-8")).digest()
    sources = next((sorted(pair) for pair, result in PAIR_ATTRIBUTES.items() if result == attribute), None)
    if sources is not None:
        attribute = sources[digest[0] % 2]
    tier3 = [m for m in content.materials.values() if m.tier == 3]
    pool = [m for m in tier3 if m.attribute == attribute] or tier3
    return pool[digest[1] % len(pool)].id if pool else None
```

```python
        treasures.challenge_drop），不碰 Game.rng：整季測試與量表的亂數序列不位移（FB-129）。序章不掉。"""
        if chance <= 0 or prologue_rules.active(self.state, self.content):

        seed = f"三階|{self.world.get_season_number()}|{self.state.player.name}|{record.id}|{tag}"

            return []
        mid = materials.tier3_pick(self.content, squad.attribute, seed)
        line = materials.grant(self.state, self.content, mid) if mid is not None else None
        if not line:

        record.materials.append(line.removeprefix(materials.GRANT_PREFIX))
        return [line]
```

```python
def forge_step(game: Game) -> str | None:
    """伺服器假人在鐵匠鋪打造的下一顆（打造第二批，PM 2026-10-12 決定第 3 條）：照整季機器人的 forge_plan／armor_plan 挑這一爐
    （一般組合、名器、偶然碰上的神器配方都照打；不讀口訣），回單子的下一步——打開 → 種類 → 主料 → 輔料 → 開爐（防具沒有種類）；
    單子跟這一爐對不上（存檔留下的、計畫變了）回「不打了」。沒有要打的時候，兵器頁上裝備庫裡有比手上更好的那把就換上
    （smithing.better_in_rack；防具的換上 armor.wanted 本來就會）；這一頁沒事、另一頁有一爐要打回切頁那一顆（同 smith_want）。
    工錢付了之後剩不到 FORGE_SILVER_RESERVE 兩的那一爐不打。不淬煉、不拆。沒事是 None。"""
    s, c, w = game.state, game.content, game.world
    p = s.player
    art = team.player_art(s, c, w, p.member.wugong_id)

    def affordable(plan):
        if plan is None:
            return None
        cost = smithing.price(c, smithing.tier_of(c, plan[1]), smithing.slot_of(plan[0]))
        return plan if p.stats.get("silver", 0) - cost >= FORGE_SILVER_RESERVE else None

    plans = {
        "weapon": affordable(smithing.forge_plan(s, c, w, art)),
        "armor": affordable(smithing.armor_plan(s, c, w, team.player_art(s, c, w, p.member.neigong_id))),
    }
    d = p.smith_draft
    if d is not None:
        plan = plans.get(smithing.slot_of(d.kind))
        if plan is None:
            return smithing.CANCEL
        kind, main, aux = plan
        if d.kind not in (None, kind) or d.main not in (None, main) or d.aux not in (None, aux):
            return smithing.CANCEL
        if d.kind is None:
            return f"{smithing.KIND}{kind}"
        if d.main is None:
            return f"{smithing.MAIN}{main}"
        if d.aux is None:
            return f"{smithing.AUX}{aux}"
        return f"{smithing.GO}{kind}:{main}:{aux}"
    here = equipment.page(p, c) if p.picking_smith else equipment.first_page(c)
    if plans.get(here) is not None:
        return smithing.OPEN
    better = smithing.better_in_rack(s, c, w, art) if here == "weapon" else None
    if better is not None:
        return f"smith:wield:{better.id}"
    other = next((slot for slot, plan in plans.items() if plan is not None and slot != here), None)
    return None if other is None else f"smith:page:{other}"
```
