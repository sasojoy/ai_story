# 兵器（第二批：自己打造）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 玩家在城鎮的鐵匠鋪挑種類、主料、輔料打一把兵器（屬性照兩樣素材、階照主料、品質每爐擲骰，配方全服共享、第一個打出來的人等模型取名），用素材淬煉身上那把；拆解先問一次（FB-125）；整季機器人會打造與淬煉，伺服器假人不打造。

**Architecture:** 新模組 `tianxia/smithing.py` 放打造與淬煉的全部規則（配方、屬性、工錢、拒絕原因、品質機率、三段式取名的 A 段與 C 段、鐵匠鋪一步一步的選單、淬煉、機器人用的判斷）；它 import `team`、`fusion`，所以 `weapons` 不能 import 它（`team` 會 import `weapons`）。純文字與名字的小工具（配方鍵、兵器字、退路字表、階品寫法）放在 `weapons.py`，`content.py` 驗退路字表時只 import `weapons`。全服兵器配方存在資料庫第 4 版新加的 `gear_recipes` 表（配方鍵的前綴就是欄位：武器「兵|」，之後防具打造用「鎧|」共用這張表），名字跟武學、改過的名字、意境共用一個名字空間。鐵匠鋪的「打造兵器…」是一步一步的選單（`PlayerState.smith_draft`），開爐那一顆的 id 把整張單子寫在裡面（`smith:forge-go:<種類>:<主料>:<輔料>`），A 段與 C 段讀同一張單子；伺服器在 `server.choose` 對這一顆走鎖外取名。

**Tech Stack:** Python 3.12、pydantic、SQLite、pytest（`-n auto`）、原生 JavaScript 網頁（`web/app.js`、node 假瀏覽器測試）。

**Spec:** `docs/superpowers/specs/2026-10-09-兵器-design.md`（4.2 打造、4.3 品質擲骰、4.4 配方全服共享與首創取名、4.7 淬煉、4.7.1 拆解的確認；第五節資料；第六節機器人與假人；第八節第二批）。另依企劃者 2026-10-10 的第二批附帶決定 (a)～(e)（寫在下面 Global Constraints）。

**跟《裝備四欄》的關係**：同一天的 `docs/superpowers/specs/2026-10-10-裝備四欄-design.md`（待企劃者審閱全文）把兵器擴成四欄（武器、防具、坐騎、寶物），本計畫是裡面「兵器二」那一塊。先後已定，見下一節。

FORGE_PREFIX = "兵|"  # 兵器配方鍵的開頭（兵器設計 4.4）：前綴就是欄位（裝備四欄設計 4.7），之後防具打造用同一張 gear_recipes 表、前綴「鎧|」


def recipe_key(kind: str, main: str, aux: str) -> str:
    """兵器配方鍵（4.4）：「兵|種類|主料+輔料」。前綴「兵|」就是武器那一欄（之後防具是「鎧|主料+輔料」，共用 gear_recipes）。
    主輔不交換：同兩種素材對調是另一個配方。"""
    return f"{FORGE_PREFIX}{kind}|{main}+{aux}"


def recipe_parts(key: str | None) -> tuple[str, str, str] | None:
    """recipe_key 拆回（種類, 主料, 輔料）；不是武器欄的配方鍵（別的前綴，例如之後防具的「鎧|」，或 None）回 None。"""
    if not key or not key.startswith(FORGE_PREFIX):
        return None
    kind, _, pair = key[len(FORGE_PREFIX):].partition("|")
    main, plus, aux = pair.partition("+")
    return (kind, main, aux) if kind and plus and main and aux else None


def new_weapon(
    state: GameState, *, name: str, kind: str, attribute: str, tier: int, quality: str, recipe: str | None = None,
) -> Weapon:
    """新的一把（流水號 +1）；recipe 是自己打的那一把的配方鍵，買的與掉落的沒有。"""
    state.player.weapon_serial += 1
    return Weapon(id=f"兵:{state.player.weapon_serial}", name=name, kind=kind, attribute=attribute, tier=tier, quality=quality,
                  recipe=recipe)

| 引擎 | 配方鍵、屬性、階、工錢、品質擲骰、全服登記、淬煉 |

這個模組 import team 與 fusion（品質的推法、悟性、天時地利）；team 會 import weapons，所以 weapons 不能 import 這裡。
鐵匠鋪的選單項（Option）在 engine 裡，回選單的函式延後 import（同 foreshadow.talk_options）。"""
from __future__ import annotations

from collections import Counter

from . import weapons
from .insights import merged_attribute
from .models import WEAPON_KINDS, Content
from .state import GameState
from .world_state import WorldStateStore

NOT_ENOUGH = "身上的素材不到兩個"  # 待 joy 潤


def tier_of(content: Content, main: str) -> int:
    """打出來的階照主料的階（4.2）。"""
    return content.materials[main].tier


def price(content: Content, tier: int) -> int:
    """打一把這一階的工錢（4.2，Config.weapons.forge_silver）。"""
    return content.config.weapons.forge_silver.get(str(tier), 0)


def attribute_with(content: Content, tianji: int, kind: str, main: str, aux: str) -> str:
    """打出來的屬性（4.2）：照 insights.merged_attribute，種子是「天機|配方鍵」（同 fusion.recipe_seed），所以同一季同一個配方一樣。
    同屬性與四對（剛快、柔慢、快柔、剛慢）合出來的跟主輔順序無關；其餘組合（剛柔、快慢）照種子的雜湊挑兩者之一，配方鍵分主輔，
    主輔對調是另一個配方，挑到的屬性可能不同（4.4：主輔不交換）。選單一次要算好幾個時先讀一次天機，用這一個。"""
    seed = f"{tianji}|{weapons.recipe_key(kind, main, aux)}"
    return merged_attribute(content.materials[main], content.materials[aux], seed)


def attribute_of(world: WorldStateStore, content: Content, kind: str, main: str, aux: str) -> str:
    return attribute_with(content, world.read().tianji, kind, main, aux)


def forge_problem(state: GameState, content: Content, kind: str, main: str, aux: str) -> str | None:
    """打不成的原因；None＝打得成。順序：不在鐵匠鋪、種類、素材認不得、素材不夠（主輔同一種要兩個）、裝備庫滿、銀兩不夠。
    鐵匠鋪的鈕灰掉時寫它，C 段（forge）也再驗一次。"""
    if not weapons.smith_here(state, content):
        return weapons.NOT_HERE
    if kind not in WEAPON_KINDS:
        return "沒有這種兵器"
    if main not in content.materials or aux not in content.materials:
        return "沒有這種素材"
    held = state.player.materials
    for mid, need in Counter([main, aux]).items():
        if held.get(mid, 0) < need:
            return f"{content.materials[mid].name}不夠（要 {need} 個）"
    if weapons.rack_full(state, content):
        return weapons.RACK_FULL
    short = price(content, tier_of(content, main)) - state.player.stats.get("silver", 0)
    return f"還差 {short} 兩" if short > 0 else None

```python
def odds_from_points(scored: list[tuple[str, float]], rule, base: dict[str, float]) -> QualityOdds:
    """把各因素的分數加成造化分，從 base（普通搭配的平均）往上或往下推，上品、下品各自夾住，中品是剩下的。
    rule 要有 up_per_point、low_per_point、up_range、low_range、shown_from、lines（FuseQuality、SmithQuality 都有）；
    合成（_points）與打造（smithing.forge_odds）共用這一個。"""
    total = sum(base.values()) or 1
    up0, low0 = base.get("上品", 0) * 100 / total, base.get("下品", 0) * 100 / total
    score = sum(points for _, points in scored)
    up = min(max(up0 + score * rule.up_per_point, rule.up_range[0]), rule.up_range[1])
    low = min(max(low0 - score * rule.low_per_point, rule.low_range[0]), rule.low_range[1])
    up, low = round(up), round(low)
    odds = {"下品": float(low), "中品": float(max(0, 100 - up - low)), "上品": float(up)}
    shown = sorted((item for item in scored if abs(item[1]) >= rule.shown_from), key=lambda item: -abs(item[1]))
    reasons = []
    for factor, points in shown:
        line = rule.lines.get(factor, ["", ""])[0 if points > 0 else 1]
        if line and len(reasons) < 2:
            reasons.append(line)
    return QualityOdds(odds, tuple(reasons))


def _points(content: Content, scored: list[tuple[str, float]]) -> QualityOdds:
    """合成的品質機率：權重是 Config.fuse_quality，從普通搭配的平均（Config.fuse_quality_odds）推。"""
    cfg = content.config
    return odds_from_points(scored, cfg.fuse_quality, cfg.fuse_quality_odds)
```

class SmithQuality(_Strict):
    """打造的品質機率（兵器設計 4.3；跟 FuseQuality 同一套推法，fusion.odds_from_points）：這一爐的組成加成造化分，
    從 odds（下品 50／中品 30／上品 20）往上或往下推，上品夾在 up_range、下品夾在 low_range。數字都是【預設】。
    天時地利（企劃者 2026-10-10 第二批附帶決定 b：沿用合成那一套）預設 0（測試內容不開），正式值在 config.json：
    地利同合成（此地探索悟得到同屬性的意境，fusion.terrain_here），戰場、心靜也同合成；兵器沒有正邪，所以沒有晝夜。"""

    odds: dict[str, float] = Field(default_factory=lambda: {"下品": 50, "中品": 30, "上品": 20})
    up_per_point: float = Field(default=0.5, ge=0)
    low_per_point: float = Field(default=1.0, ge=0)
    up_range: tuple[float, float] = (5, 45)
    low_range: tuple[float, float] = (15, 80)
    # 輔料比主料高幾階 → 分數（「-1」是輔料低一階）：同階或更高加分、低階扣分（4.3）
    aux_tier: dict[str, float] = Field(default_factory=lambda: {"-2": -16, "-1": -8, "0": 4, "1": 8, "2": 12})
    wis_weight: float = Field(default=0.5, ge=0)  # 悟性：stat_factor 多出來的百分點 × 這個（同 FuseQuality.wis_weight）
    practice_point: float = Field(default=2, ge=0)  # 熟手：這個配方這一季你打過一次加幾分
    practice_cap: float = Field(default=10, ge=0)  # 熟手最多加幾分
    terrain: float = 0  # 地利：此地探索悟得到跟打出來的兵器同屬性的意境（fusion.terrain_here，同合成）
    battlefield: float = 0  # 戰場：打出剛的兵器、人在營寨或（第一季）亂局的大區（fusion.battlefield_here）

def setting_points(state: GameState, content: Content, attribute: str) -> list[tuple[str, float]]:
    """打造的天時地利（附帶決定 b）：地利、戰場、心靜都同合成（地利看此地探索悟得到同屬性的意境）。最多 setting_max 條。
    兵器沒有正邪，所以合成的「晝夜」這裡沒有。"""
    rule = content.config.weapons.quality
    out: list[tuple[str, float]] = []
    if rule.terrain and fusion.terrain_here(state, content, attribute):
        out.append(("terrain", rule.terrain))
    if rule.battlefield and attribute == "剛" and fusion.battlefield_here(state, content):
        out.append(("battlefield", rule.battlefield))
    if rule.calm and fusion.calm_now(state, rule.calm_hours):
        out.append(("calm", rule.calm))
    out.sort(key=lambda item: -abs(item[1]))
    return out[: rule.setting_max]


def setting_line(content: Content, scored: list[tuple[str, float]]) -> list[str]:
    """結果多一句含蓄的話：天時地利合起來加分寫 setting_good、扣分寫 setting_bad；沒有、或那句是空的就不寫。"""
    rule = content.config.weapons.quality
    total = sum(points for _, points in scored)
    line = rule.setting_good if total > 0 else rule.setting_bad if total < 0 else ""
    return [line] if line else []


def forge_odds(state: GameState, content: Content, world: WorldStateStore, kind: str, main: str, aux: str) -> QualityOdds:
    """這一爐的品質機率（4.3）：輔料的階（比主料高幾階）、悟性、熟手（這個配方這一季打過幾次，有上限）、天時地利，
    從 Config.weapons.quality.odds 推（fusion.odds_from_points）。只看這一爐的組成，配方有沒有人打過都一樣。"""
    rule = content.config.weapons.quality
    m, a = content.materials[main], content.materials[aux]
    wis = state.player.stats.get("wis", team.BASE_STAT)
    done = state.player.forge_counts.get(weapons.recipe_key(kind, main, aux), 0)
    scored = [
        ("aux", rule.aux_tier.get(str(a.tier - m.tier), 0.0)),
        ("wis", (team.stat_factor(content, wis) - 1) * 100 * rule.wis_weight),
        ("practice", min(rule.practice_cap, rule.practice_point * done)),
    ]
    scored += setting_points(state, content, attribute_of(world, content, kind, main, aux))
    return fusion.odds_from_points(scored, rule, rule.odds)

    "劍": ("劍",), "刀": ("刀",), "槍": ("槍", "矛"), "棍": ("棍", "杖", "錘"), "弓弩": ("弩", "弓"), "拳腳": ("拳套", "護手", "拳"),

SHOP_CLASH = "跟鐵匠鋪架上的兵器同名"  # 待 joy 潤


def kind_problem(kind: str, name: str) -> str | None:
    """兵器配方的名字對不對得上種類（附帶決定 c；naming.NamingRequest.check 跑它）：要有這一種的字、不能有別種的字、
    不能跟架上的現成兵器（shop_name）同名——不然買的跟打的分不出來。None＝可以。"""
    if not any(word in name for word in WEAPON_WORDS.get(kind, ())):
        return KIND_MISSING
    if any(word in name for other, words in WEAPON_WORDS.items() if other != kind for word in words):
        return KIND_CLASH
    if name in {shop_name(k, a) for k in WEAPON_KINDS for a in ATTR_WORDS}:
        return SHOP_CLASH
    return None


def fallback_name(content: Content, key: str, kind: str, salt: int = 0, tianji: int = 0) -> str:
    """兵器配方的退路名字（模型叫不動、取壞了）：字首＋craft_names.weapon 的一個字＋兵器字（NOUNS），一定帶兵器的字。
    種子同 naming.fallback_name（配方鍵＋這一季的天機，加鹽），同一個配方同一季永遠組出同一個名字。"""
    names = content.craft_names
    seed = key if tianji == 0 else f"{tianji}|{key}"
    digest = hashlib.sha256(f"{seed}#{salt}".encode()).digest()
    return names.prefixes[digest[0] % len(names.prefixes)] + names.weapon[digest[1] % len(names.weapon)] + NOUNS[kind]

def echo(state: GameState, content: Content, thing: MartialArt | Insight | WeaponRecipe, first: bool, made: str = "練") -> None:
    """首創名望回饋（Config.first_echo）：你合出（或打出，made="打"）別人首創的那一門（照著合、合到舊的都算），在這一季的
    WorldState.echoes 記你一筆；首創者自己的 Game 同步時補名望（Game._deliver_echoes），這裡不去動別人的角色。一個人一門只算一次、

    第一季沒開著時什麼都不做。意境寫「」，武學與兵器寫【】。"""
    me = state.player.name
    if first or not thing.creator or me in (thing.creator, thing.co_creator) or getattr(thing, "preset", False):
        return
    if not season_one(content, state.world):
        return

    if me in entry.followers or len(entry.followers) >= rule.cap:
        return
    entry.followers.append(me)
    if len(entry.followers) == rule.cap:
        template = ECHO_RUMOR if made == "練" else ECHO_RUMOR_FORGED

                creator=state.player.name, creator_shown=state.player.name, note=note if candidate == name else "",
            )
            recipe, first = world.claim_weapon_recipe(key, draft)
            if recipe is not None:
                break
        if recipe is None:
            return None, [FIZZLE]
    quality = fusion.roll_quality(odds, rng)
    p = state.player
    used = Counter([main, aux])
    for mid, n in used.items():
        p.materials[mid] -= n
        if not p.materials[mid]:
            del p.materials[mid]
    cost = price(content, tier)
    p.stats["silver"] -= cost
    p.forge_counts[key] = p.forge_counts.get(key, 0) + 1
    weapon = weapons.new_weapon(state, name=recipe.name, kind=kind, attribute=recipe.attribute, tier=tier, quality=quality, recipe=key)
    m, a = content.materials[main], content.materials[aux]
    what = f"兩份{m.name}" if main == aux else f"{m.name}與{a.name}"
    msgs = [FORGED.format(what=what, name=recipe.name, kind=kind, attribute=recipe.attribute, grade=weapons.grade(weapon))
            + _arrival(state, recipe, first)]
    msgs += setting_line(content, setting)
    msgs.append(f"銀兩 -{cost}")
    msgs += [f"{content.materials[mid].name} -{n}" for mid, n in used.items()]
    msgs.append(weapons.store(state, content, weapon))
    fusion.echo(state, content, recipe, first, made="打")
    return weapon, msgs

    """鐵匠鋪上這一下的江湖紀錄標題：打造的每一步是「打造」，其餘是「鐵匠鋪」。"""
    return FORGE_TITLE if is_forge_step(arg) else weapons.SMITH


def _held(state: GameState, content: Content) -> list[tuple[str, int]]:
    """背包裡打得了的素材：高階的先、同階數量多的先、再照 id（最可能要用的排在第一屏）。"""
    mats = content.materials
    return sorted(
        ((mid, n) for mid, n in state.player.materials.items() if n > 0 and mid in mats),
        key=lambda pair: (-mats[pair[0]].tier, -pair[1], pair[0]),
    )


def open_problem(state: GameState, content: Content) -> str | None:
    """「打造兵器…」按不按得下去：裝備庫滿了、素材不到兩個、最便宜的一爐也付不起，就灰掉寫原因。"""
    if weapons.rack_full(state, content):
        return weapons.RACK_FULL
    held = _held(state, content)
    if sum(n for _, n in held) < 2:
        return NOT_ENOUGH
    short = min(price(content, content.materials[mid].tier) for mid, _ in held) - state.player.stats.get("silver", 0)
    return f"還差 {short} 兩" if short > 0 else None


def forge_door(state: GameState, content: Content):
    """鐵匠鋪選單上的「打造兵器…」：打開一步一步的單子（step 的 "forge"）。"""
    from .engine import Option  # noqa: PLC0415  延後 import：engine → smithing

    problem = open_problem(state, content)
    return Option(id=OPEN, label=f"打造兵器…（{problem or '挑種類、主料、輔料'}）", enabled=problem is None)


def step(state: GameState, content: Content, verb: str, arg: str) -> list[str]:
    """單子往前或往後一步（選項都由 Game.choose 驗過在選單上，arg 一定是選單給的）。開爐（forge-go）不在這裡，見 forge。"""
    p = state.player
    if verb == "forge":
        p.smith_draft = SmithDraft()
        return [ASK_KIND]
    d = p.smith_draft
    if d is None:
        return ["（此刻無法這麼做。）"]
    if verb == "forge-kind":
        d.kind = arg
        return [ASK_MAIN]
    if verb == "forge-main":
        d.main = arg
        return [ASK_AUX]
    if verb == "forge-aux":
        d.aux = arg
        return [READY]
    if verb == "forge-undo":
        if d.aux is not None:
            d.aux = None
            return [ASK_AUX]
        if d.main is not None:
            d.main = None
            return [ASK_MAIN]
        d.kind = None
        return [ASK_KIND]
    if verb == "forge-cancel":
        p.smith_draft = None
        return [CANCELLED]
    return ["（此刻無法這麼做。）"]


def go_option(state: GameState, content: Content, world: WorldStateStore, kind: str, main: str, aux: str):
    """開爐那一顆：寫配方名（有人打過）或「還沒人打過」、種類屬性階、工錢與三個品質的機率（不寫品級）；打不成灰掉寫原因。
    沒人打過的要等模型取名，帶 wait。"""
    from .engine import Option  # noqa: PLC0415

    known = world.lookup_weapon_recipe(weapons.recipe_key(kind, main, aux))
    tier = tier_of(content, main)
    problem = forge_problem(state, content, kind, main, aux)
    head = KNOWN_RECIPE.format(name=known.name) if known else NEW_RECIPE
    odds = fusion.quality_odds_text(forge_odds(state, content, world, kind, main, aux))
    note = problem or f"工錢 {price(content, tier)} 兩；{odds}"
    attribute = attribute_of(world, content, kind, main, aux)
    return Option(
        id=f"{GO}{kind}:{main}:{aux}",
        label=f"開爐：{head}（{weapons.NOUNS[kind]}・屬{attribute}・{weapons.TIER_WORDS[tier]}・{note}）",
        enabled=problem is None, wait="" if known else FORGE_WAIT,
    )


def draft_options(state: GameState, content: Content, world: WorldStateStore, art) -> list:
    """單子這一步的選單：挑種類（配得上身上武學的排第一）→ 挑主料（寫階、剩幾個、工錢；付不起灰掉）→ 挑輔料（寫合出來的屬性；
    主料那一種只剩一個時不列）→ 開爐。每一步後面是「上一步」「不打了」（挑種類那一步只有「不打了」）。"""
    from .engine import Option  # noqa: PLC0415

    d = state.player.smith_draft
    fit = weapons.art_weapon(art.id, content, world) if art is not None else None
    undo, cancel = Option(id=UNDO, label="上一步"), Option(id=CANCEL, label="不打了")
    if d.kind is None:
        kinds = sorted(WEAPON_KINDS, key=lambda k: k != fit)
        return [Option(id=f"{KIND}{k}", label=weapons.NOUNS[k] + (weapons.FITS_MARK if k == fit else "")) for k in kinds] + [cancel]
    mats = content.materials
    held = _held(state, content)
    if d.main is None:
        silver = state.player.stats.get("silver", 0)
        out = []
        for mid, n in held:
            m = mats[mid]
            cost = price(content, m.tier)
            note = f"還差 {cost - silver} 兩" if cost > silver else f"工錢 {cost} 兩"
            out.append(Option(id=f"{MAIN}{mid}", label=f"主料：{m.name}（{m.attribute}・{weapons.TIER_WORDS[m.tier]}・剩 {n}・{note}）",
                              enabled=cost <= silver))
        return out + [undo, cancel]
    if d.aux is None:
        tianji = world.read().tianji
        out = []
        for mid, n in held:
            left = n - (1 if mid == d.main else 0)
            if left < 1:
                continue
            m = mats[mid]
            attribute = attribute_with(content, tianji, d.kind, d.main, mid)
            mark = ATTR_MARK if art is not None and d.kind == fit and attribute == art.attribute else ""
            out.append(Option(id=f"{AUX}{mid}", label=f"輔料：{m.name}（{m.attribute}・{weapons.TIER_WORDS[m.tier]}・剩 {left}）→ 屬{attribute}{mark}"))
        return out + [undo, cancel]
    return [go_option(state, content, world, d.kind, d.main, d.aux), undo, cancel]

def temper_problem(state: GameState, content: Content) -> str | None:

def forge_plan(state: GameState, content: Content, world: WorldStateStore, art) -> tuple[str, str, str] | None:
    """整季機器人要打哪一把：身上那門武學配得上的種類；主料挑背包裡最高階的（同階先挑跟武學同屬性的、再挑最多的、再照 id）；
    輔料先挑同一種（夠兩個時），不然挑跟主料最近一階、數量最多的。手上或裝備庫已經有一把配得上、階比主料高、或同階而且是自己打的，
    就不打（不然每次路過都打一把）。打不成（forge_problem）是 None。"""
    if art is None or not weapons.smith_here(state, content):
        return None
    kind = weapons.art_weapon(art.id, content, world)
    if kind is None:
        return None
    mats = content.materials
    held = {mid: n for mid, n in state.player.materials.items() if n > 0 and mid in mats}
    if sum(held.values()) < 2:
        return None
    top = max(mats[mid].tier for mid in held)
    mine = [w for w in [state.player.weapon, *state.player.rack] if weapons.usable(w, art, content, world)]
    if any(w.tier > top or (w.tier == top and w.recipe is not None) for w in mine):
        return None
    main = min((mid for mid in held if mats[mid].tier == top), key=lambda mid: (mats[mid].attribute != art.attribute, -held[mid], mid))
    if held[main] >= 2:
        aux = main
    else:
        aux = min((mid for mid in held if mid != main), key=lambda mid: (top - mats[mid].tier, -held[mid], mid))
    return (kind, main, aux) if forge_problem(state, content, kind, main, aux) is None else None


def better_in_rack(state: GameState, content: Content, world: WorldStateStore, art) -> Weapon | None:
    """裝備庫裡威力加成比手上那把高的那一把（最高的；同分照 id），沒有是 None。"""
    now = weapons.bonus(state.player.weapon, art, content, world)
    best = max(state.player.rack, key=lambda w: (weapons.bonus(w, art, content, world), w.id), default=None)
    return best if best is not None and weapons.bonus(best, art, content, world) > now + 1e-9 else None


def temper_wanted(state: GameState, content: Content, world: WorldStateStore, art) -> bool:
    """手上那把配得上、淬得了、而且沒有更高的一把要打（素材先留給打新的）。"""
    return (
        weapons.usable(state.player.weapon, art, content, world) and temper_problem(state, content) is None
        and forge_plan(state, content, world, art) is None
    )

    return (
        forge_plan(state, content, world, art) is not None or better_in_rack(state, content, world, art) is not None
        or temper_wanted(state, content, world, art)
    )

def visit_smith(game: Game) -> None:
    """城裡有鐵匠鋪就看一眼（兵器設計第六節）：照 weapons.wanted 換、買、修；再照 smithing.forge_plan 打一把、把裝備庫裡更好的換上、

    s, c, w = game.state, game.content, game.world

    def art():
        return team.player_art(s, c, w, s.player.member.wugong_id)

    def enabled() -> set[str]:
        return {o.id for o in game.options(odds=False) if o.enabled}

    if s.pending_event or not weapons.smith_here(s, c):
        return
    if weapons.wanted(s, c, w, art()) is None and not smithing.has_errand(s, c, w, art()):

        return

        if move is None or move not in enabled():
            break

    if plan is not None:
        for oid in smithing.wizard_steps(*plan):
            if oid not in enabled():
                break
            game.choose(oid)
    better = smithing.better_in_rack(s, c, w, art())
    if better is not None and f"smith:wield:{better.id}" in enabled():
        game.choose(f"smith:wield:{better.id}")
    for _ in range(c.config.weapons.temper_max):
        if not smithing.temper_wanted(s, c, w, art()) or smithing.TEMPER not in enabled():
