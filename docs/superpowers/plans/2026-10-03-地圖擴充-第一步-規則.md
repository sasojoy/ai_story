# 地圖擴充第一步「規則」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement step 1 (規則) of the map-expansion design on the existing 22 locations: road kinds on connections, natural stamina regen every 3 minutes, 打坐 as a real sit-down state, timed travel with 步行／趕路／疾行, an 在路上 state with stopping at the next station, battles you must be present in the region for, and bots that walk, hurry to rallies and skip turns on the road.

**Architecture:** Content gains road kinds (`Location.connections` items become `Connection` objects, a `str` subclass with `.to` and `.road`), travel settings in `Config` and a `region` on each battle. `tianxia/atlas.py` owns all pure travel math (walking minutes per road, shortest-time routes, stamina and time per mode, the three 安排前往 buttons). `tianxia/engine.py` stores the journey and the sit-down start in `PlayerState`, measures both on the shared season clock (`WorldState.time`, the same clock 閉關 uses), and processes due arrivals whenever `sync(now)` or `advance(seconds)` moves that clock. Battle presence is a flag on the shared battle participant, written by each player's own `Game` when they depart or arrive.

**Tech Stack:** Python 3.14, Pydantic v2 (pydantic-core custom schema for `Connection`), Gradio (app.py only), pytest.

**Spec:** `docs/superpowers/specs/2026-10-03-地圖擴充與移動-design.md` (step 1 = section 十, item 1; rules in sections 二, 三, 六; tests in section 九)

## Header notes

### Agreed data format (Task 1) — what the PM gets, and what differs from the agreement

Delivered exactly as agreed, with these names locked (the PM's step 2/3 tests already use them; **nothing was renamed**):

- `Location.connections`: each JSON entry is either a string (an ordinary road, 路) or `{"to": "<location id>", "road": "官道"|"路"|"山路"}`. Both ends must list the connection with the same road kind; `content.validate` checks it.
- Each loaded entry is a `tianxia.models.Connection` exposing `.to` (the destination id, a plain `str`) and `.road` (`"官道"`, `"路"` or `"山路"`).
- `Location.move_cost` is gone (model field and the 3 entries in `content/locations.json`).
- `Config` gains `rest_regen_multiplier` 2, `travel_minutes_per_unit` 0.0375, `road_factor` `{"官道": 0.8, "路": 1.0, "山路": 1.5}`, `hurry_stamina_per_minute` 1, `dash_stamina_per_minute` 2; `stamina_regen_seconds` becomes 180.
- `BattleDef.region` (a `MapRegion.id`); `huangjin_showdown` gets `"region": "yingchuan_area"`.

Improvements beyond the agreement (each has a reason; none changes the JSON the PM writes):

1. **`Connection` is a `str` subclass.** Its string value *is* the destination id, so every existing reader that treats `connections` as a list of ids (`atlas.road_hops`, `bot_policy`, `engine.options`, `content.validate`, and the PM-owned `mapview._roads`) keeps working without a single edit, while `.to` and `.road` are there for the PM's tests and the new travel code. It dumps back to the same JSON shape (a plain string for 路, the object otherwise).
2. **`Location.road_to(dest) -> RoadKind`** helper (returns `"路"` for plain strings or unknown destinations).
3. **`road_factor` is typed `dict[RoadKind, float]`**, so a misspelled key fails at load time; `validate` additionally requires all three kinds and positive factors.
4. **`validate` rejects a location listing the same destination twice** (a string and an object to the same place would be ambiguous about the road kind).
5. **`BattleDef.region` is optional in the model** (`None` = anywhere; only in-memory test battles do this) but `validate` requires it whenever the map defines regions, which the real and fixture content both do.
6. **`atlas.leg_minutes(content, a, b)`** ships in Task 1 so the PM's timing tests (spec 九: route times within ±20%) can compute walking minutes the same way the engine does.

### Time model (read this before any task)

- Travel minutes and the 打坐 doubling are **game time**. Real time enters only through `Game.sync(now)` (`elapsed × time_scale`) and `Game.advance(seconds)`. With the real `time_scale` 1.0, game minutes are real minutes, which is what the spec's 真實時間 means.
- **Arrival times and the sit-down start are stored as season-clock seconds** (`WorldState.time`), exactly like 閉關's `busy_until`/`seclusion_start`. `sync(now)` first catches the shared season clock up (`catch_up_season`), then `_advance_player_local`, then processes due arrivals; `advance(seconds)` does the same. Test bots (`tianxia/bot.py`, used by `test_real_content`) only call `advance()`, so a wall-clock-based design would leave them on the road forever.
- 打坐 doubling applies to the player-local elapsed seconds that already drive natural regen; because `app.act` and the bot runner always `sync(now)` before an action, time is attributed to the state the player was in.
- The season clock does not run while the season is preparing or resting. Nobody can depart while preparing; if the season ends during a trip, arrivals that were due before the end are still processed and then the journey ends where the player stands (`_arrivals`). The next season resets the player (`new_game_state`), clearing any journey or sit-down.
- The 3-day newbie rule (`newbie_days`, doubles 氣血 regen on the season clock) is untouched; 打坐 does not double 氣血.
- **No new wall-clock reads anywhere in `tianxia/`.** Nothing in this plan adds `time.time()`; existing reads (`_advance_battle_round`, `world._fire`, `world.start_pending_battle`) are not moved.

### Open decisions (defaults chosen)

1. **Main-screen move buttons walk only.** One button per neighbour, "前往 湖邊（步行約 3 分鐘）", along the direct road, always enabled (walking is free). 趕路 and 疾行 are offered by the three 安排前往 buttons on the map's detail panel. Reason: `app.MAX_BUTTONS` is 10 and 宛城 already shows 10 options today; three buttons per neighbour would push 打坐 off the screen.
2. **打坐 always fits on screen.** `app.visible_options` keeps `act:rest` when there are more than 10 options. This matters once step 2 adds more roads.
3. **What the player sees mid-route:**
   - The scene shows **在路上**: destination, mode, arrival clock, minutes left, and the next station.
   - The status panel gets a 🧭 line.
   - The options are one disabled info button, plus 喊停 when two or more stations remain.
   - `player.location` stays at the last station reached, so the minimap stays centred there.
4. **Stopping (喊停):**
   - It is free and stops at the next station.
   - Stamina already paid for 趕路 is not refunded, and the message says so.
   - It is not offered on the last leg or after already stopping.
   - You cannot re-route while on the road (travel is blocked); stop, arrive, then travel again.
5. **Storage:** `PlayerState.journey: Journey | None`. A `Journey` holds:
   - `mode`;
   - `path`, the stations after the start;
   - `arrive_at`, an absolute season-clock time per station;
   - `reached`;
   - `stop_at`.

   `PlayerState.resting_since: float | None` holds the season-clock time of sitting down. Both are in `state.py`; nothing new goes into `WorldState`.
6. **Rounding:** 趕路／疾行 stamina is `minutes × rate` rounded half up, at least 1. Minutes shown to players are rounded half up, at least 1. Costs use the whole route's walking minutes.
7. **Arrival rules per station:**
   - Each station sets the location, adds it to visited, runs tutorial `note_action("move")` and runs `check_thresholds`. Departing no longer counts as a tutorial "move"; arriving does.
   - The revisit flourish (LLM) is added only at the trip's final stop.
8. **Journal:**
   - Departure writes 「前往 X（途經 …）」 with the mode as its tag ("步行約 3 分鐘").
   - Arrivals processed in `sync`/`advance` merge into that entry when it is still the newest (`journal.add_arrival`); otherwise they get their own entry tagged 抵達. 江湖大事 fired by an arrival go into that entry, not the separate 江湖大事 entry.
9. **打坐:**
   - Regen is multiplied by `rest_regen_multiplier` and 氣血 regen is unchanged.
   - You stand up automatically when stamina is full. Sitting is allowed at full stamina (you stand up again on the next tick).
   - A battle rally does not interrupt 打坐 by itself, but joining a battle stands you up.
   - 門下 actions (練功, 煉製, 療傷) stay allowed while sitting or travelling, as they are during 閉關.
10. **Battle presence:**
    - A participant counts as "away" while on the road, even inside the region, and while standing outside the region.
    - An away participant's action for the current round is dropped, and the round does not wait for them.
    - When they come back, they act again from the current round.
    - If everyone on the field is away or eliminated and the round times out, the battle ends with its fallback outcome. This reuses the existing "no fighters" rule.
11. **Bots and urgency:**
    - "Urgent" means the bot's own side has a battle mustering or active, and the bot is not present.
    - The bot then hurries one station at a time toward the nearest station of that region, by travel time, and walks if it cannot afford to hurry.
    - Bots never dash and never sit.
    - "Own front line about to fall" is left for step 4 tuning.
12. **`travel_minutes_per_unit` = 0.0375.** The 21 current roads average 79.34 map units, so one station is about 2.98 minutes. Stations range from 1.6 to 5.7 minutes. The PM sets 0.04 in step 2 together with the new coordinates. Tests never hard-code the real value.

RoadKind = Literal["官道", "路", "山路"]
ROADS: tuple[RoadKind, ...] = ("官道", "路", "山路")  # 路的種類（地圖擴充設計 3.1）；沒標的是一般的「路」


class _ConnectionSpec(_Strict):
    """內容檔裡寫成物件的一條路：{"to": 地點 id, "road": 路的種類}。"""

    to: str
    road: RoadKind = "路"


class Connection(str):
    """一條路（Location.connections 的一筆）：字串本身就是目的地的地點 id，另外帶路的種類 road。

    做成 str 的子類別，是為了讓既有把 connections 當成地點 id 清單用的程式（大地圖、視野、假人、
    內容檢查）一行都不用改；要路的種類讀 .road，要純字串的地點 id 讀 .to。內容檔裡寫成字串（一般路）
    或 {"to": 地點 id, "road": "官道"|"路"|"山路"}（地圖擴充設計 3.1），寫回去也是同一個樣子。"""

    road: RoadKind

    def __new__(cls, to: str, road: RoadKind = "路") -> Connection:
        obj = super().__new__(cls, to)
        obj.road = road
        return obj

    @property
    def to(self) -> str:
        return str(self)

    def __repr__(self) -> str:
        return f"Connection({self.to!r}, {self.road!r})"

    def __reduce__(self):
        return (type(self), (self.to, self.road))

    @classmethod
    def _parse(cls, value: Any) -> Connection:
        if isinstance(value, Connection):
            return value
        if isinstance(value, str):
            return cls(value)
        if isinstance(value, dict):
            spec = _ConnectionSpec(**value)  # 欄位拼錯、路的種類寫錯時這裡就報錯
            return cls(spec.to, spec.road)
        raise ValueError('連線要寫成地點 id，或 {"to": 地點 id, "road": 路的種類}')

    def _dump(self) -> str | dict[str, str]:
        return self.to if self.road == "路" else {"to": self.to, "road": self.road}

    @classmethod
    def __get_pydantic_core_schema__(cls, source: Any, handler: GetCoreSchemaHandler) -> core_schema.CoreSchema:
        return core_schema.no_info_plain_validator_function(
            cls._parse, serialization=core_schema.plain_serializer_function_ser_schema(cls._dump),
        )

MODES: dict[str, str] = {"walk": "步行", "hurry": "趕路", "dash": "疾行"}  # 三種走法（地圖擴充設計 3.2），依序是詳情欄按鈕的順序
TIME_SHARE: dict[str, float] = {"walk": 1.0, "hurry": 0.5, "dash": 0.0}  # 各花全程的幾成時間


def leg_minutes(content: Content, a: str, b: str) -> float:
    """相鄰兩地 a、b 之間的路程（步行幾分鐘）：地圖上的距離 × 路的種類係數 × 換算比例（地圖擴充設計 3.1）。"""
    cfg = content.config
    start, end = content.locations[a], content.locations[b]
    distance = math.hypot(start.x - end.x, start.y - end.y)
    return distance * cfg.road_factor[start.road_to(b)] * cfg.travel_minutes_per_unit


def whole_minutes(minutes: float) -> int:
    """給玩家看的分鐘數：四捨五入（.5 進位），至少 1 分鐘。"""
    return max(1, math.floor(minutes + 0.5))


def travel_seconds(minutes: float, mode: TravelMode) -> float:
    """走完 minutes 分鐘的路程要幾秒（遊戲時間）：步行全程、趕路一半、疾行立刻到。"""
    return minutes * 60 * TIME_SHARE[mode]


def travel_stamina(content: Content, minutes: float, mode: TravelMode) -> int:
    """這種走法出發時一次扣的體力：步行 0；趕路、疾行照每分鐘路程的點數算，四捨五入（.5 進位）、至少 1 點。"""
    cfg = content.config
    rate = {"walk": 0.0, "hurry": cfg.hurry_stamina_per_minute, "dash": cfg.dash_stamina_per_minute}[mode]
    return 0 if rate <= 0 else max(1, math.floor(minutes * rate + 0.5))


def mode_when(minutes: float, mode: TravelMode) -> str:
    """這種走法要花多久：「約 5 分鐘」「立刻到」。"""
    return "立刻到" if mode == "dash" else f"約 {whole_minutes(minutes * TIME_SHARE[mode])} 分鐘"


def mode_text(content: Content, minutes: float, mode: TravelMode) -> str:
    """「步行約 9 分鐘」「趕路約 5 分鐘・體力 9」「疾行立刻到・體力 18」：選單與詳情欄用。"""
    stamina = travel_stamina(content, minutes, mode)
    return MODES[mode] + mode_when(minutes, mode) + (f"・體力 {stamina}" if stamina else "")


@dataclass(frozen=True)
class Route:
    path: tuple[str, ...]  # 依序要走的地點，最後一個是目的地（不含所在地）；所在地本身是空的
    legs: tuple[float, ...] = ()  # 每一段的路程（步行分鐘），跟 path 一一對應

    @property
    def minutes(self) -> float:
        """全程的路程（步行分鐘）。"""
        return sum(self.legs)

    @property
    def via(self) -> tuple[str, ...]:
        """途經的地點（不含目的地）。"""
        return self.path[:-1]

    @property
    def cost(self) -> int:
        """相容大地圖的路線層：mapview.py 還寫著「N 體力」。在它改成寫分鐘以前，給這條路趕路要的體力
        （趕路每分鐘 1 點時就是四捨五入的分鐘數）；所在地是 0。"""
        return whole_minutes(self.minutes) if self.path else 0


def shortest_routes(state: GameState, content: Content, allowed: set[str] | None = None) -> dict[str, Route]:
    """從所在地出發、只走 allowed 裡的地點（None＝所有已開放的地點），到每個地點路程最短（步行分鐘最少）
    的走法（地圖擴充設計 3.2）。一樣近取站數少的，再一樣時比地點 id 的順序，結果固定。"""
    if allowed is None:
        allowed = {loc_id for loc_id, loc in content.locations.items() if is_unlocked(loc, state)}
    best: dict[str, Route] = {}
    heap: list[tuple[float, int, tuple[str, ...], tuple[float, ...], str]] = [(0.0, 0, (), (), state.player.location)]
    while heap:
        minutes, hops, path, legs, here = heapq.heappop(heap)
        if here in best:
            continue
        best[here] = Route(path, legs)
        for dest in content.locations[here].connections:
            dest_id = str(dest)
            if dest_id in allowed and dest_id not in best:
                leg = leg_minutes(content, here, dest_id)
                # 分鐘數取到小數第 6 位再比，免得一樣長的路因為浮點誤差分出先後
                heapq.heappush(heap, (round(minutes + leg, 6), hops + 1, path + (dest_id,), legs + (leg,), dest_id))
    return best


def routes(state: GameState, content: Content) -> dict[str, Route]:
    """從所在地出發、只走摸清且已開放的地點，到每個摸清地點路程最短的走法（取代原本最省體力的路線）。"""
    return shortest_routes(state, content, known_locations(state, content))

def travel_block(state: GameState) -> str | None:
    """現在不能安排前往的原因（賽季已結束、有事件待處理、閉關中、打坐中）；可以時為 None。"""

    if state.player.resting_since is not None:
        return "打坐中，先起身才能安排前往"
    return None


def travel_refusal(state: GameState, content: Content, loc_id: str, mode: TravelMode) -> str | None:
    """用這種走法安排前往這裡，不行的原因；可以時為 None。"""
    route = routes(state, content).get(loc_id)
    if route is None or not route.path:
        return "無法安排前往這裡"
    reason = travel_block(state)
    if reason:
        return reason
    cost = travel_stamina(content, route.minutes, mode)
    if state.player.stamina < cost:
        return f"體力不足，{MODES[mode]}要 {cost} 體力"
    return None


def travel_options(state: GameState, content: Content, loc_id: str) -> list[TravelOption] | None:
    """詳情欄底下的按鈕：步行、趕路、疾行各一個，寫時間與體力，體力不夠的按不下去（地圖擴充設計 3.2）。

    route = routes(state, content).get(loc_id)
    if route is None or not route.path:
        return None
    reason = travel_block(state)
    if reason:

    out: list[TravelOption] = []

        else:
            price = f"・體力 {cost}" if cost else ""
            out.append(TravelOption(mode, f"{MODES[mode]}（{mode_when(route.minutes, mode)}{price}）", True))
    return out

def path_legs(content: Content, start: str, path: list[str]) -> list[float]:
    """從 start 照 path 一站一站走，每一段的路程（步行分鐘）。"""

    return [leg_minutes(content, a, b) for a, b in zip(stops, stops[1:])]


def arrival_times(now: float, legs: list[float], mode: TravelMode) -> list[float]:

    def _depart(self, path: list[str], mode: TravelMode) -> list[str]:
        """出發（地圖擴充設計 3.2、3.3）：趕路、疾行的體力出發時一次扣，照走法排好每一站的抵達時間。

        s, c = self.state, self.content
        legs = atlas.path_legs(c, s.player.location, path)
        minutes = sum(legs)
        cost = atlas.travel_stamina(c, minutes, mode)
        s.player.stamina -= cost
        s.player.journey = Journey(mode=mode, path=path, arrive_at=atlas.arrival_times(s.world.time, legs, mode))
        if self._draft is not None:

    def _arrivals(self) -> list[str]:

        那一站）就下馬。賽季已經落幕時，落幕前就該到的站照樣抵達（時鐘停在落幕那一刻，之後的站不會再到），
        然後停在當下那一站；抵達某一站時觸發了賽季落幕，就停在那一站。不在行動裡（sync、advance）時自己寫
        江湖紀錄（見 journal.add_arrival）；疾行在 travel() 的行動裡，寫在那次行動的紀錄。"""
        s, c = self.state, self.content
        j = s.player.journey
        if j is None or (j.arrive_at[j.reached] > s.world.time and not s.world.ended):
            return []
        own = self._draft is None
        if own:
            self._draft = Draft(atlas.journey_title(c, j.path))
        try:
            already_over = s.world.ended
            msgs: list[str] = []
            when = s.world.time
            while j.reached <= j.last and j.arrive_at[j.reached] <= s.world.time:
                if s.world.ended and not already_over:
                    break  # 剛抵達的那一站觸發了賽季落幕：停在那裡
                when = j.arrive_at[j.reached]
                j.reached += 1
                msgs += self._arrive(j.path[j.reached - 1], final=j.reached > j.last)
            done = j.reached > j.last or s.world.ended
            if done:
                s.player.journey = None
                if s.player.location != j.path[-1]:
                    reason = "賽季落幕" if s.world.ended else "喊停"
                    self._draft.tag = f"{reason}，停在 {c.locations[s.player.location].name}"
            if own:
                entry = self._draft.entry(when, msgs)
                if done or entry.lines or entry.changes:  # 只到了中途的站、又沒有別的事，不另寫一則
                    journal.add_arrival(s, entry, done)
        finally:
            if own:
                self._draft = None
        return msgs

    def _arrive(self, loc_id: str, final: bool) -> list[str]:
        """抵達一站：照原本走到一個地點的規則——地點描寫、新手引導、大勢門檻。終點是重遊的一般地點時才多請模型
        補一句此刻的小細節（中途的站不補，省得一趟路叫好幾次模型）。"""
        s, c = self.state, self.content
        dest = c.locations[loc_id]
        is_revisit = loc_id in s.player.visited
        s.player.location = loc_id
        s.player.visited.add(loc_id)
        text = self.location_text()
        if final and is_revisit and not dest.important:
            flourish = flavor.polish_revisit(self.client, dest.name, dest.description)
            if flourish:
                text = f"{text}\n\n{flourish}"
        self._hide(text)
        return [text] + note_action(s, c, self.world, "move") + check_thresholds(s, c, self.world, self.client)

    def _journey_line(self) -> str:
        """在路上的那一句（狀態列、場景共用）：「往寶洞（步行），第1天 00:08 抵達，還要約 8 分鐘；下一站湖邊」。"""
        s, c = self.state, self.content
        j = s.player.journey
        end = j.arrive_at[j.last]

        )

        return line

def set_away(instance: BattleInstance, name: str, away: bool) -> None:

def safest_option_tag(instance: BattleInstance, definition: BattleDef, name: str) -> str | None:
    """這個人這回合最保守的固定選項（氣血損耗最低；一樣低時取框架裡排前面的）。只看他自己陣營能選的，

    options = [o for o in options_for(instance, definition, name) if not o.free_text]
    if not options:
        return None
    return min(options, key=lambda o: definition.action_tags.get(o.tag, BattleActionEffect()).neili_damage).tag

        """人在這場決戰的大區、而且不在路上，才算到了戰場（地圖擴充設計第六節）；決戰不限地點時只看在不在路上。"""

def take_turn(game: Game, profile: BotProfile, rng: random.Random) -> list[str]:
    """做一個動作（外加不受強度影響的照顧動作）；沒有能做的事（例如體力不夠）就什麼都不做，回傳空清單。
    在路上的假人這一輪跳過，連照顧動作都不做（地圖擴充設計 3.4）。"""
    if game.state.player.journey is not None:
        return []
    look_after(game, rng)
    s = game.state
    if s.player.pending_companion:
        return game.choose("talk:leave")
    rally = _toward_battle(game)
    if rally is not None:
        return rally
    options = [o for o in game.options(odds=False) if o.enabled and o.id != "act:rest"]
    if not options:
        return []
    ids = [o.id for o in options]
    if s.player.faction is None and profile.faction is not None and not s.pending_event \
            and not any(i.startswith("battle:") for i in ids):
        step = _toward_faction(game, profile.faction, ids)
        if step is not None:
            return game.choose(step)
    choice = pick(game, options, profile, rng)
    return game.choose(choice) if choice else []


def _toward_battle(game: Game) -> list[str] | None:
    """自己這一方的全服決戰在集結或開打、自己人卻不在那個大區：往那個大區路程最近的地點走一站，體力夠就趕路、
    不夠就步行（地圖擴充設計 3.4：陣營目標急的時候趕路；假人不疾行）。不是這種情況、走不過去、或現在不能
    安排前往（例如有事件待處理）就回傳 None，照平常挑選項。"""
    region = game.rally_region()
    if region is None:
        return None
    hop = next_hop(game, atlas.region_locations(game.content, region))
    if hop is None:
        return None
    ways = {option.mode: option for option in game.travel_options(hop) or []}
    for mode in ("hurry", "walk"):
        if mode in ways and ways[mode].enabled:
            return game.travel(hop, mode)
    return None


def next_hop(game: Game, targets: list[str]) -> str | None:
    """從所在地往路程最近的目標走的下一站：照地圖連線走路程最短的路（地圖擴充設計 3.2）、跳過還沒開放的地點
    （不管摸清了沒）；已經在目標上或走不到時回傳 None。"""
    if game.state.player.location in targets:
        return None
    found = atlas.shortest_routes(game.state, game.content)
    reachable = [found[t] for t in targets if t in found and found[t].path]
    if not reachable:
        return None
    best = min(reachable, key=lambda route: (round(route.minutes, 6), len(route.path), route.path))
    return best.path[0]
