## ① 許可實跑（第二段）

1. 裝範本：`support_session_init.py <scratchpad>\waveX\b227\desk --url http://127.0.0.1:8443 --config <b227>\secret\support.json --python C:/Ray/專案/天下大勢/.venv/Scripts/python.exe`。金鑰檔放 `desk` 外面（在裡面腳本會拒，結束碼 2），內容 `{"bot_token": <40 字亂數>}`；8443 不起伺服器（「不存在的埠」那一種，許可判斷跟伺服器無關）。
2. `desk\.claude\settings.local.json` 拿掉 `enabledPlugins`（不接 Discord）；其餘四條原樣。
3. 每一條在 `desk` 裡跑一次：`claude -p "<請照字面執行這一行：…>" --output-format json --model haiku --setting-sources project,local --strict-mcp-config`。
   - `--setting-sources project,local`：不讀 `~/.claude/settings.json` 的放行（那裡的 allow 會讓結果不準）；`--strict-mcp-config`：不掛任何 MCP。
   - **絕不**帶 `--dangerously-skip-permissions`、`--permission-mode`、`--allowedTools`、`--add-dir`。
   - 判讀只看輸出 JSON 的 `permission_denials`（有沒有那一筆 Bash／Read／Write），不看結束碼；另記模型實際有沒有叫工具（`num_turns`、結果字）。模型自己拒絕不算「被擋」，要看到 denial；模型沒叫工具就換一句更直接的指令重跑一次，仍不叫就記「模型不叫，許可沒被走到」。

## ② 兩條自動測試（`test_support_session.py`，要 Git Bash，照 :134-137 的找法，沒有就 skip）

- `test_expanded_arguments_never_reach_the_server`：`_init` 時 `--python` 填**真的** `sys.executable`、`--url` 填 `http://127.0.0.1:9`、金鑰檔自造假 token；把展開後會長成的字直接當參數給 `cli.sh`：`queue "ray 61"`（帶空白的使用者名稱）、`queue a.txt b.txt c.txt`（一串檔名）、`ticket 1 '{"bot_token": "<假 token>"}'`（一段 JSON）。證明：結束碼 2（argparse 在讀金鑰與連線之前，`support_cli.py:236` 先於 `:243`）、stdout＋stderr 不含假 token、零個 HTTP。零 HTTP 的證法：不開埠；`--url` 指 `:9`，若真的連了會印「連不上伺服器」而不是 argparse 的 usage，斷言輸出有 `usage:` 或 `unrecognized`／`invalid`、沒有連線失敗那句。
  - 注意：JSON 那條 argparse 會把參數印回（`unrecognized arguments: …`）。若因此輸出含 token → 先看①實跑結果：被擋就只在 cli.sh 註解寫明是縱深；要讓這條綠只能收緊 `cli.sh`（擋 `"`、`{`、`}` 之一，到 python 之前就固定句退出），不改 `support_cli.py`（懷疑者 `safer_way`）。寫進 decided。
- `test_every_command_in_the_session_rules_exists`：抓 `docs/support/session/CLAUDE.md` 每個 `cli.sh <字>` 的子指令（`queue`、`ticket`、`answer`、`note`、`close`），每一個都在 `support_cli._parser(True)` 的 subparsers choices 裡；`--close`、`--human` 是 `answer` 的選項也對一次。只 import 腳本（`_load`），不 import `tianxia`。
- 兩條都不開埠、不起假 webhook 伺服器；單條預期 <1 秒，量了 ≥1 秒就標 slow。
