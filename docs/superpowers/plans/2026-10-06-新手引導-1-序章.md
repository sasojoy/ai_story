> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新角色一進遊戲先在師父的草廬走完十一步序章：遇險、拜師、悟意境、合成、練成、修練、打坐、雪恥一戰、配點、熔煉、出師走到潁川。草廬只有序章裡的人看得到；畫面跟著教到的東西一樣一樣亮起來；師父的話放在對話框。

**Architecture:** 新模組 `tianxia/prologue.py` 管序章的規則（在不在序章、進出序章、這一步的特別規則、畫面要亮什麼）。序章的每一步還是 `content/tutorial.json` 的 `TutorialStep`，多了幾個選填欄位描述這一步的特別規則（端出哪則事件、對手是誰、結果安排成什麼、只准熔哪一門……）；`guide.note_action` 照舊推進步驟。草廬是一個 `Location.prologue_only` 的地點：`atlas.is_unlocked` 只對站在那裡的人放行。序章裡合成出來的四門武學由內容先寫好名字（`content/preset_recipes.json`），不等模型。伺服器多送一個 `prologue`（要亮的畫面元件、要發光的鈕），網頁照它藏分頁、狀態列與行動列的格子。

**Tech Stack:** Python 3／pydantic／SQLite（`tianxia/` 規則引擎）、FastAPI（`server.py`）、原生 JavaScript（`web/app.js`，沒有建置步驟）、pytest。

## Global Constraints

- `tianxia/` 不 import 任何網頁框架；`engine.Game` 是唯一對外門面；引擎不讀時鐘。
- 數字全由規則引擎決定；序章不叫模型（合成用寫好的名字，雪恥那一場不是大場面）。
- 武學、人物名稱原創；正式文字照設計文件第十節（S1 審過的用語），不自己改字。
- 假人看不出來：伺服器假人、整季機器人、腳本建的角色都不走序章（`Game.new` 預設 `prologue=False`）。只有網頁上建立角色（`server.create_character`）走序章。
- 測試內容 `tests/fixtures/content` **沒有序章**（`tutorial.location` 是 None），所有既有測試的行為一個字都不變。序章的測試用 `prologue_content` fixture（Task 1）。
- 存檔相容：舊存檔一律當作走過序章（設計 7.2），不會被拉回草廬；資料庫結構不改（`SCHEMA_VERSION` 不動）。
- 序章不看第一季開關：beta 季、第一季都一樣有序章。
- 測試：`.venv/Scripts/python.exe -m pytest -q`；網頁：`node --check web/app.js`，畫面用 375×812 看過（`http://dev.localhost:<port>`，不要用 127.0.0.1，會把 QA 登出）。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。
- 臨時腳本要設 `TIANXIA_DB`，印中文要把 stdout 包成 UTF-8。

```python
class TutorialGoal(_Strict):
    """每一項都要符合才算完成；空的（或 False 的）欄位不檢查。"""

    # order：替軍令記到一次（計畫 T6）。choice～melt：序章（新手引導計畫一）那幾步要的動作：選了事件的選項、打開修練／煉製頁、
    # 修練、打坐、遊歷、配點、熔煉
    action: Literal[
        "explore", "socialize", "move", "view_map", "recruit", "practice", "order",
        "choice", "view_tab", "cultivate", "rest", "train", "allocate", "melt",
    ] | None = None
    locations: list[str] = Field(default_factory=list)
    condition: Condition = Field(default_factory=Condition)
```

```python
"""序章（新手引導重做設計第三、六、七節）：新角色先在師父的草廬走完前 Tutorial.prologue_steps 步，才進真實世界。

草廬是 Location.prologue_only 的地點：只有站在那裡的人看得到、到得了（atlas.is_unlocked）。序章每一步的特別規則
寫在 TutorialStep 上（content/tutorial.json），這裡把它們讀出來給 engine 用；步驟怎麼推進照舊是 guide.note_action。
沒有序章的內容（tutorial.location 是 None，例如測試內容）這裡每個函式都是「什麼都不做」。"""
from __future__ import annotations

from .models import Content, Option, TutorialStep
from .rules import apply_effect
from .state import GameState, PlayerState, ONBOARDING_VERSION
from .world_state import WorldStateStore

OLD_BASE_STEPS = 6  # 舊引導不分季的六步（t1～t6）；舊存檔第 6 步起是第一季的兩步（t7、t8），換成序章之後往後挪


def has(content: Content) -> bool:
    return content.tutorial.location is not None


def active(state: GameState, content: Content) -> bool:
    """在序章裡：站在草廬，而且序章還沒走完。走在出師的路上也算（抵達潁川那一刻才離開草廬）。"""
    t = content.tutorial
    return t.location is not None and state.player.location == t.location and state.player.tutorial_step < t.prologue_steps


def step(state: GameState, content: Content) -> TutorialStep | None:
    return content.tutorial.steps[state.player.tutorial_step] if active(state, content) else None


def start_stamina(content: Content) -> int:
    """序章開局的體力：探索一次、合成一次、修練一次剛好用完，第 7 步才有「體力見底、打坐」（設計 3.2）。
    合成的體力是武學與成長計畫五加的（fuse_stamina）；還沒有那個欄位時當 0。"""
    cfg = content.config
    return cfg.action_cost["explore"] + getattr(cfg, "fuse_stamina", 0) + cfg.cultivate_stamina


def begin(state: GameState, content: Content) -> None:
    """把角色放進序章的第一步：草廬、序章的體力、開場事件（遇險）。新角色（Game.new(prologue=True)）與序章走到一半就換季的
    角色用；可以重複呼叫。"""
    t, p = content.tutorial, state.player
    if t.location is None:
        return
    p.location = t.location
    p.journey = None
    p.visited.add(t.location)
    p.tutorial_step = 0
    p.stamina = float(start_stamina(content))
    state.pending_event = t.start_event


def _prologue_events(content: Content) -> set[str]:
    """序章會端出來的事件：開場那一則一路接下去的（next_event），加上每一步的 explore_event。"""
    t = content.tutorial
    found: set[str] = set()
    todo = [t.start_event] + [s.explore_event for s in t.steps[: t.prologue_steps]]
    while todo:
        event_id = todo.pop()
        if event_id is None or event_id in found or event_id not in content.events:
            continue
        found.add(event_id)
        todo += [ch.effect.next_event for ch in content.events[event_id].choices]
    return found


def finish(state: GameState, content: Content, world: WorldStateStore, *, purse: bool) -> list[str]:
    """不是一步一步走完、而是直接離開序章（略過、不走序章的角色、讀檔時發現序章卡住）：站到起點、序章的事件收掉、
    步數跳過序章。purse：給出師那一步的獎勵（盤纏、體力補滿；設計 7.3：略過的人也拿）。回傳獎勵的訊息。"""
    t, p = content.tutorial, state.player
    if t.location is None:
        return []
    if p.location == t.location:
        p.location = content.scenario.start_location
        p.journey = None
        p.resting_since = None
    p.visited.add(p.location)
    if state.pending_event in _prologue_events(content):
        state.pending_event = None
    msgs: list[str] = []
    if p.tutorial_step < t.prologue_steps:
        p.tutorial_step = t.prologue_steps
        if purse:
            msgs = apply_effect(t.steps[t.prologue_steps - 1].reward, state, content, world)
    p.stamina = max(p.stamina, float(content.config.stamina_max)) if purse else p.stamina
    return msgs


def migrated_step(player: PlayerState, content: Content) -> int:
    """舊存檔（onboarding 比 ONBOARDING_VERSION 小）的引導步數換成新的：一律當作走過序章（設計 7.2），
    舊的第一季兩步（舊的第 6、7 步）接在序章後面、走到哪裡就接著那裡。沒有序章的內容照舊。"""
    n = content.tutorial.prologue_steps
    if player.onboarding >= ONBOARDING_VERSION or n == 0:
        return player.tutorial_step
    return n + max(0, player.tutorial_step - OLD_BASE_STEPS)
```

`Game.prologue_recap`：

```python
    def prologue_recap(self) -> str:
        """設定頁的「重看序章」（設計 7.1）：序章的事件與師父的話照順序排成一頁，只能讀。沒有序章是空字串。"""
        c = self.content
        t = c.tutorial
        if t.location is None:
            return ""
        parts: list[str] = []
        event_id = t.start_event
        while event_id is not None and event_id in c.events:  # 開場那一則一路接下去（遇險、拜師）
            event = c.events[event_id]
            parts.append(f"**{event.title}**\n\n{event.text}")
            event_id = next((ch.effect.next_event for ch in event.choices if ch.effect.next_event), None)
        for step in t.steps[: t.prologue_steps]:
            text = "\n\n".join(x for x in (step.scene, step.text) if x)
            if text:
                parts.append(text.replace("{武學}", "新武學"))
        if t.leave_text:
            parts.append(t.leave_text)
        return "\n\n---\n\n".join(parts)
```
