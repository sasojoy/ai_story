# 輿圖第三版 第 3 批：天下圖（真實地形） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 派工單定了：開發自己一步一步做（不開子代理），計畫不必給企劃者審。

**Goal:** 打開輿圖第一眼是一張整張天下、不自由縮放的「天下圖」：五個大區的地面照「離哪個地點最近」上誰的顏色（顏色與幾方從劇本讀）、任兩方相接畫紅線、有主與沒人佔相接畫細墨線、高級資源地金點、大區名＋各方幾處與寶幾處（只寫不是 0 的）、你在哪；版圖變化在天下圖上播；點一區進現在那張可縮放的地圖（區圖第 4 批之前的替身）。「正在翻」「激戰」留掛鉤：疊層有資料才畫。

**Architecture:** 環形版第 2 批（`origin/dev/map-2-picks` 74b076e2）的畫法程式搬到真實地形：幾何是純函式 `tianxia/worldgeo.py`（照抄），`mapdata.base()["world"]` 交出取景框、大區、地面格、相鄰的邊、劇本的每一方與沒人佔的顏色；網頁的天下圖是同一張底圖換固定取景（`worldFit`），`#mk` 畫地面與記號。環形專屬的（圈、核心「璽」、新天下的州與地點、人物搬家）不搬。

**Tech Stack:** Python 3（pydantic、純幾何）、原生 JS（`web/app.js`）、CSS；pytest＋`tests/webharness.py`（node）。

**Spec:** 設計 `docs/superpowers/specs/2026-10-20-輿圖簡化-design.md`（三版，只在 develop 的 pm-relay 工作樹：第一章、3.3、5.1、5.4、5.5、5.6、第七、九、十章、第十一章第 3 條）；開發手冊 `tianxia-map-remake`。

## Global Constraints

- 地理照舊仿真實地形：五個大區、42 處地點、現有的路（不改 `content/map.json` 的多邊形、`locations.json`）。
- 地面一方一色＋沒人佔一色；顏色與幾方從劇本讀；**程式裡不寫死「兩方」「官巾」「藍黃灰」**；任兩方相接就是前線（設計 3.3）。
- 地面的顏色一律讀 `territory.controller`（`Config.territory` 關著整張灰；同一個劇本規則開關不同的季也用新畫法，設計 5.6）；沒有控制方照灰，不照開季歸屬上色（企劃者挑的）。
- 天下圖的路淡淡透上來（企劃者挑的）；大區名底下的數字只寫不是 0 的、全是 0 那一行不畫（企劃者挑的）。
- 天下圖不拖不縮、沒有圖例（設計 5.1、第一章）。深色主題時地圖本身照舊是紙色（設計 5.5）。新寫給玩家看的字標「待 joy 潤」。任何畫面不能透露誰是假人。
- 不做：區圖與卡（第 4 批）、拿掉 5.4 那一表（第 4 批）、翻地規則（`dev/flip-1`）、區塊表（`dev/blocks-2` 重排，這一批照現在的 `territory.blocks` 畫、不改內容）。

### 1.3 「正在翻」「激戰」的掛鉤（等 `dev/flip-1`）

疊層 `mapdata.state()["places"][地點]` 由規則那一批補三個鍵（這一批的網頁照這個形狀讀，沒有這個鍵就不畫）：

- `tug`：`{陣營 id: 進度 0～100}`——這一塊每一個攻方那一條（設計 4.1；只列 > 0 的；冷卻中或沒人推是 `None`／不給）。
- `melee`：`true`＝激戰（兩邊都有人在 `melee` 的時間窗〔預設 10 分鐘〕內推過這一塊，設計 4.3）。
- `cool`：剛易手、還要幾分鐘才能再推（`None`＝沒在冷卻）；天下圖不畫，留給第 4 批的卡。

畫法（天下圖，`worldParts`）：

- **正在翻**（兩色拔河）：那一格先照守方（控制方或沒人佔）的地面色塗，再疊一層**攻方的顏色**，濃淡＝進度最高的那一方的進度（`opacity = 進度 ÷ 100 × WORLD_TUG_MAX`）；用斜紋（`<pattern>`，每一方一個、顏色照 `sideInk`）而不是一片實色，跟「已經佔下」分得開。照那一區的輪廓裁。對比圖：實色泛進來（甲）／斜紋泛進來（乙），先照乙做。
- **激戰**：那一格的輪廓一圈紅光（`FRONT_RED`），`.w-melee` 一閃一閃（CSS 動畫；`prefers-reduced-motion` 不閃、照樣是一圈紅）。
