## 三段式（`routes.yiwen_step`，照 `features/guard/routes.py::guard_say`）

1. 第一行照舊 gate：`enabled` 關或 `rules.on` 假 → `[]`（不進鎖）。
2. **A** `started, req = shell._open_request(game, lambda: actions.step_request(game, body))`（`_open_request` 本身會同步、擋暫停、存檔）。`step_request` 包 `not_while_preparing`。回 `list` → 直接回（擋下的那一句或 `[]`）；回 `Replay` → `shell.act(game, lambda g: actions.apply_step(g, req, None, ""))`，不叫模型、不審字。
   - A 只讀：驗眼前那一則（`valid`、`opening`/`node`/`tale` 對得上、沒走完）；算「有效的則」：`w.tale`，或 `w.tale == 0` 時旁檔 `tale_by_opening` 那一列是自己的（第 251 批 `_reattach` 的條件，**真的接回留在 C**）。
   - `pick` 0～2：照 label；`pick == "typed"`：`speech.clean(text)`，`typed_problem` 不是 None → 回 `[refuse_typed]`（**不加 tries**，A 不寫）；`w.tries >= typed_tries` 或寫不下去（`_writable` 假：別人的則）→ 回 `[locked]`；clean 過的字等於這一步某顆做法的 label → 當成按那一顆（`typed=False`）。`pick == "zhupi"`：別人自己說的那一幕重放，`text` 要等於某個 `typed=1` 子節點的 `pick`，找不到回 `[]`。
   - 這一步那一顆已經有子節點 → `Replay`；沒有又 `_writable` 假 → `[locked]`；`store.muted` → 自己說回 `[locked]`、猜法照走。
   - 擲順逆：種子照第 247 批 `roll("yiwen", season, key, tale_key, w.node)`（不改，替身那一路的輸出跟異聞一一樣）。`prompt = rules.build_prompt(...)`。
3. **B**（鎖外）：`left = lambda: t.step_budget_seconds - (shell._monotonic() - started)`。自己說的先 `screened = shell.screen_text(game, req.text, speech.MOTTO)`；`left() < t.step_min_write_seconds` → 回 `[busy]`（`_line` 挑 `busy` 組那一句；什麼都不動）。`draft = shell.model_call(game, lambda: writer.write_scene(lambda: shell.within_budget(game.client, left()), req, t, left), fallback=None, left=left(), busy=<busy 那一句>)`；`Busy` 丟那一句、`QueueTimeout` 丟殼的 `BUSY_QUEUE_TIMEOUT`（殼現成，`GameError` 400，前端 toast）。`screened == "bad"` 時不叫寫幕、`draft=None` 直接進 C（C 看 `screened`）。
4. **C** `shell.act(game, not_while_preparing(lambda g: actions.apply_step(g, req, draft, screened)))`。重驗：同季（`_season == req.season`）、`_on`、`valid`、`w.opening == req.opening`、`w.node == req.node`、`w.tale in (req.tale, 0→接回之後的那一則)`；第一幕（則還沒開）：`taken[opening].by == key`（被世界那一格放回 → 回 `[gone]`、清眼前）；`store.muted`。`screened == "bad"` 或 `draft.verdict == "improper"`（只有 `req.typed` 時認；猜法那一步回 improper 當成檢查沒過）→ 不寫、`w.tries += 1`、回 `[refuse_typed]`。`(tale,parent,pick)` 已被寫掉（`add_node` 回 `taken`）→ 照那一列重放、多回 `taken` 那一句。其餘照 `_write_node`：`draft` 是 None 或 `draft.problems` 非空（兩次都沒過）→ 存替身（`broken`＋退路做法，`fallback=1`；**模型的字不存**）；合格 → 存 `draft.text`/`options`/`ledger`、`fallback=0`。獎勵、`step_walk`、第三步 `_finish` 照異聞一。
- `writer.write_scene`：`client_for()` 是 None → None（替身）。第一次回來 `check_scene` 有毛病、`tuning.retry > 0`、`left() >= step_min_write_seconds`、`client_for()` 還給得出 → 把毛病代碼換成一句話貼回去重問一次；還不行回 `SceneDraft(problems=...)`。例外（連不上、逾時、JSON 壞）一律吞掉當寫壞。`verdict == "improper"` 不重問。
