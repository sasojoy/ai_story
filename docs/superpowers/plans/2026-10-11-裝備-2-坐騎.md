# 裝備（第二批：坐騎）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 裝備四欄的第三欄「坐騎」：騎著馬趕路、疾行省體力（駑馬 25%／良駒 40%／名駒 55%）、步行與趕路快（30／45／60%），全部乘飽足係數；出發那一刻把步調快照進 `Journey.pace`，選單、輿圖、詳情欄、拒絕話寫的體力與時間跟實際扣的一模一樣；飽足度每換一段路扣、拿一階素材餵；四個城鎮的馬市買駑馬；結伴同行照帶頭的人的坐騎走、體力各付各的；打仗裡的三個用途——決戰騎兵（強攻、奇襲 +5／10／15%）、截殺追逃（守方腳力減攻方，夾 0～40%）、落敗策馬脫身（保住那一成銀兩 30／50／70%）；整季機器人與伺服器假人會買、會餵、會換。

**Architecture:** 新模組 `tianxia/mounts.py` 放坐騎自己的全部規則（數字：腳力 `saving`、步調 `pace`、騎兵 `cavalry`、脫身 `escape`、截殺追逃 `raid_flee`；飽足 `hunger` 與餵 `feed`；馬市 `market_here`／`buy`／`wield`；名字與階；機器人該按哪一顆 `wanted`；修練頁每一列與角色卡），只 import `models`、`state`、`equipment`。`equipment.SLOTS` 加 `mount` 一列（`Slot.road_locked`：路上不能換），`WIELDABLE` 收坐騎。`atlas` 反過來 import `mounts`：本來就收 `state` 的函式（`route_stamina`、`route_text`、`travel_options`、`detail_text`）在裡面算步調與腳力，純函式（`travel_seconds`、`mode_when`、`arrival_times` 的 `pace`，`travel_stamina` 的 `saving`，`mode_text` 兩個都收）改成**必填的關鍵字參數**；體力拆成兩段進位（`foot_stamina` 原本的、`ride_stamina` 騎馬省下之後的），結伴同行時跟著的人拿帶頭的人那一份 `foot` 照自己的腳力算。決戰騎兵在 `battle_instance.move_scores(cavalry=)`，加入那一刻連馬名一起快照進 `BattleParticipant`；截殺追逃與落敗脫身各用自己的亂數，不動 `Game.rng`。馬市的第二層選單照 `picking_smith` 那一串整串照抄（`PlayerState.picking_market`）。全部在角色 JSON 裡，**資料庫不升版**。

**Tech Stack:** Python 3.12、pydantic、SQLite（不動結構）、pytest（`-n auto`）、原生 JavaScript 網頁（`web/app.js`、node 假瀏覽器測試）。

**Spec:** `docs/superpowers/specs/2026-10-10-裝備四欄-design.md`（企劃者 2026-10-10～11 審過）：第五節全部（5.1 數字、5.2 體力照比例算〔企劃者選丙〕、5.3 出發時快照進 Journey、5.4 飽足與餵、5.5 馬市、5.6 馬的名字與階、5.8 結伴同行、5.9 決戰騎兵、5.10 截殺追逃、5.11 落敗策馬脫身）；2.3 的「路上不能換坐騎」；2.5 角色卡與修練頁坐騎那一段；2.6 開關；第九節坐騎那幾條；第十節量表坐騎那一項；第十一節「裝備二」。5.7 好馬的來源（懸賞、事件、名將）是裝備三，不在這一批。決戰與截殺是 Joy 寫的程式，企劃者 2026-10-11 定由我們這邊改，不用等 Joy。

- **`Equipment.template` 這一批不加**：名駒的專名與名將贈禮要照 `template` 從內容讀，那是裝備三建 `content/gear.json` 時的事。這一批 `mounts` 與引擎自己寫的馬名（馬市的鈕、餵、餓了的提醒、修練頁、角色卡、決戰與截殺的句子）都經過 `mounts.name_of`（現在就是 `item.name`）；**但 `equipment.store`（`put_on`「你騎上了【X】。」、`STORED`「【X】放上了裝備庫。」）與 `equipment.wield`（`WIELDED`「你換上了【X】。」）是四欄共用的，直接用 `item.name`**，買馬、換馬那三句繞過 `name_of`。這一批不動 equipment 的這兩個函式（`item.name` 就是存檔裡的名字，現在寫出來一樣）；裝備三讓名駒照 template 讀名字時，要在 equipment 加一個依欄位取名的掛鉤（例如 `Slot` 多一欄取名函式，或由各欄把名字傳進 `store`／`wield`），不能只改 `name_of`。
- **頭目戰不吃騎兵**：`_duel_start` 用的也是 `_battle_scores()`，騎兵直接加進去頭目戰也會跟著加。設計 2.1 只列決戰、截殺、落敗三個用途，頭目戰又是 Joy 調過的數字，所以 `_battle_scores(mounted=True)` 多一個參數，頭目戰傳 `False`；不給參數照舊能呼叫（test_engine 十來處這樣用）。
- **截殺脫身不扣守方飽足、不看守方忙不忙**：設計沒寫。跑一段路扣飽足是抵達新的一站時的事，脫身沒有換站；`raid_refusal` 本來就不看對方忙不忙（截殺不必他同意），閉關、打坐中的人照樣能策馬脫身。寫回設計 5.10。
- **餵的「閒著」照設計字面**：不在路上、不在閉關（`mounts.feed_problem`）。不用 `Game._idle`：它還擋打坐、待處理事件、頭目戰、求見選單、懸賞榜、鐵匠鋪，比設計嚴；餵不花體力、不花錢，修練頁那一顆按得下去就餵。

def riding(state: GameState, content: Content) -> Equipment | None:
    """身上那匹；開關關著、沒騎是 None。"""
    item = state.player.mount
    return item if on(content) and item is not None and item.slot == "mount" else None


def _cell(table: dict[str, float], item: Equipment) -> float:
    return table.get(str(item.tier), 0.0)


def fed_factor(content: Content, item: Equipment) -> float:
    """飽足係數（5.1、5.4）：餓到底剩 edge_floor，吃飽是 1。"""
    floor = content.config.mounts.edge_floor
    return floor + (1 - floor) * max(0, min(100, item.edge)) / 100


def _quality(content: Content, item: Equipment) -> float:
    return content.config.mounts.quality_bonus.get(item.quality, 0.0)

    """這一匹路上快幾成（5.1）：路上快那一列（含品質）×飽足係數。"""
    return (_cell(content.config.mounts.speed, item) + _quality(content, item)) * fed_factor(content, item)


def leg_power(content: Content, item: Equipment | None) -> float:
    """這一匹的腳力（5.1）：省體力那一列（含品質）×飽足係數。不是坐騎、開關關著是 0。"""
    if item is None or item.slot != "mount" or not on(content):
        return 0.0
    return (_cell(content.config.mounts.stamina_save, item) + _quality(content, item)) * fed_factor(content, item)

    return leg_power(content, item.model_copy(update={"edge": 100})) if item is not None else 0.0

    return leg_power(content, riding(state, content))

    """步調（5.3）：步行、趕路的時間乘它＝1－路上快（含品質）×飽足係數；沒騎馬是 1。出發時快照進 Journey.pace。"""
    item = riding(state, content)
    return 1.0 if item is None else 1 - speed_of(content, item)


def cavalry(state: GameState, content: Content) -> float:

    item = riding(state, content)
    return 0.0 if item is None else _cell(content.config.mounts.cavalry, item) * fed_factor(content, item)

    item = riding(state, content)
    return 0.0 if item is None else _cell(content.config.mounts.escape, item) * fed_factor(content, item)


def raid_flee(content: Content, attacker: GameState, target: GameState) -> float:
    """截殺追逃（5.10）：被截殺的人策馬脫身的機會＝守方腳力－攻方腳力，夾在 0～raid_escape_cap。開關關著兩邊都是 0。"""
    gap = saving(target, content) - saving(attacker, content)
    return max(0.0, min(content.config.mounts.raid_escape_cap, gap))

def tenths(chance: float) -> int:
    """幾成：四捨五入、.5 進位（不用 round：round(2.5) 是 2）。"""
    return int(chance * 10 + 0.5)


def odds_text(chance: float) -> str:
    """寫給玩家看的機會（截殺確認句、必敗問句）：「約 3 成」；不到半成寫「不到一成」。待 joy 潤。"""
    n = tenths(chance)
    return f"約 {n} 成" if n else "不到一成"


def pct(ratio: float) -> str:
    """寫成整數百分比（設計 2.5 的例子：25%×0.8＝20%）：.5 進位，同 tenths 與 atlas 的 math.floor(x + 0.5)。
    不用 f"{ratio:.0%}"：它跟 round 一樣把 .5 捨到偶數，餓到底的駑馬省 12.5% 會寫成 12%、騎兵 2.5% 寫成 2%。"""
    return f"{math.floor(ratio * 100 + 0.5)}%"


def coat_for(loc_id: str) -> str:
    """馬市那一匹的毛色（5.6）：照地點 id 的 sha256 挑，同一處永遠一樣、正式內容四處不一樣。取前 8 個位元組當整數：

    digest = hashlib.sha256(loc_id.encode("utf-8")).digest()
    return COATS[int.from_bytes(digest[:8], "big") % len(COATS)]

    return item.name

    """「駑馬・下品」（5.6：坐騎不用 equipment.grade 的「一階下品」）。"""
    return f"{TIER_NAMES.get(item.tier, '')}・{item.quality}"

```python
def travel_seconds(minutes: float, mode: TravelMode, *, pace: float) -> float:
    """走完 minutes 分鐘的路程要幾秒（遊戲時間）：步行全程、趕路一半、疾行立刻到；再乘 pace（出發時騎的馬，裝備四欄 5.3：
    1＝沒騎馬）。pace 必填、不給預設：漏改的呼叫處直接丟 TypeError，不會悄悄照沒騎馬算。"""
    return minutes * 60 * TIME_SHARE[mode] * pace


def foot_stamina(content: Content, minutes: float, mode: TravelMode) -> int:
    """不騎馬時這種走法出發要扣的體力：步行 0；趕路、疾行照每分鐘路程的點數算，四捨五入（.5 進位）、至少 1 點。"""
    cfg = content.config
    rate = {"walk": 0.0, "hurry": cfg.hurry_stamina_per_minute, "dash": cfg.dash_stamina_per_minute}[mode]
    return 0 if rate <= 0 else max(1, math.floor(minutes * rate + 0.5))


def ride_stamina(foot: int, saving: float) -> int:
    """騎馬省下之後的體力（裝備四欄 5.2，企劃者 2026-10-10 選丙：照比例算、不設保底）：四捨五入（原本的體力 ×（1－腳力）），
    .5 一律進位（不用 round：Python 的 round 把 .5 捨到偶數，4.5 會變 4），剩下的至少 1 點；原本就是 0（步行）照舊 0。
    結伴同行時跟著的人拿帶頭的人的 foot 照自己的腳力算（Game._lead）。"""
    return 0 if foot <= 0 else max(1, math.floor(foot * (1 - saving) + 0.5))


def travel_stamina(content: Content, minutes: float, mode: TravelMode, *, saving: float) -> int:
    """這種走法出發時一次扣的體力：原本的（foot_stamina）再照腳力省（ride_stamina）。saving 必填（同 travel_seconds 的 pace）。"""
    return ride_stamina(foot_stamina(content, minutes, mode), saving)


def mode_when(minutes: float, mode: TravelMode, *, pace: float) -> str:
    """這種走法要花多久：「約 5 分鐘」「立刻到」；時間乘步調（5.3）。"""
    return "立刻到" if mode == "dash" else f"約 {whole_minutes(minutes * TIME_SHARE[mode] * pace)} 分鐘"


def mode_text(content: Content, minutes: float, mode: TravelMode, *, pace: float, saving: float) -> str:
    """「步行約 9 分鐘」「趕路約 5 分鐘・體力 9」「疾行立刻到・體力 18」：選單與詳情欄用。騎著馬時呼叫端傳步調與腳力（5.3）。"""
    stamina = travel_stamina(content, minutes, mode, saving=saving)
    return MODES[mode] + mode_when(minutes, mode, pace=pace) + (f"・體力 {stamina}" if stamina else "")
```

def hunger(state: GameState, content: Content, mode: str) -> list[str]:
    """抵達新的一站（Game._arrivals 的 new_leg）：身上那匹扣飽足度（步行、趕路 −5，疾行 −10）；第一次低到 edge_warn 以下回一句提醒
    （只一次，餵過或換一匹才重設）。沒騎馬、開關關著不扣。結伴同行時每個人照自己的馬扣（各自那一份 Game 的 _arrivals）。"""
    item, rule = riding(state, content), content.config.mounts
    if item is None:
        return []
    item.edge = max(0, item.edge - rule.hunger.get(mode, 0))
    if item.edge < rule.edge_warn and not state.player.hunger_warned:
        state.player.hunger_warned = True
        return [HUNGRY_WARNING.format(name=name_of(item))]
    return []


def feed_problem(state: GameState, content: Content) -> str | None:
    """餵不了的原因：沒騎馬（或開關關著）、在路上、閉關中、吃飽了、沒有一階素材。閒著時哪裡都能餵（不看打坐、選單，見計畫「範圍與取捨」）。"""
    p = state.player
    item = riding(state, content)
    if item is None:
        return NO_MOUNT
    if p.journey is not None:
        return FEED_ON_ROAD
    if p.busy_until is not None:
        return FEED_SECLUDED
    if item.edge >= 100:
        return NOT_HUNGRY
    if repair_material(state, content) is None:
        return NO_REPAIR_MATERIAL
    return None


def feed_note(state: GameState, content: Content) -> str:
    """「餵」鈕上那一段（修練頁、馬市）：餵得了寫用哪一種素材（「精鐵砂×1」），餵不了寫為什麼。"""
    problem = feed_problem(state, content)
    if problem is not None:
        return problem
    return f"{content.materials[repair_material(state, content)].name}×1"


def feed(state: GameState, content: Content) -> list[str]:
    """餵（5.4）：一個一階素材（屬性不限，背包裡最多的那一種，同修兵器），飽足回滿，不花銀兩；重設提醒。"""
    problem = feed_problem(state, content)
    if problem is not None:
        return [f"（{problem}。）"]
    p = state.player
    material = repair_material(state, content)
    p.materials[material] -= 1
    if not p.materials[material]:
        del p.materials[material]
    p.mount.edge, p.hunger_warned = 100, False
    return [FED.format(material=content.materials[material].name, name=name_of(p.mount))]
```

        """結伴同行：帶頭的你出發、改道、喊停之後，跟著的人照抄這一趟（同樣的路、同樣的抵達時間，連步調 Journey.pace 一起抄：

        （atlas.route_foot_stamina；喊停是 0），每個跟著的人照自己的坐騎再省（atlas.ride_stamina、mounts.saving）。
        start 是你動身的地點（從路上改道、喊停時是 None）。跟不上的人（體力不夠、手上有事、已經不在這裡）就散了，兩邊各記一句。
        回傳寫給你的幾句。told 是寫進跟著的人紀錄的那一句。"""
        me = self.state.player
        j = me.journey
        lines: list[str] = []
        for other in self._party(catch_up=True):
            o = other.state.player
            cost = atlas.ride_stamina(foot, mounts.saving(other.state, self.content))  # 這個人自己騎的馬省下之後要付的
            # 路是帶頭的人認得的路，跟著的人不必自己認得（所以不問 travel_refusal），只看他手上有沒有事、體力夠不夠
            block = atlas.travel_block(other.state, self.content)
            if start is not None and (o.journey is not None or o.location != start):
                problem = social.GONE.rstrip("。")
            elif start is not None and block is not None:
                problem = block.reason
            else:
                problem = None if o.stamina >= cost else f"體力不足，要 {cost} 體力"
            if problem is not None:
                o.tagalong = None
                other._write(f"結伴同行・{me.name}", [f"{me.name}{told.split('，')[0]}，你沒能跟上（{problem}）。"])
                lines.append(f"{o.name}沒能跟上，你們就此分開。")
            else:
                o.stamina -= cost
                o.journey = j.model_copy(deep=True)
                o.leg_actions = o.leg_actions | me.leg_actions
                other._write(f"結伴同行・{me.name}", [told] + ([f"體力 -{cost}"] if cost else []))
                if j.mode == "dash":
                    other._arrivals()
                lines.append(f"{o.name}跟著你。")
            self._save_kin(other)
            self.touched.add(o.name)
        return lines

def market_here(state: GameState, content: Content) -> bool:
    """這裡有開著的馬市：坐騎開著、人不在路上、地點有「馬市」標籤。"""

def shop_item(state: GameState, content: Content) -> Equipment:
    """馬市那一匹（還沒買，id 是「架:馬」）：駑馬下品，毛色照這一處（5.6）。「買」鈕寫它、買下來照它新開一匹。"""
    name = horse_name(coat_for(state.player.location), 1)
    return Equipment(id="架:馬", slot="mount", name=name, tier=1, quality="下品")


def new_mount(state: GameState, *, name: str, tier: int, quality: str) -> Equipment:
    """新的一匹（四欄共用的流水號 +1，id「騎:N」）。裝備三的良駒、名駒也從這裡開。"""
    return Equipment(id=equipment.next_id(state, "mount"), slot="mount", name=name, tier=tier, quality=quality)


def rack_full(state: GameState, content: Content) -> bool:
    return equipment.rack_full(state, content, "mount")


def buy_problem(state: GameState, content: Content) -> str | None:
    if not market_here(state, content):
        return NOT_MARKET  # 選單關了、人走了：引擎層自己也再驗一次
    if rack_full(state, content):
        return RACK_FULL
    short = content.config.mounts.shop_price - state.player.stats.get("silver", 0)
    return f"還差 {short} 兩" if short > 0 else None


def buy(state: GameState, content: Content) -> list[str]:
    """買一匹駑馬下品（5.5）：身上沒馬就直接騎上，不然放進裝備庫（equipment.store）。"""
    problem = buy_problem(state, content)
    if problem is not None:
        return [f"（{problem}。）"]
    price = content.config.mounts.shop_price
    state.player.stats["silver"] -= price
    shop = shop_item(state, content)
    item = new_mount(state, name=shop.name, tier=shop.tier, quality=shop.quality)
    return [BOUGHT.format(price=price, name=name_of(item)), equipment.store(state, item)]


def wield(state: GameState, content: Content, item_id: str) -> list[str]:
    """馬市的「換上」：只看坐騎那一欄；路上不能換由 equipment.wield 擋（Slot.road_locked）。"""
    return equipment.wield(state, content, item_id, ("mount",))

def wanted(state: GameState, content: Content, reserve: int = 0) -> str | None:
    """在馬市最該按的那一顆（整季機器人與伺服器假人共用）：裝備庫裡有比身上快的（比吃飽的腳力，餓了的好馬不吃虧）就換上；
    身上沒有坐騎、付得起馬價＋reserve 就買（馬市只賣駑馬：身上有馬就不買第二匹）；飽足低於 FEED_AT、餵得了就餵。不在馬市是 None。"""
    if not market_here(state, content):
        return None
    p = state.player
    now = fresh_power(content, p.mount)
    best = max(equipment.in_slot(p, "mount"), key=lambda m: (fresh_power(content, m), m.id), default=None)
    if best is not None and fresh_power(content, best) > now + 1e-9:
        return f"{WIELD}{best.id}"
    if p.mount is None and buy_problem(state, content) is None and \
            p.stats.get("silver", 0) >= content.config.mounts.shop_price + reserve:
        return BUY
    if p.mount is not None and p.mount.edge < FEED_AT and feed_problem(state, content) is None:
        return FEED
    return None

def _row(state: GameState, content: Content, item: Equipment, worn: bool) -> dict:
    """修練頁坐騎那一段的一列：階品、飽足度（wear_word）、趕路疾行省幾成（save）、路上快幾成（speed）、決戰強攻奇襲多幾成（cavalry）、
    落敗脫身的機會（escape）——設計 2.5：路上快、騎兵、脫身寫在修練頁這一列，不擠進角色卡；每一項都照這一匹自己的階、品質與飽足算
    （同 cavalry()／escape() 的公式，只是不看身上騎的是不是牠）。身上那匹另給「餵」鈕的能不能按（feed）與那一段字（feed_note：
    用哪一種素材，或為什麼不行）。每一列給「換上」能不能按（wield_ok）與原因（wield_note）：路上不能換坐騎（2.3），網頁照它把裝備庫
    那一列的「換上」灰掉，不必按了才知道。裝備庫裡的沒有「餵」，也沒有拆解（4.8）。"""
    rule, fed = content.config.mounts, fed_factor(content, item)
    on_road = state.player.journey is not None
    row = {
        "id": item.id, "name": name_of(item), "tier": item.tier, "quality": item.quality, "grade": grade(item),
        "edge": item.edge, "wear_word": WEAR_WORD,  # 網頁照這個字寫「飽足度 N」（3.1 的字表，不在網頁寫死）
        "save": pct(leg_power(content, item)), "speed": pct(speed_of(content, item)),
        "cavalry": pct(_cell(rule.cavalry, item) * fed), "escape": pct(_cell(rule.escape, item) * fed),
        "feed": False, "feed_note": "", "wield_ok": not on_road, "wield_note": ON_ROAD if on_road else "",
    }
    if worn:
        row["feed"] = feed_problem(state, content) is None
        row["feed_note"] = feed_note(state, content)
    return row


def rows(state: GameState, content: Content) -> dict:
    """修練頁的坐騎那一段（skillview.gear_rows）：身上那匹、裝備庫裡的馬。開關關著時 worn 是 None、rack 是空的。"""
    p = state.player
    if not on(content):
        return {"worn": None, "rack": []}
    return {
        "worn": _row(state, content, p.mount, True) if p.mount is not None else None,
        "rack": [_row(state, content, m, False) for m in equipment.in_slot(p, "mount")],
    }


def card_line(state: GameState, content: Content) -> str:
    """本人卡上的「坐騎」那一行（2.5，待 joy 潤）：沒騎或開關關著是空字串。路上快、騎兵、脫身寫在修練頁那一列（_row 的 speed、
    cavalry、escape），不擠進角色卡。"""
    item = riding(state, content)
    if item is None:
        return ""
    return f"坐騎　【{name_of(item)}】{grade(item)}・{WEAR_WORD} {item.edge}，趕路疾行省 {pct(leg_power(content, item))} 體力"

def move_scores(
    tuning: BattleTuning, power: float, outer: str | None, inner: str | None, role: str = "", cavalry: float = 0.0,
) -> dict[str, float]:
    """這個人每一招的份量（還沒乘氣血狀態，戰鬥系統 3.4）：實力 × 適性 ÷ 100，職位拿手的那一招再乘（1＋role_move_bonus），
    騎著馬時強攻、奇襲再乘（1＋cavalry）（裝備四欄 5.9：跟職位疊乘；cavalry 是 mounts.cavalry，已經乘過飽足係數）。
    實力見 strength；適性 ＝ 75 ± 武學（招式）屬性 15 ± 內功屬性 10，夾在 50～100。
    outer／inner 是武學與內功的屬性（沒學是 None，不加減）。加入戰局時由那個玩家自己的 Game 算好快照進來。
    最後只 round 一次：沒騎馬時乘的是 1，數字跟以前一模一樣。"""
    base = strength(tuning, power)
    scores = {}
    for move in MOVES:
        fit = tuning.affinity_base
        for attribute, step in ((outer, tuning.affinity_outer), (inner, tuning.affinity_inner)):
            good, bad = tuning.affinity.get(attribute, (None, None)) if attribute else (None, None)
            fit += step if move == good else -step if move == bad else 0.0
        bonus = 1 + tuning.role_move_bonus if ROLE_MOVES.get(role) == move else 1.0
        ride = 1 + cavalry if move in CAVALRY_MOVES else 1.0
        scores[move] = round(base * max(50.0, min(100.0, fit)) / 100 * bonus * ride, 1)
    return scores
```

def visit_market(game: Game) -> None:
    """城裡有馬市就看一眼（裝備四欄設計第九節）：照 market_want 換、買、餵（最多各一次），最後離開。不花體力。

    if s.pending_event or market_want(game) is None:
        return

    def enabled() -> set[str]:
        return {o.id for o in game.options(odds=False) if o.enabled}

    if "act:market" not in enabled():
        return
    game.choose("act:market")
    for _ in range(3):
        move = market_want(game)
        if move is None or move not in enabled():

        game.choose(move)
    if s.player.picking_market:
        game.choose(mounts.BACK)

"""坐騎量表（docs/superpowers/specs/2026-10-10-裝備四欄-design.md 第十節第 2 項；裝備二）：整季機器人跑幾個種子，比開坐騎與關坐騎。

週末的機器人一季只走 81～90 段（FB-129），--steer 照 measure_gear 的 _steer 一半的時候照手上的懸賞、軍令走。模型一律不連。

from tianxia import atlas, bot, bot_policy, bounties, database, mounts, naming, orders  # noqa: E402

STEER = 0.5  # 同 measure_gear、measure_sanren：一半的時候照手上的事走
GAITS = ("walk", "hurry", "dash")


def _cleanup() -> None:
    """結束時關掉所有資料庫連線再刪暫存資料夾（Windows 上開著的檔刪不掉）。"""

def _steer(game, options, rng) -> str | None:
    """照抄 scripts/measure_gear.py 的 _steer（同一個量法；那支腳本一 import 就改 stdout 與 TIANXIA_DB，不能直接 import）。
    合併後 measure_gear 的 _steer 跟這裡不一樣時，照它的實際寫法抄。"""
    if game.state.pending_event or rng.random() >= STEER:
        return None
    s, c = game.state, game.content
    ids = {o.id for o in options}
    here = s.player.location
    work = {b.kind for b in bounties.mine(s, c) if b.location == here}
    if "act:train" in ids and ("strike" in work or orders.win_counts(s, c, s.player.faction, here)):
        return "act:train"
    if "act:explore" in ids and "scout" in work:
        return "act:explore"
    if "act:duty" in ids and orders.duty_counts(s, c, s.player.faction, here):
        return "act:duty"
    places = bounties.targets(s, c) + orders.targets(s, c, s.player.faction)
    hop = bot_policy.next_hop(game, places) if places else None
    move = next((i for i in ids if i.startswith("move:") and i.partition(":")[2].partition(":")[0] == hop), None)
    if move is not None:
        return move
    return "act:train" if "act:train" in ids else None


def run(seed: int, profile: str | None, mounts_on: bool, steer: bool, gait: str, season_one: bool) -> dict:
    content = load_content(ROOT / "content", profile=profile)
    content.config.mounts.enabled = mounts_on
    if season_one:
        content.config.season_one = True
    gaits = random.Random(f"gait|{seed}")
    legs = dict.fromkeys(GAITS, 0)
    sums = dict.fromkeys(("walk_s", "foot_s", "paid", "foot", "bought", "spent", "fed", "losses", "escaped", "kept"), 0.0)
    cavalry: dict[str, float] = {}  # 決戰 id → 本人加入時快照的騎兵加成（沒騎馬是 0）
    real_depart, real_lose = Game._depart, Game._lose_silver
    real_hunger, real_buy, real_feed, original_pick = mounts.hunger, mounts.buy, mounts.feed, bot.pick

    def depart(self, route, mode):
        """出發那一刻（扣體力之前）：這一趟扣多少、沒騎馬要扣多少；步行、趕路花多久、沒騎馬要多久。"""
        s, c = self.state, self.content
        sums["paid"] += atlas.route_stamina(s, c, route, mode)
        sums["foot"] += atlas.route_foot_stamina(s, c, route, mode)
        if mode != "dash" and not atlas.returns_at_once(s, c, route):
            plain = sum(atlas.travel_seconds(leg, mode, pace=1.0) for leg in route.legs)
            sums["foot_s"] += plain
            sums["walk_s"] += plain * mounts.pace(s, c)
        return real_depart(self, route, mode)

    def hunger(state, content_, mode):
        legs[mode] += 1
        return real_hunger(state, content_, mode)

    def buy(state, content_):
        before = state.player.stats.get("silver", 0)
        out = real_buy(state, content_)
        paid = before - state.player.stats.get("silver", 0)
        if paid > 0:
            sums["bought"] += 1
            sums["spent"] += paid
        return out

    def feed(state, content_):
        before = sum(state.player.materials.values())
        out = real_feed(state, content_)
        sums["fed"] += before > sum(state.player.materials.values())
        return out

    def lose(self, record):
        purse = self.state.player.stats.get("silver", 0)
        out = real_lose(self, record)
        sums["losses"] += 1
        if purse // 10 and record.silver == 0:
            sums["escaped"] += 1
            sums["kept"] += purse // 10
        return out

    def pick(game, options, rng):
        steered = _steer(game, options, rng) if steer else None
        return steered if steered is not None else original_pick(game, options, rng)

    def observe(game) -> None:
        if gait == "mix":
            game.set_move_mode(gaits.choice(GAITS))  # 下一步的選單照這種走法列「前往」
        battle = game.world.get_battle()
        me = battle.participants.get(game.state.player.name) if battle is not None else None
        if me is not None:
            cavalry.setdefault(battle.battle_id, me.cavalry)

    def refuse(*args, **kwargs):
        raise RuntimeError("量測不連模型")

    # engine 照模組屬性呼叫 mounts.hunger、mounts.buy、mounts.feed，照類別找 Game._depart、Game._lose_silver，
    # bot.play_season 照模組全域呼叫 pick：都換得到
    with mock.patch.object(naming, "propose", lambda *a, **k: (None, "")), \
            mock.patch.object(naming, "pick", lambda *a, **k: (None, "")), \
            mock.patch.object(OllamaClient, "chat_structured", refuse), mock.patch.object(OllamaClient, "chat_text", refuse), \
            mock.patch("requests.post", refuse), mock.patch("requests.get", refuse), \
            mock.patch.object(Game, "_depart", depart), mock.patch.object(Game, "_lose_silver", lose), \
            mock.patch.object(mounts, "hunger", hunger), mock.patch.object(mounts, "buy", buy), \
            mock.patch.object(mounts, "feed", feed), mock.patch.object(bot, "pick", pick):
        game = bot.play_season(content, seed, world=open_world(TMP / f"s{seed}-{int(mounts_on)}.db"), observe=observe)
    p = game.state.player
    season = game.state.world
    rode = [v for v in cavalry.values() if v > 0]
    return {
        "legs": legs, "walk_h": sums["walk_s"] / 3600, "foot_h": sums["foot_s"] / 3600,
        "paid": round(sums["paid"]), "foot": round(sums["foot"]), "bought": round(sums["bought"]), "spent": round(sums["spent"]),
        "fed": round(sums["fed"]), "losses": round(sums["losses"]), "escaped": round(sums["escaped"]), "kept": round(sums["kept"]),
        "fought": len(cavalry), "rode": len(rode), "cavalry": sum(rode) / len(rode) if rode else None,
        "mount": f"{p.mount.name}（{mounts.WEAR_WORD} {p.mount.edge}）" if p.mount else "—",
        "tier1": sum(n for mid, n in p.materials.items() if content.materials[mid].tier == 1),
        "silver": p.stats.get("silver", 0), "hours": season.time / 3600, "ending": season.ending_id or "—",
    }


def _saved(spent: float, plain: float) -> str:
    return "—" if plain <= 0 else f"{1 - spent / plain:.0%}"


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--seeds", type=int, nargs="+", default=[1, 2, 3, 4, 5])
    parser.add_argument("--profile", default=None)
    parser.add_argument("--steer", action="store_true", help="一半的時候照手上的懸賞、軍令走（週末那一組用，同 measure_gear）")
    parser.add_argument("--gait", choices=("walk", "mix"), default="walk", help="mix：每一步照種子擲一次走法（步行、趕路、疾行）")
    parser.add_argument("--season-one", action="store_true", help="打開第一季開關（14 天設定量決戰騎兵用）")
    args = parser.parse_args()
    content = load_content(ROOT / "content", profile=args.profile)
    extra = ("（照手上的事走）" if args.steer else "") + ("（走法混著用）" if args.gait == "mix" else "") \
        + ("（第一季開關開）" if args.season_one else "")
    print(profile_line(content, args.profile) + extra, flush=True)
    for seed in args.seeds:
        for on in (False, True):
            r = run(seed, args.profile, on, args.steer, args.gait, args.season_one)
            legs = r["legs"]
            cav = "—" if r["cavalry"] is None else f"+{r['cavalry']:.0%}"
            print(f"種子 {seed} 坐騎{'開' if on else '關'}：走了 {sum(legs.values())} 段（步行 {legs['walk']}、趕路 {legs['hurry']}、"
                  f"疾行 {legs['dash']}）、走路花 {r['walk_h']:.1f} 小時（沒騎馬要 {r['foot_h']:.1f}，省 {_saved(r['walk_h'], r['foot_h'])}）、"
                  f"趕路疾行體力 {r['paid']}（沒騎馬要 {r['foot']}，省 {_saved(r['paid'], r['foot'])}）、"
                  f"買馬 {r['bought']} 匹（{r['spent']} 兩）、餵 {r['fed']} 次、落敗 {r['losses']} 場（策馬脫身 {r['escaped']} 場、"
                  f"保住 {r['kept']} 兩）、決戰騎著馬 {r['rode']}／{r['fought']} 場（騎兵平均 {cav}）、季末坐騎 {r['mount']}、"
                  f"一階素材 {r['tier1']}、銀兩 {r['silver']}、季長 {r['hours']:.1f} 小時（世界時間）、結局 {r['ending']}", flush=True)


if __name__ == "__main__":
    main()
