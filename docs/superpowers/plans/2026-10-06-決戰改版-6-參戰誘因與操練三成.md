# 決戰改版 6：參戰誘因與操練三成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兩件事。
1. **參戰誘因**：參加全服決戰照個人貢獻發心得與名望。贏的一邊多拿，大勝更多；前三名寫進傳聞與江湖史。
2. **操練三成**：在自己陣營跟自己人操練，獎勵只給對手的三成。

**Architecture:**
- **操練**（Task 1）：只改 `engine._drill`，乘 `Config.drill_reward_share`，跟決戰無關，什麼時候做都可以。
- **個人貢獻**：每回合在 `resolve_round` 裡跟著推力一起記，累積在 `BattleParticipant.contribution`。
  - 固定招：份量 × 剋制。
  - 代出（逾時、作戰方針、AI）：一半。
  - 放手一搏：成了乘倍數，敗了 0。
  - 豪強：份量 × 膠著。
- **勝負**：收場時把贏家與大勝、險勝記在戰鬥上（`winner`、`margin`）。時刻表決戰由 `_settle_showdown` 照鎖定改寫。
- **發獎**：每個參戰者自己的 `Game` 在補送戰報時（`_file_showdown`）照自己的貢獻發給自己，所以只發一次、離線的人回來才拿，假人跟真人一樣。
- **前三名**：收場那一刻（`_apply_battle_outcome`）寫一則傳聞、一行江湖史。

**Tech Stack:** Python 3、pydantic（`tianxia/`）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-03-戰鬥系統-design.md`

## Global Constraints

- **操練**：心得、經驗只給對手的三成（`drill_reward_share` 0.3），四捨五入。不會輸、不扣氣血、推大勢照舊。操練原本就不給銀兩、不掉素材，不變。
- **個人貢獻**（每回合記一筆，倒下之後不再記，已經記的照算）：
  - 自己出固定招：這一回合算進自己這邊的份量（份量 × 剋制係數，含功效）。
  - 逾時、作戰方針、AI 代出：一半（`auto_share` 0.5）。
  - 放手一搏：成了是份量 × 倍數；敗了 0。
  - 豪強：自己那一份 × 膠著程度；保存實力本來就算一半，代出再一半；兩軍都沒人出手的回合是 0（同第三方的收穫）。
- **收場發獎**：
  - 基數：心得 ＝ 貢獻 ÷ 15、名望 ＝ 貢獻 ÷ 150。
  - 倍數：自己這邊贏 ×1.5、大勝 ×2；輸的、平手的、豪強 ×1。
  - 乘勝：自己這邊贏時再 ×（1 ＋ 乘勝）。
  - 悟招：有貢獻就多給它的數字（5）心得。
  - 心得、名望各自四捨五入。
- **誰贏**：一般決戰照戰局（`result_at`，不看鎖定）。時刻表決戰照 `_settle_showdown` 判的（看鎖定）。
- **不發的情況**：
  - 季終沒打完收起來的決戰。
  - 上一季的決戰：角色換季重來了，只補一則紀錄。
  - 貢獻是 0 的人（加入了但一回合都沒出手）。
- **前三名**：貢獻最高、而且大於 0 的三位，收場時寫一則傳聞（全服）與一行江湖史，例：「長社火攻一役，出力最多的是甲、乙、丙。」假人跟真人一樣上榜（看不出誰是假人）。
- **戰報**：自己那一則多一行「你出力 N，全場第 k」，數值變化列「心得 +X」「名望 +Y」。
- 數字全由規則引擎決定，全部【預設】，放在 `Config`（操練）與 `Config.battle`（決戰）。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

## Review Focus

1. **只發一次**：同步兩次、或收場的人與補送的人是同一個，心得不會發兩次。→ Task 3 `test_the_reward_is_paid_once`。
2. **季終沒打完、上一季的**：都不發。→ Task 3 `test_no_reward_for_an_unfinished_or_last_seasons_battle`。
3. **倒下的人**：倒下之前的貢獻照算，之後的回合不再加。→ Task 2 `test_the_fallen_keep_what_they_earned_and_earn_no_more`。
4. **豪強不吃勝負加成**：不論誰贏都是 ×1，乘勝也不加。→ Task 3 `test_warlords_are_paid_flat`。
5. **零貢獻**：加入了卻沒出手的人不發、不上前三名，悟招也不給。→ Task 3 `test_no_contribution_no_reward_and_no_ranking`。

```python
    def _battle_reward(
        self, battle: battle_instance.BattleInstance, me: battle_instance.BattleParticipant, definition: BattleDef | None,
    ) -> tuple[int, int]:
        """參戰獎勵（戰鬥系統第七節）：心得 ＝ 貢獻 ÷ 15、名望 ＝ 貢獻 ÷ 150；自己這邊贏 ×1.5、大勝 ×2，
        贏了再乘（1 ＋ 乘勝）；有貢獻就多給悟招的心得（3.6）。豪強照 ×1（第六節）。沒貢獻什麼都沒有。"""
        if me.contribution <= 0:
            return 0, 0
        tuning = self.content.config.battle
        third = definition is not None and definition.third is not None and me.faction == definition.third.faction
        mult = 1.0
        if not third and battle.winner == me.faction:
            mult = (tuning.big_win_bonus if battle.margin == "大勝" else tuning.win_bonus) * (
                1 + me.traits.get(battle_instance.SPOILS, 0.0)
            )
        xinde = int(me.contribution / tuning.reward_xinde_per * mult + 0.5) + int(me.traits.get(battle_instance.INSIGHT, 0))
        fame = int(me.contribution / tuning.reward_fame_per * mult + 0.5)
        return xinde, fame
```

## 計畫裡的決定（設計沒寫死、這份替實作選的）

| 題目 | 這份的做法 | 理由 |
|---|---|---|
| 獎勵什麼時候發 | 各自的 `Game` 補送戰報時發給自己 | 決戰狀態是共用的，角色只能由自己的 `Game` 改；補送本來就只做一次，離線的人回來才拿 |
| 乘勝怎麼疊 | 贏的倍數再 ×（1 ＋ 乘勝） | 第七節寫「再 +10%／層」，是在勝負加成之上再加 |
| 悟招什麼時候給 | 有貢獻就給，輸贏都給 | 3.6 寫「參戰獎勵多 5 心得」，沒有限勝方；沒出手的不給，免得掛名就拿 |
| 上一季的決戰 | 只補紀錄、不發 | 角色每季重來，把上一季的心得名望發到新角色身上說不通 |
| 季終沒打完 | 不發 | 第七節是「收場發獎」；沒打完不算勝負，也沒有收場 |
| 一般決戰的大勝 | 照時刻表決戰同一個門檻（偏離 15） | 同一套 `result_at`，兩種決戰的「大勝」意思一樣 |
| 豪強的代出 | 保存實力的一半再一半 | 第六節「代出保存實力，個人貢獻記一半」，保存實力本身又算一半 |
| 戰報多寫什麼 | 「你出力 N，全場第 k」與心得、名望 | 讓人看得到自己這一場值多少；名次比數字好懂 |

## 不在這份

- 排行榜頁面（全季的貢獻排名）：第七節沒選「只給名聲與排名」，這次不做。
- 內傷累積的目標值：第八節，等測試的真人數據。
- 天品素材：第八節結案。
