# 線上架構：伺服器主動推送（SSE）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 有東西變了，伺服器主動告訴開著的分頁，分頁不必每 10 秒來問。有兩種情況：
- 自己的動作做完，自己其他的分頁要刷新；
- 大家都看得到的世界變了，例如大事、江湖史、天下大事、決戰的回合。

連著推送時，分頁每 60 秒才問一次；推送斷了就自動回到每 10 秒問一次。

**Architecture:**
- 新的 `server_push.py`（專案根目錄）提供：
  - `PushHub`：誰開著哪些分頁，可以從任何執行緒送通知；
  - `world_fingerprint`：只看公開欄位的世界指紋；
  - `watch_world`：背景看守，指紋變了才廣播，兩次至少隔 10 秒；
  - `sse_stream`：一條 SSE 連線。
- `server.py` 多三樣東西：
  - `GET /api/events`（async、`text/event-stream`）；
  - `act()` 做完時通知那個角色；
  - `main()` 開看守執行緒。
- 前端用瀏覽器內建的 `EventSource`，收到通知就叫既有的 `poll()`。`poll()` 已經會防重疊、只重畫有變的部分。
- 只送「哪一種變了」（`self`／`world`），不送內容：誰的資料都不會被推給別人。

**Tech Stack:** Python 3 `asyncio`／`threading`、FastAPI `StreamingResponse`（既有套件，**不加新套件**）、原生 JS `EventSource`，pytest。

**Spec:** `docs/superpowers/specs/2026-10-02-線上架構-design.md`：
- 5.3「推送：每個開著的分頁一條 WebSocket，伺服器只推有變化的部分；取代現在每個分頁每 10 秒重畫 38 個區塊」；
- 第七節「網頁前端」（Vue 3【預設】）；
- 第十一節的「每個分頁每 10 秒重畫 38 個區塊」。

計畫依據 main `308e427`。

**排程與風險**：在備份、伺服器排程、LLM 佇列之後（企劃者 2026-10-06：全部做完再一起測）。
- **開關預設關**：`Config.push_events = False` 時不開看守、不開 `/api/events`（回 404），前端照舊每 10 秒輪詢，行為一字不差。
- **斷線時退回輪詢**：
  - `EventSource` 的 `onerror` 一觸發，前端就回到每 10 秒輪詢；

- **驗收**：Task 4 由控制者做。
  - 預覽伺服器，兩個分頁、兩個帳號；
  - 一個分頁做動作，另一個在 1～3 秒內跟著刷新；
  - 一場決戰的回合結算，兩邊都在幾秒內看到；
  - 關掉伺服器，前端回到 10 秒輪詢；重開後重新登入照常；
  - 經過 `--share`（trycloudflare）再做一次。
- 推送核心（Task 1）的程式與 7 條測試，已經在 scratch 照抄跑過，全過。其中包括「TestClient 讀 SSE 端點」這一招：要讓串流自己結束，TestClient 才會回來。

## 決定：用 SSE，不用 WebSocket；封測不換 Vue

這兩件是 PM 2026-10-06 交代「一起想」的。這份計畫照下面的決定寫；企劃者要推翻的話，見每一條最後一句。

- **SSE，不是 WebSocket**：
  - 這一版只需要「伺服器 → 分頁」的通知；動作照舊用 POST，伺服器已經有行動鎖與重讀角色那一套，不必改成走推送的連線。
  - SSE 是普通的 HTTP 串流：FastAPI 的 `StreamingResponse` 就做得到，**不用裝新套件**。uvicorn 要收 WebSocket，得另裝 `websockets` 或 `wsproto`；這台機器封鎖過帶 DLL 的套件（`requirements.txt` 有記載）。
  - 瀏覽器的 `EventSource` 自帶斷線重連。
  - Cloudflare 照樣轉送 `text/event-stream`。
  - 要換回 WebSocket 時，只有 `/api/events` 與前端連線的那幾行要改，`PushHub`、看守、指紋都照用。
- **封測不換 Vue**：
  - 現在的前端是原生 JS，`web/app.js` 約 1850 行，沒有建置步驟，手機版面、輪詢、各分頁的局部重畫都已經做好、驗過。
  - 換 Vue 等於前端整個重寫，還要多一套 node 工具鏈。封測要測的是玩法，不是前端框架，而且這跟「範圍凍結」衝突。
  - 什麼時候再談：正式開服前，前端真的要拆成元件（例如管理者面板、決戰面板要大改）時，跟壓測的結果一起看。
  - 這一條寫進設計文件第七節（Task 4）。
- **只送通知、不送內容**：
  - 設計 5.3 寫「只推有變化的部分」。這一版推的是「哪一種變了」，分頁收到再抓 `/api/main`。
  - 好處：不用動前端怎麼畫畫面，也不會把誰的資料推給不該看的人。
  - 代價：世界一變，每個開著的分頁都會抓一次。看守限制兩次 `world` 至少隔 10 秒，所以最壞跟現在的 10 秒輪詢一樣多；世界沒變時少很多。
  - 真的要「推內容本身」，例如把天下大事、決戰卡直接推出去，等第 6 份壓測的結果再說。

## Global Constraints

- `server_push.py` 放專案根目錄；`tianxia/` 這份計畫不動（引擎不讀時鐘）。
- **不加任何新套件**；`requirements.txt` 不動。
- **世界指紋只看公開的東西**：已浮現的大勢線、結局、主線幕次、時刻表已結算的大事、開過的決戰、大勢人物、天下大事那一層傳聞的最大流水號、江湖史筆數、決戰的公開狀態（哪一場、階段、第幾回合、戰局、人數、這一回合出手了幾個）。
  - **不看**：時間、鎖定、搶輸、豪強名單、伏筆、軍令、隱藏的大勢線、陣營軍情與地方傳聞。
  - 不然「什麼都沒變卻收到刷新」會洩漏誰在什麼時候做了看不見的事（伏筆鎖定看不出來，計畫 T7）。

- **開關預設關**：`Config.push_events: bool = False`；`push_watch_seconds: float = 5`；`push_world_min_seconds: float = 10`。
- 前端：原生 JS、`node --check web/app.js` 要過；不加外部函式庫。
- 測試一律用暫存資料庫；不碰 `saves/`、`.local/`、`C:\Ray\tianxia-play\`。

"""伺服器主動通知（線上架構設計 5.3）：只送「哪一種變了」；指紋只看公開的東西。"""
import asyncio
import threading

from fastapi.testclient import TestClient

def _listen(hub, name):
    """開一個事件迴圈、訂閱 name；回傳 (收到的清單, 執行緒, 迴圈)。收到 None（hub.close）就退訂、結束。"""
    got, ready = [], threading.Event()
    loop = asyncio.new_event_loop()

    async def main():
        queue: asyncio.Queue = asyncio.Queue()
        hub.subscribe(name, loop, queue)
        ready.set()
        while True:
            item = await queue.get()
            if item is None:
                break
            got.append(item)
        hub.unsubscribe(name, loop, queue)

    thread = threading.Thread(target=lambda: loop.run_until_complete(main()))
    thread.start()
    assert ready.wait(2)
    return got, thread, loop


def _finish(thread, loop):
    thread.join(2)
    loop.close()


def test_notify_reaches_only_that_character_and_broadcast_reaches_all():
    hub = server_push.PushHub()
    a, ta, la = _listen(hub, "甲")
    b, tb, lb = _listen(hub, "乙")
    assert hub.count() == 2
    assert hub.notify("甲") == 1
    assert hub.broadcast() == 2
    hub.close()
    _finish(ta, la)
    _finish(tb, lb)
    assert a == ["self", "world"] and b == ["world"]
    assert hub.count() == 0  # 斷了就退訂，不會越積越多（Review Focus 4）

```python
"""伺服器主動通知（線上架構設計 5.3）：用 SSE（Server-Sent Events）告訴開著的分頁「有東西變了」，分頁再去抓 /api/main。

兩種通知：
- self：某個角色自己做完一個動作，他其他開著的分頁該刷新了；
- world：大家都看得到的世界變了（大事、江湖史、天下大事傳聞、決戰、大勢人物、已浮現的大勢線），每個分頁都刷新。
  由背景的看守（watch_world）每隔幾秒比一次「公開的世界指紋」，變了才發，而且兩次 world 之間至少隔 min_interval 秒。

指紋只看大家本來就看得到的東西：鎖定、搶輸、豪強、伏筆、軍令、隱藏的大勢線、陣營軍情與地方傳聞都不算，
不然「什麼都沒變卻收到刷新」會洩漏誰在什麼時候做了看不見的事（伏筆鎖定看不出來，計畫 T7）。

放在專案根目錄、不在 tianxia/：要用執行緒、事件迴圈與時鐘。只送「哪一種變了」，不送內容，所以不會把誰的資料推給別人。"""
from __future__ import annotations

import asyncio
import hashlib
import json
import threading
import time
from collections.abc import Callable

SELF, WORLD = "self", "world"


class PushHub:
    def __init__(self) -> None:
        self._lock = threading.Lock()
        self._subs: dict[str, set[tuple[asyncio.AbstractEventLoop, asyncio.Queue]]] = {}

    def subscribe(self, name: str, loop: asyncio.AbstractEventLoop, queue: asyncio.Queue) -> None:
        with self._lock:
            self._subs.setdefault(name, set()).add((loop, queue))

    def unsubscribe(self, name: str, loop: asyncio.AbstractEventLoop, queue: asyncio.Queue) -> None:
        with self._lock:
            subs = self._subs.get(name)
            if subs is not None:
                subs.discard((loop, queue))
                if not subs:
                    del self._subs[name]

    def notify(self, name: str, kind: str = SELF) -> int:
        """通知這個角色開著的每個分頁；回傳送了幾個。可以從任何執行緒呼叫。"""
        with self._lock:
            targets = list(self._subs.get(name, ()))
        return sum(_deliver(loop, queue, kind) for loop, queue in targets)

    def broadcast(self, kind: str = WORLD) -> int:
        with self._lock:
            targets = [t for subs in self._subs.values() for t in subs]
        return sum(_deliver(loop, queue, kind) for loop, queue in targets)

    def close(self) -> None:
        """叫每一條連線結束（測試與關伺服器用）：送 None，串流收到就停。"""
        with self._lock:
            targets = [t for subs in self._subs.values() for t in subs]
        for loop, queue in targets:
            _deliver(loop, queue, None)

    def count(self) -> int:
        with self._lock:
            return sum(len(subs) for subs in self._subs.values())


def _deliver(loop: asyncio.AbstractEventLoop, queue: asyncio.Queue, item) -> bool:
    try:
        loop.call_soon_threadsafe(queue.put_nowait, item)
        return True
    except RuntimeError:  # 那條連線的事件迴圈已經關了
        return False


def world_fingerprint(season_number: int, phase: str, season, battle) -> str:
    """大家都看得到的世界部分的指紋。時間本身不算（時鐘一直在走，靠慢速輪詢更新）。"""
    public = {
        "season": season_number,
        "phase": phase,
        "trends": {k: v for k, v in sorted(season.trends.items()) if k in season.revealed},
        "ending": season.ending_title,
        "act": [season.storyline, season.act],
        "timeline": sorted(season.timeline),
        "opened": sorted(season.showdowns_opened),
        "figures": {k: v.model_dump() for k, v in sorted(season.figures.items())},
        "rumor": max((r.id or 0 for r in season.rumors if r.layer == "world"), default=0),
        "chronicle": len(season.chronicle),
        "battle": None if battle is None else [
            battle.battle_id, battle.phase, battle.round_number, battle.trend,
            len(battle.participants), len(battle.round.pending_actions),
        ],
    }
    blob = json.dumps(public, sort_keys=True, ensure_ascii=False, default=str)
    return hashlib.sha256(blob.encode("utf-8")).hexdigest()


def watch_world(
    hub: PushHub, fingerprint: Callable[[], str], stop: threading.Event, interval: float, min_interval: float,
    clock: Callable[[], float] = time.monotonic,
) -> None:
    """看守：每 interval 秒算一次指紋，跟上次發出去的不同、而且離上次 world 至少 min_interval 秒，就廣播 world。
    還沒到 min_interval 的變化不記下來，下一輪照樣看得出來、時間到了再發。算指紋出錯就跳過這一輪。"""
    sent = None
    last = float("-inf")
    while not stop.wait(interval):
        try:
            now_fp = fingerprint()
        except Exception as e:  # noqa: BLE001  看守不能因為一次讀不到就停
            print(f"推送的看守讀不到世界：{e!r}", flush=True)
            continue
        if sent is None:
            sent = now_fp
            continue
        now = clock()
        if now_fp != sent and now - last >= min_interval:
            hub.broadcast(WORLD)
            sent, last = now_fp, now


async def sse_stream(hub: PushHub, name: str, heartbeat: float = 15.0):
    """一條 SSE 連線：訂閱 name、把通知寫成 SSE 的格式；每 heartbeat 秒沒事就送一行註解，代理才不會當它斷了；
    收到 None（hub.close）就結束；不論怎麼結束（含分頁關掉、連線被切）都退訂。"""
    loop = asyncio.get_running_loop()
    queue: asyncio.Queue = asyncio.Queue()
    hub.subscribe(name, loop, queue)
    try:
        yield "retry: 5000\n\n"
        while True:
            try:
                item = await asyncio.wait_for(queue.get(), timeout=heartbeat)
            except asyncio.TimeoutError:
                yield ": ping\n\n"
                continue
            if item is None:
                break
            yield f"event: {item}\ndata: {{}}\n\n"
    finally:
        hub.unsubscribe(name, loop, queue)
```
