# 武學與成長（二）屬性與威力 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 升級給屬性點自己分配；四屬性各管一件事（臂力管外功、根骨管內功與氣血與內傷、身法管閃、悟性管修練與領悟）；內功與武學同屬性加成、相剋打折；正邪武學跟名聲共鳴；善名、惡名到門檻悟得浩然、血煞。

**Architecture:** 加成全部在規則引擎算好，用一個小資料結構 `encounter.Boost`（外功加幾成、內功加幾成、整個人乘幾倍）交給 `encounter.member_power`；`encounter.py` 照舊只處理數字。誰該拿什麼加成由 `team.py` 決定。

**Tech Stack:** Python 3、pydantic、FastAPI、原生 JavaScript、pytest。

**Spec:** `docs/superpowers/specs/2026-10-05-武學與成長-design.md`（第五、六、七節）。

**執行方式：** 企劃者 2026-10-05 選定**子代理逐步做**（superpowers:subagent-driven-development：每個 Task 一個新的子代理實作、另一個子代理審過才做下一個，最後整條分支再審一次）。開工時間由 PM 排在第一季濃縮版週末測試之後。

**前提：** 計畫一（`2026-10-05-武學與成長-1-武學核心.md`）已經做完併進 `main`：會用到 `team.player_art`、`insights.learn`、`cultivation.chance`、`MartialArt.lean`、`InsightDef.grant`。

## Global Constraints

- 同計畫一的 Global Constraints（排程、`tianxia/` 不 import 網頁框架、數值由規則引擎決定、繁體中文、`PlayerState` 新欄位要有預設值、測試指令、commit 規矩）。
- 預設數字（設計第十一節）一律放 `Config`：`stat_points_per_level = 1`、`stat_cap = 15`、`stat_bonus_per_point = 0.03`、`pairing_bonus = 0.2`、`pairing_penalty = 0.2`、`resonance_per_point = 0.005`、`resonance_cap = 0.2`。
- 加成的乘數不能讓任何量變成負的：`1 + 加成` 一律夾在 0.1 以上，`1 − 減免` 一律夾在 0 以上。

## Review Focus

1. **事件把屬性加超過上限**：奇遇給「臂力 +3」時屬性已經 14，結果要停在 15，而且訊息照實寫（不能寫 +3 但只加了 1 還不說）——測試在 Task 1。
2. **一次升好幾級**：打一場大勝連升兩級，屬性點要給兩點、提示寫對剩幾點——測試在 Task 1。
3. **熔掉浩然之後名聲又漲**：浩然是「第一次到 15」才給，熔掉之後不會再送一次——測試在 Task 4。
4. **根骨改了氣血上限，目前氣血不能超過新的上限也不能憑空回滿**：配點加根骨時，氣血條的分子不變、分母變大——測試在 Task 2。
5. **同伴不吃玩家的加成**：帶著同伴打仗，加成只算在玩家本人身上——測試在 Task 2。

## 計畫裡的實作決定

| 題目 | 怎麼做 | 為什麼 |
|---|---|---|
| 同伴吃不吃這些加成 | **不吃**：屬性加成、內外搭配、正邪共鳴都只算在玩家本人 | 設計第五、六、七節談的都是玩家本人；同伴的平衡在氣血設計 §1.4 調過，不連帶動 |
| 根骨的氣血上限怎麼加 | 上限 ×（1＋3%×（根骨－5）），跟其他屬性同一個比例；刪掉沒人讀的 `neili_per_con` | 設計 6.1 說數字要跟 A1 一起校準；用同一個比例最好懂，也不會一點根骨就多四十點血 |
| 根骨的「內傷好得快」 | 一場損耗裡變成內傷的比例 ×（1－3%×（根骨－5）） | 現在內傷不會自己好；「好得快」最接近的是「同樣挨打，內傷少一點」，不用另做自然痊癒 |
| 身法的「少掉一點氣血」 | 一場損耗 ×（1－3%×（身法－5）） | 同上，一個屬性一個比例 |
| 悟性的「悟到意境的機會」 | 探索三選一裡「悟意境」那一支的比重 ×（1＋3%×（悟性－5）） | 設計 6.1 |
| 浩然、血煞「第一次到 15」 | 給過就記一個旗標 `悟得:<id>`，之後熔掉也不再給 | 設計 7.2 寫「第一次」；不然熔了又拿、拿了又熔可以刷心得 |
| 屬性點一次給幾點 | 每升一級 1 點；一次升好幾級就給好幾點 | 設計 6.2 |

```python
def allocate_points(game: Game, rng: random.Random) -> None:
    """升級得到的屬性點隨機分掉（還沒到頂的那幾項裡挑）。"""
    p, cap = game.state.player, game.content.config.stat_cap
    while p.stat_points > 0:
        open_stats = [k for k in team.COMBAT_STATS if p.stats.get(k, 0) < cap]
        if not open_stats:
            return
        game.allocate_stat(rng.choice(open_stats))
```

```python
def test_a_boost_raises_the_outer_and_inner_arts(state, content, world):

    state.player.member.wugong_id = "basic_fist"
    state.player.member.neigong_id = "basic_breath"
```

```python
class Boost(BaseModel):
    """一個人在這一場的加成（武學與成長設計 5.1、6.1、7.4）。由呼叫端算好傳進來，這個模組只算數字。"""

    outer: float = 0.0  # 武學（外功）威力加幾成：臂力
    inner: float = 0.0  # 內功威力加幾成：根骨
    factor: float = 1.0  # 整個人的乘數：內外搭配 × 正邪共鳴


def member_power(
    member: HasMartialArts, arts: dict[str, MartialArt], opponent_attribute: str | None = None,
    condition: float = 1.0, boost: Boost | None = None,
) -> float:
    """這個人目前貢獻的威力：沒學武學就是 0。condition 是氣血狀態係數，boost 是這個人的加成（同伴不傳）。"""
    if not member.wugong_id or member.wugong_id not in arts:
        return 0.0
    boost = boost or Boost()
    wugong = arts[member.wugong_id]
    power = power_at(wugong, member.wugong_level) * max(0.1, 1 + boost.outer)
    if member.neigong_id and member.neigong_id in arts:
        neigong = arts[member.neigong_id]
        power *= 1 + power_at(neigong, member.neigong_level) * max(0.1, 1 + boost.inner) / NEIGONG_BONUS_DIVISOR
    power *= boost.factor
    if opponent_attribute and counters(wugong.attribute, opponent_attribute):
        power *= COUNTER_BONUS
    return power * condition


def team_power(
    members: list[HasMartialArts], arts: dict[str, MartialArt], opponent_attribute: str | None = None,
    conditions: list[float] | None = None, boosts: list[Boost | None] | None = None,
) -> float:
    """隊伍總威力。conditions、boosts 跟 members 一一對應；省略時當作全員滿血、沒有加成。"""
    if conditions is None:
        conditions = [1.0] * len(members)
    if boosts is None:
        boosts = [None] * len(members)
    return sum(
        member_power(m, arts, opponent_attribute, c, b) for m, c, b in zip(members, conditions, boosts)
    )
```

```python
    """氣血上限：基礎＋每級加成，再乘上根骨的加成（武學與成長設計 6.1）。"""

def neili_ceiling(content: Content, member, con: float = BASE_STAT) -> float:
    cap = neili_cap(content, member.level, con)
    return max(cap * MIN_CEILING_RATIO, cap - getattr(member, "injury", 0.0))


def member_neili(content: Content, member, con: float = BASE_STAT) -> tuple[float, float]:
    cap = neili_cap(content, member.level, con)
    ceiling = neili_ceiling(content, member, con)
    now = ceiling if member.neili is None else min(member.neili, ceiling)
    return now, cap


def regen_neili(content: Content, member, fraction: float, con: float = BASE_STAT) -> None:
    if member.neili is None:

    cap = neili_cap(content, member.level, con)
    ceiling = neili_ceiling(content, member, con)
    member.neili += cap * fraction
    if member.neili >= ceiling:
        member.neili = None
```

```python
    member.neili = max(0.0, now - loss)
    after, _ = member_neili(content, member, con)
    return now - after, hurt
```

```python
def pairing(content: Content, wugong: MartialArt | None, neigong: MartialArt | None) -> float:
    """內功與武學的搭配（武學與成長設計 5.1）：同屬性加成、相剋的一對打折、其他不變；少一門就不算。"""
    if wugong is None or neigong is None:
        return 1.0
    cfg = content.config
    if wugong.attribute == neigong.attribute:
        return 1 + cfg.pairing_bonus
    if counters(wugong.attribute, neigong.attribute):
        return max(0.1, 1 - cfg.pairing_penalty)
    return 1.0


def resonance(state: GameState, content: Content, art: MartialArt | None) -> float:
    """正邪共鳴（設計 7.4）：正派武學吃現在的善名、邪派吃惡名，名聲 ÷ 2 %、最多 resonance_cap；
    沒有正邪、或用了反的那一派，就是 1（不反噬）。"""
    stat = {"正": "good", "邪": "evil"}.get(art.lean) if art is not None else None
    if stat is None:
        return 1.0
    cfg = content.config
    return 1 + min(cfg.resonance_cap, state.player.stats.get(stat, 0) * cfg.resonance_per_point)
```

```python
        flag = f"悟得:{d.id}"
        if flag in p.flags or p.stats.get(d.grant.stat, 0) < d.grant.at:
            continue
        p.flags.add(flag)
        msgs.append(f"你心有所感，胸中多了一股{d.name}之氣。")
        msgs += learn(state, content, world, d.id)
    return msgs
```
