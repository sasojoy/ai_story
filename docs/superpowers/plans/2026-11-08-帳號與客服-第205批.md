## 三、核心：`tianxia/core/identity_base.py`（只改 `phone_ok` 與它要的查詢）

## 五、封測發放的手機編號

- `mall/rules.py` 加 `grant_phone_ref(subject) -> "grant:beta:phone:<subject>"` 與 `grant_beta_phone(content, wallet, owner, subject, now)`：同一筆 `wallet.db.transaction()` 裡，`has_ref(手機編號)` 有了回 0；否則 `post(owner, amount, "grant", grant_ref(owner))`，成了再 `post(owner, 0, "grant", 手機編號, note=…)`；`grant_beta` 不動。
- `actions.grant`：`phone_subject(ctx, "mall_grant")` 是 None（閘關、不在名單、假人）走舊的 `grant_beta`，一個字不變；有值走 `grant_beta_phone`。
- 一輩子一次：編號在 `mall_ledger`（`ref` UNIQUE），解綁（`remove_login`）、刪帳號都不刪帳本，自然不放掉。開閘前已發的（有 `grant:beta:<主人>`）不追回、也不補記手機編號。
