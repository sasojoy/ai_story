# 結局與跨季（世界記憶、陣營獎勵、稱號、江湖史留名、結算卡的「你的這一季」） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 第一季收季那一刻把整個天下的樣子寫成「世界記憶」存下來，下一季讀得到：各陣營照名次與自己的貢獻在下一季開局拿到銀兩、心得（只看上一季、不疊加、有上限）；出力前幾名與改寫史書大事的人拿到跨季稱號，名字留在江湖史；稱號寫在名號旁邊；休季的結算卡多一張「你的這一季」；新的一季開局，每個人的江湖紀錄最上面是「上一季」那一則前情，第二季的劇本可以照 `prev:` 世界旗標寫條件。全部藏在第一季的開關（而且這一季蓋了章）後面，開關關著時 beta 的收季、換季與畫面一個字都不變。

**Architecture:** 世界記憶是 `state.SeasonMemory`，在 `world.end_season` 的第一季分支組好、存在那一季的 `WorldState.memory`（`seasons` 表那一列整份存著，換季不刪）；`WorldStateStore.season_memory(季別)` 只取那一列的 `memory` 鍵，是這份計畫、計畫 2 與第二季共用的「讀上一季」介面。稱號的目錄在新的 `content/titles.json`，`tianxia/honors.py` 在收季時頒（`AWARDERS`：出力前幾名、改寫大事的人；第 4 階的席次之後掛上來）、季中由 `grant_now` 頒（碎片的關鍵人物，計畫 2 呼叫），一律記在世界記憶。獎勵的公式在 `tianxia/rewards.py`（純函式，數字在 `Config`）。角色換季重來（`Game._reset_player_for_new_season`）最後多一步 `_carry_last_season`：讀世界記憶，把稱號、起手資源、前情寫進「上一季」那一則；`fresh_season` 照上一季的記憶種 `prev:` 旗標。

**Tech Stack:** Python 3.14、pydantic、FastAPI、原生 JavaScript、pytest。

## Global Constraints

- `tianxia/` 是純規則引擎，不得 import 任何網頁框架；引擎不讀電腦時鐘；資料庫是唯一的真實來源；數值全部由規則引擎決定（CLAUDE.md「架構」「原則」）。
- **開關**：每一個新行為只在 `rules.season_one(content, world)` 成立時發生（`Config.season_one` 開著，**而且那一季開季時蓋了「開」的章**）：
  - 世界記憶與稱號、江湖史留名只在 `world.end_season` 的第一季分支寫；
  - 換季時發稱號、起手資源、前情看**新的這一季**有沒有開第一季的規則，`prev:` 旗標也是；
  - `honors.grant_now` 在開關關著時什麼都不做。
  開關關著（或沒蓋章的 beta 季）時：收季照舊、`memory` 是 `None`、換季照舊、結算卡照舊不出現；沒拿過稱號的人狀態列沒有 `titles` 鍵（稱號是自己的、跨季保留：以前在第一季拿到的，開關關了也照樣顯示）。開與關兩邊都有測試（Task 2、3、6、7、8）。
- **不改資料表、不升 `SCHEMA_VERSION`**：世界記憶存在 `seasons` 那一列的 JSON（`WorldState.memory`）；讀的時候 `json_extract` 只取那個鍵，這份計畫之前存的季沒有這個鍵，讀成 `None`。
- **新欄位都有預設值**，舊存檔、舊資料庫直接讀得進來：`WorldState.memory`／`title_grants`、`PlayerState.titles`、`Ending.winner`／`memory`、`Scenario.figure_memory`、`Config.season_reward_*`、`Content.titles`（沒有 `titles.json` 就是空的，測試夾具照舊）。
- **一個動作一筆交易；`mutate` 不能巢狀**：世界記憶在 `end_season` 裡組（呼叫端已經在 `mutate_season` 裡），只讀角色存檔、不另開 `mutate`；發獎在角色的換季重來裡（伺服器進鎖重讀角色、動作後存檔），從同一份上一季的存檔重算，所以只發一次。
- **假人看不出來**：稱號、獎勵、前情跟真人走同一條換季路徑；排行與江湖史寫名號，真人假人一樣，不標、不排除假人。
- **匿名**（企劃者 2026-10-06）：只有地方傳聞的單一事件可以匿名。這份新寫的江湖史、排行一律寫名號；稱號只接在寫名號的地方（地方傳聞的「某位少俠」不接，不然等於認出人）。
- **時間單位**：這份沒有世界裡的時長（獎勵、稱號都是季與季之間的事）；「隔季」看的是賽季編號。
- **內容**：稱號、江湖史句型、獎勵說明、世界記憶句照表寫進新檔（`content/titles.json`）或劇本層的欄位（`scenario.json` 的結局與 `figure_memory`），標「待 S1／joy 潤」；**不改 `content/events/` 底下任何檔**。
- 每個任務做完全套都要過；不碰 `saves/`、`.local/`。

```python
"""世界記憶（第一季設計 13.1、13.2、第十四節；計畫 2026-10-06-結局與跨季）：一季收季那一刻的樣子怎麼算。

資料模型在 state.py（SeasonMemory，存在那一季的 WorldState.memory）；寫入在 world.end_season（第一季收季時），讀取是
WorldStateStore.season_memory。這裡只放純函式：陣營名次、組一份記憶、下一季開局「上一季」那一則與 prev: 世界旗標。"""
from __future__ import annotations

from .models import Ending


def placing(ending: Ending, standing: dict[str, int], factions: list[str]) -> list[str]:
    """陣營名次（第一季設計 13.2：勝方滿額、第二名一半、第三名三成）：結局的勝方第一，其餘照最終態勢由高到低，平手照劇本的
    陣營順序。勝方不必是態勢最高的（計畫 2 的持璽結局）。結局沒寫勝方（beta 的結局）是空的——沒有名次，也就沒有陣營獎勵。"""
    if ending.winner is None or ending.winner not in factions:
        return []
    order = {faction: i for i, faction in enumerate(factions)}
    rest = sorted((f for f in factions if f != ending.winner), key=lambda f: (-standing.get(f, 0), order[f]))
    return [ending.winner, *rest]
```

```python
def build(
    state: GameState, content: Content, ending: Ending, early: bool, contributions: dict[str, list[TopRow]],
) -> SeasonMemory:
    """收季那一刻（world.end_season，第一季）的世界記憶。contributions 是各陣營出過力的每一個人
    （leaderboard.faction_contributions，照貢獻排）；沒有資料庫可查的純函式呼叫是空的，那就沒有出力的統計、也就沒有陣營獎勵。
    最終戰況讀 end_season 先存好的 final_trends。世界記憶句是結局的 memory，再接 figure_memory 裡狀態對得上的人物。"""
    w = state.world
    standing = stances(state, content)
    notes = [ending.memory] if ending.memory else []
    for fid, lines in content.scenario.figure_memory.items():
        figure = w.figures.get(fid)
        if figure is not None and figure.status in lines:
            notes.append(lines[figure.status])
    return SeasonMemory(
        scenario=content.scenario.id, scenario_name=content.scenario.name, ending=ending.id, ending_title=ending.title,
        early=early, winner=ending.winner, placing=placing(ending, standing, [f.id for f in content.scenario.factions]),
        stances=standing, trends=dict(w.final_trends),
        figures={fid: FigureFate(status=f.status, prestige=f.prestige, front=f.front) for fid, f in w.figures.items()},
        events={eid: r.key for eid, r in w.timeline.items()},
        rewriters={eid: r.locked_by for eid, r in w.timeline.items() if r.locked_by},
        notes=notes,
        tallies={f: FactionTally(total=sum(r.contrib for r in rows), people=len(rows)) for f, rows in contributions.items()},
        top={f: rows[:TOP_CONTRIB] for f, rows in contributions.items()},
    )
```

```python
def faction_contributions(
    content: Content, world: WorldStateStore, characters: CharacterStore | None = None,
) -> dict[str, list[TopRow]]:
    """各陣營這一季出過力的每一個人（世界記憶、稱號、陣營獎勵用；計畫 結局與跨季）：這一季的角色、有陣營、貢獻大於 0，
    照貢獻排（同分照存檔順序）。名字寫名號：排行與江湖史一律具名（企劃者 2026-10-06：只有地方傳聞的單一事件可以匿名）；
    真人與假人一樣列、看不出來。劇本的每個陣營都有一格，沒人出力是空的。"""
    season_number = world.get_season_number()
    rows: dict[str, list[TopRow]] = {f.id: [] for f in content.scenario.factions}
    for state in (characters or open_characters()).all():
        p = state.player
        if p.season_number != season_number or p.faction not in rows or p.contrib <= 0:
            continue
        rows[p.faction].append(TopRow(name=p.name, contrib=p.contrib))
    for people in rows.values():
        people.sort(key=lambda row: row.contrib, reverse=True)
    return rows
```

```python
def _by_foreshadow(state: GameState, content: Content, title: TitleDef, contributions: dict[str, list[TopRow]]) -> list[str]:
    """這件大事被 side 這一方的人鎖定、結算成他那一方的具名版本（時間軸記著 locked_by）：改寫史書的就是他。"""
    w = state.world
    result = w.timeline.get(title.event or "")
    lock = w.locks.get(title.event or "")
    if result is None or not result.locked_by or lock is None or lock.side != title.side:
        return []

def award(state: GameState, content: Content, contributions: dict[str, list[TopRow]]) -> list[TitleGrant]:
    """收季時頒的稱號（world.end_season，第一季）：季中已經頒的（WorldState.title_grants）在前，再照目錄的順序頒收季時才算的
    那幾種；同一個人同一個稱號只算一次。"""
    grants = list(state.world.title_grants)
    for title in content.titles.values():
        awarder = AWARDERS.get(title.source)
        if awarder is None:
            continue
        for name in awarder(state, content, title, contributions):
            if any(g.title == title.id and g.name == name for g in grants):
                continue
            grants.append(TitleGrant(title=title.id, name=name, text=title.name))
    return grants

    title = content.titles.get(title_id)
    w = state.world
    if title is None or not season_one(content, w) or any(g.title == title_id and g.name == name for g in w.title_grants):
        return False
    w.title_grants.append(TitleGrant(title=title.id, name=name, text=title.name))
    return True
```

```python
"""陣營獎勵與起手資源（第一季設計 13.2、第十四節；計畫 2026-10-06-結局與跨季）：上一季的名次與自己的貢獻，換成下一季開局的
銀兩、心得。只看上一季的世界記憶（SeasonMemory）、不疊加、有上限；散人、沒出力、結局沒有勝方都是空的。純函式，數字全在 Config。"""
from __future__ import annotations

from .models import Content
from .state import SeasonMemory

PLACES = ("第一", "第二", "第三")
EPS = 1e-9  # 無條件捨去前的浮點誤差（0.3 × 40 這種算出 11.999… 的時候）


def season_reward(content: Content, memory: SeasonMemory | None, faction: str | None, contrib: int) -> dict[str, int]:
    """這個人該拿的起手資源：{屬性鍵: 數量}，只列大於 0 的。陣營額度＝每人基準 × 出過力的人數 × 名次比例，個人份額＝額度 ×
    自己的貢獻 ÷ 陣營總貢獻（比總和還大時算整份），每一項夾在上限、無條件捨去。"""
    if memory is None or faction is None or contrib <= 0 or faction not in memory.placing:
        return {}
    cfg = content.config
    place = memory.placing.index(faction)
    tally = memory.tallies.get(faction)
    if place >= len(cfg.season_reward_place) or tally is None or tally.people <= 0:
        return {}
    share = contrib / max(tally.total, contrib)
    reward: dict[str, int] = {}
    for key, base in cfg.season_reward_base.items():
        amount = int(base * cfg.season_reward_place[place] * tally.people * share + EPS)
        amount = min(amount, cfg.season_reward_cap.get(key, amount))
        if amount > 0:
            reward[key] = amount
    return reward


def place_text(place: int) -> str:
    """名次的說法（place 從 0 起算）：第一、第二、第三，再後面寫「第 4」。"""
    return PLACES[place] if place < len(PLACES) else f"第 {place + 1}"


def faction_name(content: Content, faction: str) -> str:
    return next((f.name for f in content.scenario.factions if f.id == faction), faction)


def reward_line(content: Content, memory: SeasonMemory, faction: str, contrib: int) -> str:
    """下一季開局「上一季」那一則的一句（有獎勵時才寫）：陣營的名次與自己出的力，後面接「銀兩 +N」這種數值變化。"""
    name = faction_name(content, faction)
    return f"上一季{name}名列{place_text(memory.placing.index(faction))}，你替{name}出了 {contrib} 點力，論功行賞："
```

```python
                continue
```

```python
def recap_lines(memory: SeasonMemory, number: int) -> list[str]:
    """下一季開局「上一季」那一則的前情（Game._carry_last_season）：第幾季、哪個劇本、以哪個結局落幕，再接留給下一季的

    return [f"上一季（第 {number} 季・{memory.scenario_name}）以「{memory.ending_title}」落幕。", *memory.notes]


def carry_flags(memory: SeasonMemory) -> set[str]:
    """下一季開季時種下的世界旗標（world_state.fresh_season），給第二季的劇本寫條件（Condition.world_flags_all／
    world_flags_none），不必另寫程式：
    - prev:ending:<結局 id>、prev:winner:<勝方陣營>；
    - prev:<人物 id>:<狀態>：收季時不在場的大勢人物（active 以外：退場 retired、重創 crippled、下獄 jailed、還沒出場 away）；
    - prev:locked:<大事 id>：被鎖定改寫的時刻表大事；
    - prev:seal:<陣營>：季末玉璽碎片的持有者（計畫 2 寫 seal_holder 之後才有）。"""
    flags = {f"prev:ending:{memory.ending}"}

        flags.add(f"prev:winner:{memory.winner}")
    flags |= {f"prev:{fid}:{fate.status}" for fid, fate in memory.figures.items() if fate.status != "active"}
    flags |= {f"prev:locked:{eid}" for eid in memory.rewriters}
    if memory.seal_holder is not None:
        flags.add(f"prev:seal:{memory.seal_holder}")
    return flags
```

```python
    """休季結算卡上「你的這一季」那一句（Game.season_result）：散人、沒出力、結局沒有名次各一句；有名次的寫名次與出的力，
```
