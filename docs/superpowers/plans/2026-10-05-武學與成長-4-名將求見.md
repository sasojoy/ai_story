# 武學與成長（四）名將求見 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 名將所在的地點，求見的按鈕一直都在、按得下去；門檻以名望為主，投靠了那位名將陣營的人每升一階抵 5 點；門檻不夠就被一句他自己口吻的話打發，附上還差多少——不叫模型、不花體力、不加情誼。

**Architecture:** 門檻的算法收在 `rules.can_meet` 旁邊的 `rules.audience_bar`（引擎、伏筆都已經只認 `can_meet`）；打發的話是人物的內容欄位 `CharacterDef.brush_off`，沒寫就用一句通用的。選單的改動在 `engine.py`：一位名將的地點直接放「求見某某」，兩位以上照舊用求見選單，但名單裡每一位都按得下去。

**Tech Stack:** Python 3、pydantic、pytest。

**Spec:** `docs/superpowers/specs/2026-10-05-武學與成長-design.md`（第九節）。

**執行方式：** 企劃者 2026-10-05 選定**子代理逐步做**（superpowers:subagent-driven-development：每個 Task 一個新的子代理實作、另一個子代理審過才做下一個，最後整條分支再審一次）。開工時間由 PM 排在第一季濃縮版週末測試之後。

**前提：** 濃縮版 T4（大勢人物，`content/figures.json`、`FigureDef.character`、`FigureDef.faction`、`figures.of_character`）與 T5（晉升，`PlayerState.rank`）已經併進 `main`。開工前確認：

## Global Constraints

- 同計畫一的 Global Constraints。
- 打發不叫模型、不花體力、不加情誼（設計 9.1）。
- 照舊的不動：結識事件認識過的人不受門檻限制（`結識:<id>` 旗標）；每位名將每天最多聊 3 輪；剛被你打敗、閉門不見（T4 的 `SNUB_NOTE`）照舊按不下去。
- 預設數字：`audience_rank_discount = 5`。
- **整季機器人的陷阱**（CLAUDE.md「踩過的坑」）：多了永遠按得下去的選項，`bot.py` 的「沒有任何 enabled 選項就推進時間」訊號會失效。所以會被打發的求見，機器人與假人都要排除。

## Review Focus

1. **整季模擬跑不完**：會被打發的求見永遠按得下去，機器人隨機挑到就一直白按——測試在 Task 1（`pick` 不挑會被打發的求見），全套的 `test_real_content` 也要照常結束。
2. **門檻夠了的人不能變成被打發**：抵了階級之後剛好到門檻的人要見得到（等於也算夠）——測試在 Task 1。
3. **散人與敵對陣營**：散人只看名望；敵對陣營的階級不抵（設計 9.1）——測試在 Task 1。
4. **被打發時不能先扣體力再退**：現在的 `_call` 一進來就扣交友的體力，打發的路要在扣之前就走掉——測試在 Task 1。
5. **被打發不該叫模型**：伺服器對 `call:<人物>` 會先走對話的鎖外備料；被打發時備料要回 None——測試在 Task 1。

```python
def audience_bar(state: GameState, content: Content, companion_id: str) -> int:
    """這位人物此刻對你的求見門檻（武學與成長設計 9.1）：名望門檻，投靠了他的陣營的人每升一階抵 audience_rank_discount；
    散人與敵對陣營只看名望。最低 0。"""
    bar = content.characters[companion_id].audience_fame
    figure = next((f for f in content.figures.values() if f.character == companion_id), None)
    p = state.player
    if figure is not None and p.faction is not None and p.faction == figure.faction:
        bar -= p.rank * content.config.audience_rank_discount
    return max(0, bar)


def can_meet(state: GameState, content: Content, companion_id: str) -> bool:
    """（說明照原本的寫，「名望到了他的求見門檻」改成「名望到了 audience_bar」。）"""
    p = state.player
    return f"結識:{companion_id}" in p.flags or p.stats.get("fame", 0) >= audience_bar(state, content, companion_id)
```

```python
    def _brush_off(self, companion_id: str) -> list[str]:
        """門檻不夠時被打發（武學與成長設計 9.1）：他自己口吻的一句（內容沒寫就用通用的），附上還差多少。
        不叫模型、不花體力、不加情誼。"""
        s, c = self.state, self.content
        ch = c.characters[companion_id]
        line = self.rng.choice(ch.brush_off) if ch.brush_off else f"{ch.name}連見都不見你，門口的人把你請了出去。"
        short = audience_bar(s, c, companion_id) - s.player.stats.get("fame", 0)
        figure = next((f for f in c.figures.values() if f.character == companion_id), None)
        hint = f"名望還差 {short}"
        if figure is not None and s.player.faction == figure.faction:
            faction = next((f.name for f in c.scenario.factions if f.id == figure.faction), figure.faction)
            hint += f"，或在{faction}再升一階"
        return [f"{line}（{hint}）"]
```

`_call`：先判斷，打發的路在扣體力之前走掉：

```python
    def _call(self, arg: str, prepared: companion_agent.PreparedTurn | None = None) -> list[str]:
        """（說明照原本的寫，加一句：門檻不夠就被打發，不花體力、不叫模型，見 _brush_off。）"""
        self.state.player.picking_audience = False
        if arg == "back":
            return ["你收回名帖，暫且不求見了。"]
        if not self._can_meet(arg):
            return self._brush_off(arg)
        self.state.player.stamina -= self.content.config.action_cost["socialize"]
        return self._open_dialogue(arg, prepared)
```

`_action_title` 的 `call` 那一支不用改（標題照舊是「求見・某某」）。
