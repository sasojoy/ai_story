# 線上架構第 2 期：LLM 佇列 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 所有在行動鎖外叫模型的地方，先在同一個佇列排隊。規則如下：
- 顯卡同時只處理幾件；
- 真人先、假人後，假人有上限；
- 每個人同時最多一件；
- 排太久就直接用退路，不叫模型；
- 玩家等的時候看得到前面還有幾件。

**Architecture:**
- 新的 `llm_queue.py`（專案根目錄，伺服器那一層，不在 `tianxia/`）提供 `LlmQueue.run(owner, job, fallback=…, bot=…, wait=…)`：排隊、輪到了執行 `job()`、回傳結果。
- `server.py` 的五個鎖外呼叫點（對話、大場面判讀、開爐取名、隨口應對的評分與潤色）一律改走 `model_call(game, job, fallback=…)`：佇列開著就排隊，關著就照舊直接叫。
- 開爐與大場面的預算，扣掉排隊等掉的時間再傳給模型，所以整段最多還是 60 秒。
- 前端在這幾個請求等待時，每 2 秒問一次 `/api/queue`，在按鈕上加「前面還有 N 件」。

**Tech Stack:** Python 3 `threading`、FastAPI（既有）、原生 JS（既有 `web/app.js`），pytest。

**Spec:** `docs/superpowers/specs/2026-10-02-線上架構-design.md` 5.2「LLM 工作（都在主迴圈外面）」：
- 用戶清單；

- 「佇列只接手鎖外生成那一段」；

## Global Constraints

- **`llm_queue.py` 放在專案根目錄**，不在 `tianxia/`：它要用執行緒與時鐘，引擎不讀時鐘（CLAUDE.md）。`tianxia/` 這份計畫不動。
- **佇列只管「鎖外」的呼叫**，也就是三段式的 B 段。
  - 排隊與等模型時都**不握行動鎖**。
  - 鎖內的小呼叫照現在的 `in_lock_model_timeout`（15 秒）與全服斷路器，不進佇列。包括 `Game._quick_client` 的那些：決戰回合潤色、決戰自訂行動的評分、重遊點綴句。
- **退路與現在一字不差**：
  - 對話是 `PreparedTurn(..., turn=None)`，那一輪取消、不扣體力；
  - 大場面是 `None`，照樣打、優勢 0；
  - 開爐取名是 `NO_NAME`，走退路字表；
  - 隨口應對評分是 `event_llm.DEFAULT_FREE_TEXT_SUCCESS_RATE`（40）；
  - 潤色是 `None`，不插句子。
- **時間預算**：
  - 開爐（`naming_budget_seconds`）與大場面（`big_fight_budget_seconds`）的預算，從 A 段開始算，扣掉等鎖與排隊的時間才交給模型；
  - 量時間用 `server._monotonic`，測試才撥得動。
- **每個人同時最多一件**：鍵是角色名號的 casefold。同一個人第二件直接拿退路，不排隊。
- **假人**：
  - 假人的對話與放手一搏照舊不用模型（`bot_runner` 把 `game.client` 設成 `None`）；
  - 假人取名（武學計畫，週末後）在佇列裡走 `bot=True`，受 `llm_queue_bot_cap` 限制；
  - **`run_bots.py` 是另一支程式，用不到伺服器這個佇列**。假人移進伺服器程式之前，它照 PM 10/5 的暫時做法（一次最多一件、有一件在等時跳過首次融合），佇列不替它排；
  - 假人不能被看出來：佇列的位置、管理者看的數字，都只給總數，不列名號。
- **開關預設關**：
  - `Config.llm_queue_slots: int = 0`（0＝不建佇列）；
  - `llm_queue_bot_cap: int = 1`；
  - `llm_queue_wait_seconds: float = 20`。
- 前端：原生 JS，沒有建置步驟、不加外部函式庫；`node --check web/app.js` 要過。

## Review Focus

1. **同一個玩家連按兩下、或兩個分頁同時送**：第二件拿退路，不能卡在第一件後面排兩次隊，也不能叫兩次模型。Task 1、Task 2 各一條測試。
2. **模型很慢、佇列排滿**：排超過 `llm_queue_wait_seconds` 的直接拿退路，請求在時限內回來；佇列裡的位置要讓出來，不能卡死後面的人。Task 1 一條測試。
3. **job 丟例外**（模型回傳格式壞掉而呼叫端沒接住）：位置一定讓出來，例外照樣往外丟。由伺服器既有的錯誤處理回應，不讓佇列卡住。Task 1 一條測試。
4. **開爐、大場面排隊等了很久才輪到**：交給模型的預算要扣掉排隊的時間，整段不能超過 60 秒。Task 2 一條測試。
5. **開關關著**：五個呼叫點照現在的方式直接叫模型，`/api/queue` 回 `{"ahead": null}`，前端什麼都不多顯示。Task 2、Task 3 各一條測試。

"""LLM 佇列（線上架構設計 5.2）：真人先、假人有上限、一人一件、排太久拿退路、看得到前面幾件。"""
import threading
import time

import pytest

import llm_queue


def _hold(queue, owner, *, bot=False, wait=5.0):
    """讓 owner 的一件在佇列裡跑著不放，直到 release.set()；回傳 (started, release, thread, result)。"""
    started, release, result = threading.Event(), threading.Event(), {}

    def job():
        started.set()
        release.wait(5)
        return f"{owner} 的結果"

    def go():
        result["value"] = queue.run(owner, job, fallback="退路", bot=bot, wait=wait)

    thread = threading.Thread(target=go)
    thread.start()
    return started, release, thread, result


def _wait_until(predicate, seconds=2.0):
    end = time.monotonic() + seconds
    while time.monotonic() < end:
        if predicate():
            return True
        time.sleep(0.005)
    return False


def test_runs_the_job_and_returns_its_result():
    queue = llm_queue.LlmQueue(slots=1, bot_cap=1)
    assert queue.run("甲", lambda: 7, fallback=0) == 7
    assert queue.snapshot() == {"running": 0, "waiting": 0, "bots_waiting": 0}


def test_humans_go_before_bots_that_queued_earlier():
    queue = llm_queue.LlmQueue(slots=1, bot_cap=2)
    started, release, holder, _ = _hold(queue, "佔著的人")
    assert started.wait(2)
    order = []
    bot = threading.Thread(target=lambda: queue.run("假人甲", lambda: order.append("假人"), fallback=None, bot=True))
    bot.start()
    assert _wait_until(lambda: queue.snapshot()["bots_waiting"] == 1)
    human = threading.Thread(target=lambda: queue.run("真人乙", lambda: order.append("真人"), fallback=None))
    human.start()
    assert _wait_until(lambda: queue.snapshot()["waiting"] == 1)
    assert queue.position("真人乙") == 1 and queue.position("假人甲") == 2
    release.set()
    for t in (holder, bot, human):
        t.join(2)
    assert order == ["真人", "假人"]


def test_one_job_per_person_the_second_gets_the_fallback():
    """同一個人連按兩下、開兩個分頁：第二件直接拿退路，不叫模型（Review Focus 1）。"""
    queue = llm_queue.LlmQueue(slots=2, bot_cap=1)
    started, release, holder, _ = _hold(queue, "甲")
    assert started.wait(2)
    called = []
    assert queue.run("甲", lambda: called.append(1), fallback="退路") == "退路"
    assert called == []
    release.set()
    holder.join(2)


def test_bot_cap_full_means_fallback():

    started, release, holder, _ = _hold(queue, "假人甲", bot=True)
    assert started.wait(2)
    assert queue.run("假人乙", lambda: "叫了", fallback="退路", bot=True) == "退路"
    release.set()
    holder.join(2)


def test_waiting_too_long_gives_the_fallback_without_calling():
    """排超過 wait 秒：拿退路、不叫模型，位置讓出來（Review Focus 2）。"""

    started, release, holder, result = _hold(queue, "甲")
    assert started.wait(2)
    assert queue.position("甲") == 0

    holder.join(2)
    assert result["value"] == "甲 的結果" and queue.position("甲") is None

```python
"""LLM 佇列（線上架構設計 5.2，第 2 期）：行動鎖外叫模型之前先在這裡排隊。

顯卡同時只處理 slots 件。排隊的規則：
- 真人先、假人後，同一種照先來後到；
- 每個人（名號）同時最多一件在排或在跑，第二件直接拿退路的結果；
- 假人在排加在跑最多 bot_cap 件，滿了也直接拿退路；
- 排超過 wait 秒還沒輪到，就拿退路、不叫模型。
輪到了才執行 job()，執行時不握任何鎖（呼叫端在行動鎖外叫這裡）。

只管「什麼時候輪到誰」，不管模型本身：job 裡面自己的逾時、重問、失敗退路照舊（例如 naming.generate 的預算）。
放在專案根目錄、不在 tianxia/：它要用執行緒與時鐘，引擎不讀時鐘（CLAUDE.md）。"""
from __future__ import annotations

import itertools
import threading
import time
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import TypeVar

T = TypeVar("T")

HUMAN, BOT = 0, 1  # 排序的第一個鍵：真人先


@dataclass(order=True)
class _Ticket:
    rank: tuple[int, int]  # （真人 0／假人 1, 掛號順序）
    owner: str = field(compare=False)
    bot: bool = field(compare=False)


class LlmQueue:
    def __init__(self, slots: int, bot_cap: int, clock: Callable[[], float] = time.monotonic):
        if slots < 1:
            raise ValueError("slots 至少要 1")
        self.slots = slots
        self.bot_cap = bot_cap
        self._clock = clock
        self._cond = threading.Condition()
        self._waiting: list[_Ticket] = []
        self._active: list[_Ticket] = []
        self._seq = itertools.count()

    def run(self, owner: str, job: Callable[[], T], *, fallback: T, bot: bool = False, wait: float = 30.0) -> T:
        """排隊、輪到了執行 job() 並回傳它的結果。以下三種情況回傳 fallback、不執行 job：
        同一個人已經有一件、假人滿了、排超過 wait 秒。job 丟出的例外照樣往外丟，位置一定會讓出來。"""
        with self._cond:
            mine = self._waiting + self._active
            if any(t.owner == owner for t in mine):
                return fallback
            if bot and sum(t.bot for t in mine) >= self.bot_cap:
                return fallback
            ticket = _Ticket((BOT if bot else HUMAN, next(self._seq)), owner, bot)
            self._waiting.append(ticket)
            deadline = self._clock() + wait
            while not self._turn_of(ticket):
                left = deadline - self._clock()
                if left <= 0:
                    self._waiting.remove(ticket)
                    self._cond.notify_all()
                    return fallback
                self._cond.wait(left)
            self._waiting.remove(ticket)
            self._active.append(ticket)
        try:
            return job()
        finally:
            with self._cond:
                self._active.remove(ticket)
                self._cond.notify_all()

    def _turn_of(self, ticket: _Ticket) -> bool:
        return len(self._active) < self.slots and min(self._waiting) is ticket

    def position(self, owner: str) -> int | None:
        """這個人的那一件前面還有幾件（正在跑的也算）；正在跑是 0；沒有在排也沒在跑是 None。"""
        with self._cond:
            if any(t.owner == owner for t in self._active):
                return 0
            for i, t in enumerate(sorted(self._waiting)):
                if t.owner == owner:
                    return len(self._active) + i
            return None

    def snapshot(self) -> dict[str, int]:
        """管理者看的總數：正在跑幾件、真人在排幾件、假人在排幾件（不列名號）。"""
        with self._cond:
            return {
                "running": len(self._active),
                "waiting": sum(not t.bot for t in self._waiting),
                "bots_waiting": sum(t.bot for t in self._waiting),
            }
```
