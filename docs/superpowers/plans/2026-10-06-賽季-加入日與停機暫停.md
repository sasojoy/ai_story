# 賽季：新手福利從加入日起算、公告停機時鐘暫停 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兩件賽季生命週期的事：①新手福利（前 3 天氣血回復加倍、新立門戶福緣）從每個角色自己加入這一季的那一刻起算；②管理者（或主機端腳本）可以讓賽季時鐘暫停——停機維護那段時間不算進賽季、決戰不推、玩家不能行動、假人不出手，繼續之後季末與排好的決戰跟著往後延，打到一半的決戰剩下的時間不變。

**Architecture:**
- 加入時間是 `PlayerState.joined_at`（世界秒）：新角色與換季重來的角色先是 `None`，第一次 `sync`（補算完賽季之後）或 `advance` 才蓋；舊存檔讀成 `0.0`（從季初算，跟現在一樣）。`roster.since_join` 把「加入以來」換成季曆秒，`newbie`／`fortune_due`／`fortune_overdue` 照它算——只在 `rules.season_one` 成立時，beta 那一季照舊從季初、用世界天。
- 暫停是 `SharedWorldState.paused_at`（存在 `world` 表那一列的 JSON，不改資料表）。兩個關口：補算看 `catch_up_season`（暫停中不推、對時點不動），決戰看 `Game._battle_status(tick=True)`（暫停中只讀）。玩家的同步、`options()` 的 tick、Infra 排程計畫的 `Game.world_tick` 都只走這兩個關口，所以誰先合進 main 都不用改別人。繼續（`resume_clock`）把對時點與決戰的現實期限往後挪停的長度。
- 擋動作分兩層：引擎的 `options()` 暫停中只給一顆灰的（`choose()` 自己就按不下去，假人、整季機器人也一樣）；伺服器在拿到行動鎖、同步之後擋不走選單的動作（`act` 與鎖外三段的 A 段）。管理者動作暫停中只按得到「繼續」。

**Tech Stack:** Python 3、pydantic、FastAPI（既有）、SQLite（既有）、pytest；原生 JavaScript（`web/app.js`，沒有建置步驟）。

## Global Constraints

- `tianxia/` 不 import 任何網頁框架；**引擎不讀電腦時鐘**：暫停、繼續的現實時間由 `server.py`（`time.time()`）或主機端腳本的 `main()` 傳進來（`admin_pause_clock(now)`、`pause_clock(now)`）；測試一律給固定的數字。
- **資料庫是唯一的真實來源**：暫停記在 `world` 表那一列（`SharedWorldState.paused_at`），伺服器重開、假人程式、主機端腳本看的都是同一個欄位；不改資料表、不升 `SCHEMA_VERSION`。
- **新欄位都有預設值**，舊存檔、舊資料庫直接讀得進來：`PlayerState.joined_at` 預設 `0.0`（新角色才明寫 `None`），`SharedWorldState.paused_at` 預設 `None`。
- **第一季開關**：加入時間的讀法（Task 1）只在 `rules.season_one(content, world)` 成立時改；開關關著、或這一季沒蓋「開」的章，新手福利照舊從季初算（`test_with_the_switch_off_the_perks_still_follow_the_season_clock`）。暫停不看開關（待確認 B8），但沒人按就什麼都不變：Task 3 的管理者測試就是在開關關著的測試內容上跑的。
- **補算時間只算一次、只往前**：暫停中 `catch_up_season` 連對時點都不碰；繼續時對時點往後挪停的長度，不是設成「現在」（主機端腳本沒先補算就暫停時，暫停前那一小段照算）。
- **`mutate` 不能巢狀**：`pause_clock`／`resume_clock` 各自是一次 `mutate`，決戰期限在同一個 `mutate` 裡改（`shift_deadlines` 只改傳進來的物件，不碰存取介面）。
- **伺服器假人跟真人看不出差別**：暫停對每個角色一樣；假人程式暫停中整輪跳過，主控台照舊只印數字。
- **擋動作在鎖裡**：伺服器在拿到行動鎖、同步之後才看 `paused_at()`，丟 `GameError` 時整筆交易撤回；鎖外三段（對話、大場面、開爐、隨口應對）在 A 段就擋，模型一次都不叫。
- 畫面文字只用繁體中文；行動名稱照 CLAUDE.md（遊歷、交友）。不碰 `content/`（這份沒有新內容）、不碰 `saves/`、`.local/`。

## Review Focus

最可能害到玩家、而一般單元測試不會碰到的五件事；每一條的測試已經寫進負責那段程式的任務：

1. **伺服器停機期間整個關掉再開**：記憶體裡什麼都沒有，暫停要還在（重開資料庫讀得到），開回來第一個同步不能把停機那段補進去；主機端腳本沒先補算就暫停，暫停前那一小段也不能少（Task 2 `test_the_pause_survives_a_restart`、`test_a_paused_season_clock_does_not_move_and_resume_skips_the_paused_span`、`test_resume_still_counts_the_bit_before_the_pause_that_nobody_caught_up`）。
2. **決戰打到一半暫停**：暫停中每次刷新（`options()` 的 tick）都不逾時、不代選、不結算；繼續之後這一回合剩下的時間跟暫停前一樣；集結中暫停，畫面上的倒數停住（Task 3 `test_a_running_showdown_round_waits_out_the_pause_and_keeps_its_remaining_time`、`test_the_muster_countdown_stands_still_while_paused`；資料層 Task 2 `test_resume_shifts_the_muster_deadline_and_the_open_round`）。
3. **暫停跨過時刻表大事與排定的決戰**：照原本的時鐘早就該開打、該結算的，暫停中一件都不發生；繼續之後照排定的季時間開、每件只一次（Task 3 `test_a_pause_across_a_showdown_and_a_timetable_event_fires_nothing_until_resume_then_each_once`）。

def since_join(state: GameState, content: Content) -> float | None:
    """第一季（rules.season_one）：自己加入這一季以來過了多少季曆秒。世界裡的天數看季曆（PM 2026-10-06），所以跟著

    不是第一季回 None：新手福利照舊從季初起算、用世界的天數，beta 一點都不變。"""
    w = state.world
    if not rules.season_one(content, w):

    joined = state.player.joined_at
    elapsed = 0.0 if joined is None else max(0.0, w.time - joined)

    # ── 賽季時鐘暫停 ──────────────────────────────────────

    def paused_at(self) -> float | None:
        with self.db.snapshot() as conn:
            row = conn.execute("SELECT json_extract(data, '$.paused_at') AS at FROM world WHERE id = 1").fetchone()
        return None if row is None or row["at"] is None else float(row["at"])

    def pause_clock(self, now: float) -> bool:
        result = {"ok": False}

        def _apply(state: SharedWorldState) -> None:
            if state.paused_at is not None or state.season_phase() != "running":
                return
            state.paused_at = now
            result["ok"] = True

        self.mutate(_apply)
        return result["ok"]

    def resume_clock(self, now: float) -> float | None:
        result: dict[str, float | None] = {"span": None}

        def _apply(state: SharedWorldState) -> None:
            if state.paused_at is None:
                return
            span = max(0.0, now - state.paused_at)
            state.paused_at = None
            if state.season_last_real is not None:
                state.season_last_real += span
            if state.active_battle is not None:
                shift_deadlines(state.active_battle, span)
            result["span"] = span

        self.mutate(_apply)
        return result["span"]

"""主機端：讓賽季時鐘暫停或繼續（線上架構設計第四節、8.3「公告停機時賽季時鐘暫停，季末跟著往後延」）。

「暫停賽季時鐘」「繼續」是同一件事（WorldStateStore.pause_clock／resume_clock），不用登入；伺服器開著也可以跑
（拿同一把行動鎖，一筆交易做完）。
執行：.venv/Scripts/python.exe scripts/season_clock.py pause|resume|status [--db <資料庫檔>]
"""
from __future__ import annotations

import argparse
import sys
import time
from collections.abc import Callable
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))

from tianxia.database import default_path  # noqa: E402
from tianxia.sqlite_world import open_world  # noqa: E402

PHASES = {"preparing": "籌備中", "running": "進行中", "resting": "休季"}


def main(argv: list[str] | None = None, clock: Callable[[], float] = time.time) -> int:
    parser = argparse.ArgumentParser(description="讓賽季時鐘暫停或繼續（停機維護用）")
    parser.add_argument("action", choices=("pause", "resume", "status"), help="pause 暫停、resume 繼續、status 看現在的狀態")
    parser.add_argument("--db", default=None, help="資料庫檔（預設：環境變數 TIANXIA_DB，沒設就是 saves/tianxia.db）")
    args = parser.parse_args(argv)
    path = Path(args.db) if args.db else default_path()
    print(f"資料庫：{path.resolve()}")
    if not path.exists():  # 打錯路徑時不要憑空開一個新的資料庫
        print("找不到這個資料庫檔。")
        return 1
    world = open_world(path)
    now = clock()
    with world.action_lock():
        phase, at = world.season_phase(), world.paused_at()
        if args.action == "pause":
            if at is not None:
                print(f"賽季時鐘已經停著了（停了 {int((now - at) // 60)} 分鐘）。")
                return 0
            if not world.pause_clock(now):
                print(f"現在是{PHASES[phase]}，沒有時鐘可以停。")
                return 1
            print("賽季時鐘停了：季的時間不走、決戰不推，玩家暫時不能行動。開回來之後跑：season_clock.py resume")
            return 0
        if args.action == "resume":
            span = world.resume_clock(now)
            if span is None:
                print("賽季時鐘沒有暫停。")
                return 0
            print(f"賽季時鐘接著走了（停了 {int(span // 60)} 分鐘）；排好的決戰與季末都往後挪了一樣長。")
            return 0
        clock_text = "在走" if at is None else f"停了 {int((now - at) // 60)} 分鐘"
        print(f"賽季：{PHASES[phase]}；時鐘：{clock_text}。")
        return 0


if __name__ == "__main__":
    sys.exit(main())

def _pause_step(world, now: float, pause: tuple[float, float], frozen: list[float], log: dict) -> None:
    """到了就暫停（一季只停一次）、停滿就繼續；繼續的那一刻（還沒有人同步之前）記下停的這一段季走了多少——應該是 0。"""
    start, end = START + pause[0] * 3600, START + (pause[0] + pause[1]) * 3600
    if not frozen and start <= now < end and world.pause_clock(now):
        frozen.append(world.get_season().time)
