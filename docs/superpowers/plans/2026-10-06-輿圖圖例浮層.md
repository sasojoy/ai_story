**Goal:** 輿圖的圖例（六種地點圖示、視野狀態怎麼畫、外圈與這一層的說明、局勢層的打擊記號那一行）不再畫在 SVG 裡面跟著地圖平移、縮放，改成伺服器把它當資料跟 SVG 並排給網頁，網頁在地圖框左下角疊一層半透明、可收合、不跟著地圖動的 HTML 圖例。

## Global Constraints

- `tianxia/` 是純規則引擎，不得 import 任何網頁框架；引擎不讀電腦時鐘；資料庫是唯一的真實來源；伺服器假人跟真人看不出差別（CLAUDE.md「架構」「原則」）。這份計畫只動畫面與畫面要的資料，不碰任何狀態、存檔、資料表（不升 `SCHEMA_VERSION`）、行動或規則。
- **不放在 `rules.season_one` 後面**：圖例是兩種賽季（beta 與第一季）都看得到的畫面，沒有「開關關著要跟以前一模一樣」的行為可言；內容（`LEGEND_*` 的每一個字）一字不改，所以舊畫面與新畫面的文字完全相同，只是位置換了。
- **圖例內容的來源只有 `mapview.py` 的 `LEGEND_*` 常數**：網頁不寫死任何一個圖例的字，伺服器怎麼給就怎麼畫；局勢層的打擊記號那一行跟 `render_map` 標 `◎` 是同一個條件（`atlas.strike_marks`），所以沒標的人看不到那一行、也不會洩漏沒摸清的地點（那一行只講「本週軍令要打擊的人物」，沒有地名）。
- **小地圖沒有圖例，照舊**（`render_minimap` 不動）。大地圖以外的畫面不動。
- 網頁的原始 HTML 規矩：圖例的文字欄位一律 `esc()`；唯一原樣放進頁面的是 `icons[].svg`，那是 `mapart.icon_svg()` 用常數畫出來的圖，不含任何玩家輸入。
- 網頁沒有建置步驟、不靠外部函式庫；畫面文字只用繁體中文；觸控目標至少 44px；顏色用地圖的固定紙色（地圖本身不跟深色主題走，圖例也不跟）。

- 本計畫不動季曆、換季、戰線、結算，所以 PM 要求的「weekend 設定的假人整季模擬」與「全新資料庫開季」兩項驗收**不適用**；改成最後一節的瀏覽器驗收。

## 這份計畫先定的

1. **資料長相**（`legend_data` 回的 dict，全是字串，直接是 JSON）：`icons`（六個 `{kind, label, svg}`，順序照 `LEGEND_ICONS`）、`states`（視野狀態那一句）、`ring`（外圈那一句）、`layer`（這一層的說明；認不得的圖層是空字串）、`strike`（局勢層有打擊記號時那一句，否則空字串）。原本「外圈」與「圖層說明」在 SVG 裡是同一行，現在拆成兩個欄位，網頁各自成一行。
2. **圖示的畫法**：全彩（`look="full"`）、不加圓盤與外圈，畫在 24×20 的畫布裡（`ICON_BOX`），尺寸就是地圖放大到原尺寸時的圖示大小（原本在 SVG 裡縮成七成，現在不縮）。`ICON_BOX` 的大小由測試量過：六個圖示的實際範圍都在畫布裡。
3. **圖例層的位置**：放在 `.map-wrap` 裡面、`.map-ctl` 後面，`position: absolute`，所以不在被 `transform` 的那張 SVG 裡，平移縮放都帶不走它；外層 `pointer-events: none`，只有收合鈕與說明那一塊收滑鼠與觸控，框裡沒字的地方照常拖地圖、點地點。收合鈕在最下面、說明疊在它上面（`flex-direction: column-reverse`），展開、收合時鈕不跳位置。
4. **展開收合不重畫整頁**（原地改 `aria-expanded`、`hidden` 與 class）：重畫會把地圖框整個換掉。
5. **選擇的優先順序**：這個瀏覽器存過 `open`／`shut` 就照它；沒存過（或存不了）才依寬度（手機收合、寬螢幕展開）。每次載入網頁讀一次存起來，之後在記憶體裡。

    for d, width in re.findall(r'<path d="([^"]+)"(?: fill="[^"]*"| stroke="[^"]*" stroke-width="([\d.]+)")', markup):
        half = float(width) / 2 if width else 0.0
        x = y = 0.0
        for cmd, args in re.findall(r"([MLQVHZvhaz])([^MLQVHZvhaz]*)", d):
            nums = [float(n) for n in re.findall(r"-?\d+(?:\.\d+)?", args)]
            if cmd == "Q":  # 控制點也算進來：曲線不會超出控制點圍起來的範圍
                xs += [nums[0] - half, nums[0] + half]
                ys += [nums[1] - half, nums[1] + half]
            if cmd in "MLQ":
                x, y = nums[-2], nums[-1]
            elif cmd == "V":
                y = nums[0]
            elif cmd == "H":
                x = nums[0]
            elif cmd == "v":
                y += nums[0]
            elif cmd == "h":
                x += nums[0]
            elif cmd == "a":  # 圓弧只看終點（相對座標）
                x, y = x + nums[-2], y + nums[-1]
            xs += [x - half, x + half]
            ys += [y - half, y + half]
    return min(xs), min(ys), max(xs), max(ys)

  const LEGEND_KEY = "tx-map-legend"; // 值是 "open" 或 "shut"
  function legendChoice() {
    try {
      const v = localStorage.getItem(LEGEND_KEY);
      return v === "open" ? true : v === "shut" ? false : null;
    } catch (e) { return null; /* 讀不到就當沒選過 */ }
  }
  function legendOpen() {
    if (S.mapLegend === undefined) S.mapLegend = legendChoice();
    return S.mapLegend !== null ? S.mapLegend : !(PHONE && PHONE.matches);
  }
  // 收合鈕在最下面、說明疊在它上面（style.css 的 column-reverse）：展開收合時鈕不跳位置
  function legendHtml(lg) {
    if (!lg) return "";
    const open = legendOpen();
    return `<div class="map-legend${open ? " open" : ""}">
      <button type="button" class="legend-toggle" data-act="legend-toggle" aria-expanded="${open}" aria-controls="map-legend-body"><svg viewBox="0 0 24 24" aria-hidden="true"><path d="M6 15l6-6 6 6"/></svg>圖例</button>
      <div class="legend-body" id="map-legend-body"${open ? "" : " hidden"}>
        <ul class="legend-icons">${lg.icons.map((i) => `<li>${i.svg}<span>${esc(i.label)}</span></li>`).join("")}</ul>
        <p>${esc(lg.states)}</p>
        <p>${esc(lg.ring)}</p>
        ${lg.layer ? `<p>${esc(lg.layer)}</p>` : ""}
        ${lg.strike ? `<p>${esc(lg.strike)}</p>` : ""}
      </div>
    </div>`;
  }
  // 按圖例的鈕：原地展開／收合，不重畫整頁（重畫會把地圖框整個換掉）
  function legendToggle(btn) {
    const open = btn.getAttribute("aria-expanded") !== "true";
    S.mapLegend = open;
    try { localStorage.setItem(LEGEND_KEY, open ? "open" : "shut"); } catch (e) { /* 存不了就只在這一頁有效 */ }
    btn.setAttribute("aria-expanded", String(open));
    const box = btn.closest(".map-legend");
    box.classList.toggle("open", open);
    box.querySelector(".legend-body").hidden = !open;
  }

  // ── 輿圖的視圖（W16）：純數學，不碰 DOM ──
