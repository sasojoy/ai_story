# 決戰改版 2：作戰方針與 AI 代挑 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每回合時間到還沒出手的人不再一律固守：照自己設的作戰方針出招（穩守到底、能攻就攻、交給 AI）；交給 AI 的人照處境分組，每一邊每回合只問模型一次，在行動鎖外先挑好，叫不動照「能攻就攻」。

**Architecture:** 方針記在 `BattleParticipant.stance`（預設交給 AI），加入時與每一回合都能改（決戰選項多三顆「方針：…」）。逾時代出（`battle_instance.fill_timed_out_actions`）照方針挑招：穩守到底一律固守、能攻就攻是氣血過半出自己份量最高的招否則固守、交給 AI 讀這一回合模型替那一組挑好的招（`BattleRound.ai_picks`），沒有就照能攻就攻。模型呼叫照專案的三段做法：A 鎖內開單（`battle_ai.prepare`）→ B 鎖外問模型（`battle_ai.ask`）→ C 鎖內確認還是同一回合才寫進去（`battle_ai.store`）。伺服器在輪詢（`/api/main`）時看要不要開單，開了就交給背景執行緒做 B、C；假人程式不叫模型。

**Tech Stack:** Python 3／pydantic（`tianxia/`）、FastAPI（`server.py`）、pytest；網頁不用改（方針是決戰選項的按鈕）。

**Spec:** `docs/superpowers/specs/2026-10-03-戰鬥系統-design.md` 3.3、3.4 末段（方針跟著三招改）。

**開工條件：** 決戰改版計畫一（三招與推力）併進 main 之後；名字照計畫一（`MOVES`、`BattleTuning`、`BattleParticipant.scores`、`last_result`、`BattleInstance.last_mix`、`battle_instance.condition`、`option_of`、`resolve_round(..., tuning=)`、`fill_timed_out_actions(..., tuning=)`）。

**執行方式：** 子代理逐步做（superpowers:subagent-driven-development：每個 Task 一個新的子代理實作、另一個子代理審過才做下一個，最後整條分支再審一次）。

## Global Constraints

- 方針三種【預設】：`hold` 穩守到底（一律固守）、`attack` 能攻就攻（這一場的氣血過半出自己份量最高的招，否則固守）、`ai` 交給 AI（**預設值**）。方針只挑固定招，不替人放手一搏（3.3）。
- 只在**時間到還沒出手**時才照方針出；自己按了招就照自己按的。代出的人照舊記進 `round.auto_picked`（計畫六的貢獻記一半看它）。
- AI 分組看四件事（3.3、3.4 末段）：氣血剩多少（高＞⅔、中＞⅓、低）、上一回合出什麼招（第一回合是「無」）、自己這邊領先還是落後（看戰局：官軍 > 50 是官軍領先；剛好 50 是相持）、最拿手的招（份量最高）。
- **每一邊每回合只問一次**，只問有人選「交給 AI」的那一邊；問的時候把這一邊所有組一起問。模型只回每一組一招（一個 tag），推多少、扣多少照規則算（同放手一搏「AI 只估成功率」的分工）。
- 模型在**行動鎖外**問（三段：A 鎖內開單、B 鎖外問、C 鎖內寫入前確認還是同一場、同一回合）；B 段有時間預算（`Config.battle.ai_budget_seconds`，預設 60）。
- 模型叫不動、太慢、回的招不認得、那一組沒回：那一組照「能攻就攻」。
- 假人（`bot_policy`、整季機器人）不叫模型，也不改方針；假人自己每回合出招（照計畫一的 `bot_choose_action`），不走代出。
- 新的「永遠按得下去」的方針按鈕要從機器人的選擇裡排除（CLAUDE.md 記過的坑：永遠 enabled 的選項會打壞整季模擬的推進）。
- 數字全由規則引擎決定。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

## Review Focus

1. **回合換了，模型才回來**：C 段寫入前確認還是同一場、同一回合，晚到的答案丟掉，不會寫進下一回合。→ Task 3 `test_late_picks_for_an_old_round_are_dropped`。
2. **模型回了奇怪的東西**（不認得的招、少了幾組、多了不存在的組、整個連不上）：認得的照用，其他組照能攻就攻。→ Task 3 `test_bad_or_missing_picks_fall_back_to_attack_when_able`。
3. **同一回合不重複問**：好幾個人同時輪詢，只開一張單；B 段沒回來、超過預算再允許重開。→ Task 3 `test_one_ask_per_side_per_round`。
4. **方針按鈕不能打壞機器人**：整季模擬裡機器人不會一直按方針（它永遠按得下去）。→ Task 2 `test_bots_never_pick_a_stance_button`。
5. **倒下、離開大區的人**：不代出、不分組、不問模型。→ Task 1 `test_the_fallen_and_the_away_are_not_picked_for`。

```python
def hp_band(p: BattleParticipant) -> str:
    share = p.neili / p.neili_cap if p.neili_cap else 0.0
    return "高" if share > 2 / 3 else "中" if share > 1 / 3 else "低"


def best_move(p: BattleParticipant) -> str:
    """份量最高的招；一樣高時照 MOVES 的順序（強攻、固守、奇襲）。沒有份量（舊資料）是固守。"""
    if not p.scores:
        return "固守"
    return max(MOVES, key=lambda m: p.scores.get(m, 0.0))


def lead_word(instance: BattleInstance, definition: BattleDef, faction: str) -> str:
    first = definition.factions[0].id
    if instance.trend == CENTER:
        return "相持"
    ahead = instance.trend > CENTER if faction == first else instance.trend < CENTER
    return "領先" if ahead else "落後"


def group_key(instance: BattleInstance, definition: BattleDef, p: BattleParticipant) -> str:
    """AI 分組（戰鬥系統 3.3、3.4 末段）：氣血、上一回合的招、領先或落後、最拿手的招。"""
    return "|".join((hp_band(p), p.last_move or "無", lead_word(instance, definition, p.faction), best_move(p)))


def attack_pick(p: BattleParticipant) -> str:
    """能攻就攻：這一場的氣血過半出最拿手的招，否則固守。也是 AI 叫不動時的退路。"""
    return best_move(p) if p.neili > p.neili_cap / 2 else "固守"


def stance_pick(instance: BattleInstance, definition: BattleDef, p: BattleParticipant) -> str:
    if p.stance == "hold":
        return "固守"
    if p.stance == "attack":
        return attack_pick(p)
    picked = instance.round.ai_picks.get(p.faction, {}).get(group_key(instance, definition, p))
    return picked if picked in MOVES else attack_pick(p)


def set_stance(instance: BattleInstance, name: str, stance: str) -> bool:
    """改方針（加入之後、集結期與開打後都能改）；不是三種之一、不在名單上回 False。"""
    p = instance.participants.get(name)
    if p is None or stance not in STANCES:
        return False
    p.stance = stance
    return True

def fill_timed_out_actions(instance: BattleInstance, definition: BattleDef, tuning: BattleTuning | None = None) -> None:
    """逾時：還沒送出行動的在場者，照自己的作戰方針出一招（戰鬥系統 3.3）：穩守到底、能攻就攻、交給 AI（讀這一回合
    模型替那一組挑好的招，沒有就照能攻就攻）。代出的人記進 round.auto_picked：這一回合不算他自己出手（FB-027），
    計畫六的貢獻記一半。這一幕沒有那一招可選（不該發生，內容驗證保證三招都有）就跳過這個人。"""
    for p in _active_participants(instance):
        if p.name in instance.round.pending_actions:
            continue
        move = stance_pick(instance, definition, p)
        option = next(
            (o for o in options_for(instance, definition, p.name) if not o.free_text and o.move == move), None,
        )
        if option is None:
            continue
        instance.round.pending_actions[p.name] = option.tag
        instance.round.auto_picked.append(p.name)
```

```python
"""決戰的 AI 代挑（戰鬥系統設計 3.3）：選「交給 AI」的人時間到還沒出手，由模型照處境替他那一組挑一招。

| 誰 | 做什麼 |
|---|---|
| 規則 | 分組（battle_instance.group_key）、退路（能攻就攻）、推多少扣多少 |
| 模型 | 每一邊每回合一次，替每一組挑一招（一個 tag），不碰數字 |

三段（同人物對話、開爐取名）：A prepare（行動鎖內、很快）→ B ask（鎖外、很慢、有預算）→ C store（鎖內，確認還是同一場、同一回合）。
"""
from __future__ import annotations

import copy
from collections import Counter
from dataclasses import dataclass

from pydantic import BaseModel

from . import battle_instance as bi
from .models import MOVES, BattleDef
from .ollama_client import OllamaClient

SYSTEM_PROMPT = (
    "你是漢末戰場上替一方將士臨陣決斷的參謀。每回合只有三招：強攻、固守、奇襲；"
    "固守剋強攻、強攻剋奇襲、奇襲剋固守。你要替每一組人挑一招，只回招名，不要解釋，不要提任何數字。"
)
LEAD_WORDS = {"領先": "我方佔上風", "落後": "我方落了下風", "相持": "兩軍相持"}


class GroupPicks(BaseModel):
    picks: dict[str, str]  # 組的編號（"1"、"2"…）→ 招名


@dataclass(frozen=True)
class PreparedPicks:
    record_id: int | None
    battle_id: str
    round_number: int
    faction: str
    keys: tuple[str, ...]  # 第 i 組（從 1 起算）的 group_key
    messages: list[dict[str, str]]


def prepare(
    instance: bi.BattleInstance, definition: BattleDef, faction: str, now: float, retry: float,
) -> PreparedPicks | None:
    """A（鎖內）：這一邊有在場、選交給 AI、還沒出手的人，這一回合還沒有答案、也沒有人正在問（或問了超過 retry 秒，
    上一個執行緒可能掛了），就開單、記下開單的時間；否則 None。"""
    if instance.phase != "active" or faction in instance.round.ai_picks:
        return None
    asked = instance.round.ai_asked_real.get(faction)
    if asked is not None and now - asked < retry:
        return None
    people = [
        p for p in bi.active_participants(instance)
        if p.faction == faction and p.stance == "ai" and p.name not in instance.round.pending_actions
    ]
    if not people:
        return None
    groups = Counter(bi.group_key(instance, definition, p) for p in people)
    keys = tuple(sorted(groups))
    names = {f.id: f.name for f in definition.factions}
    enemy = next(f.id for f in definition.factions if f.id != faction)
    seen = instance.last_mix.get(enemy)
    last = "・".join(f"{m} {round(seen[m] * 100)}%" for m in MOVES) if seen else "還沒交手"
    lines = []
    for i, key in enumerate(keys, start=1):
        hp, move, lead, best = key.split("|")
        lines.append(f"{i}. 氣血{hp}、上回合出{move}、最拿手{best}（{groups[key]} 人）")
    lead = LEAD_WORDS[bi.lead_word(instance, definition, faction)]
    act = bi.current_act(instance, definition)
    user = (
        f"戰場：【{act.title}】{bi.act_text(instance, definition)}\n"
        f"我方：{names[faction]}；{lead}。對面上一回合：{last}。\n"
        "各組：\n" + "\n".join(lines) + "\n\n"
        "回 picks：每一組的編號對一招（強攻、固守、奇襲之一）。"
    )
    instance.round.ai_asked_real[faction] = now
    return PreparedPicks(
        record_id=instance.record_id, battle_id=instance.battle_id, round_number=instance.round_number,
        faction=faction, keys=keys,
        messages=[{"role": "system", "content": SYSTEM_PROMPT}, {"role": "user", "content": user}],
    )


def ask(client: OllamaClient | None, prepared: PreparedPicks, budget: float) -> dict[str, str]:
    """B（鎖外）：問模型一次，回組 → 招；連不上、回不出、招不認得、組不存在都丟掉（那幾組照能攻就攻）。"""
    if client is None or budget <= 0:
        return {}
    caller, own = client, getattr(client, "timeout", None)
    if isinstance(own, (int, float)):  # 真的 OllamaClient：拿複本把逾時壓到預算以內（原本那個不動，別的請求可能正在用）
        caller = copy.copy(client)
        caller.timeout = min(own, budget)
    try:
        reply = caller.chat_structured(prepared.messages, GroupPicks, required_fields=["picks"])
    except Exception:  # noqa: BLE001  連不上、逾時、格式不對
        return {}
    if reply is None:
        return {}
    out = {}
    for index, move in (reply.picks or {}).items():
        if str(index).isdigit() and 1 <= int(index) <= len(prepared.keys) and move in MOVES:
            out[prepared.keys[int(index) - 1]] = move
    return out


def store(instance: bi.BattleInstance, prepared: PreparedPicks, picks: dict[str, str]) -> bool:
    """C（鎖內）：還是同一場、同一回合、還在打才寫；晚到的丟掉（Review Focus 1）。"""
    same = (
        instance.phase == "active" and instance.battle_id == prepared.battle_id
        and instance.record_id == prepared.record_id and instance.round_number == prepared.round_number
    )
    if not same:
        return False
    instance.round.ai_picks[prepared.faction] = dict(picks)
    return True
```

```python
    def battle_ai_requests(self) -> list[battle_ai.PreparedPicks]:
        """AI 代挑的 A 段（行動鎖內、很快；server.battle_ai_round）：進行中的決戰，兩邊各看要不要開單。
        要開的單會在共用戰鬥狀態記下開單時間，所以要在 mutate_battle 裡做。假人不叫這個。"""
        status = self._battle_status(tick=False)
        if status is None:
            return []
        battle, definition = status
        if battle.phase != "active":
            return []
        retry = self.content.config.battle.ai_retry_seconds
        out: list[battle_ai.PreparedPicks] = []

        def _apply(b: battle_instance.BattleInstance) -> None:
            for f in definition.factions:
                prepared = battle_ai.prepare(b, definition, f.id, now=self.now, retry=retry)
                if prepared is not None:
                    out.append(prepared)

        self.world.mutate_battle(_apply)
        return out
```

`server.py`：

```python
_BATTLE_AI_RUNNING = threading.Lock()  # 同一時間只跑一個 AI 代挑的執行緒（每回合每邊一次，不需要更多）


def battle_ai_round(game: Game) -> None:
    """AI 代挑三段（戰鬥系統 3.3）：A 鎖內開單 → B 鎖外問模型 → C 鎖內確認同一回合再寫。輪詢時由背景執行緒呼叫。"""
    with _locked(game):
        game.sync(time.time())
        requests = game.battle_ai_requests()
        open_characters().save(game.state)
    budget = game.content.config.battle.ai_budget_seconds
    for prepared in requests:
        picks = battle_ai.ask(game.client, prepared, budget)
        with game.world.action_lock():
            game.world.mutate_battle(lambda b, p=prepared, k=picks: battle_ai.store(b, p, k))


def _kick_battle_ai(game: Game) -> None:
    """輪詢時看要不要開 AI 代挑的執行緒：已經有一個在跑就算了（不擋這次輪詢）。"""
    if not _BATTLE_AI_RUNNING.acquire(blocking=False):
        return

    def run() -> None:
        try:
            battle_ai_round(game)
        except Exception:  # noqa: BLE001  代挑失敗不影響任何人：時間到照能攻就攻
            pass
        finally:
            _BATTLE_AI_RUNNING.release()

    threading.Thread(target=run, daemon=True).start()
```

## 計畫裡的決定（設計沒寫死、這份替實作選的）

| 題目 | 這份的做法 | 理由 |
|---|---|---|
| 方針放哪 | 決戰選項多三顆「方針：…」按鈕，目前那顆灰掉 | 網頁不用改；集結期與開打後都看得到、都能改 |
| 誰觸發 AI 代挑 | 伺服器輪詢（`/api/main`）時開背景執行緒，同時只跑一個 | 假人不叫模型；一回合 5 分鐘、每 10 秒有人輪詢就來得及 |
| 重複問 | 開單時記時間，90 秒內不重開 | 好幾個人同時輪詢只問一次；執行緒掛了也能重來 |
| 組的編號 | 照 group_key 排序後編 1、2、3… | 模型只要回編號對招，不用重寫組的描述 |
| 能攻就攻的「拿手」 | 份量最高的招，一樣高照強攻、固守、奇襲的順序 | 決定性；沒有份量的舊資料當固守 |
