# 正式季整合第 2 批：四階料與鐵匠鋪 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans（PM 派工：在 session 裡一步一步做，不開子代理、不開 Workflow）. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 素材從三階變四階：四種四階料加在素材表最後；三階恢復成一般好料（收購、黑市、二換三不限一天）；三換四一季 2 個；四階裝備的加成、工錢、淬煉；四階打出名器的機率大增；九件神器改用四階；四階不賣、不捐、不算糧草、不送人、不被搶；鐵匠講四條規矩；機器人跟著會用。

**Architecture:** 新開關 `Config.four_tiers`（`FourTiers`，預設開、測試內容關）只管「規則」：三階收購與黑市、拿掉二換三一天一個、三換四、四階名器機率、鐵匠的規矩。數字表（加成、減損、工錢、淬煉、品質分、求兵倍數）直接在原本的表上加第 4 階：沒有四階料就碰不到。內容（四階料、九件神器、名器名字表）是全服一份，開關收不回（設計 10.1）。四階名器用新欄位 `Equipment.named_entry` 指到新內容檔 `content/tier4_named.json`。

**Tech Stack:** Python 3.12、pydantic、pytest；內容 JSON。

**Spec:** `docs/superpowers/specs/2026-10-17-正式季整合-design.md` 第四、五章（4.2、4.4、4.5 的三換四、4.6、5.1～5.3、5.5、5.10）、6.6、8.1 打造與素材、10.1 素材四階、12.3 第 37 條；分批第十一章第 2 批。
