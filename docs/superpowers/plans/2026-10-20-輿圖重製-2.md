# 輿圖重製 第 2 批：天下圖 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 派工單定了：開發自己一步一步做（不開子代理），計畫不必給企劃者審。

**Goal:** 打開輿圖第一眼是一張整張天下、不自由縮放的「天下圖」：州郡地面照「離哪個地點最近」上誰的顏色、任兩方相接畫紅線、有主與沒人佔相接畫細墨線、高級資源地金點、核心朱印「璽」、州名＋各方幾處與寶幾處、你在哪；版圖變化在天下圖上播。

**Architecture:** 幾何（每州自己的沃羅諾伊、相鄰兩塊地面的邊、州名擺哪）是純函式 `tianxia/worldgeo.py`，`mapdata.base()["world"]` 把它與劇本的陣營顏色、圈、沒人佔的顏色一起交給網頁（跟底圖一起照開放的地點快取）；誰佔著照舊在疊層。網頁不另開一張圖：天下圖就是同一張底圖（已經烤成點陣的山水）換一個固定的取景（`worldFit`），`#mk` 畫地面與記號；點一州換回現在的可縮放地圖（第 3 批換成區圖之前的替身）並對準那一州。

**Tech Stack:** Python 3（pydantic 模型、純幾何）、原生 JS（`web/app.js`，沒有建置步驟）、CSS；測試 pytest＋`tests/webharness.py`（node）。

**Spec:** `docs/superpowers/specs/2026-10-20-輿圖簡化-design.md`（這個分支上沒有那份檔，在 `pm/handoff-1020b`；第一章、3.5、3.6、4.1、4.5、4.6、第七章第 4、7、8 條、第十、十一章）。開發手冊 `tianxia-map-remake`（「分批與檔案」第 2 條）。

## Global Constraints

- 輿圖只有兩張不自由縮放的圖；天下圖整張天下一屏看完、沒有捏合縮放、沒有圖例（設計 4.1、第一章）。
- 地面一方一色＋沒人佔一色；顏色與幾方從劇本讀；**程式裡不准出現寫死的「兩方」「西半邊官軍／東半邊黃巾」「藍黃灰」**；任兩方相接就是前線（設計 3.6）。
- 地面的顏色一律讀 `territory.controller`（`Config.territory` 關著整張灰）；同一個劇本規則開關不同的季也用新畫法（設計 4.6）。
- 地面分法「離哪個地點最近」，正式畫法開發定（設計第七章第 7 條）。
- 深色主題時地圖本身照舊是紙色（設計 4.5）。新寫給玩家看的字標「待 joy 潤」。任何畫面不能透露誰是假人。
- 不做：區圖與卡（第 3 批）、拿掉 4.4 那一表（第 3 批）、出生點與序章（第 4 批）、大勢值的線與攻城公告（第 5 批）。
