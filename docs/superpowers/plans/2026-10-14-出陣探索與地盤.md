# 出陣、探索三選一與地盤易手 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **PM 2026-10-14 派工**：不要開多代理工作流程，也不要每個 task 各派一個子代理；一個 task 一個 commit，最終審查一個人看就好。計畫從已定的設計寫，不必等 PM 核。

**Goal:** 把遊歷改成限次、只替陣營推大勢的「出陣」（攻、守、攪局），探索改成玩家自己挑的三選一（找素材、找事件、靜心感悟），戰線地點照戰線、割據與大事易手並帶來敵情、價錢、事件的差別，推大勢加上盡頭阻力與季長縮放。

**Architecture:** 四個開關各管一塊、預設開、測試內容關：`Config.push_resistance`（`push.resistance_share` 在 `Game.push_trend`、`figures.tick`、`orders.front_push` 三處打折，每人每曆日上限與出陣推的量乘季長倍數）、`Config.territory`（新模組 `tianxia/territory.py`：控制方存在 `WorldState.territory`，`rules.change_trend` 每動一次就重算，`territory.squads_at` 取代地點的 `enemies` 給遊歷、探索、懸賞、攻城、輿圖用）、`Config.sortie`（新模組 `tianxia/sortie.py` 放純規則，`Game._sortie` 打或不打；選項 id 照留 `act:train`）、`Config.explore_modes`（新模組 `tianxia/explore_modes.py`，`act:explore` 留作展開的入口，三種是 `explore:gather|seek|sense`，骰子都用自己的亂數）。資料庫結構不動，新欄位都在角色與世界狀態的 JSON 裡、有預設值。

**Tech Stack:** Python 3.12、pydantic、SQLite（維持第 5 版）、pytest（`-n 8`）、原生 JavaScript（`web/app.js`，測試用 node 假瀏覽器）。

**Spec:** `docs/superpowers/specs/2026-10-14-出陣探索與地盤-design.md`（企劃者 2026-10-14 審過）。計畫與設計有出入時以設計為準；設計沒寫的照現有程式的寫法，寫在下一節。

**分支：** `sortie-territory`，從 main `13008bae` 開（開工時 origin/main 也是它）。

## 跟設計寫的時候不一樣、或設計沒寫而照程式定的（開工前讀程式查到的）

1. **出陣沿用選項 id `act:train`**（設計第二節：id 可以照留）：伺服器的大場面判讀（`server.may_judge_fight` 寫死認 `act:train`）、網頁行動列、機器人、量表、約四十個測試檔都認它，所以 `may_judge_fight` **不用改**——守、攪局不打仗，`Game.fight_request` 自然回 None。玩家看得到的字（鈕、紀錄標題、戰報類型）才改成「出陣」；新的戰報類型是 `BattleRecord.kind == "sortie"`（舊戰報的 `train` 照舊顯示「遊歷」）。
2. **戰線地點**＝地點的 `train_trend` 寫了戰線：鍵是戰線 id 就是那一條；鍵是 `front`（`models.FRONT_KEY`）照地點所在大區的戰線（`rules.front_of`）。**洛陽兩處（洛陽官道、孟津渡）寫的 `front` 就是 `FRONT_KEY`**，它們在洛陽大區，那個大區的 `front` 是 None：第一季規則開著時這兩處遊歷什麼都不推（`resolve_trend` 回 None），規則關著的季推黃巾聲勢。照設計的退路當成**不在戰線上**：沒有出陣鈕、不參與地盤。正式內容剩 14 處戰線地點：大本營 5（長社、盧植營、黃巾別部營寨、鉅鹿道壇、南陽黃巾營）、廣宗 1、可易手 8。
3. **規則關著的季（14 天的預設設定）三條戰線都換成黃巾聲勢**（`rules.resolve_trend`）：拔河看的是黃巾聲勢（`territory.line_value`），三條線上的地點一起動；那種季沒有豪強割據這條線，豪強不佔地；豪強在那種季沒有目標，攪局照樣往 50 拉黃巾聲勢。開季時黃巾聲勢 25，八處可易手的地點都歸官軍。
4. **盡頭阻力只管戰線**（第一季的三條戰線；規則關著的季是它們合成的黃巾聲勢），豪強割據、玉璽線索不管。打了折的那一下推動那一行多一句 `push.RESISTED_LINE`，即使這一下沒推到整點。
5. **事件五折只管可重複的事件**（`source="event"`），一次性的事（`event_once`：標了 once、或這一下新立世界旗標）照全額——同 FB-166 的道理；也只管戰線。數字在 `Config.explore_modes.event_trend_share`（設計 3.2 寫在這一組）。
6. **貢獻照推的「名目量」全額記**（設計 2.4「全額記貢獻」）：`push_trend` 收到的 `delta`（季長倍數、盡頭阻力、事件五折之前）進 `push.contribution`，超過每日上限的那一份照舊只記兩成。
7. **守的「自家那一路」**取這裡自家陣營隊伍裡經驗最高的一路（同分取先列的）；**攪局給什麼設計沒寫**：照守的算法給此刻控制方隊伍裡經驗最高的那一路的三成（不然豪強每天五次出陣什麼都不長）。
8. **自家地盤上有截糧軍令帶來的敵方運糧隊時，出陣是攻打運糧隊**（`orders.extra_enemies`）：截糧的地點與相鄰站常常是自家地盤，不這樣截糧就做不了。
9. **割據佔地**：佔下的地點固定不換位（不隨戰線移動改佔別處）；第一處在割據 ≥60、第二處在 ≥80 才加；50～60 之間維持手上的；<50 一次全部交還給拔河。每條線挑「門檻最接近此刻戰線、還沒佔的」那一處，同距離取排在官軍那頭的。
10. **每個控制方站的隊伍寫在劇本的 `territory.garrison`**（設計寫的是例 `Location.garrison`）：拔河排序、固定地點、隊伍放在同一個區塊，joy 對一處就好。先用現有的隊伍照危險度組（表在 Task 2）。
11. **大事指定易手只做時刻表的結果**（`TimetableOutcome.control`）；beta 的門檻決戰（`BattleOutcome`）沒有內容要用，不做。廣宗只有「官軍大勝」交給官軍（險勝那一版是外城破、退守內城）。指定的地點記下「那一刻規則算出來的控制方」（`TerritoryState.pinned`），規則算出來的控制方改變那一刻才回到規則。
12. **大本營包含不在戰線上的投靠點**（宛城、鄉里結社、曹氏莊院、豪族塢堡）：它們有控制方（地盤福利照算），但不是戰線地點、沒有出陣。
13. **第一次算地盤不發天下大事**：`WorldState.territory` 是 None（開季、舊存檔、第 4 季中途上線）時第一次重算不發；管理者開季（`open_season` 重蓋章）時把它清成 None。讀控制方時 None 就照規則現算（不存）。
14. **找素材撞上的對手**：手上有這裡的討伐懸賞、那一路不是自己人時就是它（Review Focus 5：地點易手之後那一路不站在這裡了，懸賞還交得了）；否則照設計挑最弱的一路。
15. **探索三種的骰子全部用自己的亂數**（設計只寫了素材）：頭目戰、撞上怪、戰後事件 30%、奇遇 2.5%、事件抽選、有所感的場景、破境丹，種子「探索|季數|名號|第幾次探索|用途」（新欄位 `PlayerState.explore_seq`）。開關關著時舊的探索照舊用 `Game.rng`，序列不位移。
16. **序章的雪恥照留 `act:train` 與舊的遊歷打法**（不看出陣開關、不算出陣次數），出陣開著時鈕上寫「雪恥」；`content/tutorial.json` 那兩句跟著改，序章的 `allow`／`glow` id 不用改（設計第七節「選單 id 清單同步」在這個做法下不用動）。
17. **守勢行動（巡哨、傳道、保境安民，`act:duty`）照留**：設計沒提。它不限次、只受每人每曆日上限，推力也吃盡頭阻力。要不要收進出陣次數或拿掉，請 PM 定（見回報）。
18. **「週末設定推力一個字都不變」的讀法**：季長倍數在 2.5 天是 1，所以出陣每次推的量、每人每曆日上限在週末設定一個字都不變；盡頭阻力與事件五折照設計兩種季都有。
19. **按「探索」在三選一開著時**只回一句 `explore_modes.PICK`、不花體力、不寫江湖紀錄、不算新手引導（不然按一下沒做事也算「探索過」）。
20. **正式內容的舊測試**：四個開關預設開、測試內容（`tests/fixtures/content/config.json`）關，可是約三十個測試檔用正式內容按遊歷、探索、推大勢。每個 task 會讓其中一批變紅；處理規則寫在 Global Constraints，`tests/conftest.py` 新增 `classic_rules(content)`。
21. **出陣的鈕寫是哪一種**：設計 2.3 寫「出陣（今日還能 N 次）」；照遊歷鈕的慣例（體力、勝算都寫在括號裡，網頁照「・」切）寫成「出陣・攻（體力 6・今日還能 3 次・黃巾嘍囉・有把握）」「出陣・守（體力 6・今日還能 3 次・零風險）」，行動列那一格名字是「出陣・守」、小字「今日 3 次」。
22. **設計 5.5 拿掉 `drill_long_season_share`**：守、攪局走 `push_trend(source="sortie")`，只乘季長倍數；那個設定欄位照留，只剩出陣開關關著時的舊操練（`Game.drill_scale`）讀它。

## Review Focus

1. **出陣次數在台灣時間 00:00 換日**：UTC 15:59:59 用滿五次，下一秒（台灣 00:00）就又有五次；整季機器人只 `advance` 不 `sync`，次數也要跟著換日。→ Task 3 的 `test_five_a_day_then_grey_until_taiwan_midnight`、`test_advancing_rolls_the_sortie_day`。
2. **地盤在門檻上來回翻**：戰線在門檻上下一兩點來回動，控制方不跟著翻、天下大事不洗版；越過 ±5 才翻一次。→ Task 2 的 `test_the_band_stops_flapping_on_the_threshold`。
3. **豪強佔地與大事指定同時發生**：大事剛把一處交給官軍，割據漲到 60 選中同一處——規則算出來的控制方變了，指定作廢、歸豪強、發一句天下大事。→ Task 2 的 `test_a_pinned_spot_goes_to_the_gentry_when_the_gentry_rises`。
4. **舊存檔讀進來沒有控制方**（第 4 季中途上線）：`WorldState.territory` 是 None，讀控制方照規則現算；第一次重算不發天下大事；之後照常。→ Task 2 的 `test_an_old_season_without_territory_reads_the_rule_and_announces_nothing`。
5. **散人手上的討伐懸賞，目標地點易手之後還交得了**：揭了「汝南荒野打黃巾嘍囉」，汝南荒野被官軍拿回去（站的換成官軍），找素材撞上的照樣是黃巾嘍囉，打贏交差。→ Task 4 的 `test_a_ranger_finishes_a_strike_bounty_after_the_spot_changed_hands`。

```python
RESISTED_LINE = "深入敵境，推進艱難。"  # 待 joy 潤：盡頭阻力打了折的那一下，推動那一行後面多這一句（出陣探索與地盤設計 5.1）


def resistance_share(value: float, direction: float, tuning: PushResistance) -> float:
    """推之前戰線在 value、這一下往 direction（正：往 100；負：往 0）推：打幾折（設計 5.1）。只看推的方向：往盡頭推
    （50 以上還往上、50 以下還往下）照離 50 多遠——full_within（15）以內全額（35～65，亂局帶）、half_within（35）以內
    mid_share、再外面 far_share；往回拉、正好在 50、方向是 0 都全額。"""
    if direction == 0 or value == 50 or (direction > 0) != (value > 50):
        return 1.0
    far = abs(value - 50)
    if far <= tuning.full_within:
        return 1.0
    if far <= tuning.half_within:
        return tuning.mid_share
    return tuning.far_share


def resistance(value: float, delta: float, tuning: PushResistance) -> float:
    """打過盡頭阻力的推力（delta 帶正負號）。"""
    return delta * resistance_share(value, delta, tuning)


def round_half_away(x: float) -> int:
    """四捨五入成整數，.5 往離 0 遠的方向進（軍令達成推的整點：1.6 → 2、−0.6 → −1）。"""
    return int(math.copysign(math.floor(abs(x) + 0.5), x))
```

```python
- Scenario.territory.lines 裡的可易手地點照拔河（戰線的值對各地點的門檻，±band 不動）、豪強割據（≥geju_one 每條線一處、
  ≥geju_two 兩處、<geju_release 交還）與大事指定（assign：留到規則算出來的控制方改變那一刻）。
存在 WorldState.territory（整份 JSON，資料庫結構不動）；None＝這一季還沒算過：第一次算不發天下大事（設計第六節）。
拔河看的線照 rules.resolve_trend：第一季是那條戰線，規則關著的季是黃巾聲勢（三條線上的地點一起動，那種季沒有割據）。
只讀寫 WorldState；天下大事與江湖史直接記進 world.rumors／world.chronicle（rules.add_rumor 要 GameState）。
開關（Config.territory.enabled）關著或劇本沒寫 territory：controller 回 None，squads_at 照 Location.enemies。
rules → territory 只在 rules.change_trend 裡延後 import；這裡 import rules 整個模組、呼叫時才取屬性。"""
from __future__ import annotations

from . import rules

FLIP_LINE = "{place}落入{side}之手。"  # 待 joy 潤：易手那一刻的天下大事與江湖史（設計 4.3 第 2 點）
CONTROL_LINE = "此刻由{side}控制"  # 待 joy 潤：輿圖詳情欄局勢那一行


def on(content: Content) -> bool:
    return content.config.territory.enabled and bool(content.scenario.factions) and content.scenario.territory is not None


def line_of(content: Content, loc_id: str) -> str | None:
    """這個地點是哪一條戰線上的戰線地點（只看內容，不看季）；不是戰線地點是 None。出陣只在這種地點（sortie.mode）。"""
    loc = content.locations.get(loc_id)
    if loc is None:
        return None
    fronts = set(rules.front_ids(content))
    for key in loc.train_trend:
        line = rules.front_of(content, loc_id) if key == FRONT_KEY else key
        if line in fronts:
            return line
    return None


def bases(content: Content) -> dict[str, str]:
    """大本營：劇本陣營的投靠點 → 那個陣營（設計 4.1）。"""
    return {loc_id: f.id for f in content.scenario.factions for loc_id in f.join_at}


def sides(content: Content, line: str) -> tuple[str | None, str | None]:
    """這條戰線兩頭是誰：（目標往 0 推的陣營, 目標往 100 推的陣營）；照劇本陣營的 goals（內容寫的戰線 id，不換鍵）。"""
    low = next((f.id for f in content.scenario.factions if f.goals.get(line, 0) < 0), None)
    high = next((f.id for f in content.scenario.factions if f.goals.get(line, 0) > 0), None)
    return low, high


def geju_side(content: Content) -> str | None:
    """割據佔地的那一方：目標推豪強割據的陣營。"""
    return next((f.id for f in content.scenario.factions if f.goals.get(rules.GEJU, 0) > 0), None)


def threshold(j: int, k: int) -> float:
    """從低的那一頭數第 j 個（1 起算）、共 k 個可易手地點的門檻：75 − 50 ×（j − 0.5）÷ k（設計 4.2）。"""
    return 75 - 50 * (j - 0.5) / k


def line_value(world: WorldState, content: Content, line: str) -> int:
    """拔河看的值：這條戰線照這一季的規則換成真的會動的線（第一季是它自己；規則關著的季是黃巾聲勢）。"""
    return rules.world_trend_value(world, content, rules.resolve_trend(content, world, line) or line)


def _tug(prev: str | None, value: float, t: float, low: str, high: str, band: int) -> str:
    if value >= t + band:
        return high
    if value <= t - band:
        return low
    if prev in (low, high):
        return prev
    return high if value >= t else low  # 第一次算、剛好在緩衝裡：照門檻


def _recompute(world: WorldState, content: Content, t: TerritoryState) -> dict[str, str]:
    """可易手地點照規則此刻歸誰（拔河、割據），順便更新 t.tug 與 t.geju；回傳 {地點: 控制方}。"""
    cfg = content.config.territory
    haoqiang = geju_side(content)
    geju = rules.world_trend_value(world, content, rules.GEJU) if rules.trend_shown(content, world, rules.GEJU) else None
    held = list(t.geju)
    result: dict[str, str] = {}
    for line, spots in content.scenario.territory.lines.items():
        low, high = sides(content, line)
        if low is None or high is None or not spots:
            continue
        value = line_value(world, content, line)
        k = len(spots)
        for j, loc_id in enumerate(spots, start=1):
            t.tug[loc_id] = _tug(t.tug.get(loc_id), value, threshold(j, k), low, high, cfg.band)
        if haoqiang is None or geju is None or geju < cfg.geju_release:
            held = [loc_id for loc_id in held if loc_id not in spots]
        else:
            mine = [loc_id for loc_id in held if loc_id in spots]
            want = 2 if geju >= cfg.geju_two else 1 if geju >= cfg.geju_one else 0
            free = sorted(
                (loc_id for loc_id in spots if loc_id not in mine),
                key=lambda loc_id: (abs(threshold(spots.index(loc_id) + 1, k) - value), spots.index(loc_id)),
            )
            held += free[: max(0, want - len(mine))]
        for loc_id in spots:
            result[loc_id] = haoqiang if haoqiang is not None and loc_id in held else t.tug[loc_id]
    t.geju = held
    return result


def _control_now(world: WorldState, content: Content, t: TerritoryState) -> dict[str, str]:
    control = dict(bases(content))
    for loc_id, side in content.scenario.territory.fixed.items():
        control[loc_id] = t.control.get(loc_id, side)
    for loc_id, side in _recompute(world, content, t).items():
        if t.pinned.get(loc_id) == side and loc_id in t.control:
            control[loc_id] = t.control[loc_id]  # 大事指定的留著：規則算出來的還跟指定那一刻一樣
        else:
            t.pinned.pop(loc_id, None)
            control[loc_id] = side
    return control


def _announce(world: WorldState, content: Content, before: dict[str, str], after: dict[str, str]) -> None:
    for loc_id, side in after.items():
        if before.get(loc_id) not in (None, side):
            text = FLIP_LINE.format(place=content.locations[loc_id].name, side=content.scenario.faction_name(side, side))
            world.rumors.append(Rumor(time=world.time, text=text, location=loc_id, layer="world"))
            world.chronicle.append(Rumor(time=world.time, text=text))


def update(world: WorldState, content: Content) -> None:
    """重算一次（設計 4.2 最後一段）：rules.change_trend 真的動了一條線、決戰結果直接寫進季（Game._apply_outcome_trends_and_flags）、
    推進世界（world.advance_world_state）時叫。這一季第一次算（world.territory 是 None）不發天下大事；之後控制方換了的地點各發
    一句天下大事、記一筆江湖史。開關關著什麼都不做。"""
    if not on(content):
        return
    first = world.territory is None
    t = world.territory or TerritoryState()
    before = dict(t.control)
    t.control = _control_now(world, content, t)
    world.territory = t
    if not first:
        _announce(world, content, before, t.control)


def assign(world: WorldState, content: Content, given: dict[str, str]) -> None:
    """大事指定易手（TimetableOutcome.control，設計 4.2 第 3 點）：先照規則算一次，再把指定的地點換成指定的那一方。可易手的地點記下
    「這一刻規則算出來的控制方」（pinned），之後規則算出來的改變那一刻才回到規則；固定的地點（廣宗）換了就是換了。大本營不收
    （載入時也擋）。換了的地點照樣發天下大事。"""
    if not on(content) or not given:
        return
    update(world, content)
    t = world.territory
    base, fixed, haoqiang = bases(content), content.scenario.territory.fixed, geju_side(content)
    before = dict(t.control)
    for loc_id, side in given.items():
        if loc_id in base or loc_id not in t.control:
            continue
        if loc_id not in fixed:
            t.pinned[loc_id] = haoqiang if haoqiang is not None and loc_id in t.geju else t.tug[loc_id]
        t.control[loc_id] = side
    _announce(world, content, before, t.control)


def controller(world: WorldState, content: Content, loc_id: str) -> str | None:
    """這個地點此刻歸誰；不是戰線地點也不是大本營、或開關關著是 None。這一季還沒算過時照規則現算（不存，Review Focus 4）。"""
    if not on(content):
        return None
    t = world.territory
    if t is not None and loc_id in t.control:
        return t.control[loc_id]
    if loc_id in bases(content):
        return bases(content)[loc_id]
    if line_of(content, loc_id) is None and loc_id not in content.scenario.territory.fixed:
        return None
    return _control_now(world, content, (t or TerritoryState()).model_copy(deep=True)).get(loc_id)


def squads_at(world: WorldState, content: Content, loc_id: str) -> list[str]:
    """這個地點此刻站的隊伍（設計 4.3 第 1 點）：寫了 garrison 的地點是無陣營的那幾路（Location.enemies 裡的，誰控制都在）加上
    控制方那一組；其餘（開關關著、大本營沒寫 garrison）照 Location.enemies。遊歷、出陣、探索、懸賞、攻城、輿圖都讀它。"""
    loc = content.locations[loc_id]
    side = controller(world, content, loc_id)
    garrison = content.scenario.territory.garrison.get(loc_id) if side is not None else None
    if not garrison:
        return list(loc.enemies)
    neutral = [sid for sid in loc.enemies if sid in content.squads and content.squads[sid].faction is None]
    return neutral + [sid for sid in garrison.get(side, []) if sid not in neutral]


def price_factor(world: WorldState, content: Content, faction: str | None, loc_id: str) -> float:
    """地盤福利（設計 4.3 第 3 點）：在自己陣營控制的地方 own_price、別的陣營控制的地方 enemy_price；散人、沒有控制方是 1。"""
    side = controller(world, content, loc_id)
    if side is None or faction is None:
        return 1.0
    cfg = content.config.territory
    return cfg.own_price if side == faction else cfg.enemy_price
```

```python
    """地盤（Scenario.territory，出陣探索與地盤設計第四節）：戰線認得、兩頭有陣營；可易手的地點真的在那條戰線上、不是大本營、
```

```python
"""出陣（docs/superpowers/specs/2026-10-14-出陣探索與地盤-design.md 第二節；遊歷改版）。

只有投靠了陣營的人、只在戰線地點（territory.line_of）；照這裡此刻歸誰（territory.controller）分攻、守、攪局。每人每天
Config.sortie.per_day 次（攻守攪局共用），跟回體丹同一套換日（Game._pill_day：pill_now 的現實時間、pill_day_utc_offset_hours 的 00:00）。

選項 id 照留 act:train（設計第二節：程式裡的 id 可以照留）：伺服器的大場面判讀（server.may_judge_fight）、網頁行動列、機器人、量表都認它。"""
from __future__ import annotations

from typing import Literal

from . import rules, territory
from .models import Content
from .state import PlayerState, WorldState

Mode = Literal["attack", "hold", "stir"]
NAME = "出陣"  # 待 joy 潤
MODE_NAMES: dict[str, str] = {"attack": "攻", "hold": "守", "stir": "攪局"}  # 待 joy 潤
LEFT_NOTE = "今日還能 {n} 次"  # 待 joy 潤：鈕上體力後面那一段
USED_UP = "今日已出陣 {n} 次，明日 00:00 後再出陣"  # 待 joy 潤（設計 2.3；鈕上不帶句號，行動列底下那一行補句號）
HOLD_LINE = "你在{place}整頓營伍、巡守要道，替自家守住這一處。"  # 待 joy 潤
STIR_LINE = "你在{place}四處放話、暗中撥弄兩邊，這一帶的局面又亂了幾分。"  # 待 joy 潤
PROLOGUE_FIGHT = "雪恥"  # 待 joy 潤：序章那一場寫好的仗（不算出陣次數，鈕上與紀錄標題寫它）


def on(content: Content) -> bool:
    """出陣開著：Config.sortie.enabled，而且劇本有陣營（不看第一季開關，同懸賞、叛投）。"""
    return content.config.sortie.enabled and bool(content.scenario.factions)


def left_today(p: PlayerState, content: Content, today: int) -> int:
    """今天還能出陣幾次（today 是 Game._pill_day）。"""
    return max(0, content.config.sortie.per_day - (p.sorties_today if p.sortie_day == today else 0))


def spend(p: PlayerState, today: int) -> None:
    p.sorties_today = (p.sorties_today if p.sortie_day == today else 0) + 1
    p.sortie_day = today


def mode(content: Content, world: WorldState, faction: str | None, loc_id: str, foes: bool) -> Mode | None:
    """在這裡出陣是哪一種；None＝這裡沒有出陣鈕（散人、不是戰線地點、別人的地盤卻沒有能打的隊伍）。
    foes：這裡有能打的對手（Game._sortie_foes：控制方的隊伍，加上截糧帶來的敵方運糧隊）。
    陣營在這條戰線上沒有目標（豪強）一律攪局；別人控制的地方攻；自己控制的（地盤關著時：這裡沒有能打的）守，
    有截糧的運糧隊照打。"""
    if faction is None or not on(content):
        return None
    line = territory.line_of(content, loc_id)
    side = content.scenario.find_faction(faction)
    if line is None or side is None:
        return None
    if not side.goals.get(line):
        return "stir"
    controller = territory.controller(world, content, loc_id)
    if controller is not None and controller != faction:
        return "attack" if foes else None
    return "attack" if foes else "hold"


def pushes(content: Content, world: WorldState, faction: str, loc_id: str, how: Mode) -> dict[str, float]:
    """這一下推哪幾條線、各推多少（季長倍數與盡頭阻力在 Game.push_trend 再打）：攻是地點寫的量（train_trend）往自己陣營的目標推；
    守是攻的 hold_share；攪局是攻的 hold_share、往 50 拉（線在 50 什麼都不推）。鍵照 rules.resolve_trend 換過（規則關著的季是黃巾聲勢）。"""
    loc = content.locations[loc_id]
    goals = rules.resolve_goals(content, world, content.scenario.faction(faction).goals)
    share = 1.0 if how == "attack" else content.config.sortie.hold_share
    out: dict[str, float] = {}
    for key, delta in loc.train_trend.items():
        target = rules.resolve_trend(content, world, key, loc_id)
        if target is None:
            continue
        if how == "stir":
            value = rules.world_trend_value(world, content, target)
            direction = -1 if value > 50 else 1 if value < 50 else 0
        else:
            direction = goals.get(target, 0)
        amount = abs(delta) * direction * share
        if amount:
            out[target] = out.get(target, 0.0) + amount
    return out
```

```python
        if how is None:
            return None

        left = self.sorties_left()

        return self._train_option(loc, cost, odds, name=name, tail=tail)

        """出陣（act:train；體力 _act 已經扣了）：記今天一次，照這裡此刻歸誰攻、守或攪局。不接戰後事件（搬到找素材，設計 2.4）。

        how = self._sortie_mode(loc)

            msgs = self._squad_encounter(squad.id, as_sortie=True)
        else:
            msgs = self._sortie_hold(loc, how)
        return msgs + self._guide(note_action(s, c, self.world, "order"))

        經驗整隊一起拿（同遊歷），升級照寫進戰報。"""
        p, share = self.state.player, self.content.config.drill_reward_share
        msgs: list[str] = []
        xinde = drill_share(squad.reward_xinde, share)
        if xinde:

            record.xinde = xinde

        record.exp = exp
        levels, record.levelups = team.grant_team_exp(self.state, self.content, self.world, exp)
        record.notes += levels
        return msgs + levels

        """守、攪局拿誰的數字（設計 2.4「守用這個地點自己陣營那一路的數字」）：守是這裡自家陣營的隊伍、攪局是此刻控制方的隊伍
        （設計沒寫，照守的算法），取經驗最高的一路、同分取先列的；沒有是 None（不給心得經驗，推力照推）。"""
        s, c = self.state, self.content
        side = s.player.faction if how == "hold" else territory.controller(s.world, c, loc.id)

            c.squads[sid] for sid in territory.squads_at(s.world, c, loc.id)
            if c.squads[sid].faction is not None and (side is None or c.squads[sid].faction == side)
        ]
        return max(squads, key=lambda q: q.exp) if squads else None

        if how == "hold":
            msgs += self._order_credit(kind="duty", front=territory.line_of(c, loc.id))
        return msgs
```

```python
def _game(faction=None, at="yingshui", **cfg):
```

```python
三種各自一個 id（explore:gather|seek|sense），一樣的體力。這裡放純規則（id、字、找素材給什麼、撞不撞怪、自己的亂數）；

MODES = (GATHER, SEEK, SENSE)

def on(content: Content) -> bool:
    return content.config.explore_modes.enabled


def option_id(mode: str) -> str:
    return f"{PREFIX}{mode}"


def rng_for(season: int, name: str, serial: int, what: str) -> random.Random:
    """這一次探索、這一個用途自己的亂數：季數｜名號｜第幾次探索（PlayerState.explore_seq）｜用途。決定性，不動 Game.rng。"""
    return random.Random(f"探索|{season}|{name}|{serial}|{what}")


def is_town(content: Content, loc: Location) -> bool:
    return content.config.explore_mix_of(loc.tags).kind == "town"


def gather_finds(content: Content, loc: Location, rng: random.Random) -> list[str]:
    """找素材撿到的素材 id（設計 3.1 的表）：屬性照這裡寫的素材（Location.materials），沒寫就從同階全部挑；城鎮 town_chance 一個一階；
    其餘一定一個一階，照危險度 second_tier 的機會再一個二階。三階不從這裡來。"""
    cfg = content.config.explore_modes
    kinds = {content.materials[m].attribute for m in loc.materials if m in content.materials}

    def one(tier: int) -> str | None:
        pool = [m for m in materials.by_tier(content, tier) if m.attribute in kinds] or materials.by_tier(content, tier)
        return rng.choice(pool).id if pool else None

    if is_town(content, loc):
        found = [one(1)] if rng.random() < cfg.town_chance else []
    else:
        found = [one(1)]
        if rng.random() < cfg.second_tier.get(loc.danger, 0.0):
            found.append(one(2))
    return [mid for mid in found if mid is not None]


def encounter_due(content: Content, loc: Location, rng: random.Random) -> bool:
    """找素材撞不撞上怪：城鎮不撞，其餘 encounter_chance。"""
    return not is_town(content, loc) and rng.random() < content.config.explore_modes.encounter_chance
```

```python
    def _here_squads(self, loc_id: str) -> list[str]:
        """這個地點此刻站的隊伍（territory.squads_at）。"""
        return territory.squads_at(self.state.world, self.content, loc_id)

    def _explore_mode(self, mode: str) -> list[str]:
        """探索三選一的一種（設計第三節）：體力同探索；在召見的地點端出晉升奇遇（同探索）。三種都擲破境丹、都算打探懸賞的交差。
        擲骰都用自己的亂數（explore_modes.rng_for），不碰 Game.rng。"""
        s, c = self.state, self.content
        p = s.player
        p.stamina -= self._action_costs()["explore"]
        promotion = ranks.summons_event(s, c)
        if promotion is not None:
            return self._present(c.events[promotion])
        p.explore_seq += 1
        roll = functools.partial(explore_modes.rng_for, self.world.get_season_number(), p.name, p.explore_seq)
        loc = c.locations[p.location]
        if mode == explore_modes.GATHER:
            msgs = self._gather(loc, roll("找素材"))

        else:

        scouted = bounties.on_explore(s, c, self.world, p.location)  # 打探：三種都算（設計 3.4）
        return msgs + self._legend_find(roll("破境丹")) + scouted

    def _gather(self, loc: Location, rng: random.Random) -> list[str]:
        """找素材（設計 3.1）：有頭目的地點先擲頭目戰（Config.duel.explore_chance）；撿素材（explore_modes.gather_finds）；
        城鎮以外 encounter_chance 撞上一場（_gather_fight）。"""
        s, c = self.state, self.content
        boss = duel_rules.available(s, c)
        if boss is not None and rng.random() < c.config.duel.explore_chance:
            return self._duel_start(boss)
        msgs = [explore_modes.GATHER_LINE.format(place=loc.name)]
        found = [line for mid in explore_modes.gather_finds(c, loc, rng) if (line := materials.grant(s, c, mid))]
        msgs += found or [explore_modes.GATHER_NONE]
        if explore_modes.encounter_due(c, loc, rng):
            msgs += self._gather_fight(loc, rng)
        return msgs

    def _gather_foe(self, loc: Location) -> Squad | None:
        """找素材撞上的那一路（設計 3.1）：手上有這裡的討伐懸賞、那一路不是自己人時就是它（散人不能出陣，討伐靠這裡；地點易手之後
        那一路不站在這裡也找得到，Review Focus 5）；否則是這裡不是自己陣營的隊伍裡最弱的一路（同分取先列的）。都沒有是 None。"""
        s, c = self.state, self.content
        for b in bounties.mine(s, c):
            if b.kind == "strike" and b.location == loc.id and b.squad in c.squads and not self._drills_with(c.squads[b.squad]):
                return c.squads[b.squad]
        foes = self._wild_foes(loc)
        return min(foes, key=lambda foe: foe.difficulty) if foes else None

    def _gather_fight(self, loc: Location, rng: random.Random) -> list[str]:
        """撞上一場（設計 3.1）：照探索的野怪打（扣氣血減半、不問模型、不推大勢：_squad_encounter(wild=True)），打贏給全額的經驗、心得、
        銀兩、掉落，也算討伐懸賞的交差；打完 train_event_chance 接一則戰後事件（從遊歷搬過來，事件池照舊叫 train）。"""
        s, c = self.state, self.content
        squad = self._gather_foe(loc)
        if squad is None:
            return []
        msgs = [explore_modes.FOE_LINE.format(foe=squad.name)] + self._squad_encounter(squad.id, wild=True)
        record = next((r for r in s.battles if r.id == s.battle_card), None)
        if record is not None and record.tier in team.WIN_TIERS:
            msgs += bounties.on_win(s, c, self.world, loc.id, squad.id)
        if rng.random() < c.config.train_event_chance:
            event = pick_event(s, c, "train", rng)
            if event is not None:
                msgs += self._present(event, "train")
        return msgs

    def _seek(self, rng: random.Random) -> list[str]:
        """找事件（設計 3.2）：一次性奇遇先擲 rare_explore_chance，沒中照防重複輪替抽這裡可重複的事件；殘譜與半張鑄譜在這裡擲（_scrap_find）。
        事件推戰線的五折在 push_trend（source="event"）。"""
        s, c = self.state, self.content
        if event_candidates(s, c, "explore", "rare") and rng.random() < c.config.rare_explore_chance:
            msgs = self._present(pick_event(s, c, "explore", rng, "rare"), "explore")
        else:
            event = pick_event(s, c, "explore", rng, "common")
            msgs = self._present(event, "explore") if event is not None else [explore_modes.SEEK_NONE]
        return msgs + self._scrap_find()
```
