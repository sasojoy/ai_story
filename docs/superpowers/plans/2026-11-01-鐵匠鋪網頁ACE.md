# 鐵匠鋪與合成流程・網頁 A、C、E 批 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans（派工明講不開子代理，一個人照順序做）. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把設計稿第三節 3.1～3.5、第三之二節 3.6、3.8 的「網頁」那一半做進 `web/app.js`／`web/style.css`：作罷先問、灰格就地熬、爐火鈕、裝備庫併頁與批量拆解、預覽卡寫真意、品質的淬煉上限與磨得慢、神器頁。

**Architecture:** 主機側 B、D 兩批已經把資料給齊（`forge.furnace`、`_rack` 每列的 `repair`／`temper`／`into`／`tempers`、`grand_pct`、`temper_max`／`wear_note`、`smith_view.divine`），這三批只動網頁，**`tianxia/`、`server.py` 一行都不改**。鐵匠鋪還在 `app.js` 那一群（沒成包、不在搬包中），照手冊第十五節「修 bug 與小延伸改在原位」：畫法改在 `app.js` 原本那幾支函式旁邊；新加的樣式放 `style.css` 檔尾自己一段、字級一律 em（同酒肆、玉璽那一層；`tests/core/test_desktop_type.py` 只掃店面那一段，em 跟著電腦寬 `.shop-layer` 19.5px 自己放大 1.3 倍）。

**Tech Stack:** 原生 JS（沒有建置）、CSS；測試 `tests/kit/webharness.py`（node 跑整支 app.js 的假瀏覽器）、pytest；實機量測與截圖用無頭 Chromium＋CDP（`網頁.md`）。

**Spec:** `docs/superpowers/specs/2026-10-29-鐵匠鋪與合成流程-design.md`（第三節、三之二節的網頁那一半、第五節 A／C／E、第六節網頁那幾條、第八節、第十、十一節）；鍵名照 `docs/superpowers/handoff/2026-10-24-減法季主機側交接.md` 第〇之零節「進行中：鐵匠鋪」。

## Global Constraints

- 規則一字不改；網頁不自己判斷規則：按得下去與否、原因、小字一律照伺服器給的（`problem`、`why`、`use`、`short`、`left_text`、`odds`）。
- 新寫給玩家看的字標 `// 待 joy 潤`，列進設計稿第八節（PM 准加行）。
- `web/` 的字與註解不准出現「假人」「機器人」「bot」（`tests/bots/test_server_bots.py` 掃）。
- 顏色用 `:root` 變數或店面那一套固定暗底色；動畫照 `prefers-reduced-motion` 關掉；新 class 加前綴不撞名（`rk-`、`dv-`、`brew-`、`fu-`）。
- 375 寬：裝備庫一列不折到字中間（FB-297：字切成 `nbHtml` 小段、`.btn` 裡整段先包一個 span）、店面字級最低照 FB-305。
- 修練頁到輿圖那一段不用單字母變數 `x`；被別的 DRIVER 切出去的函式（`previewCardHtml` 在 `test_arts_pages` 的清單裡）不加新的 helper 呼叫。
- 不碰 `tianxia/features/*`、`tianxia/core/`、資料庫結構；不下載、不安裝；伺服器只用 8154、`smithweb.localhost`，模型網址指 `127.0.0.1:9`。

## Review Focus

1. **神器頁不能漏 5.10**：這一季輪到、還沒人打出、自己也沒打中過的那一件，畫出來的 HTML 裡不出現它的名字（網頁只畫伺服器給的；收藏冊沒打出過的格子 `id`、`name` 是 None，畫「？」）→ Task 7 用真的 `divine_view` 驗一次、再拿手寫的一份驗「？」不帶 data。
2. **批量拆解勾到後來不能拆的**（輪詢之後那一件不在了、或成了原品）：送出的只限現在列上 `into` 不是 None 的 → Task 4 `rackPicks` 照現在的列過濾，測一條「勾了之後那一件不見了」。
3. **灰格熬完、手上那一份爐子說法是舊的**：素材格改照 `forge.materials`（新的）畫，舊的 `S.shopLine` 沒有那一格時當放得進去，熬完再問一次 `/api/smith_line` → Task 2 測熬完的那一格變實格。
4. **銀兩出口關著**（`forge.furnace` 是 None）：爐火不可點、那一行不畫，打造頁跟現在一個字不差 → Task 3 測 None 時沒有 `shop-furnace`、HTML 跟改之前同一個函式吐的一樣。
5. **舊的 `S.shopTab === "temper"`**（網頁沒重新載入、手上記著舊分頁）：當裝備庫 → Task 4 測。
