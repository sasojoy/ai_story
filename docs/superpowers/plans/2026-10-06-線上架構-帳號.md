## 開工前企劃者要準備的東西（週末前做不到的原因）

**為什麼週末前做不到**：
- LINE、Google 登入要事先登記一個**固定的回傳網址**；
- trycloudflare 的臨時網址每次重開伺服器都會換，登記不了；
- 所以要先有自己的網域，再加上綁在網域上的 Cloudflare 具名 Tunnel；
- LINE、Google 兩邊的設定與審核也要時間。

程式可以先照這份計畫寫好、用假的登入服務測完。真的登入要等下面這張清單齊了才驗得了。

| # | 要準備的 | 怎麼做（大要） | 交給誰、放在哪 |
|---|---|---|---|
| 1 | **一個網域** | 在 Cloudflare 買最省事，一年約 NT$300～500【估】（線上架構設計第六節）。例如 `tianxia-game.com` | 告訴 PM 網域名稱 |

| 6 | **管理者用哪個登入** | 企劃者自己先用 LINE 或 Google 登入一次（要一組邀請碼），再用主機端腳本把管理者角色綁上去（Task 5） | 開服當天做 |

> **For agentic workers:** 上面那張清單是給企劃者的，實作者不碰任何外部帳號、不建任何 channel 或用戶端；測試一律用假的登入服務。

**Goal:** 封測的線上版只開 LINE 與 Google 登入。第一次登入要輸入一次邀請碼。帳號密碼登入在線上版關掉，只留在開發與測試環境。另外，給壓測一個只在測試環境開的登入後門。

**Architecture:**
- **帳號資料不改舊表**：`logins` 表本來就是「帳號上的登入方式」（provider, subject），LINE、Google 只是新的 provider。
- **帳號的代號**：
  - 帳號密碼照舊是小寫帳號；
  - LINE、Google 是 `line:<那邊的使用者編號>`、`google:<…>`。帳號密碼的帳號只能用英數字與底線，不會跟冒號撞。
- **邀請碼**：新增兩張表 `invites`、`invite_uses`，資料庫結構升一版。
- **`oauth.py`**（專案根目錄，用 `requests`）：組授權網址、拿授權碼換身分。身分驗證靠兩邊官方的驗證端點：
  - LINE：`/oauth2/v2.1/verify`；
  - Google：`tokeninfo`；
  - 不另裝 JWT 套件。
- **`server.py`**：
  - 加 `/auth/<服務>/start`、`/auth/<服務>/callback`、`/api/invite`；
  - `Config.password_login` 關掉時，帳號密碼的端點回 404；
  - cookie 在 https 時加 `Secure`。

**Tech Stack:** Python 3、`requests`（既有）、FastAPI（既有）、原生 JS，pytest。不加新套件。

**Spec:** `docs/superpowers/specs/2026-10-02-線上架構-design.md`：

## Global Constraints

- **不存個資**：只存「哪個登入服務＋那邊的使用者編號（subject）」；顯示名稱一律寫「LINE 使用者」「Google 使用者」，不存 email、不存對方的暱稱與頭像（設計第六節）。
- **密鑰不進 git**：
  - LINE、Google 的 client id／secret 與對外網址放在 `.local/oauth.json`（`.local/` 已經不進 git），或環境變數 `TIANXIA_OAUTH` 指的檔；
  - 測試用假的。
- **`tianxia/` 不 import 網頁框架、不讀時鐘**（CLAUDE.md）：
  - 帳號與邀請碼的讀寫在 `tianxia/accounts.py`、`tianxia/invites.py`，時間由呼叫端傳入；
  - 叫外部服務的 `oauth.py` 放專案根目錄。
- **資料庫結構升一版**：照 `tianxia/database.py` 檔頭寫的做法：新的一組句子、`MIGRATIONS[舊版]`、`SCHEMA_VERSION` 加一。
  - **開工前先問 PM 這一版的號碼**：武學計畫已經用了第 2 版，別的計畫可能也在排。
  - 舊檔要能升上來。
- **帳號不存在、邀請碼不對、名號被用掉**，各自回同一句話（帳號密碼登入設計第三節的精神）：
  - 邀請碼不論是打錯、用完還是根本沒有，都回「邀請碼不對，或已經用完了。」
- **假人不能被看出來**：假人沒有帳號（設計第六節），登入、邀請碼的任何訊息都不提假人。
- **測試用的登入後門**：
  - 只在環境變數 `TIANXIA_TEST_LOGIN=1` 時開；
  - 跟 OAuth 設定同時出現時，伺服器拒絕啟動，線上版不可能開著它（設計 9.1、9.3 第 5 條）。
- **cookie**：`HttpOnly`、`SameSite=Lax`，30 天；請求是 https 時加 `Secure`（看 `X-Forwarded-Proto`，因為 Cloudflare 到本機是 http）。
- 測試一律用暫存資料庫與假的登入服務；不連 LINE、Google；不碰 `saves/`、`.local/`、`C:\Ray\tianxia-play\`。

## Review Focus

1. **兩個分頁同時用同一組只剩一次的邀請碼**：只有一個成功，另一個拿到「邀請碼不對，或已經用完了。」，不能兩個都建出帳號。Task 1 一條測試。
2. **偽造或過期的登入回傳**：
   - 以下都要擋下，導回首頁顯示「登入沒有成功，請再試一次。」，不能建帳號、不能登入：
     - `state` 不對；
     - 超過 10 分鐘；
     - 同一個 `state` 用兩次；
     - 換身分失敗（例如 Google 的 `aud` 不是我們的 client id）。
   - Task 3、Task 4 各一條。
3. **同一個人第二次登入**：不再要邀請碼，直接進同一個帳號、同一個角色。Task 4 一條。
4. **線上版關掉帳號密碼登入**：`/api/login`、`/api/register`、`/api/password` 都回 404，登入頁不出現帳號密碼欄位；管理者幫人重設密碼的那一項也不出現。Task 4 一條。
5. **測試後門誤開在線上版**：OAuth 設定與 `TIANXIA_TEST_LOGIN=1` 同時出現，伺服器啟動就停下來、說明原因。Task 5 一條。

```python
"""邀請碼（線上架構設計第六節、3.2）：管理者產生、可設可用次數、記得被誰用掉。"""
import threading

from tianxia.database import open_database
from tianxia.invites import INVITE_BAD, InviteStore, normalize_code


def _account(db, created=0.0) -> int:
    with db.transaction() as conn:
        return conn.execute("INSERT INTO accounts (character, character_key, created) VALUES (NULL, NULL, ?)", (created,)).lastrowid


def test_codes_are_unique_readable_and_normalized(tmp_path):
    store = InviteStore(open_database(tmp_path / "t.db"))
    codes = store.create(20, uses=1, now=1.0)
    assert len(set(codes)) == 20
    assert all(len(c) == 8 and c.isalnum() and c.isupper() for c in codes)
    assert not any(ch in "".join(codes) for ch in "O0I1")  # 不收容易看錯的字
    assert normalize_code(f" {codes[0][:4].lower()}-{codes[0][4:]} ") == codes[0]


def test_redeem_counts_down_and_records_who(tmp_path):
    db = open_database(tmp_path / "t.db")
    store = InviteStore(db)
    code, = store.create(1, uses=2, now=1.0)
    a, b, c = _account(db), _account(db), _account(db)
    with db.transaction() as conn:
        assert store.redeem(conn, code, a, now=2.0)
        assert store.redeem(conn, code.lower(), b, now=3.0)
        assert not store.redeem(conn, code, c, now=4.0)  # 用完了
        assert not store.redeem(conn, "NOPE1234", c, now=4.0)  # 沒有這組
        used = [r[0] for r in conn.execute("SELECT account_id FROM invite_uses WHERE code = ? ORDER BY time", (code,))]
    assert used == [a, b] and store.remaining(code) == 0
    assert INVITE_BAD == "邀請碼不對，或已經用完了。"


def test_two_tabs_racing_for_the_last_use(tmp_path):
    """同一組只剩一次：兩個執行緒同時兌換，只有一個成功（Review Focus 1）。"""
    db = open_database(tmp_path / "t.db")
    store = InviteStore(db)
    code, = store.create(1, uses=1, now=1.0)
    ids = [_account(db), _account(db)]
    results = []

    def go(account_id):
        with db.transaction() as conn:
            results.append(store.redeem(conn, code, account_id, now=2.0))

    threads = [threading.Thread(target=go, args=(i,)) for i in ids]
    for t in threads:
        t.start()
    for t in threads:
        t.join(5)
    assert sorted(results) == [False, True]
```

```python
"""邀請碼（線上架構設計第六節、3.2）：封測期間，每個帳號第一次登入時輸入一次。管理者在主機上用腳本產生
（scripts/make_invites.py），可設可用次數；誰用了哪一組另記一列。正式上線時拿掉這一步。

兌換一定在呼叫端的交易裡做（建帳號那一筆）：扣次數用 UPDATE ... WHERE uses_left > 0，兩個請求同時兌換最後一次，
只有一個改得到那一列。時間由呼叫端傳入（引擎不讀時鐘）。"""
from __future__ import annotations

import secrets

from .database import Database

INVITE_BAD = "邀請碼不對，或已經用完了。"  # 打錯、用完、根本沒有：同一句話
ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"  # 拿掉 O 0 I 1，手抄、口述不會看錯
CODE_LENGTH = 8


def normalize_code(code: str | None) -> str:
    """玩家打的碼：去掉空白與連字號、轉大寫。"""
    return "".join(ch for ch in (code or "").upper() if ch.isalnum())


class InviteStore:
    def __init__(self, db: Database):
        self.db = db

    def create(self, count: int, uses: int, now: float, note: str = "") -> list[str]:
        codes: list[str] = []
        with self.db.transaction() as conn:
            while len(codes) < count:
                code = "".join(secrets.choice(ALPHABET) for _ in range(CODE_LENGTH))
                cur = conn.execute(
                    "INSERT OR IGNORE INTO invites (code, uses_left, uses_total, created, note) VALUES (?, ?, ?, ?, ?)",
                    (code, uses, uses, now, note),
                )
                if cur.rowcount == 1:
                    codes.append(code)
        return codes

    def redeem(self, conn, code: str, account_id: int, now: float) -> bool:
        """在呼叫端的交易裡兌換一次：扣得到就記下誰用的、回 True；打錯、用完、沒有這組回 False。"""
        key = normalize_code(code)
        cur = conn.execute("UPDATE invites SET uses_left = uses_left - 1 WHERE code = ? AND uses_left > 0", (key,))
        if cur.rowcount != 1:
            return False
        conn.execute("INSERT INTO invite_uses (code, account_id, time) VALUES (?, ?, ?)", (key, account_id, now))
        return True

    def remaining(self, code: str) -> int | None:
        with self.db.snapshot() as conn:
            row = conn.execute("SELECT uses_left FROM invites WHERE code = ?", (normalize_code(code),)).fetchone()
        return None if row is None else row[0]
```

```python
"""LINE、Google 登入（線上架構設計第六節）。

流程（OAuth 2.0 授權碼）：
1. /auth/<服務>/start 導去對方的授權頁，帶一個一次性的 state；
2. 對方導回 /auth/<服務>/callback?code=…&state=…；
3. 伺服器用授權碼換 id_token，再交給對方官方的驗證端點確認（LINE：/oauth2/v2.1/verify；Google：tokeninfo，並核對
   aud 是我們的 client id、iss 是 Google），拿到那邊的使用者編號 subject。
只留 subject，不存 email、暱稱、頭像（顯示名稱一律寫「LINE 使用者」「Google 使用者」）。不另裝 JWT 套件。

設定在 .local/oauth.json（或環境變數 TIANXIA_OAUTH 指的檔），不進 git；檔案不存在＝沒有任何第三方登入（開發環境）。
放在專案根目錄、不在 tianxia/：要叫外部服務。"""
from __future__ import annotations

import json
import os
import urllib.parse
from dataclasses import dataclass
from pathlib import Path

import requests

ROOT = Path(__file__).resolve().parent
CONFIG_ENV = "TIANXIA_OAUTH"
DEFAULT_CONFIG = ROOT / ".local" / "oauth.json"
TIMEOUT = 15
LINE_VERIFY = "https://api.line.me/oauth2/v2.1/verify"
GOOGLE_TOKENINFO = "https://oauth2.googleapis.com/tokeninfo"
GOOGLE_ISSUERS = ("accounts.google.com", "https://accounts.google.com")
ENDPOINTS = {  # 服務 → （按鈕上的字, 授權頁, 換 token 的端點, scope）
    "line": ("LINE", "https://access.line.me/oauth2/v2.1/authorize", "https://api.line.me/oauth2/v2.1/token", "openid profile"),
    "google": ("Google", "https://accounts.google.com/o/oauth2/v2/auth", "https://oauth2.googleapis.com/token", "openid"),
}


class OAuthError(Exception):
    """登入沒成功（對方拒絕、換不到 token、驗證不過）。訊息只寫進紀錄，不給玩家看細節。"""


@dataclass(frozen=True)
class Provider:
    name: str
    label: str
    client_id: str
    client_secret: str
    authorize_endpoint: str
    token_endpoint: str
    scope: str


def load_config(path: str | Path | None = None) -> tuple[str, dict[str, Provider]]:
    path = Path(path or os.environ.get(CONFIG_ENV) or DEFAULT_CONFIG)
    if not path.is_file():
        return "", {}
    raw = json.loads(path.read_text(encoding="utf-8"))
    base = str(raw.get("base_url", "")).rstrip("/")
    providers = {}
    for name, (label, authorize, token, scope) in ENDPOINTS.items():
        entry = raw.get(name) or {}
        if entry.get("client_id") and entry.get("client_secret"):
            providers[name] = Provider(name, label, entry["client_id"], entry["client_secret"], authorize, token, scope)
    return base, providers


def redirect_uri(base: str, provider: Provider) -> str:
    return f"{base}/auth/{provider.name}/callback"


def authorize_url(base: str, provider: Provider, state: str) -> str:
    query = {
        "response_type": "code", "client_id": provider.client_id, "redirect_uri": redirect_uri(base, provider),
        "state": state, "scope": provider.scope,
    }
    return f"{provider.authorize_endpoint}?{urllib.parse.urlencode(query)}"


def exchange(base: str, provider: Provider, code: str, http=requests) -> str:
    """授權碼換身分，回傳那邊的使用者編號（subject）。任何一步不對都丟 OAuthError。"""
    try:
        r = http.post(provider.token_endpoint, data={
            "grant_type": "authorization_code", "code": code, "redirect_uri": redirect_uri(base, provider),
            "client_id": provider.client_id, "client_secret": provider.client_secret,
        }, timeout=TIMEOUT)
        if r.status_code != 200 or not r.json().get("id_token"):
            raise OAuthError(f"{provider.name} 換 token 失敗：{r.status_code}")
        id_token = r.json()["id_token"]
        if provider.name == "line":
            v = http.post(LINE_VERIFY, data={"id_token": id_token, "client_id": provider.client_id}, timeout=TIMEOUT)
            claims = v.json() if v.status_code == 200 else {}
            if claims.get("aud") not in (None, provider.client_id):
                raise OAuthError("LINE 的 aud 不是我們的 channel")
        else:
            v = http.get(GOOGLE_TOKENINFO, params={"id_token": id_token}, timeout=TIMEOUT)
            claims = v.json() if v.status_code == 200 else {}
            if claims.get("aud") != provider.client_id or claims.get("iss") not in GOOGLE_ISSUERS:
                raise OAuthError("Google 的 aud／iss 不對")
        subject = claims.get("sub")
        if not subject:
            raise OAuthError(f"{provider.name} 驗證不過")
        return str(subject)
    except (requests.RequestException, ValueError, KeyError) as e:
        raise OAuthError(f"{provider.name} 連線或格式錯誤：{e!r}") from e
```

```python
def _https(request: Request) -> bool:

def _fresh(entries: dict, ttl: float) -> None:
    now = time.time()
    for key in [k for k, v in entries.items() if now - v[-1] > ttl]:

    if p is None:
        raise HTTPException(404)
    entry = STATES.pop(state, None)
    if error or not code or entry is None or entry[0] != provider or time.time() - entry[1] > STATE_SECONDS:
        return RedirectResponse("/?login_failed=1", status_code=302)
    try:
        subject = oauth.exchange(OAUTH_BASE, p, code)
    except oauth.OAuthError as e:
        print(f"第三方登入失敗：{e}", flush=True)
        return RedirectResponse("/?login_failed=1", status_code=302)
    key = account_key(provider, subject)
    if account_store().get(key) is not None:
        response = RedirectResponse("/", status_code=302)
        _start_session(response, key, request)
        return response
    _fresh(PENDING, STATE_SECONDS)
    token = secrets.token_urlsafe(24)
    PENDING[token] = (provider, subject, time.time())
    response = RedirectResponse("/?invite=1", status_code=302)
    response.set_cookie(PENDING_COOKIE, token, httponly=True, samesite="lax", max_age=STATE_SECONDS, secure=_https(request))
    return response


@app.post("/api/invite")
def api_invite(request: Request, response: Response, body: dict = Body(...)):
    pending = PENDING.get(request.cookies.get(PENDING_COOKIE, ""))
    if pending is None or time.time() - pending[2] > STATE_SECONDS:
        raise GameError("登入逾時了，請重新用 LINE 或 Google 登入一次。")
    try:
        key = account_store().create_with_login(pending[0], pending[1], str(body.get("code", "")), now=time.time())
    except AccountError as e:
        raise GameError(str(e)) from e
    PENDING.pop(request.cookies.get(PENDING_COOKIE, ""), None)
    response.delete_cookie(PENDING_COOKIE)
    _start_session(response, key, request)
    return _entry(key)
```
