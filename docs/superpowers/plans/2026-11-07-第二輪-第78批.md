## 二、條件（全部成立才回 `max-age=31536000, immutable`，其餘 `no-cache`）

照這個順序問，前面不成立就不讀檔：

1. `os.environ.get(PUBLIC_URL_ENV)` 是真值。寫法照 L1915、L2385（空字串算沒設）。**每個請求當場讀**，不存模組層，測試才 patch 得到。`PUBLIC_URL_ENV` 在 L2372，比 class 晚定義，呼叫時才解析，沒問題。
2. `path.lower()` 不在 `{"index.html", "sw.js"}`。`path` 是 StaticFiles 給的相對路徑，已經 normpath。`lower()` 是因為線上是 NTFS，大小寫不分。
3. 查詢字串整串等於 `v=<現在的內容雜湊>`：`scope.get("query_string", b"") == b"v=" + content_version((WEB / path).read_bytes()).encode()`。先看開頭是不是 `b"v="`，不是就不讀檔。不解析查詢字串：頁面產生的網址就只有這一種，`?v=H&x=1` 回 `no-cache`。

寫法的決定：

- 雜湊**每次當場算**，不用 `PAGE` 開機時算的那份，也不記憶。這是不把人釘死的關鍵：改了檔沒重開，舊網址的 `?v=` 對不上就回 `no-cache`；蓋上 immutable 的回應，內容一定等於網址上的雜湊。（D 波審查補：「對不上就回 no-cache」只對真的打到伺服器的請求成立。手機已存 immutable 不會再發請求、邊緣有存的不回源，所以設了 `TIANXIA_PUBLIC_URL` 的伺服器改 `web/` 一定要重開，`PAGE` 才換新網址。）Cloudflare 邊緣照查詢字串存，也不會存錯（D 波審查補：這句是假設，zone 的快取設定 repo 裡沒有紀錄；上線驗法多一行 `?v=0000000000` 要是 no-cache、不是 HIT，寫在主機端操作文件「固定網域」）。
- 成本：量到全部 63 支共 10.5 毫秒，最大一支（style.css，243 KB）0.25 毫秒，不必記憶。`get_response` 是 async，讀檔用 `run_in_threadpool`（L65 已 import），不擋事件圈。
- `super().get_response` 找不到檔會先丟 404，走不到這段，404 照舊沒有 Cache-Control（map 軌錄到 `null`）。
- 不動 `journal_css`（L1998）與 `manifest`（L2477）：它們是自己的路由，不經 `WebFiles`，派工單只准改 `get_response`。

順帶成立，不必另寫邏輯：

- **304 與 HEAD 也拿到長快取**。現況 304 就帶著這一行蓋的標頭（量過），所以已經快取舊標頭的手機再驗一次，瀏覽器就換成新標頭，上線不用換網址、不用清快取。部署後的 `curl -I` 也看得到。

## 四、兩條測試

用 L2570 那條同一個 `client`，雜湊用 L2549 的 `_version_of`（測試自己算，不拿 server 的函式比）。設環境變數寫 `monkeypatch.setenv(server.PUBLIC_URL_ENV, "https://tianxiadashi.com")`。

**第一條：條件都成立才是長快取**

- 設了環境變數：`/static/app.js?v=H`、`/static/style.css?v=H`、`/static/icon-180.png?v=H` 都是 200、`max-age=31536000, immutable`。
- 同一條：`client.head(...)` 一樣；帶 `If-None-Match`（ETag 取自第一次回應）是 304，也一樣。
- 網址從 `client.get("/").text` 抓第一支 `/static/app.js?v=...`，再比 `_version_of`，順便鎖住「頁面給的網址就是拿得到長快取的網址」。

**第二條：其餘照舊 no-cache（各打一次）**

- 設了環境變數：
  - `/static/app.js`（沒帶 `?v=`）
  - `/static/app.js?v=0000000000`（對不上）
  - `/static/app.js?v=H&x=1`（多帶參數）
  - `/`
  - `/admin`
  - `/sw.js`
  - `/static/sw.js?v=<sw.js 的雜湊>`
  - `/static/index.html?v=<index.html 的雜湊>`
  - `/journal.css?v=<雜湊>`
  - `/manifest.webmanifest?v=<雜湊>`
- 環境變數設成空字串、以及 `delenv`：`/static/app.js?v=H` 也是 `no-cache`。
- 每一個都先斷言 200，免得打到 404 也算過。
