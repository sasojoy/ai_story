# 決戰改版 4：武學的功效進決戰 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全服決戰讀武學的功效。八個一般功效、六個特別功效各對一件決戰自己的事（戰鬥系統 3.6 的表）。例：先手讓每一幕第一回合份量高一點，穩讓被剋時虧得少，護命一場一次留一口氣。

**Architecture:**
- **快照**：加入戰局時，由那個玩家自己的 `Game` 把身上兩門的功效換成數字，快照進 `BattleParticipant.traits`，照功效的 hook 記。跟份量的快照同一個時機、同一個理由：戰局結算只看共用戰鬥狀態，不能回頭讀別人的角色。
- **結算**：`resolve_round` 照 hook 讀這些數字。
  - 份量：破甲、先手、借力、厚。
  - 剋制：穩、險。
  - 扣血：化勁、不動、護命。
  - 回血：吸取、回春。
  - 放手一搏：連環。
- **畫面**：按鈕上的分數算進破甲與先手；「你上一回合」多寫這回合派上用場的功效。
- **參戰獎勵**：乘勝、悟招只快照、不在這份用，由決戰改版六接。

**Tech Stack:** Python 3、pydantic（`tianxia/`）、pytest。

**Spec:**
- `docs/superpowers/specs/2026-10-03-戰鬥系統-design.md` 3.6（數字【預設】，企劃者 2026-10-06「照這樣」）。
- `docs/superpowers/specs/2026-10-05-武學與成長-design.md` 第十三節。

## Global Constraints

- **只算本人身上那兩門**：層數乘品質倍數、套上限，照 `traits.amount`（武學與成長 13.1、13.2）。每層多少、上限多少都讀 `content/traits.json`，3.6 的數字跟它一致。
- **快照時機**：加入戰局時快照，加入之後換武學不影響這一場（3.6 最後一條）。
- **一般功效在決戰的用法**（括號是 hook）：
  - 先手（`big_win`）：每一幕的第一回合，份量 ×（1 ＋ 先手）。
  - 破甲（`difficulty_cut`）：份量 ×（1 ＋ 破甲）。跟先手相加，不相乘。
  - 穩（`luck_narrow`）：剋制係數低於 1 的那一段 ×（1 − 穩）。只動份量，扣血照原本的係數。
  - 險（`luck_widen`）：剋制係數高於 1 的那一段 ×（1 ＋ 險）。只動份量。
  - 化勁（`toll_cut`）：這一回合扣的氣血 ×（1 − 化勁），固定招與放手一搏都算。
  - 吸取（`win_heal`）：自己這邊這一回合往前推時，回氣血上限 × 吸取。
  - 厚（`condition_floor`）：氣血狀態的下限 ＋ 厚，份量也乘氣血狀態。
  - 乘勝（`win_reward`）：只快照，決戰改版六用。
- **特別功效在決戰的用法**：
  - 連環（`double_luck`）：放手一搏擲兩次，取好的那次。
  - 不動（`no_injury`）：被剋時扣的氣血不加重，（2 − 係數）最多算 1。
  - 護命（`no_loss`）：一場一次，氣血歸零時留 1 點、不倒下。
  - 借力（`power_from_difficulty`）：份量 ＋ 借力 × 對面這回合的平均份量。
  - 回春（`heal_after`）：每回合回氣血上限 × 回春。
  - 悟招（`win_xinde`）：只快照，決戰改版六用。
  - 輕身：決戰裡沒作用。
  - 名將本命絕學的獨特特別功效：hook 不在上面的，一律不作用；等劇情寫本命絕學時再談。
- **回氣血**：回到這一場的氣血上限為止，只在這一場裡，不回到角色身上（3.6）。這一回合倒下的人不回。
- **舊資料**：沒有 `traits` 的參戰者等於沒有功效，照常打。
- 數字全由規則引擎決定，全部【預設】。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

## Review Focus

1. **護命只有一次**：第二次歸零就照常倒下。→ Task 2 `test_last_breath_saves_once_per_battle`。
2. **穩帶滿也翻不了盤**：被剋的係數再怎麼拉也到不了 1 以上；險不碰被剋的那一段。→ Task 1 `test_steady_and_daring_bend_only_their_side_of_the_counter`。
3. **回血不超過上限**：快滿血的人吸取加回春，回到上限為止。→ Task 2 `test_heals_stop_at_the_cap`。

5. **舊資料**：存在資料庫裡、沒有 `traits` 欄的參戰者讀得進來，打起來跟沒功效一樣。→ Task 1 `test_old_fighters_without_traits_still_load`。

```python
def battle_snapshot(content: Content, lo: Loadout) -> dict[str, float]:
    """全服決戰要的功效數字（戰鬥系統 3.6）：一般功效照 hook 記 amount（每層 × 層數，套上限），特別功效照 hook 記它的 amount。
    決戰的戰局只看共用戰鬥狀態、不能回頭讀角色，所以加入戰局時由那個玩家自己的 Game 快照這一份（engine._battle_traits）。"""
    out = {t.hook: amount(content, lo, t.hook) for t in content.traits.general if lo.layers.get(t.hook)}
    out.update({hook: sp.amount for hook, sp in lo.specials.items()})
    return out
```

```python
def condition(p: BattleParticipant) -> float:
    """這一場的氣血狀態（戰鬥系統 3.4）：同遭遇戰，見底時五成；帶【厚】的下限再高一點（3.6）。"""
    return encounter.condition_of(p.neili, p.neili_cap, floor=encounter.CONDITION_FLOOR + p.traits.get(STURDY, 0.0))
```

新增：

```python
def is_opening(instance: BattleInstance, definition: BattleDef) -> bool:
    """正要結算的是不是某一幕的第一回合（先手，戰鬥系統 3.6）；round_number 是已經結算了幾回合。"""
    return instance.round_number % definition.rounds_per_act == 0


def own_share(p: BattleParticipant, move: str, opening: bool) -> float:
    """這個人這一招自己的份量（剋制之前）：快照的份量 × 氣血狀態 ×（1 ＋ 破甲 ＋ 這一幕第一回合的先手）（戰鬥系統 3.4、3.6）。
    按鈕上的分數也是這個數字。"""
    bonus = p.traits.get(PIERCE, 0.0) + (p.traits.get(OPENING, 0.0) if opening else 0.0)
    return p.scores.get(move, 0.0) * condition(p) * (1 + bonus)


def trait_coef(p: BattleParticipant, coef: float) -> float:
    """穩、險改的是算份量用的剋制係數（戰鬥系統 3.6）：被剋（低於 1）的那一段 ×（1 − 穩），剋到人（高於 1）的那一段 ×（1 ＋ 險）。
    穩最多六成，所以被剋的再怎麼拉也到不了 1。扣氣血照原本的係數（被剋時少扣的是不動）。"""
    if coef < 1:
        return 1 - (1 - coef) * (1 - p.traits.get(STEADY, 0.0))
    return 1 + (coef - 1) * (1 + p.traits.get(DARING, 0.0))
```

```python
兩邊各 20 人，威力從新手到高手之間抽，屬性隨機。七成出拿手招、兩成亂出、一成放手一搏（成功率 50，招照拿手的）。

印收場戰局的中位數與官軍倒下幾人，跟「兩邊都沒有功效」那一行比。

用法：.venv/Scripts/python.exe scripts/measure_battle_traits.py
"""
from __future__ import annotations

import io
import random
import statistics
import sys
from pathlib import Path

from tianxia.content import load_content  # noqa: E402
from tianxia.models import MOVES  # noqa: E402

ATTRS = ("剛", "實", "陽", "柔", "陰", "慢", "快", "虛")
CODES = {"強攻": "strong", "固守": "hold", "奇襲": "raid"}


def run(definition, tuning, perk, seed):
    rng = random.Random(seed)
    battle = bi.start_muster(definition, now=0)
    for side in ("guan", "huang"):
        for i in range(20):
            power = rng.uniform(0, 150)
            scores = bi.move_scores(tuning, power, rng.choice(ATTRS), rng.choice(ATTRS))
            bi.join_faction(battle, f"{side}{i}", side, neili_cap=400, power=power, scores=scores,
                            traits=perk if side == "guan" else None)
    bi.close_muster(battle, definition, rng, now=0)
    while battle.phase == "active":
        act = bi.current_act(battle, definition)
        for name, p in battle.participants.items():
            if p.eliminated:
                continue
            best = max(MOVES, key=lambda m: p.scores[m])
            pick = rng.random()
            reckless = next((o.tag for o in act.options if o.free_text and o.faction in (None, p.faction)), None)
            if pick < 0.1 and reckless:
                bi.submit_action(battle, name, reckless, text="放手一搏", success_rate=50, move=best)
            else:
                move = best if pick < 0.8 else rng.choice(MOVES)
                bi.submit_action(battle, name, f"{p.faction}_{CODES[move]}")
        bi.resolve_round(battle, definition, rng, now=0, tuning=tuning)
    fallen = sum(p.eliminated for p in battle.participants.values() if p.faction == "guan")
    return battle.trend, fallen

    perks |= {t.name: {t.hook: t.amount} for t in content.traits.special if t.pool}
    for label, perk in perks.items():
        ends = [run(definition, tuning, perk, seed) for seed in range(20)]
        print(f"{label}：收場戰局中位 {statistics.median(t for t, _ in ends)}，"
              f"官軍倒下中位 {statistics.median(f for _, f in ends)}")


if __name__ == "__main__":
```

## 計畫裡的決定（設計沒寫死、這份替實作選的）

| 題目 | 這份的做法 | 理由 |
|---|---|---|
| 快照記什麼 | 照 hook 記數字（已套上限） | 戰局結算不能讀內容與角色；hook 是程式裡穩定的名字，功效的顯示名稱可能被改 |
| 先手與破甲同時有 | 相加：×（1 ＋ 破甲 ＋ 先手） | 兩個都是「份量 +x%」，相加比相乘好懂 |
| 穩、險改的係數算不算進扣血 | 不算，扣血照原本的係數 | 3.6 寫的是「份量打折少」；被剋時少扣血是不動的事，兩個功效不重疊 |
| 借力的「對面平均份量」 | 對面這回合每個出手的人的份量（剋制、功效加過；借力、放手一搏倍數之前）的平均 | 要先算一輪才知道；不含倍數，免得一個人賭贏就讓對面整排借到大力 |
