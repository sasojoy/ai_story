# 裝備（第一批：四欄化＋防具現成）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兵器的 `Weapon` 泛化成四欄的 `Equipment`（武器、防具、坐騎、寶物共用 100 格裝備庫，每個讀裝備庫的地方照欄位過濾、舊存檔照讀）；做好防具的現成部分：一場仗少扣的氣血與內傷（跟化勁合計最多 60%）、截殺輸的一方只吃防具、耐久與修、鐵匠鋪分「兵器」「防具」兩頁與架上四件、拆解、角色卡與修練頁「裝備」的武器、防具兩段；整季機器人與伺服器假人會買、修、換防具。

**Architecture:** 新模組 `tianxia/equipment.py` 放跟欄位內容無關的部分（欄位表 `SLOTS`、各欄開著沒、裝備庫裡某一欄的、滿了沒、拿到新東西放哪、換上、拆解的共用流程與問句、階品寫法、鐵匠鋪開不開門與停在哪一頁）；它只 import `insights`、`materials`、`models`、`state`，不 import `weapons`、`armor`、`team`、`rules`。新模組 `tianxia/armor.py` 放防具自己的（減損、耐久、架上四件、買、修、換、拆、機器人該按哪一顆、修練頁每一列、角色卡那一行）；它只 import `models`、`state`、`martial_arts`、`equipment`，身上那門內功由呼叫端解好再傳進來（`team.armor_cut`、`skillview`、`bot`），跟 `weapons` 拿武學的做法一樣。`weapons.py` 原本的共用部分搬進 `equipment`、原名照留（re-export），`store`／`rack_full`／`wield`／`dismantle` 改成轉呼叫 `equipment`、只看武器那一欄，所以兵器第二批的 `smithing` 幾乎不用動。import 只有一個方向：`skillview`、`team`、`engine`、`bot` → `weapons`／`armor` → `equipment`。修練頁四段的資料由 `skillview.gear_rows` 組，`server.menxia_view` 只轉成 JSON（`gear` 這個鍵取代 `weapons`）。全部在角色 JSON 裡，**資料庫不升版**。

**Tech Stack:** Python 3.12、pydantic、SQLite（不動結構）、pytest（`-n auto`）、原生 JavaScript 網頁（`web/app.js`、node 假瀏覽器測試）。

**Spec:** `docs/superpowers/specs/2026-10-10-裝備四欄-design.md`（企劃者 2026-10-10 審過）：第二節 2.2、2.3、2.5、2.6 跟武器、防具有關的部分；第三節；第四節（4.7 防具打造除外）；第九節防具那幾條；第十節量表的防具那一項；第十一節「裝備一」。另照兵器第二批計畫 `docs/superpowers/plans/2026-10-10-兵器-2-自己打造.md`「先後」一節列給裝備一的第 1～3 條（第 4 條防具打造不在這一批）。

## 範圍與取捨

- **做**：第三節資料形狀（`Equipment`、`PlayerState.armor`、舊存檔、照欄位過濾、`equipment.py`／`armor.py` 分工）；第四節防具（4.1～4.6、4.8、4.9）；2.2、2.3、2.5（武器、防具兩段）、2.6；第九節防具；第十節防具那一項；兵器第二批「先後」第 1～3 條（FB-125 的排版與問句照搬、`smithing` 讀裝備庫只看武器欄、修練頁武器段帶淬煉與配方）。第 3 條「防具那一段也用得上 tempers、recipe」這一批只做到一半：防具不能淬、不能打，`armor._row` 先送 `tempers`（這一批一直是 0，`cut` 已經算進去），**不送 `recipe`**，網頁的 `armorRow` 兩樣都不畫；防具段的「淬煉 N/5」「配方」等防具打造那一批再接（照武器列的寫法，值是 0 或沒有時不畫）。

- **PlayerState 這一批只加 `armor`、`armor_warned`、`smith_page`**；`Equipment.slot` 的 Literal 先把四種值寫齊（`weapon`、`armor`、`mount`、`treasure`）。坐騎、寶物的欄位（`mount`、`treasure`、`hunger_warned`、`picking_market`、`treasure_day`、`treasure_drops`、`held_gear`、`Equipment.template`、`Journey.pace`）等裝備二、三各自加。理由：
  1. `equipment.SLOTS` 只列 `weapon`、`armor`，`on()` 對表外的欄位回 False：裝備庫裡混進坐騎、寶物時它們不列、不能換、不能拆——這正是設計 3.3 要的「混了四欄」那支測試；Literal 寫齊才建得出坐騎與寶物來測，不必先有 `PlayerState.mount`。
  2. 現在加 `mount`、`treasure` 欄位，`Config` 卻還沒有 `mounts`、`treasures`，`on()` 得特別處理，只會多出永遠回 False 的死碼與一直是 None 的存檔欄位。
  3. pydantic 讀舊存檔時缺的欄位自動補預設值：裝備二只要在 `SLOTS` 加一列、`PlayerState` 加一個欄位、`Config` 加一組，不必回頭改 `equipment` 的共用函式，也不必寫遷移。晚一批加，也少一批「部署退回舊程式會丟欄位」的東西。

```python
    return entry is not None and getattr(content.config, entry.rules).enabled


def worn(p: PlayerState, slot: str) -> Equipment | None:
    """身上這一欄那一件；表外的欄位是 None。"""
    return getattr(p, slot) if slot in SLOTS else None


def in_slot(p: PlayerState, slot: str) -> list[Equipment]:
    """裝備庫裡這一欄的（照放進去的先後）。3.3：每個讀裝備庫的地方都照欄位過濾，不要直接讀 p.rack。"""
    return [item for item in p.rack if item.slot == slot]


def in_town(state: GameState, content: Content) -> bool:
    """人不在路上、所在地點有「城鎮」標籤（有鐵匠鋪的地方，兵器設計 4.1）。"""
    if state.player.journey is not None:
        return False
    return TOWN_TAG in (content.locations[state.player.location].tags or [])


def rack_full(state: GameState, content: Content, slot: str) -> bool:
    """這一欄身上有東西、裝備庫（四欄合算）也滿了，就放不下（2.2；這一欄空著的話新的直接穿上，用不到裝備庫）。"""
    return worn(state.player, slot) is not None and len(state.player.rack) >= content.config.weapons.rack_cap


def next_id(state: GameState, slot: str) -> str:
    """新的一件的 id（流水號 +1；四欄共用 weapon_serial，舊的「兵:N」不重編）。"""
    state.player.weapon_serial += 1
    return f"{SLOTS[slot].prefix}:{state.player.weapon_serial}"


def store(state: GameState, item: Equipment) -> str:
    """拿到一件（2.2）：這一欄身上空著就穿上（重設這一欄的提醒：穿上的是另一件），不然放進裝備庫（呼叫端先用 rack_full 擋）。"""
    p = state.player
    entry = SLOTS[item.slot]
    if worn(p, item.slot) is None:
        setattr(p, item.slot, item)
        setattr(p, entry.warned, False)
        return entry.put_on.format(name=item.name)
    p.rack.append(item)
    return STORED.format(name=item.name)


def _find(p: PlayerState, item_id: str, slots: tuple[str, ...]) -> Equipment | None:
    return next((item for item in p.rack if item.id == item_id and item.slot in slots), None)


def wield(state: GameState, content: Content, item_id: str, slots: tuple[str, ...]) -> list[str]:
    """換上（2.3）：裝備庫裡 slots 這幾欄的一件換到身上它自己那一欄，身上原本那件放回裝備庫（空著就直接穿上）；重設那一欄的提醒。
    不花體力、不看人在做什麼。先照 id 找、再看那一欄開著沒：找到了而那一欄關著、或 slots 裡一欄都沒開著，是 NOT_NOW；
    開著的欄位裡找不到是 WIELD_MISSING（表外的坐騎、寶物也是找不到）。"""
    p = state.player
    chosen = _find(p, item_id, slots)
    if chosen is None:
        return [WIELD_MISSING if any(on(content, slot) for slot in slots) else NOT_NOW]
    if not on(content, chosen.slot):
        return [NOT_NOW]
    p.rack.remove(chosen)
    current = worn(p, chosen.slot)
    if current is not None:
        p.rack.append(current)
    setattr(p, chosen.slot, chosen)
    setattr(p, SLOTS[chosen.slot].warned, False)  # 換上來的是另一件：磨損低了要有它自己的提醒
    return [WIELDED.format(name=chosen.name)]


def grade(item: Equipment) -> str:
    """「一階下品」：階＋品質（FB-127：修練頁的裝備庫每列都要寫）。"""
    return f"{TIER_WORDS.get(item.tier, '')}{item.quality}"


def dismantle_material(content: Content, item: Equipment) -> Material:
    """拆一件拿到的素材（兵器設計 4.7.1、裝備四欄 4.8）：同階；屬性剛柔快慢直接對，陰陽虛實是兩個屬性合出來的
    （insights.PAIR_ATTRIBUTES），從兩個來源裡挑一個，由 id 的 sha256 決定（同一件永遠拆出同一種；演算法不能改，不然舊兵器拆出來的會變）。
    該階該屬性沒有素材時 by_tier 退回同階的全部。"""
    attribute = item.attribute
    sources = next((sorted(pair) for pair, result in PAIR_ATTRIBUTES.items() if result == attribute), None)
    if sources is not None:
        attribute = sources[hashlib.sha256(item.id.encode("utf-8")).digest()[0] % 2]
    return (by_tier(content, item.tier, attribute) or by_tier(content, 1, attribute) or list(content.materials.values()))[0]


def dismantle_order(item: Equipment) -> tuple[int, int, str]:
    """可拆的排前面的是磨損最多的，再來階數低的，最後照 id 求穩定（4.7.1）。"""
    return (item.edge, item.tier, item.id)


def dismantle_confirm(content: Content, item: Equipment) -> str:
    """拆解之前問的那一句（FB-125，企劃者 2026-10-10 第二批附帶決定 a）：修練頁與鐵匠鋪同一句，寫明拆出什麼。"""
    return DISMANTLE_ASK.format(name=item.name, grade=grade(item), material=dismantle_material(content, item).name)


def dismantle(state: GameState, content: Content, item_id: str, slots: tuple[str, ...]) -> list[str]:
    """拆解（兵器設計 4.7.1、裝備四欄 4.8）：裝備庫裡 slots 這幾欄的一件拆掉，換一個素材。不花銀兩、不花體力、不必在鐵匠鋪；
    網頁先問一次（FB-125），引擎收到就拆。坐騎、寶物不在 DISMANTLABLE 裡，一開頭就濾掉（寶物的 attribute 是空字串，
    丟進 dismantle_material 會硬拆出東西）。身上那件不在裝備庫裡，找不到。拒絕的順序同 wield。"""
    p = state.player
    slots = tuple(slot for slot in slots if slot in DISMANTLABLE)
    chosen = _find(p, item_id, slots)
    if chosen is None:
        return [DISMANTLE_MISSING if any(on(content, slot) for slot in slots) else NOT_NOW]
    if not on(content, chosen.slot):
        return [NOT_NOW]
    material = dismantle_material(content, chosen)
    p.rack.remove(chosen)
    p.materials[material.id] = p.materials.get(material.id, 0) + 1
    return [f"{DISMANTLE_PREFIX}【{chosen.name}】，拆出了{material.name}×1。"]


def repair_material(state: GameState, content: Content) -> str | None:
    """修要用的一階素材（武器、防具一樣）：背包裡數量最多的那一種（同數照 id），沒有是 None。"""
    held = [(n, mid) for mid, n in state.player.materials.items() if n > 0 and mid in content.materials and content.materials[mid].tier == 1]
    return max(held, key=lambda pair: (pair[0], pair[1]))[1] if held else None
```

```python
"""防具（docs/superpowers/specs/2026-10-10-裝備四欄-design.md 第四節；裝備一）：一場仗少扣的氣血與內傷、耐久、鐵匠鋪架上四件、
修、換、拆、機器人該按哪一顆、修練頁每一列與角色卡那一行。

只 import models、state、martial_arts、equipment；team 反過來呼叫它（take_encounter_toll、toll_saved、Game._raid_spoils 都經
team.armor_cut），所以這裡不 import team 或 rules——身上那門內功由呼叫端解好（team.player_art）再傳進來，同 weapons 拿武學的做法。
防具不從打仗掉（4.9）；打造與淬煉是之後的「防具打造」那一批（tempers 先算進減損，那一批不必回頭改 cut）。
"""
from __future__ import annotations

from . import equipment
from .equipment import NO_REPAIR_MATERIAL, NOT_HERE, RACK_FULL, grade, repair_material
from .martial_arts import MartialArt, counters
from .models import Content
from .state import Equipment, GameState

SHOP_ATTRIBUTES = ("剛", "柔", "快", "慢")  # 4.6：架上照屬性擺四件、不分種類；陰陽虛實要等防具打造
SHOP_NAMES = {"剛": "鐵葉甲", "柔": "軟皮甲", "快": "輕綃衫", "慢": "厚氈袍"}  # 待 joy 潤（都過了 naming.name_problem）
WEAR_WORD = equipment.WEAR_WORDS["armor"]  # 「耐久度」：角色卡、修練頁每一列（_row 的 wear_word）、鐵匠鋪修與換上兩顆鈕都讀這個，不寫死（3.1、2.5）
WORN_WARNING = "你的{name}破了好幾處，找間鐵匠鋪補一補。"  # 待 joy 潤（4.5）
EMPTY = "身上沒有防具。"  # 待 joy 潤：修練頁防具那一段身上空著
RACK_NOTE = "城裡的鐵匠鋪買得到、修得好；用不上的拆了換素材。"  # 待 joy 潤：修練頁防具那一段底下
NO_ARMOR = "身上沒有防具"  # 待 joy 潤：修鈕灰掉時的原因
NO_SUCH = "沒有這一件"  # 待 joy 潤：買架上沒有的屬性（舊分頁、手改的 id）
INTACT = "還很完好"  # 待 joy 潤：耐久滿的不用修
MATCH_NOTE = "跟你的內功同屬性"  # 待 joy 潤
CLASH_NOTE = "跟你的內功相剋"  # 待 joy 潤
BUY = "smith:armor-buy:"
REPAIR = "smith:armor-repair"
REPAIR_AT = 50  # 機器人與假人耐久低到這裡以下才修（同 weapons.REPAIR_AT）


def _match(attribute: str, neigong: MartialArt | None) -> int:
    """對上內功（4.2）：同屬性 +1、相剋（ATTRIBUTE_COUNTERS 兩個方向都查）−1、其餘或沒有內功 0。"""
    if neigong is None or not attribute:
        return 0
    if attribute == neigong.attribute:
        return 1
    return -1 if counters(attribute, neigong.attribute) or counters(neigong.attribute, attribute) else 0


def edge_factor(content: Content, item: Equipment) -> float:
    """耐久度係數（4.1）：全壞剩 edge_floor，滿的是 1。"""
    floor = content.config.armor.edge_floor
    return floor + (1 - floor) * max(0, min(100, item.edge)) / 100


def cut(item: Equipment | None, neigong: MartialArt | None, content: Content) -> float:
    """這件防具現在一場少扣幾成氣血（4.1）：（階＋品質＋淬煉＋對上內功）夾在 0 以上，再乘耐久度係數。開關關著、沒穿、
    不是防具那一欄的是 0。每次現算、不快取：換了內功、修了、破了，下一場就照新的算。內傷是扣掉的量的固定幾成，所以同比例跟著少。"""
    rule = content.config.armor
    if not rule.enabled or item is None or item.slot != "armor":
        return 0.0
    base = rule.tier_cut.get(str(item.tier), 0.0) + rule.quality_cut.get(item.quality, 0.0) + rule.temper_step * item.tempers
    base += rule.match * _match(item.attribute, neigong)
    return max(0.0, base) * edge_factor(content, item)


def fresh_cut(item: Equipment | None, neigong: MartialArt | None, content: Content) -> float:
    """修好之後（耐久 100）的減損：機器人比較兩件防具用這個，不然破一點的好防具會被當成比較差的。"""
    return cut(item.model_copy(update={"edge": 100}), neigong, content) if item is not None else 0.0


def wears(kind: str, tier: str) -> bool:
    """這一場磨不磨防具（4.5）：遊歷、探索野怪磨；截殺只有落敗的那一邊磨（截殺只有輸的挨打，4.4）。挑戰大勢人物本人的戰報 kind 是
    event，由 Game._challenge 明說要磨（_file_battle 的 armor_wear）；切磋、頭目戰、劇情戰都不磨；全服決戰不走 _file_battle。"""
    return kind in ("train", "wild") or (kind == "raid" and tier == "落敗")


def wear(state: GameState, content: Content, tier: str) -> list[str]:
    """打完一場，身上那件扣耐久度（4.5，照結果）；第一次低到 edge_warn 以下回一句提醒（只一次，修好或換一件才重設）。"""
    rule, p = content.config.armor, state.player
    if not rule.enabled or p.armor is None:
        return []
    p.armor.edge = max(0, p.armor.edge - rule.wear.get(tier, 0))
    if p.armor.edge < rule.edge_warn and not p.armor_warned:
        p.armor_warned = True
        return [WORN_WARNING.format(name=p.armor.name)]
    return []


# ---- 鐵匠鋪的防具頁（4.6）：買、修、換、拆 ----

def smith_here(state: GameState, content: Content) -> bool:
    """這裡買得到、修得了防具：防具開著、人在城鎮。"""
    return equipment.on(content, "armor") and equipment.in_town(state, content)


def shop_item(attribute: str) -> Equipment:
    """架上那一件（還沒買，id 是「架:屬性」）：一階下品。鐵匠鋪的「買」鈕寫它的減損、機器人比較用。"""
    return Equipment(id=f"架:{attribute}", slot="armor", name=SHOP_NAMES[attribute], attribute=attribute, tier=1, quality="下品")


def new_armor(state: GameState, *, name: str, attribute: str, tier: int, quality: str) -> Equipment:
    """新的一件（四欄共用的流水號 +1，id「甲:N」）。"""
    return Equipment(id=equipment.next_id(state, "armor"), slot="armor", name=name, attribute=attribute, tier=tier, quality=quality)


def rack_full(state: GameState, content: Content) -> bool:
    return equipment.rack_full(state, content, "armor")


def buy_problem(state: GameState, content: Content, attribute: str) -> str | None:
    if not smith_here(state, content):
        return NOT_HERE  # 鐵匠鋪的選單關了、人走了：引擎層自己也再驗一次
    if attribute not in SHOP_ATTRIBUTES:
        return NO_SUCH
    if rack_full(state, content):
        return RACK_FULL
    short = content.config.armor.shop_price - state.player.stats.get("silver", 0)
    return f"還差 {short} 兩" if short > 0 else None


def buy(state: GameState, content: Content, attribute: str) -> list[str]:
    problem = buy_problem(state, content, attribute)
    if problem is not None:
        return [f"（{problem}。）"]
    price = content.config.armor.shop_price
    state.player.stats["silver"] -= price
    item = new_armor(state, name=SHOP_NAMES[attribute], attribute=attribute, tier=1, quality="下品")
    return [f"你花 {price} 兩買下一件【{item.name}】。", equipment.store(state, item)]  # 待 joy 潤


def repair_problem(state: GameState, content: Content) -> str | None:
    p, rule = state.player, content.config.armor
    if not smith_here(state, content):
        return NOT_HERE
    if p.armor is None:
        return NO_ARMOR
    if p.armor.edge >= 100:
        return INTACT
    if repair_material(state, content) is None:
        return NO_REPAIR_MATERIAL
    short = rule.repair_silver - p.stats.get("silver", 0)
    return f"還差 {short} 兩" if short > 0 else None


def repair(state: GameState, content: Content) -> list[str]:
    """修（4.5）：一個一階素材（屬性不限）＋工錢，耐久度回滿。只能在鐵匠鋪。"""
    problem = repair_problem(state, content)
    if problem is not None:
        return [f"（{problem}。）"]
    p, rule = state.player, content.config.armor
    material = repair_material(state, content)
    p.materials[material] -= 1
    if not p.materials[material]:
        del p.materials[material]
    p.stats["silver"] -= rule.repair_silver
    p.armor.edge, p.armor_warned = 100, False
    return [f"鐵匠拿{content.materials[material].name}把【{p.armor.name}】補好了（銀兩 -{rule.repair_silver}）。"]  # 待 joy 潤


def wield(state: GameState, content: Content, item_id: str) -> list[str]:
    """鐵匠鋪防具頁的「換上」：只看防具那一欄。"""
    return equipment.wield(state, content, item_id, ("armor",))


def dismantle(state: GameState, content: Content, item_id: str) -> list[str]:
    """鐵匠鋪防具頁的「拆解」（4.8）：只看防具那一欄。"""
    return equipment.dismantle(state, content, item_id, ("armor",))


def _shop_pick(neigong: MartialArt | None) -> str:
    """機器人買哪一件（第九節）：跟內功同屬性的；架上沒有（陰陽虛實的內功、沒有內功）就挑第一件不相剋的（照 SHOP_ATTRIBUTES 的順序，
    每次挑同一件）。架上四件都不剋陰陽虛實，所以一定挑得到。"""
    if neigong is not None and neigong.attribute in SHOP_ATTRIBUTES:
        return neigong.attribute
    return next(a for a in SHOP_ATTRIBUTES if _match(a, neigong) >= 0)


def wanted(state: GameState, content: Content, neigong: MartialArt | None) -> str | None:
    """在鐵匠鋪防具頁最該按的那一顆（整季機器人與伺服器假人共用，裝備四欄設計第九節）：裝備庫裡有比身上好的就換上；再來架上那一件
    （_shop_pick）比身上的好就買（身上空著、或身上那件被內功剋）；再來耐久低於 REPAIR_AT 就修。比的是修好之後的減損（fresh_cut），
    身上那件跟架上一樣好就不買。不在鐵匠鋪或防具關著是 None。拆解不在這裡（機器人與假人不拆）。"""
    if not smith_here(state, content):
        return None
    p = state.player
    now = fresh_cut(p.armor, neigong, content)
    best = max(equipment.in_slot(p, "armor"), key=lambda a: (fresh_cut(a, neigong, content), a.id), default=None)
    if best is not None and fresh_cut(best, neigong, content) > now + 1e-9:
        return f"smith:wield:{best.id}"
    pick = _shop_pick(neigong)
    if fresh_cut(shop_item(pick), neigong, content) > now + 1e-9 and buy_problem(state, content, pick) is None:
        return f"{BUY}{pick}"
    if p.armor is not None and p.armor.edge < REPAIR_AT and repair_problem(state, content) is None:
        return REPAIR
    return None


# ---- 看得到（2.5）：修練頁每一列、角色卡那一行 ----

def pct(ratio: float) -> str:
    """減損寫成整數百分比（設計 2.5 的例子：8.1% 寫 8%）。"""
    return f"{ratio:.0%}"


def fit_note(item: Equipment, neigong: MartialArt | None) -> str:
    """對上內功那一句：同屬性、相剋各一句，其餘是空字串。"""
    m = _match(item.attribute, neigong)
    return MATCH_NOTE if m > 0 else CLASH_NOTE if m < 0 else ""


def _row(item: Equipment, neigong: MartialArt | None, content: Content, worn: bool = False) -> dict:
    return {
        "id": item.id, "name": item.name, "attribute": item.attribute, "tier": item.tier, "quality": item.quality,
        "grade": grade(item), "edge": item.edge, "wear_word": WEAR_WORD,  # 網頁照這個字寫「耐久度 N」（3.1 的字表，不在網頁寫死）
        "cut": pct(cut(item, neigong, content)), "fit": fit_note(item, neigong),
        "tempers": item.tempers,  # 這一批一直是 0、網頁不畫；「淬煉 N/5」與 recipe 欄等防具打造那一批再接
        "confirm": "" if worn else equipment.dismantle_confirm(content, item),  # 身上那件不能拆，沒有問句（FB-125）
    }
```

```python
def toll_saved(
    state: GameState, content: Content, world: WorldStateStore, tier: str, *, wild: bool = False,
) -> tuple[int, int]:
    """（化勁少扣的氣血, 不動免掉的內傷）（FB-084）：這一場本人真的扣的，跟拿掉那一個功效照一般算的差。
    各自只拿掉它自己那一個（化勁看氣血、不動看內傷），所以兩個數字不互相混。防具（裝備四欄設計 4.3）不是功效、一直留著：
    化勁的對照組是「只有防具」，真的扣的是「防具加化勁、夾在 Config.armor.total_cap」，所以防具省下的不會被算成化勁的。
    只讀、不動狀態：在 take_encounter_toll 之前呼叫，量的是還沒扣的那一刻；用本人的複本照 _apply_toll 同一套算，四捨五入跟
    「氣血 -N」「內傷 +N」的寫法一樣，所以「少扣了 N」加上畫面上的「氣血 -M」剛好是只有防具時的 N+M。
    沒有這兩個功效（只有防具也算沒有）、或這個結果不扣氣血，是 (0, 0)。"""
    cfg = content.config
    fraction = cfg.encounter_neili_loss.get(tier, 0.0) * (cfg.wild_neili_loss_factor if wild else 1.0)
    lo = traits.loadout(state, content, world)
    cut, still = traits.amount(content, lo, "toll_cut"), "no_injury" in lo.specials
    if fraction <= 0 or (cut <= 0 and not still):
        return 0, 0
    worn = min(cfg.armor.total_cap, armor_cut(state, content, world))
    total = min(cfg.armor.total_cap, cut + worn)
    agi, con = state.player.stats.get("agi", BASE_STAT), con_of(state, content, world, PLAYER)

    def toll(cut_: float, injury: float) -> tuple[float, float]:
        return _apply_toll(
            content, state.player.member.model_copy(), fraction * (1 - cut_), agi=agi, con=con, injury=injury,
        )

    real_lost, real_hurt = toll(total, 0.0 if still else 1.0)
    saved = round(toll(worn, 0.0 if still else 1.0)[0]) - round(real_lost) if cut > 0 else 0
    spared = round(toll(total, 1.0)[1]) - round(real_hurt) if still else 0
    return max(0, saved), max(0, spared)
```

```python
# ---- 鐵匠鋪的兩頁（裝備四欄設計 4.6）：兵器、防具；兩欄都開著時預設兵器頁，最後「離開」前一顆切到另一頁 ----

SMITH_PAGES = ("weapon", "armor")  # 照這個順序：進門停在第一個開著的
PAGE_LABELS = {"weapon": "轉去看兵器", "armor": "轉去看防具"}  # 待 joy 潤：切頁那一顆


def smith_open(state: GameState, content: Content) -> bool:
    """鐵匠鋪開不開門：武器或防具開著、人在城鎮。進門（act:smith）、收選單（存檔修補、同步）看這個；能不能買修打某一欄的東西
    另看那一欄自己的 smith_here（weapons.smith_here、armor.smith_here）。"""
    return any(on(content, slot) for slot in SMITH_PAGES) and in_town(state, content)


def first_page(content: Content) -> str:
    """走進鐵匠鋪停在哪一頁：第一個開著的（兩欄都開著是兵器頁）。"""
    return next((slot for slot in SMITH_PAGES if on(content, slot)), SMITH_PAGES[0])


def page(p: PlayerState, content: Content) -> str:
    """鐵匠鋪現在停在哪一頁：存著的那一頁還開著就是它，不然退回 first_page（開關中途關了、舊存檔）。"""
    return p.smith_page if p.smith_page in SMITH_PAGES and on(content, p.smith_page) else first_page(content)


def other_page(p: PlayerState, content: Content) -> str | None:
    """切頁那一顆要切到哪一頁：另一頁也開著才有（只開一欄時不畫切頁鈕）。"""
    here = page(p, content)
    return next((slot for slot in SMITH_PAGES if slot != here and on(content, slot)), None)


def open_smith(p: PlayerState, content: Content) -> None:
    """走進鐵匠鋪（act:smith）：打開選單、打造的單子從頭開始（兵器第二批 Review Focus 4）、停在第一個開著的那一頁。"""
    p.picking_smith, p.smith_draft, p.smith_page = True, None, first_page(content)


def close_smith(p: PlayerState) -> None:
    """收起鐵匠鋪：選單、打造的單子、停在哪一頁一起清。凡是把 picking_smith 設成 False 的地方都走這裡（離開、存檔修補、
    同步時人不在城鎮、出發），存檔裡不留舊的單子或舊的頁（裝備四欄設計 3.2）。"""
    p.picking_smith, p.smith_draft, p.smith_page = False, None, SMITH_PAGES[0]
```

```python
        other = equipment.other_page(self.state.player, self.content)
        tail = [Option(id=f"smith:page:{other}", label=equipment.PAGE_LABELS[other])] if other is not None else []
        return tail + [Option(id="smith:back", label="離開鐵匠鋪")]
```

```python
def gear_rows(state: GameState, content: Content, world: WorldStateStore) -> dict:
    """修練頁「裝備」那一塊（server.menxia_view 的 gear；裝備四欄設計 2.5）：開著的欄位一段一段（這一批武器、防具；坐騎、寶物等
    各自那一批加一段），每段是身上那件與裝備庫裡同一欄的（各欄模組的 rows）、段名、空著時那一句、底下那一句。
    格數四欄合算：used 是裝備庫裡全部的件數（關著的欄位的東西也佔格子），cap 是 Config.weapons.rack_cap。"""
    member = state.player.member
    slots = []
    if equipment.on(content, "weapon"):
        art = team.player_art(state, content, world, member.wugong_id)
        slots.append({"slot": "weapon", "label": equipment.SLOTS["weapon"].label, "empty": weapons.EMPTY, "note": weapons.RACK_NOTE,
                      **weapons.rows(state, content, world, art)})
    if equipment.on(content, "armor"):
        neigong = team.player_art(state, content, world, member.neigong_id)
        slots.append({"slot": "armor", "label": equipment.SLOTS["armor"].label, "empty": armor.EMPTY, "note": armor.RACK_NOTE,
                      **armor.rows(state, content, neigong)})
    return {"cap": content.config.weapons.rack_cap, "used": len(state.player.rack), "slots": slots}
```

```python
    """在鐵匠鋪最該按的那一顆（整季機器人與伺服器假人共用；兵器設計第六節、裝備四欄設計第九節）：兵器頁照 weapons.wanted（換、買、修），

    （假人不打造不淬煉不拆；整季機器人的打造與淬煉在 visit_smith 另外做）。都沒事是 None。"""
    s, c, w = game.state, game.content, game.world
    member = s.player.member
    moves = {
        "weapon": weapons.wanted(s, c, w, team.player_art(s, c, w, member.wugong_id)),
        "armor": armor.wanted(s, c, team.player_art(s, c, w, member.neigong_id)),
    }
    here = equipment.page(s.player, c) if s.player.picking_smith else equipment.first_page(c)
    if moves.get(here) is not None:
        return moves[here]
    other = next((slot for slot, move in moves.items() if move is not None), None)
    return None if other is None else f"smith:page:{other}"


def visit_smith(game: Game) -> None:
    """城裡有鐵匠鋪就看一眼（兵器設計第六節、裝備四欄設計第九節）：先在兵器頁照 weapons.wanted 換、買、修，再照 smithing.forge_plan
    打一把、把裝備庫裡更好的換上、淬煉手上那把（打造與淬煉的鈕只在兵器頁，所以兵器的事先做完）、收掉打造的單子；再切到防具頁照
    armor.wanted 換、買、修；最後離開。每一頁最多按四下（換、買、買了再換上、修）。不花體力。假人不走這裡（bot_policy 照 smith_want）。"""
    s, c, w = game.state, game.content, game.world

    def art():
        return team.player_art(s, c, w, s.player.member.wugong_id)

    def inner():
        return team.player_art(s, c, w, s.player.member.neigong_id)

    def enabled() -> set[str]:
        return {o.id for o in game.options(odds=False) if o.enabled}

    def press(wanted: Callable[[], str | None]) -> None:
        for _ in range(4):
            move = wanted()
            if move is None or move not in enabled():
                break
            game.choose(move)

    if s.pending_event or not equipment.smith_open(s, c):
        return
    if smith_want(game) is None and not smithing.has_errand(s, c, w, art()):
        return
    if "act:smith" not in enabled():
        return
    game.choose("act:smith")
    if equipment.page(s.player, c) == "weapon":  # 進門停在兵器頁（武器關著時直接是防具頁，這一段跳過）
        press(lambda: weapons.wanted(s, c, w, art()))
        plan = smithing.forge_plan(s, c, w, art())
        if plan is not None:
            for oid in smithing.wizard_steps(*plan):
                if oid not in enabled():
                    break
                game.choose(oid)
        better = smithing.better_in_rack(s, c, w, art())
        if better is not None and f"smith:wield:{better.id}" in enabled():
            game.choose(f"smith:wield:{better.id}")
        for _ in range(c.config.weapons.temper_max):
            if not smithing.temper_wanted(s, c, w, art()) or smithing.TEMPER not in enabled():
                break
            game.choose(smithing.TEMPER)
        if s.player.smith_draft is not None and smithing.CANCEL in enabled():
            game.choose(smithing.CANCEL)  # 單子走到一半（按不下去）：收掉，不留在單子上（單子開著時也沒有切頁鈕）

            game.choose("smith:page:armor")  # 防具的事在另一頁：兵器的事（含打造、淬煉）做完才切過去
    if equipment.page(s.player, c) == "armor":
        press(lambda: armor.wanted(s, c, inner()))
    if s.player.picking_smith:
        game.choose("smith:back")
```

```python
"""裝備量表（docs/superpowers/specs/2026-10-10-裝備四欄-design.md 第十節；裝備一：防具那一項）：整季機器人跑幾個種子，

HARD = ("險勝", "僵持", "落敗")
WINS = ("大勝", "險勝")


def _cleanup() -> None:
    """結束時關掉所有資料庫連線再刪暫存資料夾（Windows 上開著的檔刪不掉）。"""

def _steer(game, options, rng) -> str | None:
    """照抄 scripts/measure_sanren.py 的 _steer（同一個量法；那支腳本一 import 就改 stdout 與 TIANXIA_DB，不能直接 import）。"""
    if game.state.pending_event or rng.random() >= STEER:
        return None
    s, c = game.state, game.content
    ids = {o.id for o in options}
    here = s.player.location
    work = {b.kind for b in bounties.mine(s, c) if b.location == here}
    if "act:train" in ids and ("strike" in work or orders.win_counts(s, c, s.player.faction, here)):
        return "act:train"
    if "act:explore" in ids and "scout" in work:
        return "act:explore"
    if "act:duty" in ids and orders.duty_counts(s, c, s.player.faction, here):
        return "act:duty"
    places = bounties.targets(s, c) + orders.targets(s, c, s.player.faction)
    hop = bot_policy.next_hop(game, places) if places else None
    move = next((i for i in ids if i.startswith("move:") and i.partition(":")[2].partition(":")[0] == hop), None)
    if move is not None:
        return move
    return "act:train" if "act:train" in ids else None


def run(seed: int, profile: str | None, armor_on: bool, steer: bool) -> dict:
    content = load_content(ROOT / "content", profile=profile)
    content.config.armor.enabled = armor_on
    seen: set[int] = set()
    count = dict.fromkeys(("fights", "wins", "armored", "armored_hard", "hard", "after_hard", "after_hard_wins",
                           "repairs", "armor_silver", "heal_silver"), 0)
    sums = {"hp": 0.0, "injury": 0.0, "hard_hp": 0.0, "hard_cap": 0.0}
    last: dict = {"hard": False}  # 上一場（算進來的）是不是硬仗
    real_toll, real_heal, real_buy, real_repair, original_pick = team.take_encounter_toll, team.heal, armor.buy, armor.repair, bot.pick

    def toll(state, content_, world, tier, *, wild=False):
        """包住 team.take_encounter_toll：本人這一場掉了多少氣血、多了多少內傷、開打時身上有沒有防具。
        防具開的那一季只拿穿著防具的仗算硬仗、一條氣血撐幾場、硬仗之後的勝率（買防具之前打的不算防具的功勞）；防具關的那一季全算。"""
        member = state.player.member
        con = team.con_of(state, content_, world, PLAYER)
        before, cap = team.member_neili(content_, member, con)
        injury = member.injury
        armored = state.player.armor is not None  # 開打那一刻：這一場扣血時吃不吃得到防具
        out = real_toll(state, content_, world, tier, wild=wild)
        lost = max(0.0, before - team.member_neili(content_, member, con)[0])
        sums["hp"] += lost
        sums["injury"] += member.injury - injury
        hard = tier in HARD
        count["armored"] += armored
        count["armored_hard"] += armored and hard
        counted = armored or not armor_on
        if counted and last["hard"]:  # 硬仗之後緊接著再打的那一場：兩場都要算得進來
            count["after_hard"] += 1
            count["after_hard_wins"] += tier in WINS
        last["hard"] = counted and hard
        if counted and hard:
            count["hard"] += 1
            sums["hard_hp"] += lost
            sums["hard_cap"] += cap
        return out

    def paid(state, before: int) -> int:
        return max(0, before - state.player.stats.get("silver", 0))

    def heal(state, content_, member):
        before = state.player.stats.get("silver", 0)
        out = real_heal(state, content_, member)
        count["heal_silver"] += paid(state, before)
        return out

    def buy(state, content_, attribute):
        before = state.player.stats.get("silver", 0)
        out = real_buy(state, content_, attribute)
        count["armor_silver"] += paid(state, before)
        return out

    def repair(state, content_):
        before = state.player.stats.get("silver", 0)
        out = real_repair(state, content_)
        cost = paid(state, before)
        if cost:
            count["repairs"] += 1
            count["armor_silver"] += cost
        return out

    def pick(game, options, rng):
        steered = _steer(game, options, rng) if steer else None
        return steered if steered is not None else original_pick(game, options, rng)

    def observe(game) -> None:
        """遊歷野怪的場數與勝率（整季、不分有沒有防具）。硬仗之後的勝率在 toll 包裝裡算（要知道開打時有沒有穿防具）。"""
        for b in sorted((b for b in game.state.battles if b.id not in seen), key=lambda b: b.id):
            seen.add(b.id)
            if b.kind not in ("train", "wild"):
                continue
            count["fights"] += 1
            count["wins"] += b.tier in WINS

    def refuse(*args, **kwargs):
        raise RuntimeError("量測不連模型")

    # engine 照模組屬性呼叫 team.take_encounter_toll、team.heal、armor.buy、armor.repair，bot.play_season 照模組全域呼叫 pick：都換得到
    with mock.patch.object(naming, "propose", lambda *a, **k: (None, "")), \
            mock.patch.object(naming, "pick", lambda *a, **k: (None, "")), \
            mock.patch.object(OllamaClient, "chat_structured", refuse), mock.patch.object(OllamaClient, "chat_text", refuse), \
            mock.patch("requests.post", refuse), mock.patch("requests.get", refuse), \
            mock.patch.object(team, "take_encounter_toll", toll), mock.patch.object(team, "heal", heal), \
            mock.patch.object(armor, "buy", buy), mock.patch.object(armor, "repair", repair), \
            mock.patch.object(bot, "pick", pick):
        game = bot.play_season(content, seed, world=open_world(TMP / f"s{seed}-{int(armor_on)}.db"), observe=observe)
    p = game.state.player
    season = game.state.world
    return {
        "fights": count["fights"], "win": count["wins"] / count["fights"] if count["fights"] else 0.0,
        "hp": round(sums["hp"]), "injury": round(sums["injury"]), "heal_silver": count["heal_silver"],
        "armored": count["armored"], "armored_hard": count["armored_hard"],
        "hard": count["hard"], "lasts": sums["hard_cap"] / sums["hard_hp"] if sums["hard_hp"] else None,
        "after_hard": count["after_hard"],
        "after_hard_win": count["after_hard_wins"] / count["after_hard"] if count["after_hard"] else None,
        "repairs": count["repairs"], "armor_silver": count["armor_silver"],
        "armor": p.armor.name if p.armor else "—",
        "tier1": sum(n for mid, n in p.materials.items() if content.materials[mid].tier == 1),
        "silver": p.stats.get("silver", 0), "hours": season.time / 3600, "ending": season.ending_id or "—",
    }


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--seeds", type=int, nargs="+", default=[1, 2, 3, 4, 5])
    parser.add_argument("--profile", default=None)
    parser.add_argument("--steer", action="store_true", help="一半的時候照手上的懸賞、軍令走（週末那一組用，同 measure_sanren）")
    args = parser.parse_args()
    content = load_content(ROOT / "content", profile=args.profile)
    print(profile_line(content, args.profile) + ("（照手上的事走）" if args.steer else ""), flush=True)
    cfg = content.config
    cut = cfg.armor.tier_cut.get("1", 0.0) + cfg.armor.match  # 一階下品、跟內功同屬性（架上那件買對了）
    ref = "、".join(f"{t} {1 / cfg.encounter_neili_loss[t]:.1f}→{1 / (cfg.encounter_neili_loss[t] * (1 - cut)):.1f} 場"
                   for t in HARD if cfg.encounter_neili_loss.get(t))
    print(f"對照（設計 4.1 照表算，不含身法與回血；一階下品對上內功 {cut:.0%}）：{ref}", flush=True)
    for seed in args.seeds:
        for on in (False, True):
            r = run(seed, args.profile, on, args.steer)
            lasts = "—" if r["lasts"] is None else f"{r['lasts']:.1f}"
            after = "—" if r["after_hard_win"] is None else f"{r['after_hard_win']:.0%}"
            print(f"種子 {seed} 防具{'開' if on else '關'}：遊歷野怪 {r['fights']} 場（勝率 {r['win']:.0%}）、"
                  f"掉氣血 {r['hp']}、內傷 {r['injury']}、療傷 {r['heal_silver']} 兩、"
                  f"穿著防具 {r['armored']} 場（其中硬仗 {r['armored_hard']} 場）、"
                  f"硬仗 {r['hard']} 場（一條氣血撐 {lasts} 場）、硬仗之後再打的勝率 {after}（{r['after_hard']} 場）、"
                  f"修防具 {r['repairs']} 次、防具花 {r['armor_silver']} 兩、季末防具 {r['armor']}、"
                  f"一階素材 {r['tier1']}、銀兩 {r['silver']}、季長 {r['hours']:.1f} 小時（世界時間）、結局 {r['ending']}", flush=True)


if __name__ == "__main__":
    main()
```
