## 核對現行程式（開工前）

設計稿點名的東西都在，行為對得上；差異：

1. **`MAIN_ACTIONS`／`MENXIA_ACTIONS` 在 `server.py`**，引擎在 `tianxia/engine.py`。`api_do` 對 `smith_forge` 另回 `forged`，`smith_furnace` 不需要。
2. **`smith_view(state, content, world)` 沒有 `day`、`prologue`**：`furnace` 要「回體丹的換日」（`Game._pill_day`）與序章（`prologue_rules.active`），都是 Game 才有。`smith_view` 加兩個有預設的關鍵字引數（`day=None, prologue=False`），`Game.shop_view` 傳；沒給 day 的直接呼叫（現有測試）`forge.furnace` 是 None。
3. **`smithing.temper*` 已經有 `slot`（weapon／armor）**：`item_id` 加在 `slot` 後面，舊呼叫端不動。`temper_price(content, material, slot)` 沒有 state、價錢只看素材階與那一欄，`item_id` 收了不影響價錢（稿要它跟著列，D 批改淬煉規則時會用到）。
4. **`_rack` 的列已經有 `tempers`、`temper_max`**（`weapons._row`、`armor._row`）：稿說 `_rack` 加 `tempers`，實際已經有，不重複加，測試鎖住它在。
5. **`Game.dismantle_weapon` 沒擋「籌備中」，`Game.melt_many` 擋**：`dismantle_many` 照稿「照 `melt_many` 寫」，加 `@_not_while_preparing`。
6. **`smith:temper` 選項走的紀錄標題是「淬煉」**（`smithing.title`），`smith:repair` 是「鐵匠鋪」。稿寫 `temper_item` 寫「鐵匠鋪」紀錄（同 `smith_upgrade`），照稿，跟選單那條路的標題不同。
7. `smith_furnace` 沒有掌櫃那一句的情況鍵（`SMITH_SITUATIONS` 沒有 furnace）：不加（要加就得動 `content/shop_lines.json`，稿沒寫），成功與被拒都不動 `shop_line`／`shop_clue`；也不擲鐵匠順口（`act:furnace` 走打點那條路本來就不擲）。
8. 稿沒有定 API 的鍵名：`repair_item`／`temper_item` 收 `item`（也認舊的 `weapon`，同 `wield`、`dismantle`），`dismantle_many` 收 `items`（清單，同 `melt_many` 的 `arts`）。`forge.furnace.id` 寫 `"smith_furnace"`（`/api/do/<id>` 的 op；不是 `act:furnace`，店開著時選單上沒有它）。

## 任務（一步一提交，先紅後綠）

1. **`item_id`**：`equipment.target`（身上那件或裝備庫那件）、`equipment.RACK_MISSING`；`weapons.repair`／`repair_problem`、`armor.repair`／`repair_problem`、`smithing.temper_material`／`temper_price`／`temper_problem`／`temper` 多 `item_id=None`。裝備庫那件修好不動 `edge_warned`／`armor_warned`（那是身上那件的提醒旗標）。測試：`tests/gear/test_weapons_forge.py`、`test_armor_forge.py`（None 與以前一字不差、身上那件的 id 等於 None、裝備庫那件修淬完還在裝備庫、錯欄的 id、沒有的 id）。
2. **`smith_furnace` 與 `forge.furnace`**：`Game.smith_furnace`（擋法 `_trade_open(silver.on(...))`，叫 `silver.furnace`，成功寫「鐵匠鋪」紀錄）、`MAIN_ACTIONS["smith_furnace"]`、`shopview.furnace_view` 放進 `_forge` 的 `furnace`。測試：`tests/gear/test_shop.py`。
3. **`repair_item`／`temper_item`**：`Game.repair_item`／`temper_item`（共用 `_gear_work`）、`MENXIA_ACTIONS`。測試：`test_shop.py`。
4. **`dismantle_many`**：`equipment.dismantle_many`（`dismantle` 的檢查抽成共用的一個函式）、`Game.dismantle_many`、`MENXIA_ACTIONS["dismantle_many"]`。測試：`test_shop.py`。
5. **`_rack` 每列的鈕資料**：`repair`、`temper`、`into`（`worn` 那張卡的 `use` 寫法抽成共用）。測試：`test_shop.py`。
6. **`grand_pct`**：`skillview.forge_preview`。測試：`tests/arts/test_fusion.py`。
7. **3.3 的測試**（打造頁開著時 `smith_upgrade` 按得下去、熬成了素材格跟著變）與**假人與整季機器人的 `smith:repair`／`smith:temper` 不變**。
8. 導覽（`docs/guide/裝備與店面.md`、`武學與成長.md`）。
