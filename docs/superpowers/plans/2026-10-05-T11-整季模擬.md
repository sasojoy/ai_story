# T11 整季模擬與驗收腳本 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一支腳本用週末設定、暫存資料庫、假時鐘與假人程式（`BotRunner`）跑完第一季濃縮版，每個種子印出每週末的戰況與割據、十二件大事的結果與鎖定、三場決戰、每陣營每週達成的軍令、升第 2 階的人數、結局與收季時間、有沒有卡住，並照總計畫的驗收標準判定。

**Architecture:** `scripts/sim_season_one.py`：`run_season(content, db_path, seed, targets, hours, tick) -> dict` 是可以在測試裡呼叫的純函式；`main()` 只管 CLI 與印。假人程式照舊（`BotRunner`），只把「每陣營補幾人」換成每陣營各自的目標（子類別覆寫 `_fill`）、補人不等間隔。開季用 store 的 `open_season`（預設排程）再結算第 1 週（`world.settle_season_start`），跟管理者開季一樣。模型一律不叫（假人本來就不叫；保險起見把 OllamaClient 換成假的）。

**Tech Stack:** Python 3.14、pytest。

**Spec:** 總計畫 `docs/superpowers/plans/2026-10-04-第一季濃縮版.md` 的 T11 一節；版本目標第四節第 1、6 條。
