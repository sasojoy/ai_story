1. **正在跑的季**：上線那一刻正在跑的季（`WorldState` 沒有新的兩欄）挑配方、說書、殘譜、鐵匠順口、鑄譜畫面都跟改之前一模一樣；換季之後才變。

```python
def active(content: Content, tianji: int, season: WorldState | None = None) -> list[ForgeSecret]:
    """……（原文）。這一季蓋了 forge_divine_per_kind 的章（素材與經濟設計第二節）：兵器的神器配方同一種兵器只挑一條——第一季的章
    （calendar.season_one_on）池子裡每一種都挑一條；其餘的季照天機排好，挑 per_season 條、跳過已經挑到的種類。防具照舊。"""
    out: list[ForgeSecret] = []
    per_kind = season is not None and season.forge_divine_per_kind
    for group, count in content.config.forge_secrets.per_season.items():
        if count <= 0 or not equipment.on(content, group.partition(":")[0]):
            continue
        pool = sorted((r for r in content.forge_secrets.values() if group_of(r) == group), key=lambda r: _rank(tianji, r.id))
        if per_kind and group == "weapon:divine":
            kinds: dict[str, ForgeSecret] = {}
            for r in pool:
                kinds.setdefault(r.kind, r)
            picked = list(kinds.values())
            out += picked if calendar.season_one_on(season, content) else picked[:count]
        else:
            out += pool[:count]
    return out
```

設計要點（第三節）：
- 片子只給神器配方，而且只在這一季蓋了 `forge_split_clues` 的章時；名器配方照舊是三句口訣。
- 片子的名字用配方的「號」（`alias`：譜名去掉兵器字或防具字，玄晶劍 → 玄晶、寒淵拳套 → 寒淵、嶽峙鎧 → 嶽峙），不露種類。三句（待 joy 潤）：
  - 種類：`「{alias}」是一{unit}{noun}。`（防具寫「是一件防具」）
  - 主料：`「{alias}」的主料：{attr}屬的{tier}料。`
  - 輔料：`「{alias}」的輔料：{attr}屬的{tier}料。`（`tier` 照 `covers`：三階、二階以上）
- 鐵匠鋪：城鎮照「天機|地點|鐵匠」排，這一季的片子照「天機|配方|片」排，第 j 片給第 j mod 家；每一家另外照舊知道一條名器配方的鐵匠版口訣（名器配方照舊分）。花了錢之後照舊擲 `smith_chance`，中了就講**這家還沒講給你聽過**的其中一樣（種子挑）；這家的都聽過了才不說。
- 說書、殘譜：池子是名器配方的那一版口訣，加上神器配方還沒聽過的片子；先挑還沒聽過的，都聽過了重說一句聽過的（不記）。
- 鑄譜：神器配方一條一筆，`clues` 是聽過的片子的句子（照片的先後），`recipe` 是 `piece_line`（三片都聽過就完整「劍：快三＋柔三」）；打中了照舊寫名字與打中的那一爐的配方。

```python
from conftest import real_content
from tianxia import forge_secrets
from tianxia.engine import Game
from tianxia.world_state import fresh_season


def _game(c):
    import random
    g = Game.new(c, "鑄者", rng=random.Random(1))
    g.state.world = fresh_season(c)
    return g


def test_every_piece_is_known_by_some_smith():
    c = real_content("weekend")
    season = fresh_season(c)
    known = {item for town in forge_secrets.towns(c) for item in forge_secrets.smith_items(c, season, season.tianji, town)}
    divine = [r for r in forge_secrets.active(c, season.tianji, season) if r.divine]
    assert {(r.id, p) for r in divine for p in forge_secrets.PIECES} <= known


def test_a_smith_never_repeats_until_it_has_told_everything():
    c = real_content("weekend")
    g = _game(c)
    town = forge_secrets.towns(c)[0]
    g.state.player.location = town
    items = forge_secrets.smith_items(c, g.state.world, g.state.world.tianji, town)
    told = [forge_secrets.hear_smith(g.state, c, g.state.world.tianji) for _ in range(len(items) + 2)]
    assert all(told[: len(items)]) and len(set(told[: len(items)])) == len(items) and told[len(items):] == [None, None]


def test_three_pieces_make_the_book_line_complete():
    c = real_content("weekend")
    g = _game(c)
    recipe = next(r for r in forge_secrets.active(c, g.state.world.tianji, g.state.world) if r.divine and r.kind == "劍")
    book = forge_secrets.manual(g.state, g.state.world.tianji)
    book.pieces[recipe.id] = [forge_secrets.MAIN]
    assert forge_secrets.piece_line(c, recipe, [forge_secrets.MAIN]) == "？：快三＋？"
    assert forge_secrets.piece_line(c, recipe, list(forge_secrets.PIECES)) == "劍：快三＋柔三"
```
