### 2.3 兩個宣告

```python
@dataclass(frozen=True)
class Shop:            # 店面登記：一間開在城裡、坐進去選單整個換成那間店的店
    key: str                                   # _shop_open 回的字（店面那一頁畫哪一間）
    inside: Callable[[Game], bool]             # 此刻坐在店裡（picking_*）
    here: Callable[[Game], bool]               # 這裡此刻開著這間店
    close: Callable[[Game], None]              # 收起來（掌櫃那一句一併清）
    menu: Callable[[Game], list[Option]]       # 坐在店裡時的整個選單
    entry: Callable[[Game], Option | None]     # 此地還能做裡進店那一顆；這裡不開門是 None


@dataclass(frozen=True)
class Verb:            # act:<verb> 那一格的主人（act 子動詞；第 57 批其餘 28 個接上同一張表）
    verb: str
    run: Callable[[Game, Any], list[str] | None] | None = None              # _act 最前面：按下去（prepared 照傳）
    title: Callable[[Game], str | None] | None = None                       # _action_title：這一下紀錄的整個標題
    cell: Callable[[Game, Location, int, bool], list[Option] | None] | None = None  # _everyday_options：行動列那一格（[] 是接了、一顆都沒有）
    note: Callable[[Game, Location], str | None] | None = None              # action_notes：行動列底下那一行
    picks: tuple[str, ...] = ()                                             # 按了只打開一張卡的回話（不算做過、不寫紀錄）
```

每一樣回 None 都是「照舊由核心做」。三包的宣告：
- 探索包 `Verb("explore", run=出門一趟, title=「出門一趟・某地」, cell=那一顆, note=這一處多半給什麼)`，都先問 `outing_on`。
- 出陣包 `Verb("train", run=約戰開著時打開那張卡, title=出陣／雪恥／遊歷・某地, cell=地盤開著時整格, note=約戰那一句或出陣那一行, picks=(PICK,))`。
- 酒肆包 `Verb("tavern", run=進店, title=招牌)`、`Shop("tavern", inside=picking_tavern, here=rules.here, close=rules.close, menu=tavern_options, entry=開著而且這裡有酒肆時那一顆)`。
