    - 每 10～30 秒做一個動作；

## Global Constraints

- **絕不碰正式資料**：壓測一律用新的暫存資料庫（`TIANXIA_DB` 指到 `scratch`），不碰 `saves/`、`.local/`、`C:\Ray\tianxia-play\`；伺服器開在別的埠（例如 7880），不碰 7861。
- **測試後門只在測試環境**：
  - 網路層的伺服器用 `TIANXIA_TEST_LOGIN=1` 開；
  - 那個環境不能有 `.local/oauth.json`，伺服器會拒絕啟動（帳號計畫 Task 5）。
- **模型一律用假的**：伺服器的 `ollama_url` 指到 `fake_ollama.py` 的埠，用一個壓測專用的設定檔：`content/profiles/loadtest.json`，由 Task 4 建立。
- **假玩家不是假人**：壓測的角色是真人帳號的路徑（測試後門建的帳號），不碰 `PlayerState.bot`，也不影響「假人不能被看出來」。
- **腳本不 import 到正式內容的檔案路徑以外的地方**；結果寫在 `scratch` 或 `docs/superpowers/feedback/壓測結果-YYYY-MM-DD.md`（手冊的格式）。
- 引擎層腳本直接 import `server` 用 `server.act`，所以要在 import 之前設好 `TIANXIA_DB`（scratch）與 `TIANXIA_PROFILE`。這兩個環境變數由腳本自己設，寫在 import 之前。

## Review Focus

1. **假的模型很慢時，其他人不受影響**（9.2 最後一列）：網路層一部分假玩家去跟人物對話、開爐；其他只拿畫面的人，回應時間要跟沒人叫模型時差不多。Task 3 的報告把「叫模型的請求」與「其他請求」分開算。
2. **假玩家的請求失敗**（401、409、500、逾時）：要記成錯誤、照常繼續，不能讓整支壓測程式停掉，也不能把錯誤當成成功算進回應時間。Task 3 一條測試。
3. **跑到一半按 Ctrl+C**：要印出到目前為止的結果，不能什麼都沒留下。Task 2、Task 3 各一條。
4. **3000 個角色的季末結算**：要量到「收季那一下」的時間，而且收季之後伺服器還能接著回應。Task 2 一條測試（用小數字跑通流程）。
5. **百分位數算錯**（樣本很少、只有一筆、空的）：報告不能因此丟例外。Task 1 一條測試。

```python
"""壓測的共用工具：百分位數與摘要（線上架構設計 9.2 的目標都用九成五的回應時間講）。"""
from __future__ import annotations


def percentiles(samples: list[float]) -> dict[str, float | None]:
    """取最接近的那一筆（nearest-rank），樣本少也不內插；空的回 None。"""
    if not samples:
        return {"count": 0, "p50": None, "p95": None, "p99": None, "max": None}
    ordered = sorted(samples)

    def rank(q: float) -> float:
        index = max(0, min(len(ordered) - 1, int(round(q * len(ordered))) - 1))
        return ordered[index]

    return {"count": len(ordered), "p50": rank(0.50), "p95": rank(0.95), "p99": rank(0.99), "max": ordered[-1]}


def summarize(name: str, samples: list[float], errors: int) -> str:
    p = percentiles(samples)
    if not p["count"]:
        return f"{name}：0 次，錯誤 {errors}"
    return (
        f"{name}：{p['count']} 次，錯誤 {errors}，p50 {p['p50']:.3f} 秒，p95 {p['p95']:.3f} 秒，"
        f"p99 {p['p99']:.3f} 秒，最慢 {p['max']:.3f} 秒"
    )
```

`scripts/fake_ollama.py`：

```python
"""假的模型伺服器（線上架構設計 9.1：LLM 用模擬的，延遲 5～20 秒）。每一個 /api/chat 等一段隨機的時間再回 503，
所以伺服器每個叫模型的地方都會等滿、再走退路——這是「模型很慢而且常失敗」的最壞情況。/api/tags 照常回 200（健檢用）。

執行：.venv/Scripts/python.exe scripts/fake_ollama.py --port 11500 --min 5 --max 20
壓測的設定檔（content/profiles/loadtest.json）把 ollama_url 指到這裡。"""
from __future__ import annotations

import argparse
import json
import random
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer


def serve(port: int, delay: tuple[float, float], status: int = 503) -> ThreadingHTTPServer:
    low, high = delay

    class Handler(BaseHTTPRequestHandler):
        def _reply(self, code: int, body: dict) -> None:
            data = json.dumps(body).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def do_GET(self):  # noqa: N802
            self._reply(200, {"models": [{"name": "fake"}]})

        def do_POST(self):  # noqa: N802
            length = int(self.headers.get("Content-Length") or 0)
            self.rfile.read(length)
            time.sleep(random.uniform(low, high))
            self._reply(status, {"error": "fake ollama is slow on purpose"})

        def log_message(self, *args):  # 不洗版
            pass

    server = ThreadingHTTPServer(("127.0.0.1", port), Handler)
    server.daemon_threads = True
    threading.Thread(target=server.serve_forever, daemon=True).start()
    return server


def main() -> None:
    parser = argparse.ArgumentParser(description="假的模型伺服器：延遲之後回 503")
    parser.add_argument("--port", type=int, default=11500)
    parser.add_argument("--min", type=float, default=5.0)
    parser.add_argument("--max", type=float, default=20.0)
    args = parser.parse_args()
    server = serve(args.port, (args.min, args.max))
    print(f"假的模型：http://127.0.0.1:{server.server_address[1]}（每次等 {args.min:g}～{args.max:g} 秒再回 503）", flush=True)
    try:
        threading.Event().wait()
    except KeyboardInterrupt:
        server.shutdown()


if __name__ == "__main__":
    main()
```

```python
"""引擎層壓測（線上架構設計 9.1 第 1 層、9.2）：在程式裡直接走伺服器做動作的那一條路（server.act：拿行動鎖、
重讀角色、同步、做動作、存檔），量每個動作握鎖多久、每秒做得了幾個、資料庫多大、記憶體尖峰，以及 N 個角色時
管理者收季要多久。不經過網路，所以量到的是「伺服器本身」的上限；網路層另見 load_web.py。

一律開新的暫存資料庫（--workdir），不碰 saves/ 與試玩伺服器。模型用不到：選單裡會叫模型的選項（對話、交友、求見、
大場面）一律跳過，那是網路層的事。

執行：.venv/Scripts/python.exe scripts/load_engine.py --characters 3000 --actions 20000 --end-season --out <檔>
"""
from __future__ import annotations

import argparse
import json
import os
import random
import sys
import tempfile
import time
import tracemalloc
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "scripts"))

import load_common  # noqa: E402

SKIP_PREFIXES = ("talk:", "call:", "act:socialize", "act:challenge:", "choice:free")  # 會叫模型的，引擎層不做


def _import_server(db_path: Path):
    """server 在 import 時就讀環境變數、載入內容；要在 import 之前把資料庫指到暫存檔。"""
    os.environ["TIANXIA_DB"] = str(db_path)
    os.environ.setdefault("TIANXIA_PROFILE", "weekend")
    import server  # noqa: PLC0415

    server.CONTENT.config.auto_open_first_season = True
    return server


def one_action(server, game, rng: random.Random) -> float:
    """照伺服器的路做一個動作，回傳握著行動鎖的秒數。"""
    held = {}
    real_locked = server._locked

    import contextlib  # noqa: PLC0415

    @contextlib.contextmanager
    def timed(g):
        with real_locked(g):
            start = time.perf_counter()
            try:
                yield
            finally:
                held["s"] = time.perf_counter() - start

    server._locked = timed
    try:
        def pick(g):
            options = [o.id for o in g.options(odds=False) if o.enabled and not o.id.startswith(SKIP_PREFIXES)]
            return g.choose(rng.choice(options)) if options else []

        server.act(game, pick)
    finally:
        server._locked = real_locked
    return held.get("s", 0.0)


def run(characters: int, actions: int, seed: int, workdir: Path, end_season: bool) -> dict:
    db_path = Path(workdir) / "load.db"
    server = _import_server(db_path)
    rng = random.Random(seed)
    names = [f"壓測{i:04d}" for i in range(characters)]
    from tianxia.characters import open_characters  # noqa: PLC0415
    from tianxia.engine import Game  # noqa: PLC0415

    store = open_characters()
    for name in names:
        if not store.exists(name):
            store.save(Game.new(server.CONTENT, name, rng=random.Random(rng.random())).state)
    tracemalloc.start()
    locked, total, stopped = [], [], False
    started = time.perf_counter()
    try:
        for _ in range(actions):
            game = server.game_for(rng.choice(names))
            t0 = time.perf_counter()
            locked.append(one_action(server, game, rng))
            total.append(time.perf_counter() - t0)
    except KeyboardInterrupt:
        stopped = True
    elapsed = max(time.perf_counter() - started, 1e-9)
    end_seconds = None
    if end_season and not stopped:
        server.CONTENT.config.admins = [names[0]]
        admin = server.game_for(names[0])
        t0 = time.perf_counter()
        server.act(admin, lambda g: g.admin_end_season(time.time()))
        end_seconds = time.perf_counter() - t0
    _, peak = tracemalloc.get_traced_memory()
    tracemalloc.stop()
    return {
        "characters": characters, "actions_done": len(locked), "locked": locked, "total": total,
        "rate": len(locked) / elapsed, "db_mb": db_path.stat().st_size / 1e6, "peak_mb": peak / 1e6,
        "end_season_seconds": end_seconds, "stopped_early": stopped,
    }


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="引擎層壓測：直接走伺服器做動作的路，量握鎖時間與吞吐")
    parser.add_argument("--characters", type=int, default=300)
    parser.add_argument("--actions", type=int, default=5000)
    parser.add_argument("--seed", type=int, default=1)
    parser.add_argument("--end-season", action="store_true", help="最後用管理者收季，量季末結算的時間")
    parser.add_argument("--workdir", default=None, help="暫存資料庫放哪（預設開一個新的暫存資料夾）")
    parser.add_argument("--out", default=None, help="結果 JSON 寫到哪")
    args = parser.parse_args(argv)
    workdir = Path(args.workdir or tempfile.mkdtemp(prefix="tianxia-load-"))
    report = run(args.characters, args.actions, args.seed, workdir, args.end_season)
    print(load_common.summarize("握鎖時間", report["locked"], 0))
    print(load_common.summarize("每個動作（含排隊）", report["total"], 0))
    print(f"每秒 {report['rate']:.1f} 個動作；資料庫 {report['db_mb']:.1f} MB；記憶體尖峰 {report['peak_mb']:.1f} MB")
    if report["end_season_seconds"] is not None:
        print(f"{args.characters} 個角色時收季花了 {report['end_season_seconds']:.2f} 秒")
    if report["stopped_early"]:
        print("（中途停下來了：上面是到停下來為止的結果）")
    if args.out:
        Path(args.out).write_text(json.dumps(report, ensure_ascii=False), encoding="utf-8")
    return 0


if __name__ == "__main__":
    sys.stdout.reconfigure(encoding="utf-8")
    raise SystemExit(main())
```

```python
"""網路層壓測（線上架構設計 9.1 第 2 層）：很多個假的瀏覽器，用測試後門登入（/api/test_login，只在 TIANXIA_TEST_LOGIN=1），
每 poll_every 秒拿一次畫面、每 act_every 秒做一個動作（從畫面上能按的選項隨機挑）。記下每一種請求的回應時間與錯誤：
- 會叫模型的選項（對話、交友、求見、大場面）另外算成 choose_model，看「模型很慢時其他人受不受影響」（9.2 最後一列）；
- 失敗（不是 2xx、逾時、連線錯誤）記成錯誤、不算進回應時間，假玩家照常繼續。
Ctrl+C 會停下來，印出到那時為止的結果。

執行（伺服器另外開，埠與資料庫都是壓測專用的）：
  .venv/Scripts/python.exe scripts/load_web.py --base http://127.0.0.1:7880 --users 3000 --minutes 60
"""
from __future__ import annotations

import argparse
import asyncio
import random
import sys
import time
from collections import defaultdict
from pathlib import Path

import httpx

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT / "scripts"))

import load_common  # noqa: E402

MODEL_PREFIXES = ("talk:", "call:", "act:socialize", "act:challenge:")  # 會叫模型的選項（跟 server.may_generate_dialogue／may_judge_fight 一致）
TIMEOUT = 120.0  # 一個請求最多等多久（比 trycloudflare 的約 100 秒長一點，才量得到被切斷的）


async def _timed(record, kind: str, coro):
    started = time.perf_counter()
    try:
        r = await coro
    except (httpx.HTTPError, asyncio.TimeoutError):
        record["errors"][kind] += 1
        return None
    if r.status_code >= 300:
        record["errors"][kind] += 1
        return None
    record["samples"][kind].append(time.perf_counter() - started)
    return r


async def _user(i: int, base: str, transport, record, deadline: float, rng: random.Random, act_every, poll_every) -> None:
    async with httpx.AsyncClient(base_url=base, transport=transport, timeout=TIMEOUT) as client:
        r = await _timed(record, "login", client.post("/api/test_login", json={"name": f"壓測{i:04d}"}))
        if r is None:
            return
        main = r.json().get("main") or {}
        next_act = time.monotonic() + rng.uniform(*act_every)
        while time.monotonic() < deadline:
            await asyncio.sleep(min(poll_every, max(0.0, deadline - time.monotonic())))
            if time.monotonic() >= deadline:
                break
            got = await _timed(record, "main", client.get("/api/main"))
            if got is not None:
                main = got.json()
            if time.monotonic() >= next_act:
                options = [o["id"] for o in main.get("options", []) if o.get("enabled") and o["id"] != "choice:free"]
                if options:
                    pick = rng.choice(options)
                    kind = "choose_model" if pick.startswith(MODEL_PREFIXES) else "choose"
                    done = await _timed(record, kind, client.post("/api/choose", json={"id": pick}))
                    if done is not None:
                        main = done.json().get("main") or main
                next_act = time.monotonic() + rng.uniform(*act_every)


async def run(
    base_url: str, users: int, duration: float, seed: int, transport=None,
    act_every: tuple[float, float] = (10.0, 30.0), poll_every: float = 10.0,
) -> dict:
    record = {"samples": defaultdict(list), "errors": defaultdict(int), "stopped_early": False}
    for kind in ("login", "main", "choose", "choose_model"):
        record["samples"][kind]
        record["errors"][kind]
    deadline = time.monotonic() + duration
    rng = random.Random(seed)
    tasks = [
        asyncio.create_task(_user(i, base_url, transport, record, deadline, random.Random(rng.random()), act_every, poll_every))
        for i in range(users)
    ]
    try:
        await asyncio.gather(*tasks)
    except (KeyboardInterrupt, asyncio.CancelledError):
        record["stopped_early"] = True
        for t in tasks:
            t.cancel()
    record["samples"] = dict(record["samples"])
    record["errors"] = dict(record["errors"])
    return record


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="網路層壓測：很多個假的瀏覽器")
    parser.add_argument("--base", required=True, help="伺服器網址，例如 http://127.0.0.1:7880 或 https://<網域>")
    parser.add_argument("--users", type=int, default=300)
    parser.add_argument("--minutes", type=float, default=60)
    parser.add_argument("--seed", type=int, default=1)
    args = parser.parse_args(argv)
    try:
        report = asyncio.run(run(args.base, args.users, args.minutes * 60, args.seed))
    except KeyboardInterrupt:
        print("（中途停下來了）")
        return 1
    for kind in ("login", "main", "choose", "choose_model"):
        print(load_common.summarize(kind, report["samples"].get(kind, []), report["errors"].get(kind, 0)))
    return 0


if __name__ == "__main__":
    sys.stdout.reconfigure(encoding="utf-8")
    raise SystemExit(main())
```
