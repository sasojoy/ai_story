**Goal:** 做兵器設計 4.10「名將本命兵器」，也就是打造隱藏配方設計第十三節的第三批。
- 7 位名將（曹操、劉備、關羽、張飛、孫堅、袁紹、陶謙）各一把本命兵器。名字用 4.10 的暫名表，寫在 `content/gear.json`，joy 改名不動程式。
- 兩條路拿到：
  - **情誼到 80**：他送你。情誼從對話、事件、隨口應對來都算，偵測照名將贈禮的做法（`Game.choose`、`answer_event` 最後各叫一次）。
  - **打贏他本人 3 次**：他讓你奪走。7 位裡只有孫堅是大勢人物，所以這條路只有孫堅有。挑戰本人現在只在第一季規則開著、自己有陣營時才有，所以這條路現在也只有第一季有。《挑戰大勢人物每季都有》還在等企劃者，那一份合進來之後，挑戰本人每季都有，這條路也跟著每季都有，這一份不必再改。
- **每位名將每季全服一人**：記在 `WorldState.signature_arms`，鎖內改、整份 JSON，不建表。
- 加成**算神器原品**：基本 22%＋上品 4%，合計 26%。階品寫「・本命」。**不能拆、不能交求兵**。
- 拿到時江湖史一行、天下大事傳聞一句（具名）、行狀一筆。
- **上神器譜**：見聞→江湖史底下，跨季保留。
- 送兵器、奪兵器那兩句話先用暫用的，標「待 joy 潤」。企劃者 2026-10-10：「先用暫名做，不等 joy」。

**Architecture:**
- 新模組 `tianxia/signature_arms.py` 放這一批的規則：
  - 字句：`GIFT_LINE`、`SEIZE_LINE`、`GAIN_LINE`、`CHRONICLE_*`、`RUMOR_*`、`ANNAL_*`、`HOW`、`BOOK_LINE`。
  - `owned(p)`：身上、裝備庫、寄放的本命兵器。
  - `new_arm(state, arm)`：開一把。三階上品，`original=True`，`signature` 記人物 id。
  - `refresh_names(p, content)`：讀檔時照內容重寫名字。
  - `due(state, content, *, beaten=None)`：該給就給。記歸屬、交到手上（滿了寄放）、寫江湖史與傳聞。**不擲骰**。
  - `annal_line`：行狀那一句。
  - `book_rows(content, records)`：神器譜那幾行。
- 它 import `models`、`state`、`weapons`（`new_weapon`、`NOUNS`）、`treasures`（`deliver`）、`figures`（`is_out`）、`rules`（`add_chronicle`、`add_rumor`）。只有 `engine` import 它。
- 資料：
  - `models.SignatureArmDef` 加 `GearBook.signature_arms`；`WeaponRules.signature_affinity`（80）、`signature_wins`（3）。
  - `state.Equipment.signature`、`PlayerState.figure_wins`。
  - `state.SignatureClaim` 加 `WorldState.signature_arms`。
  - `WorldStateStore.signature_records()`：跨季讀 `seasons` 表的 `data`。
  - **資料庫不升版**（維持第 5 版）。
- 跟著改的現有模組：
  - `content.py`：`_gear` 認 `signature_arms` 鍵，新寫 `check_signature_arms`。
  - `naming.name_problem`：`GEAR_CLASH` 也擋本命兵器的名字。
  - `equipment`：`SIGNATURE_MARK`、`grade`、`SIGNATURE_KEPT`、`SIGNATURE_KEPT_LINE`、`kept`、`dismantle`。
  - `weapons._row` 的 `keep`。
  - `bounties.SIGNATURE_KEPT`、`fit_problem`。
  - `forge_secrets.divine_book(records, extra=None)`。
- `engine` 掛點：
  - `_signature_arms`：`choose`、`answer_event` 最後各叫一次；`_challenge` 打贏時帶戰報叫一次。
  - `_challenge` 打贏記 `figure_wins`。
  - `_drop_stale_references` 重寫名字。
  - `_dismantle_options` 寫拆不得的原因。
  - `chronicle_text` 把本命兵器那幾行併進神器譜。
- **網頁不用改**：階品與 `keep` 本來就照資料畫，神器譜是 Markdown。
- **假人不用改**：拿到是自動的；換上照 `smithing.better_in_rack`，本命兵器算原品的加成，配得上身上武學就會被換上。

**Tech Stack:** Python 3.12、pydantic、SQLite（不動結構）、pytest（`-n auto`）。

## 要 PM 定的

1. **另外六位名將的「打贏他本人三次」。**
   - 建議**甲**：這一批只有孫堅有這條路，另外六位只走情誼 80。
     - 內容檔每一把有一個 `figure` 欄位（大勢人物 id），只有孫堅那一把寫。
     - 之後六位有了能打他本人的場面（人物表加人、頭目戰），填上 `figure` 就有，程式不用改。
     - 理由：
       - 曹操、劉備、關羽、張飛、袁紹、陶謙不在人物表（`content/figures.json`），沒有「挑戰本人」可打。《挑戰每季都有》5.4 也寫明「他們的『打贏三次』要兵器三另外定，跟這份無關」。
       - 招募失敗的「決鬥」其實只扣銀兩（`roster.py` 的 `duel_chance_on_fail`），沒有打一場。
   - 乙：頭目戰（`content/duels.json`）給六位各寫一隻「跟名將過招」的頭目，打贏三次算數。要寫六隻頭目的內容與面貌，交 joy，下一批。
   - 丙：情誼到某個數時對話多一個「討教」選項，開一場單挑。新機制，不在這一批。
2. **內容放哪。**
   - 建議**甲**：`content/gear.json` 加一個 `signature_arms` 鍵。
     - 理由：
       - 名將贈禮在同一份檔裡。
       - 測試內容沒有 `gear.json`，本命兵器自然是空的，舊測試一個字都不變。
       - `naming.name_problem` 的 `GEAR_CLASH` 本來就查這一份，順手擋住模型與玩家取到這幾個名字。
   - 乙：照兵器設計第五節原文另開 `content/signature_arms.json`。要多一個載入函式、`Content` 多一個欄位，`naming` 也要另查一份。
3. **孫堅退場或重創之後。**
   - 建議：
     - 兩條路**都沒了**（《挑戰每季都有》3.5、5.4 的寫法：「他身上的機會也跟著沒了」）。
     - **把他打到重創的那一場例外照給**：第三次打贏的那一下 `_rout` 會先扣聲威，扣到 0 就重創；這一場是他「讓你奪走」的那一場，不給說不過去。做法是 `due(..., beaten=fid)`，這一場不查退場。
     - 另外六位不是大勢人物，不受影響。
   - 乙：情誼那條路照送（人退場了，兵器還能託人送來）。要多寫一句託人送來的話。
4. **拿到時的公告與寫法。**
   - 建議：
     - 江湖史一行、天下大事傳聞一句，都具名，同神器定名（`smithing.name_divine`）。
     - 行狀記一筆（人物），同名將贈禮。
     - 階品寫「三階上品・本命」。拆解鈕寫「本命兵器不能拆」，引擎回「這是名將的本命兵器……拆不得」；求兵寫「本命兵器交不得」。
     - 字全部待 joy 潤。
   - 乙：階品照「・神器」不分，拆解、求兵照原品那兩句。少改三處，可是神器譜與修練頁分不出它是打出來的還是名將給的。
5. **「打贏」怎麼算。**
   - 建議：
     - 大勝、險勝算（`team.WIN_TIERS`，同「他敗走」）；僵持、落敗不算。
     - 三次不必連著，照這一季累計，記在 `PlayerState.figure_wins`（人物 id → 次數），角色每季重來自然清掉。
     - **叛投不清**：《挑戰每季都有》5.4 寫明前官軍叛投黃巾之後也能走這條路；本命兵器一季全服只有一把，總量不變。
6. **裝備庫滿了。**
   - 建議：寄放，同名將贈禮（`treasures.deliver(..., hold=True)`），下次同步騰得出空位就補。寄放了也算給出去了。
   - 乙：同挑戰本人掉寶物，滿了就沒了、也不記。本命兵器一季全服只有一把，拿不到太傷，不建議。

數字照設計原文，不列：情誼 80、打贏 3 次（4.10【定】）。原品加成 22%＋上品 4%（打造隱藏配方設計 4.3【定】）。

def check_signature_arms(c: Content, need, known) -> None:
    """名將本命兵器（content/gear.json 的 signature_arms，兵器設計 4.10）：人物存在、一位只寫一把；種類、屬性合法；名字跟寶物、名駒、

def due(state: GameState, content: Content, *, beaten: str | None = None) -> tuple[list[Equipment], list[str]]:
    """該給的本命兵器給出去（兵器設計 4.10）：這一季還沒給過人的每一位名將，情誼到 signature_affinity 是他送的（gift），
    不然內容寫了 figure、你這一季打贏他本人 signature_wins 次是你奪走的（seized）。記下歸屬（WorldState.signature_arms，呼叫端那一下
    動作最後 _save_season 存回去）、交到你手上（裝備庫滿了寄放，treasures.deliver hold=True）、江湖史一行、天下大事傳聞一句（具名）。
    兵器關著不給也不記（開了之後照樣給得出去）。寫了 figure 的那一位這一季退場或重創就不給——beaten 是他（把他打到重創的這一場）例外。
    回（給出去的那幾把, 江湖紀錄的話）。不擲骰。"""
    p, w, cfg = state.player, state.world, content.config.weapons
    if not cfg.enabled:
        return [], []
    items: list[Equipment] = []
    lines: list[str] = []
    for arm in content.gear.signature_arms:
        if arm.character in w.signature_arms:
            continue
        if arm.figure is not None and arm.figure != beaten and figures.is_out(state, arm.figure):
            continue  # 退場、重創：這一季不再出現，本命兵器也跟著沒了（挑戰每季都有設計 3.5、5.4）
        if p.affinities.get(arm.character, 0) >= cfg.signature_affinity:
            via = "gift"
        elif arm.figure is not None and p.figure_wins.get(arm.figure, 0) >= cfg.signature_wins:
            via = "seized"
        else:
            continue
        w.signature_arms[arm.character] = SignatureClaim(owner=p.name, via=via)
        item = new_arm(state, arm)
        words = {"general": content.characters[arm.character].name, "arm": item.name}
        line = (arm.gift_line or GIFT_LINE) if via == "gift" else (arm.seize_line or SEIZE_LINE)
        lines.append(line.format(**words))
        lines += treasures.deliver(state, content, item, hold=True)
        add_chronicle(state, (CHRONICLE_GIFT if via == "gift" else CHRONICLE_SEIZED).format(who=p.name, **words))
        add_rumor(state, (RUMOR_GIFT if via == "gift" else RUMOR_SEIZED).format(who=p.name, **words), None, content=content, named=True)
        items.append(item)
    return items, lines

    return (ANNAL_GIFT if via == "gift" else ANNAL_SEIZED).format(general=general, arm=item.name)

    table = {arm.character: arm for arm in content.gear.signature_arms}
