# 新手引導 2：入伍段（引薦人三步） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 第一次投靠（或拜入陣營名下的門派）那一刻，由那一邊的引薦人（官軍老石、黃巾青禾、豪強季伯平）帶三步：入營、看戰局、第一道軍令。取代濃縮版 T6 加在舊引導最後的兩步（`t7_orders`、`t8_order_done`）。

**Architecture:** 入伍段不佔 `tutorial_step`：它是另一段，記在 `PlayerState.enlist_step`（None＝還沒開始）。內容寫在 `content/tutorial.json` 的 `enlist`：兩步的完成條件（看過軍令卡、替軍令出過一次力）與三位引薦人各自的話。`guide.note_action` 在序章走完之後順便推入伍段；`Game.guide_box` 在序章之後輪到入伍段，框上寫引薦人的名字；走完時框上是引薦人的結尾一句、按「知道了」收起。只在第一季（`rules.season_one`）才有：beta 季沒有軍令。

**Tech Stack:** Python 3／pydantic（`tianxia/`）、FastAPI（`server.py`）、原生 JavaScript（`web/app.js`）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-05-新手引導重做-design.md` 第四節（入伍段）、6.2～6.3（對話框、主線與目標）、7.1～7.3（回鍋、舊存檔、略過）、10.4、10.6（文字）。

## Global Constraints

- 入伍段只在第一季（`rules.season_one(content, state.world)`）開始；開關關著時一個字都不變。
- 入伍段只走一次：走完的人換季、再投靠都不重走（設計 7.1）；沒走完就換季的，下一季投靠時從頭走。
- 略過新手引導＝序章與入伍段都略過（設計 7.3）；略過的人不畫入伍段的框。
- 換版當下已經投靠的角色不走入伍段；還沒投靠的，第一次投靠時照常走（設計 7.2）。
- 「剛剛」只放行動的結果；引薦人的話走對話框（引導重做設計 8.1.3 的規矩照舊）。
- 假人看不出來：假人的對話框沒人看，入伍段照樣記但不影響假人的行動。
- 文字照設計 10.4（S1 審過）；引薦人的名字原創。
- 測試：`.venv/Scripts/python.exe -m pytest -q`；`node --check web/app.js`；375×812 看過（`http://dev.localhost:<port>`）。

## Review Focus

1. **投靠時一次行動完成兩件事**：投靠那一下就開始入伍段（框換成引薦人），同一下不能把第一步也算完。→ Task 1 `test_joining_opens_the_first_step_only`。
2. **拜入陣營名下的門派也算投靠**（`apply_effect` 的 `join_sect`，在事件選項裡）：一樣開始入伍段。→ Task 1 `test_joining_through_a_sect_starts_enlistment`。
3. **還在序章（或舊引導還有沒走完的步驟）就投靠**：入伍段等前面的走完才出現在框上，進度照記（第一道軍令先做了也算）。→ Task 1 `test_enlistment_waits_behind_the_tutorial`。
4. **舊存檔**：已經投靠的不走入伍段；舊的 t7、t8 步數不再指到別的步驟。→ Task 2 `test_old_saves_with_a_faction_skip_enlistment`。
5. **開關關著（beta 季）投靠**：不開始入伍段，框照舊。→ Task 1 `test_no_enlistment_outside_season_one`。

- [ ] **Step 4：`tianxia/enlist.py`**

```python
"""入伍段（新手引導重做設計第四節）：第一次投靠時由那一邊的引薦人帶兩步——看戰局（看過軍令卡）、第一道軍令。
不佔 tutorial_step：記在 PlayerState.enlist_step（None＝還沒開始）。只在第一季開始（beta 季沒有軍令）。"""
from __future__ import annotations

from .models import Content, Recruiter
from .rules import season_one
from .state import GameState
from .world_state import WorldStateStore


def _steps(content: Content):
    e = content.tutorial.enlist
    return e.steps if e is not None else []


def recruiter(state: GameState, content: Content) -> Recruiter | None:
    e, faction = content.tutorial.enlist, state.player.faction
    return e.recruiters.get(faction) if e is not None and faction is not None else None


def active(state: GameState, content: Content) -> bool:
    step = state.player.enlist_step
    return step is not None and step < len(_steps(content))


def done(state: GameState, content: Content) -> bool:
    step = state.player.enlist_step
    return step is not None and step >= len(_steps(content)) > 0


def begin_if_joined(state: GameState, content: Content) -> bool:
    """剛投靠（有陣營、入伍段還沒開始、這一季是第一季、沒有略過引導、這一邊有引薦人）：開始入伍段。回傳有沒有開始。"""
    p = state.player
    if p.enlist_step is not None or p.guide_skipped or not season_one(content, state.world):
        return False
    if recruiter(state, content) is None:
        return False
    p.enlist_step = 0
    return True


def note(state: GameState, content: Content, world: WorldStateStore, action: str) -> list[str]:
    """跟 guide.note_action 同一個做法：符合這一步就往下一步，一路到不符合為止；走完設 enlist_end（框上換結尾）。"""
    from .guide import goal_met  # guide 也 import 這裡：放在函式裡避免循環

    msgs: list[str] = []
    todo = _steps(content)
    while active(state, content) and goal_met(state, content, world, todo[state.player.enlist_step].done_when, action):
        state.player.enlist_step += 1
        msgs.append("✔ 引導完成")
    if msgs and done(state, content):
        state.player.enlist_end = True
    return msgs


def box(state: GameState, content: Content) -> dict | None:
    """入伍段的對話框：進行中是這一步的話（第一步前面接入營那一段）；剛走完是結尾、等「知道了」。其他是 None。"""
    who = recruiter(state, content)
    if who is None:
        return None
    p = state.player
    if active(state, content):
        i = p.enlist_step
        text = f"{who.intro}\n\n{who.briefing}" if i == 0 else who.order_hint
        return {
            "speaker": who.name, "scene": "", "text": text, "line": who.lines[i] if i < len(who.lines) else "",
            "done": list(p.guide_done), "end": False, "step": _steps(content)[i].id,
        }
    if p.enlist_end:
        return {"speaker": who.name, "scene": "", "text": who.done, "line": "", "done": list(p.guide_done), "end": True, "step": ""}
    return None
```
