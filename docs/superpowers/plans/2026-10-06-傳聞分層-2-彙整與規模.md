# 傳聞分層（二）：彙整、上限、見聞紀錄、規模 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 傳聞分層的「寫」那一半與規模：第一季裡，人站在大區裡就把傳聞板上的地方傳聞記進見聞紀錄（`rumor_heard`），離開之後見聞頁「我的見聞」還翻得到、輿圖的 ✦ 照它標；例行行動不再一次一則，記成各大區的計數，每 4 個季曆時寫成一則「【近況】…」摘要（人數、做了什麼、戰況、另有幾件小事）；內容寫了傳聞文字的單獨事件每個大區每季曆時最多 5 則上傳聞板，超過的併進摘要；「你不在的時候」第三段換成所在大區的摘要；全服決戰開打成為天下大事（同一句寫進江湖史）；同步不再把整季的傳聞讀進記憶體，只讀聽得到的那一部分，畫面一字不差。

**Architecture:**
- **見聞紀錄**：資料庫第 1 版就建好的 `rumor_heard` 表（線上架構第 1 期照傳聞分層 3.1 建、一直沒人寫）。`WorldStateStore.heard_rumors`／`record_heard`；`GameState.heard`（只在記憶體，`Game._reconcile_season` 每次讀）；`rules.Ears.heard` 一欄、`rules.audible` 加一條「聽過的照樣聽得到」——1a 的規則只有一份，照它在 `Ears` 留的位置接上。`Game._record_heard` 在同步的最後把 `rumor_view.newly_heard` 記進去。
- **摘要與上限**：新模組 `tianxia/rumor_digest.py`（純規則、只碰狀態與文字）：`count`（`Game.push_trend` 與 `Game._order_credit` 呼叫）、`admit`（`rules.apply_effect` 的事件傳聞先問它）、`flush`（`world.season_hour` 每曆時呼叫，跟晉升的每日彙整 `ranks.flush_news` 同一個位置，那是現成的先例）。計數放在 `WorldState`（有界：大區 × 陣營 × 種類），人頭的去重放在 `PlayerState.digest_seen`。
- **天下大事**：新模組 `tianxia/world_news.py`：`announce`（傳聞＋江湖史）、`showdown_opened`（`world._claim_showdown` 開集結的那一刻）。玉璽碎片易手由計畫 2 自己用 `rules.add_rumor(…, layer="world")` 發（協調者 2026-10-06 調整範圍），這一份確保那種直接寫的天下大事不會被上限、摘要、只讀一部分攔到或漏掉。
- **規模**：`WorldStateStore.get_season(window)`；`rules.rumor_window` 給「傳聞板上的地方傳聞（任何大區）＋自己聽過的＋其他層整季」；`Game._load_season` 是同步、重讀角色、換季重來讀季的唯一入口。
- **第一季的開關**：全部只在 `rules.season_one(content, world)` 成立時發生；開關關著（或這一季沒蓋章）時沒有見聞紀錄、沒有計數、沒有上限、沒有摘要、沒有新的天下大事、同步照舊整季讀——beta 一個字都不變（每個任務都有開關關著的測試）。

**Tech Stack:** Python 3.14、pydantic、SQLite、pytest。這一份不改網頁（`web/app.js` 的 `rumorLayersHtml` 照伺服器給的段數畫，多一段不用改）。

## Global Constraints

- `tianxia/` 不 import 任何網頁框架；**引擎不讀電腦時鐘**：摘要與上限看賽季時鐘換成的季曆（`calendar.point`），「你不在的時候」照 1a 看傳進來的 `now`。
- **一條規則**：誰聽得到哪一則只看 `rules.audible(rumor, rules.ears_of(state, content))`；見聞紀錄是 `Ears` 的一欄，不另寫判斷。同步讀哪些傳聞（`rules.rumor_window`）必須是「任何人此刻聽得到的」的超集——Task 6 有一條測試把只讀一部分與整季讀進來的畫面逐字比對。
- **時間單位**（PM 2026-10-06）：摘要間隔、每小時上限是季曆時（跟著 weekend 設定縮）；傳聞板的「3 天」照 1a 是季曆天。
- **第一季開關**：新行為只在 `rules.season_one(content, world)` 成立時發生；關著或沒蓋章時規則、存檔、畫面跟 1a 之後一樣，每個任務都有開關關著的測試。

def hour_index(world: WorldState, content: Content) -> int:
    """這一刻是這一季的第幾個曆時（從 0 起）。"""
    at = calendar.point(world.time, content, world)
    return (at.cal_day - 1) * 24 + at.hour


def window_index(world: WorldState, content: Content) -> int:
    """這一刻落在第幾段（一段 rumor_digest_hours 個曆時，每段結束寫一次摘要）。"""
    return hour_index(world, content) // content.config.rumor_digest_hours


def _region_here(state: GameState, content: Content) -> str | None:
    from . import atlas  # noqa: PLC0415  atlas → world → rumor_digest：在函式裡 import，避免循環

    region = atlas.region_of(content, state.player.location)
    return region.id if region is not None else None


def count(state: GameState, content: Content, kind: str) -> None:
    """記一次例行行動（kind：推動的來源 train／drill／duty／event，或軍令的個人部分 order）：記在此刻所在的大區、
    自己陣營（散人是 LONER）的那一格。人數一段只算一次（PlayerState.digest_seen），同一個人做十次還是「一位」。
    地圖沒有大區時不記。"""
    region = _region_here(state, content)
    if region is None:
        return
    p, w = state.player, state.world
    side = p.faction or LONER
    activity = w.activity.setdefault(region, RegionActivity())
    key = f"{side}:{kind}"
    activity.acts[key] = activity.acts.get(key, 0) + 1
    window = window_index(w, content)
    seen = f"{window}:{region}:{side}"
    p.digest_seen = [k for k in p.digest_seen if k.startswith(f"{window}:")]  # 只留這一段的
    if seen not in p.digest_seen:
        p.digest_seen.append(seen)
        activity.people[side] = activity.people.get(side, 0) + 1


def admit(state: GameState, content: Content) -> bool:
    """這一則單獨事件（內容寫了傳聞文字的事件效果，rules.apply_effect）上不上傳聞板：此刻所在的大區這個曆時已經上了
    Config.local_event_cap 則就不上，記成那個大區的 overflow（下一則摘要寫「另有幾件小事」）。地圖沒有大區時一律上。
    軍令總額度達成的外洩（orders._leak）、叛投的地方傳聞不走這裡，一定會發（3.2「一定會發的」）。"""
    region = _region_here(state, content)
    if region is None:
        return True
    w = state.world
    hour = hour_index(w, content)
    key = f"{hour}:{region}"
    w.local_hour = {k: v for k, v in w.local_hour.items() if k.startswith(f"{hour}:")}  # 只留這個曆時的
    if w.local_hour.get(key, 0) >= content.config.local_event_cap:
        w.activity.setdefault(region, RegionActivity()).overflow += 1
        return False
    w.local_hour[key] = w.local_hour.get(key, 0) + 1
    return True

```python
def headcount(n: int, unit: str = "位") -> str:
    """人數、件數的說法（3.2「大約多少人」）：十以內照實寫（週末兩個人的伺服器寫得出「兩位」，不會冒出「四十多位」），
    再多是「十餘位」「四十多位」「上百位」「兩百多位」「上千位」。"""
    if n <= 0:
        return ""
    if n == 2:
        return f"兩{unit}"
    if n < 10:
        return f"{NUMERALS[n]}{unit}"
    if n == 10:
        return f"十{unit}"
    if n < 20:
        return f"十餘{unit}"
    if n < 100:
        tens = NUMERALS[n // 10]
        return f"{tens}十{unit}" if n % 10 == 0 else f"{tens}十多{unit}"
    if n < 200:
        return f"上百{unit}"
    if n < 1000:
        return f"{'兩' if n // 100 == 2 else NUMERALS[n // 100]}百多{unit}"
    return f"上千{unit}"


def _sides(content: Content, activity: RegionActivity) -> list[str]:
    """這一段在這裡做過事的各方：照劇本陣營的順序，散人最後。"""
    order = [f.id for f in content.scenario.factions] + [LONER]
    return [s for s in order if activity.people.get(s)] + [s for s in activity.people if s not in order and activity.people[s]]


def _doing(side: str, activity: RegionActivity) -> str:
    """這一方這一段做最多的那一種事的說法。"""
    mine = {key.split(":", 1)[1]: n for key, n in activity.acts.items() if key.split(":", 1)[0] == side}
    if not mine:
        return DOING_ANY
    kind = max(mine, key=lambda k: (mine[k], -KINDS.index(k) if k in KINDS else -len(KINDS)))
    return DOING.get((side, kind)) or DOING.get((LONER, kind)) or DOING_ANY


def _changes(state: GameState, content: Content, region: MapRegion) -> list[str]:
    """這一段這個大區的戰況、豪強割據變化（不寫數字）：跟上一則摘要那一刻比（WorldState.digest_marks；沒記過照起始值）。
    沒有戰線的大區（洛陽、幽州）不寫。"""
    if region.front is None:
        return []
    w = state.world
    out: list[str] = []
    for trend_id in (region.front, rules.GEJU):
        if not rules.trend_shown(content, w, trend_id) or not rules.is_revealed(w, content, trend_id):
            continue
        start = next(t.start for t in content.scenario.trends if t.id == trend_id)
        delta = rules.trend_value(state, content, trend_id) - w.digest_marks.get(trend_id, start)
        if not delta:
            continue
        phrase = rules.front_text(content, trend_id, delta, f"{w.time}|{region.id}")
        if trend_id != rules.GEJU:  # 戰線那句是「潁川汝南：官軍步步進逼」：摘要開頭已經寫了大區，拿掉線名
            phrase = FRONT.format(phrase=phrase.removeprefix(f"{rules.trend_name(content, trend_id)}："))
        out.append(phrase)
    return out


def digest_text(state: GameState, content: Content, region: MapRegion, activity: RegionActivity) -> str:
    """一則摘要（3.2 的例句）：「【近況】潁川汝南一帶，兩位官軍討伐黃巾，一位黃巾在村口傳道；戰況上官軍步步進逼；
    豪強趁亂坐大；另有三件小事。」只寫人數、不寫名字（第七節：摘要只寫人數），真人假人一起算。"""
    names = {f.id: f.name for f in content.scenario.factions}
    parts = [
        PART.format(count=headcount(activity.people[side]), who=WHO.get(side) or names.get(side, side), doing=_doing(side, activity))
        for side in _sides(content, activity)
    ]
    clauses = (["，".join(parts)] if parts else []) + _changes(state, content, region)
    if activity.overflow:
        clauses.append(OVERFLOW.format(count=headcount(activity.overflow, "件")))
    return f"{HEAD}{OPENING.format(region=region.name)}{'；'.join(clauses)}。"


def flush(state: GameState, content: Content) -> None:
    """每跨過一個曆時呼叫一次（world.season_hour）。跨進第 rumor_digest_hours 的倍數個曆時那一刻，上一段有事的大區各發一則
    地方傳聞（不具名、沒有發生地、記著大區；傳聞板與見聞紀錄照一般的地方傳聞處理），然後清掉計數、記下此刻的戰況給下一則比。
    這一段沒人做事、也沒有被擋下的單獨事件的大區不發：人少的伺服器不會每四個時辰冒出一則空話。"""
    w = state.world
    if hour_index(w, content) % content.config.rumor_digest_hours:
        return
    for region in content.map.regions:
        activity = w.activity.get(region.id)
        if activity is None or not (any(activity.people.values()) or activity.overflow):
            continue
        rules.add_rumor(state, digest_text(state, content, region, activity), content=content, layer="local", named=False)
        w.rumors[-1].region = region.id  # 沒有發生地：大區直接記上（同 orders._leak）
    w.activity = {}
    w.digest_marks = {
        t.id: rules.trend_value(state, content, t.id) for t in content.scenario.trends if rules.is_side_trend(content, t.id)
    }
```

**為什麼這樣切、畫面為什麼一字不差（Review Focus 1）**：引擎裡所有讀 `state.world.rumors` 給人看的地方——見聞頁的清單與分層、沿途打聽、輿圖的 ✦ 與詳情、龍頭人物的近況、你不在的時候——都先過 `rules.audible`。第一季 `audible` 的地方傳聞只有兩種：在此刻所在大區的傳聞板上（`time >= board_since`），或在見聞紀錄裡（`rumor_heard`）。所以只讀「其他層整季＋地方傳聞在任何大區傳聞板上的＋自己聽過的」就一則不少：
- 傳聞板只看時間、不看大區，所以這一次請求裡走到別的大區（疾行立刻到）、在路上跨區，畫面照樣接得上；
- 陣營軍情不照陣營濾（整季讀，畫面再濾），叛投的人這一次請求就看得到新陣營的軍情；
- `board_since` 只會越來越晚：請求中途季的時鐘往前走，聽得到的地方傳聞只會變少，請求開頭讀進來的一定夠；請求中途新寫的傳聞本來就加在記憶體裡那一份；
- 其他讀 `rumors` 的地方不是給人看的：`_drop_stale_references` 只修讀進來那幾則的地點、`orders._leak` 讀的是剛加的那一則。
- 江湖史照舊整季讀（量小）；管理者工具、決戰收場、`Game.advance`（快轉）那幾處照舊 `get_season()` 整季讀（不常發生）；腳本、`scripts/sim_*` 不受影響。
