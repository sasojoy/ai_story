# 決戰改版 1：三招與推力 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全服決戰的固定招從「穩守／猛攻」改成「強攻、固守、奇襲」三招互剋：每個人每招有自己的份量（實力 × 適性 × 氣血狀態），剋制係數跟整個敵陣的出招比例比，兩邊的力量照 √人數 遞減合成，一回合最多推 10；畫面寫出每招的分數、對面上一回合的出招比例，幕文字照誰佔上風換版本。

**Architecture:** 數字集中在 `Config.battle`（`BattleTuning`，全部【預設】）；選項多一個 `move` 欄位，`action_tags` 不再管固定招。份量在加入戰局時由那個玩家自己的 `Game` 快照進 `BattleParticipant.scores`（同現在快照 `power` 的做法），`battle_instance.resolve_round` 只讀共用戰鬥狀態算推力與扣血。放手一搏這一份**先照舊**（計畫三再改），它的推動加在三招合成之後。作戰方針、AI 代挑是計畫二；逾時這一份先代出自己那一邊的「固守」。

**Tech Stack:** Python 3／pydantic（`tianxia/`）、pytest；網頁不用改（選項與場景文字都由引擎給）。

**Spec:** `docs/superpowers/specs/2026-10-03-戰鬥系統-design.md` 3.2、3.4（企劃者 2026-10-06：數字「照預設做、測完再調」）。

**開工條件：** 照 main `681192a` 寫，可以馬上開工。決戰改版二（方針與 AI 代挑）、三（放手一搏）、四（功效進決戰）、五（豪強）、六（參戰誘因）都接在這份後面。

**執行方式：** 子代理逐步做（superpowers:subagent-driven-development：每個 Task 一個新的子代理實作、另一個子代理審過才做下一個，最後整條分支再審一次）。

## Global Constraints

- 三招：`MOVES = ("強攻", "固守", "奇襲")`；**固守剋強攻、強攻剋奇襲、奇襲剋固守**（3.4）。
- 剋制係數 ＝ 1 ＋ 0.5 ×（對面出「被你剋的招」的比例）－ 0.5 ×（對面出「剋你的招」的比例），0.5～1.5。對面比例只算這一回合出**固定招**的人（放手一搏不算進比例）；對面沒人出固定招時係數是 1。
- 份量（0～100）＝ 實力 × 適性 ÷ 100 × 氣血狀態。實力 ＝ min(100, 40 ＋ 0.4 × min(威力, 150))；適性 ＝ 75 ＋ 武學屬性擅長那招 15／不擅長 −15 ＋ 內功屬性擅長 10／不擅長 −10，夾在 50～100；氣血狀態 ＝ 0.5 ＋ 0.5 × 這一場剩的氣血 ÷ 這一場的上限。全部【預設】，數字在 `Config.battle`。
- 一邊的力量 ＝ Σ（份量 × 剋制係數）÷ √（這一邊這回合出固定招的人數）；一回合推力 ＝ 10 ×（第一方 − 第二方）÷（兩方相加），四捨五入成整數。一邊沒人出固定招、另一邊有：推滿 10。兩邊都沒有：0。
- 扣氣血：強攻 60（自己的武學威力最多抵銷六成，同現在的猛攻）、奇襲 35、固守 15，再乘（2 − 剋制係數）。
- 戰局方向照舊：`factions[0]`（官軍）是正向。
- 份量在**加入戰局時**快照（同 `power`）；之後換武學、修練不影響這一場。舊資料、這次之前就加入的人沒有 `scores`，份量算 0（照常扣血與出局）。
- 放手一搏這一份照舊（`FreeTextGamble` 的公式），推動加在三招合成之後再夾 0～100；計畫三改。
- 逾時沒出手：代出自己那一邊的「固守」（計畫二改成照方針與 AI）。
- 數字全由規則引擎決定。
- `huangjin_showdown`（黃巾決戰）**保留**、一起改成三招：`season_one` 預設還是 false，預設的季打的是它；等預設改成 `season_one: true`，再照設計 5.1 從真實內容拿掉（PM 2026-10-06）。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

## Review Focus

1. **人多不是多數決**：1000 對 250、兩邊全出同一招、份量相同，一回合推 3.3 左右，不是一回合就撞到 100。→ Task 3 `test_numbers_help_but_with_diminishing_returns`。
2. **一邊沒人出手**（全倒下、全離開大區、全放手一搏）：另一邊推滿 10，不除以零。→ Task 3 `test_a_side_with_nobody_on_a_fixed_move_gets_pushed_ten`。
3. **舊的進行中戰局**：上線前就加入、沒有 `scores` 的人，結算不當機（份量 0，照常扣血）。→ Task 3 `test_a_participant_without_scores_counts_as_zero`。
4. **剋制係數的邊界**：對面全出被你剋的招 ×1.5、全出剋你的招 ×0.5，扣血跟著 ×0.5～×1.5，不會變成負的。→ Task 3 `test_counter_coefficient_spans_half_to_one_and_a_half`。
5. **幕文字換版本不洩漏鎖定**：只看公開的戰局（>50、<50、=50），跟伏筆鎖定無關。→ Task 4 `test_the_act_text_follows_who_leads`。

```python
def move_scores(tuning: BattleTuning, power: float, outer: str | None, inner: str | None) -> dict[str, float]:
    """這個人每一招的份量（還沒乘氣血狀態，戰鬥系統 3.4）：實力 × 適性 ÷ 100。
    實力 ＝ min(100, 40 ＋ 0.4 × min(威力, 150))；適性 ＝ 75 ± 武學（招式）屬性 15 ± 內功屬性 10，夾在 50～100。
    outer／inner 是武學與內功的屬性（沒學是 None，不加減）。加入戰局時由那個玩家自己的 Game 算好快照進來。"""
    strength = min(100.0, tuning.power_base + tuning.power_per * min(max(power, 0.0), tuning.power_cap))
    scores = {}
    for move in MOVES:
        fit = tuning.affinity_base
        for attribute, step in ((outer, tuning.affinity_outer), (inner, tuning.affinity_inner)):
            good, bad = tuning.affinity.get(attribute, (None, None)) if attribute else (None, None)
            fit += step if move == good else -step if move == bad else 0.0
        scores[move] = round(strength * max(50.0, min(100.0, fit)) / 100, 1)
    return scores
```

```python
def counter_coefficient(tuning: BattleTuning, move: str, enemy_mix: dict[str, float]) -> float:
    """剋制係數（戰鬥系統 3.4）：1 ＋ 0.5 × 對面出「被你剋的招」的比例 － 0.5 × 對面出「剋你的招」的比例，0.5～1.5。"""
    beaten = BEATS[move]
    beater = next(m for m, v in BEATS.items() if v == move)
    return 1 + tuning.counter * enemy_mix.get(beaten, 0.0) - tuning.counter * enemy_mix.get(beater, 0.0)


def condition(p: BattleParticipant) -> float:
    """這一場的氣血狀態：0.5 ＋ 0.5 × 剩的 ÷ 上限（同遭遇戰，戰鬥系統 3.4）。"""
    return encounter.condition_of(p.neili, p.neili_cap)


def option_of(definition: BattleDef, act_index: int, faction: str, tag: str) -> BattleOption | None:
    return next(
        (o for o in definition.acts[act_index].options if o.tag == tag and o.faction in (None, faction)), None,
    )


def _mix(moves: dict[str, str], factions: dict[str, str], side: str) -> dict[str, float]:
    """這一邊這回合各招的比例（只算出固定招的人）；沒人出就是空的。"""
    mine = [moves[name] for name in moves if factions[name] == side]
    return {m: mine.count(m) / len(mine) for m in MOVES} if mine else {}
```

```python
"""決戰改版一 Task 6：三招與推力的數字量一場（戰鬥系統設計 3.4【預設】）。只量、不改數字、不擋上線。

假人直接在 battle_instance 上打（不經過 Game）：每個人的威力從「新手到高手」之間抽、武學與內功屬性隨機，
份量照 move_scores 算；出招照幾種策略。每種情況打 9 回合，印每回合的推力與收場的戰局。

用法：.venv/Scripts/python.exe scripts/measure_battle.py
"""
from __future__ import annotations

import io
import random
import statistics
import sys
from pathlib import Path

sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))

from tianxia import battle_instance as bi  # noqa: E402
from tianxia.content import load_content  # noqa: E402
from tianxia.models import BEATS, MOVES  # noqa: E402

ATTRS = ("剛", "實", "陽", "柔", "陰", "慢", "快", "虛")
CODES = {"強攻": "strong", "固守": "hold", "奇襲": "raid"}


def best(p, rng, last_enemy):
    return max(MOVES, key=lambda m: p.scores[m])


def counter(p, rng, last_enemy):
    """猜對面這回合照上回合最多的那招出，出剋它的招。"""
    if not last_enemy:
        return best(p, rng, last_enemy)
    likely = max(last_enemy, key=last_enemy.get)
    return next(m for m, v in BEATS.items() if v == likely)


def anything(p, rng, last_enemy):
    return rng.choice(MOVES)


STRATEGIES = {"拿手": best, "剋上回合": counter, "亂出": anything}


def run(definition, tuning, guan, huang, guan_play, huang_play, seed=0):
    rng = random.Random(seed)
    battle = bi.start_muster(definition, now=0)
    for side, count in (("guan", guan), ("huang", huang)):
        for i in range(count):
            power = rng.uniform(0, 150)
            scores = bi.move_scores(tuning, power, rng.choice(ATTRS), rng.choice(ATTRS))
            bi.join_faction(battle, f"{side}{i}", side, neili_cap=400, power=power, scores=scores)
    bi.close_muster(battle, definition, rng, now=0)
    pushes = []
    while battle.phase == "active":
        before = battle.trend
        for name, p in battle.participants.items():
            if p.eliminated:
                continue
            enemy = "huang" if p.faction == "guan" else "guan"
            play = guan_play if p.faction == "guan" else huang_play
            move = play(p, rng, battle.last_mix.get(enemy, {}))
            bi.submit_action(battle, name, f"{p.faction}_{CODES[move]}")
        bi.resolve_round(battle, definition, rng, now=0, tuning=tuning)
        pushes.append(battle.trend - before)
    return battle.trend, pushes, battle.round_number


def main() -> None:
    content = load_content(ROOT / "content")
    definition = content.battles["changshe_fire"].model_copy(update={"trend_start": 50})
    tuning = content.config.battle
    cases = [(1000, 250), (600, 400), (20, 20), (10, 2), (2, 10)]
    for guan, huang in cases:
        for gname, gplay in STRATEGIES.items():
            for hname, hplay in STRATEGIES.items():
                ends = [run(definition, tuning, guan, huang, gplay, hplay, seed) for seed in range(5)]
                trends = [t for t, _, _ in ends]
                rounds = [r for _, _, r in ends]
                print(f"官 {guan}（{gname}）對 黃 {huang}（{hname}）：收場戰局 {statistics.median(trends)}"
                      f"（{min(trends)}～{max(trends)}），回合中位 {statistics.median(rounds)}，"
                      f"第一場每回合推 {ends[0][1]}")


if __name__ == "__main__":
    main()
```
