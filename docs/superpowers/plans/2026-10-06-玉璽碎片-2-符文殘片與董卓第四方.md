# 玉璽碎片 2：符文殘片、南華觀讀壁、混元一氣與董卓第四方 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「大勢任務：玉璽碎片一」的第二半，疊在第一份（`2026-10-06-玉璽碎片-1-張角之死爭奪與持璽勝利.md`）上：入口二「線索浮現」——所有人（含散人）私下蒐集符文殘片（七個來源，每人每個來源一片，必要的「廣宗的經文」第 7 週以後才出現），湊到門檻到南華觀對著石壁讀出來，揭開「張角持有傳國玉璽的一角」的秘密（天下大事、具名、「識破天書」稱號、世界旗標 `runic_revealed`、碰到才說的 `h_mandate`）；勝利條件改寫，碎片在張角手上，有人從他手上奪走才開始兩週倒數，張角守到季末黃巾以持璽獲勝；第一個從張角手上奪下碎片的人學到「混元一氣」（取代 beta 南華觀看守者給的那一份）。另外補上董卓第四方的行為（第一季設計 8.4）：擁兵自重時把他的戰線往 50 拉、持璽時回聲威、三方都能挑戰本人、聲威歸零重創時碎片掉在他營中、第 8 週接替盧植之後冀州偏黃巾而他聲威夠高時擁兵自重（沒有碎片）。假人會蒐集殘片、讀壁；兩支整季模擬回報。全部藏在第一份同一個開關後面（`shard.active`：第一季的規則、而且這一季開季時蓋了碎片的章）。

**Architecture:** 符文殘片的內容加在 `content/shard.json` 的 `runic`（`models.RunicDef`：門檻、必要的那一片、七個來源、讀壁的地點、混元一氣、字）；殘片記在角色上：來源一片一片記在 `PlayerState.runic_sources`，正式版丙二的晉升給的記在 `PlayerState.runic_pieces`（基準量）；事件的效果 `Effect.runic_source`／`Effect.runic` 給。七個來源與汝南名士是新檔 `content/events/runic.json`（條件寫 `week_min`，季曆的條件在 beta 一律不成立，所以只在第一季出現；世界旗標 `runic_closed` 在碎片現世之後把它們關掉）。南華觀在 beta 要等 `xi_open` 才去得了，第一季由新的 `season_one_off.unlocks` 拿掉那把鎖。讀壁是選項 `act:read_wall`（`shard.wall_problem`、`shard.reveal`），揭開之後碎片的樣子是第一份已經寫好的 `keeper`。董卓第四方的行為在 `shard._rival_acts`（第一份的 `shard.hour` 每曆時呼叫），挑戰他走既有的「挑戰本人」（`figures.can_challenge`、`figures.rebels_at`）。

**Tech Stack:** Python 3.14、pydantic、FastAPI、原生 JavaScript、pytest。

## Review Focus

1. **先發生的算數**：張角先死（入口一），南華觀的讀壁消失、殘片事件關掉、拿殘片不再記；已經有人讀壁揭開，別人就不能再讀；碎片在張角手上時他死了，碎片掉在廣宗、無主、不再推出一次（Task 2 `test_the_runic_events_close_once_the_shard_is_out`、Task 3 `test_the_wall_closes_when_zhangjiao_dies_first`、`test_zhangjiao_dying_with_the_shard_drops_it_ownerless`、Task 1 `test_each_source_counts_once_and_only_while_the_secret_is_kept`）。
2. **揭開了但還不倒數**：碎片在張角手上時勝利條件已經改寫（態勢的決定性勝利暫停），倒數要等有人從他手上奪走；黃巾的人不能奪自己的張角；張角守到季末是黃天當立（Task 3 `test_reading_the_wall_reveals_the_secret`、Task 4）。

4. **`h_mandate` 在引導計畫三還沒進來時什麼都不做**，進來之後讀壁的人與收到公告的人各說一次（Task 3 `test_the_mandate_hint_fires_once_the_tutorial_plan_is_in`）。
5. **董卓**：擁兵自重之後官軍也打得了他；他被打到聲威歸零，碎片掉在他營中；第二個入口沒有碎片、門檻不夠不觸發（Task 5）。

```python
# ── 符文殘片（入口二「線索浮現」；伏筆文件第七節；計畫 玉璽碎片-2）─────────────


def runic_open(state: GameState, content: Content) -> bool:
    """符文殘片還有用嗎：這一季有碎片、內容寫了符文殘片、秘密還沒揭開（碎片還沒現世），而且張角還在
    （伏筆文件 7.5：張角先死或已經有人揭開，殘片就失效）。"""
    w = state.world
    return (
        active(content, w) and content.shard.runic is not None and w.shard.phase == "hidden"
        and not figures.is_out(state, content.shard.keeper)
    )


def runic_count(state: GameState, content: Content) -> int:
    """手上算幾片：每個拿過的來源一片，加上晉升給的那幾片（PlayerState.runic_pieces 是基準量，照 foreshadow.need 換算，
    跟門檻同一個係數：黃巾第 4 階「算 2 片」在 1000 人以上那一檔就是 2 片，試玩的小伺服器是 1 片；待企劃者確認）。"""
    p, runic = state.player, content.shard.runic
    sources = len(set(p.runic_sources) & set(runic.sources))
    return sources + foreshadow.need(content, p.runic_pieces)


def runic_need(content: Content) -> int:
    """揭開要幾片：門檻（1000 人以上那一檔 7 片）照伺服器人數換算（伏筆文件 2.8：100～999 人 5 片、未滿 100 人 3 片，
    Config.foreshadow_tiers 的係數）。"""
    return foreshadow.need(content, content.shard.runic.threshold)


def add_runic(state: GameState, content: Content, source: str | None) -> list[str]:
    """事件給的一片殘片（Effect.runic_source）：殘片還有用（runic_open）、這個人還沒拿過這個來源，才記下並回一句（只有自己看得到：
    蒐集的進度一律不廣播，伏筆文件第七節）。其他時候什麼都不做、不寫字。"""
    p = state.player
    if source is None or not runic_open(state, content) or source in p.runic_sources:
        return []
    runic = content.shard.runic
    p.runic_sources.append(source)
    return [runic.lines.piece.replace("{source}", runic.sources[source]).replace("{count}", str(runic_count(state, content)))]
```

```python
def _rival_acts(state: GameState, content: Content) -> list[str]:
    """董卓第四方每曆時一次（第一季設計 8.4）：第二個入口（擁兵自重、沒有碎片）、聲威歸零掉璽；擁兵自重時把他的戰線往 50 拉
    （製造亂局，割據跟著照 4.2 漲），持璽時回聲威（守衛強度跟著聲威走）。不足一點的累積在 trend_accum（同大勢人物的推動）。"""
    sd, w, cfg = content.shard, state.world, content.config
    rival = w.figures.get(sd.rival)
    if rival is None:
        return []
    msgs = _rival_rebels(state, content, rival) + _rival_falls(state, content, rival)
    if rival.status not in figures.REBELS:
        return msgs
    front = rival.front or front_of(content, rival.location)
    if front is not None:
        whole = _accrue(w, "rival:pull", cfg.rival_pull_per_day / 24)
        gap = 50 - trend_value(state, content, front)
        if whole and gap:
            change_trend(state, content, front, max(-whole, min(whole, gap)), reveal=False)
    if rival.status == "rebel_seal":
        rival.prestige = min(100, rival.prestige + _accrue(w, "rival:regen", cfg.rival_regen_per_day / 24))
    return msgs


def _accrue(w: WorldState, key: str, amount: float) -> int:
    """累積不足一點的量，滿一點才回整數（同 figures.tick 的做法）。"""
    pending = w.trend_accum.get(key, 0.0) + amount
    whole = int(pending + 1e-9)
    w.trend_accum[key] = max(0.0, pending - whole)
    return whole


def _rival_rebels(state: GameState, content: Content, rival) -> list[str]:
    """第二個入口（8.4）：第 rival_rebel_week 週起，他在戰線上領兵（接替盧植之後）、那條戰線偏黃巾到 rival_rebel_front、
    聲威到 rival_rebel_prestige，他擁兵自重（rebel，沒有碎片）：脫離官軍、不推戰線、不當主將，天下大事。"""
    cfg, w = content.config, state.world
    if rival.status != "active" or rival.front is None or rival.prestige < cfg.rival_rebel_prestige:
        return []
    if calendar.point(w.time, content, w).week < cfg.rival_rebel_week:
        return []
    if trend_value(state, content, rival.front) < cfg.rival_rebel_front:
        return []
    rival.status = "rebel"
    if not content.shard.lines.rebel:
        return []
    lines = content.shard.lines
    text = fill(content, lines.rebel, place=place_name(content, rival.location))
    announce(state, content, lines.rebel_title, text, fill(content, lines.rebel_chronicle), location=rival.location)
    return [f"【江湖大事】{text}"]
```
