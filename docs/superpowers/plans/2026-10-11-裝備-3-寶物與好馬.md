# 裝備（第三批：寶物與好馬）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 裝備四欄的第四欄「寶物」與好馬的來源：身上一件寶物、八種效果（修練升品 ×1.2、探索悟意境 ×1.5、打贏心得 +20%、打贏經驗 +15%、閉關心得 +25%、求見門檻 −3、打贏多掉一個素材 25%、探索撿破境丹的機會 ×2；後兩種是企劃者 2026-10-11 換掉招募、氣血回復），全部經過 `treasures.amount`；寶物不設限制、隨時能換（企劃者 2026-10-11，設計 2.3【定】）；四種來源——懸賞的重賞（每週每邊寶物 15%、良駒 10%）、名將贈禮（情誼 60，七位名將各一件，名駒兩匹）、奇遇（`Effect.gear`）、挑戰大勢人物本人打贏 20%；掉落池只抽你還沒有的，都有了換 50 兩；懸賞的重賞與名將贈禮在裝備庫滿了時寄放、有空位再補；整季機器人與伺服器假人會換上更好的寶物與更快的馬。

**Architecture:** 新模組 `tianxia/treasures.py` 放寶物與好馬來源的全部規則（效果查表 `amount`、打贏多掉的那一個 `extra_drop`、拿到之後放哪 `deliver`／寄放與補發 `deliver_held`、不重複 `owned_templates`／`pick_pool`、四種來源 `bounty_prize`／`gifts_due`／`grant_effect`／`challenge_drop`、修練頁與角色卡 `rows`／`card_line`、機器人 `wanted`），只 import `models`、`state`、`equipment`、`mounts`，不 import `team`、`rules`、`cultivation`、`bounties`、`materials`（它們反過來呼叫它；多掉的素材由 engine 發）。`equipment.SLOTS` 加 `treasure` 一列、`WIELDABLE` 收寶物，**不加任何換寶物的限制**（只有坐騎照裝備二擋路上）。寶物表、名駒、名將贈禮放新內容 `content/gear.json`（`Content.gear`），數字放 `Config.treasures`。全服的「名將贈禮給了誰」（`WorldState.general_gifts`）與「這一季的天機」（`WorldState.tianji`）放進 `WorldState`（seasons.data），角色的新欄位放角色 JSON：**資料庫不升版**（維持第 4 版）。所有新的擲骰都用自己的 `random.Random(種子)`，不動 `Game.rng`；破境丹那一種寶物只把門檻放大，擲的還是原本那一顆 `self.rng.random()`，序列不位移。

**Tech Stack:** Python 3.12、pydantic、SQLite（不動結構）、pytest（`-n auto`）、原生 JavaScript 網頁（`web/app.js`、node 假瀏覽器測試）。

**Spec:** `docs/superpowers/specs/2026-10-10-裝備四欄-design.md`，**以 main `d50b0d5b` 那一版為準**（企劃者 2026-10-10 審過、數字「全部照預設」；**2026-10-11 改了三處**：寶物不設限制、隨時能換〔2.2、2.3、6.1、6.2 閉關那一列〕；招募、氣血回復兩種效果換成打贏多掉一個素材、探索撿破境丹 ×2〔6.2、6.3〕；換季四欄全部歸零確認〔2.4〕；另外 6.4 加了「挑戰大勢人物每一季都要有，另寫一份設計」）：二（2.2 拿到新東西放哪〔閉關中照一般的規則〕、2.3 換裝〔寶物隨時能換〕、2.4 換季、2.5 角色卡與修練頁、2.6 開關與最後一行「寶物的懸賞來源每季都有」）、三（3.1 `template`、3.2 `treasure`／`treasure_drops`／`held_gear`、3.4 模組怎麼拆）、5.6（良駒的名字、毛色照那一筆的種子）、5.7（好馬的來源）、六（6.1～6.5）、七（玉璽接點：這一批不做，只保證不擋）、八、九、十（第 3 項）、十一「裝備三」。設計自己還有幾處沒跟上 2026-10-11 的改動（3.2 的 `treasure_day` 與「閉關中不補發」、第七節第 4 條「一天換一次」、第十一節「換寶物的限制」、12.2 第 3、4 條），本計畫照 2026-10-11 的【定】做，那幾處見「要 PM 定的」第 4 條，Task 9 寫回設計。玉璽碎片設計 `docs/superpowers/specs/2026-10-11-玉璽碎片-design.md` 第七節（傳承那一格、`treasures.amount` 分兩格查、傳承那一格只看 `Config.seal.enabled`、`tier`／`quality` 要有預設值）只當限制讀，不做。

```python
    """寶物表、名駒、名將贈禮（content/gear.json，裝備四欄 6.3、5.7）與 Config.treasures：效果的數字剛好八種；良駒的品質權重只寫

    pool 為 false 的寶物與名駒都要有人送（不然永遠拿不到）。沒有 gear.json（測試內容）就只查設定。"""
    cfg, book = c.config.treasures, c.gear
    need(set(cfg.effects) == set(TREASURE_EFFECTS), f"Config.treasures.effects 要剛好寫八種效果：{sorted(cfg.effects)}")
    need(

        return
    need(any(t.pool for t in book.treasures.values()), "content/gear.json：掉落池（pool 為 true 的寶物）至少要一件")

    given: set[str] = set()

        if gift.line:
            need(to_traditional(gift.line) == gift.line, f"{where}：送禮那一句只能用繁體中文")
            try:
                gift.line.format(general="甲", gift="乙")

                need(False, f"{where}：送禮那一句只能用 {{general}}、{{gift}}")
    sent = {gift.gear for gift in book.gifts}
    for item_id in [t.id for t in book.treasures.values() if not t.pool] + list(book.steeds):
        need(item_id in sent, f"裝備表 {item_id}：沒有人送（pool 為 false 的寶物與名駒只從名將贈禮來）")
```

```python
def _cells(state: GameState, content: Content) -> list[tuple[str, float]]:
    """身上每一格寶物的（效果鍵, 數字）。這一批只有一般那一格（PlayerState.treasure：看 Config.treasures.enabled、查
    Config.treasures.effects）；玉璽一在這裡多加傳承那一格（PlayerState.heirloom：只看 Config.seal.enabled、不看寶物的開關，
    查 Config.seal.effects），其他掛點都不用動（玉璽碎片設計 7.2）。所以寫成一格一格往清單裡加，不在一般那一格空著時提早回傳。"""
    cells: list[tuple[str, float]] = []
    key = effect_of(content, state.player.treasure) if on(content) else None
    if key is not None:
        cells.append((key, content.config.treasures.effects.get(key, 1.0 if key in MULTIPLY else 0.0)))
    return cells


def amount(state: GameState, content: Content, effect: str) -> float:
    """這個效果此刻的數字（設計 6.1：所有掛點都經過這裡）：乘的效果是倍數（沒有是 1）、加的是加多少（沒有是 0）；
    好幾格都是同一個鍵時乘的相乘、加的相加（玉璽碎片設計 7.2）。沒帶、開關關著、效果對不上都回中性值。"""
    multiply = effect in MULTIPLY
    total = 1.0 if multiply else 0.0
    for key, value in _cells(state, content):
        if key == effect:
            total = total * value if multiply else total + value
    return total


def extra_drop(state: GameState, content: Content, dropped: list[str], season: int, record_id: int) -> str | None:
    """寶物「打贏多掉一個素材」（設計 6.2）：這一場掉了素材時，win_material 的機率從這一場**實際掉到的**素材裡挑一種、多給一個
    （計畫「要 PM 定的」第 3 條甲）；回那一種的 id，沒中、沒帶、開關關著、這一場沒掉素材都是 None（不擲）。只在遊歷、探索野怪、
    序章外由 Game._battle_rewards 叫（挑戰本人、劇情戰不吃）。發素材是 engine 的事（treasures 不 import materials）。
    自己一份亂數（寶|素材|季數|名號|戰報流水號；流水號每季從 1 算起，所以要有季數；開頭的「素材」跟挑戰本人掉寶物那一份分開），
    不碰 Game.rng（FB-129）。"""
    chance = amount(state, content, "win_material")
    if chance <= 0 or not dropped:
        return None
    rng = random.Random(f"寶|素材|{season}|{state.player.name}|{record_id}")
    if rng.random() >= chance:
        return None
    return rng.choice(list(dict.fromkeys(dropped)))  # 照掉落的順序去重：同一種掉兩筆不加重
```

```python
def good_horse(state: GameState, content: Content, rng: random.Random) -> Equipment:
    """一匹良駒（5.7；懸賞的重賞與奇遇）：毛色照那一筆的種子挑（5.6），品質照 Config.treasures.horse_quality 的權重（下 50／中 30／上 20）。
    先抽毛色、再抽品質（順序不能換，不然同一筆擲出來的馬會變）。"""
    coat = rng.choice(mounts.COATS)
    table = content.config.treasures.horse_quality
    quality = rng.choices(list(table), weights=list(table.values()))[0]
    return mounts.new_mount(state, name=mounts.horse_name(coat, 2), tier=2, quality=quality)


def pick_pool(state: GameState, content: Content, rng: random.Random) -> str | None:
    """從掉落池抽一件你還沒有的（6.5，照 template 認；排序後再抽，同一個種子永遠同一件）；都有了是 None。"""
    have = owned_templates(state.player)
    left = sorted(t.id for t in content.gear.treasures.values() if t.pool and t.id not in have)
    return rng.choice(left) if left else None


def room_for(state: GameState, content: Content, slot: str) -> bool:
    """拿得下這一欄的新東西（2.2）：身上這一欄空著，或裝備庫（四欄合算）還有空位——就是 equipment.rack_full 的反面。
    閉關中拿到的寶物照一般的規則（企劃者 2026-10-11 拿掉了先放裝備庫的例外）。"""
    return not equipment.rack_full(state, content, slot)


def deliver(state: GameState, content: Content, item: Equipment, *, hold: bool = False) -> list[str]:
    """拿到一件（2.2、6.5）：拿得下就照 equipment.store（那一欄空著穿上，否則進裝備庫）；拿不下時 hold（懸賞的重賞、名將贈禮）
    寄放進 held_gear，不然（奇遇、挑戰本人）寫明帶不走。"""
    p = state.player
    if room_for(state, content, item.slot):
        return [equipment.store(state, item)]
    if hold:
        p.held_gear.append(item)
        return [HELD.format(name=item.name)]
    return [NO_ROOM.format(name=item.name)]


def deliver_held(state: GameState, content: Content) -> list[str]:
    """寄放的東西補發（6.5；Game._deliver_held_gear 同步與快轉時叫）：那一欄開著、拿得下就照 2.2 補（那一欄空著就穿上，否則進
    裝備庫），一次補到裝備庫滿為止，補不完的（與那一欄關著的）留著。閉關中也補（計畫「要 PM 定的」第 4 條：寶物閉關中本來就能換）。"""
    p = state.player
    if not p.held_gear:
        return []
    lines: list[str] = []
    kept: list[Equipment] = []
    for item in p.held_gear:
        if equipment.on(content, item.slot) and room_for(state, content, item.slot):
            lines += [HELD_ARRIVED.format(name=item.name), equipment.store(state, item)]
        else:
            kept.append(item)
    p.held_gear = kept
    return lines


def _silver(state: GameState, content: Content, line: str) -> list[str]:
    """改給 dup_silver 兩（6.5）：那一句加「銀兩 +N」。"""
    n = content.config.treasures.dup_silver
    state.player.stats["silver"] = state.player.stats.get("silver", 0) + n
    return [line, f"銀兩 +{n}"]


def _give_horse(state: GameState, content: Content, rng: random.Random, *, hold: bool) -> list[str]:
    item = good_horse(state, content, rng)
    return [GOT_HORSE.format(grade=mounts.grade(item), name=item.name), *deliver(state, content, item, hold=hold)]


def _give_pool(state: GameState, content: Content, rng: random.Random, *, hold: bool) -> list[str]:
    """從掉落池給一件你還沒有的；都有了改給銀兩。呼叫端（不寄放的）先確認拿得下。"""
    tid = pick_pool(state, content, rng)
    if tid is None:
        return _silver(state, content, ALL_OWNED.format(silver=content.config.treasures.dup_silver))
    item = new_treasure(state, content, tid)
    effect = effect_text(content, content.gear.treasures[tid].effect)
    return [GOT.format(name=item.name, effect=effect), *deliver(state, content, item, hold=hold)]


def grant_effect(state: GameState, content: Content, gear_id: str, season: int) -> list[str]:
    """奇遇（6.4：Effect.gear，rules.apply_effect 叫）：寫的是掉落池的一件寶物、或 good_horse（一匹良駒）。那一欄關著什麼都不做；
    手上已經有同一件寶物改給 dup_silver 兩（6.5）；良駒照給（不是一人一件）；當下拿不了就沒了、寫明帶不走、不佔流水號（不寄放）。
    良駒的毛色與品質用自己一份亂數（季數＋名號＋good_horse＋四欄共用的流水號），不碰 Game.rng。"""
    from .models import GOOD_HORSE  # noqa: PLC0415  只用這一個常數

    p = state.player
    if gear_id == GOOD_HORSE:
        if not mounts.on(content):
            return []
        if not room_for(state, content, "mount"):
            return [NO_ROOM.format(name=mounts.TIER_NAMES[2])]
        rng = random.Random(f"奇遇|{season}|{p.name}|{gear_id}|{p.weapon_serial}")
        return _give_horse(state, content, rng, hold=False)
    tdef = content.gear.treasures.get(gear_id)
    if tdef is None or not on(content):
        return []
    if gear_id in owned_templates(p):
        return _silver(state, content, DUP.format(name=tdef.name, silver=content.config.treasures.dup_silver))
    if not room_for(state, content, "treasure"):
        return [NO_ROOM.format(name=tdef.name)]
    item = new_treasure(state, content, gear_id)
    return [GOT.format(name=item.name, effect=effect_text(content, tdef.effect)), *deliver(state, content, item)]
```

```python
def _row(content: Content, item: Equipment) -> dict:
    """修練頁寶物那一段的一列：名字、效果（effect 是鍵、effect_text 是給人看的那一句）。寶物隨時能換（2.3【定】），沒有「能不能換」
    的旗標；寶物不能拆，沒有拆解。"""
    key = effect_of(content, item)
    return {"id": item.id, "name": item.name, "effect": key or "", "effect_text": effect_text(content, key) if key else LOST}


def rows(state: GameState, content: Content) -> dict:
    """修練頁的寶物那一段（skillview.gear_rows）：身上那件、裝備庫裡的寶物。開關關著時 worn 是 None、rack 是空的
    （玉璽一要讓傳承那一列照 Config.seal.enabled 另外畫，見計畫「範圍與取捨」玉璽那一段第 5 點）。"""
    p = state.player
    if not on(content):
        return {"worn": None, "rack": []}
    return {
        "worn": _row(content, p.treasure) if p.treasure is not None else None,
        "rack": [_row(content, t) for t in equipment.in_slot(p, "treasure")],
    }


def card_line(state: GameState, content: Content) -> str:
    """本人卡上的「寶物」那一行（2.5，待 joy 潤）：「寶物　【烏木名刺】求見門檻 −3」；沒帶或開關關著是空字串
    （玉璽一的「傳承」那一行照 Config.seal.enabled 另寫，不經過這裡的開關）。"""
    item = state.player.treasure
    if item is None or not on(content):
        return ""
    key = effect_of(content, item)
    return f"寶物　【{item.name}】{effect_text(content, key) if key else LOST}"


def held_note(state: GameState) -> str:
```

```python
# ---- 懸賞的重賞（6.4）----

def prize_on(content: Content, prize: str | None) -> bool:
    """這一種重賞的那一欄開著沒（寶物看寶物、良駒看坐騎）。"""
    return prize is not None and equipment.on(content, PRIZE_SLOTS.get(prize, ""))


def bounty_prize(state: GameState, content: Content, season: int, bounty_id: str, prize: str, issuer: str) -> list[str]:
    """懸賞的重賞（6.4）：第一個交差的人拿（bounties._complete 判）。哪一件寶物、良駒的毛色與品質到這一刻才定，用自己一份亂數
    （季數＋名號＋懸賞 id；季數一定要有：懸賞 id 每季從 b1 算起，同懸賞榜第二批 gift_rolls 的理由），不碰 Game.rng。寶物只抽你還沒有的，
    都有了改給銀兩；裝備庫滿了寄放（held_gear），不作廢。那一欄關著什麼都不給。"""
    if not prize_on(content, prize):
        return []
    rng = random.Random(f"bounty-prize|{season}|{state.player.name}|{bounty_id}")
    head = [PRIZE_GOT.format(issuer=issuer)]
    if prize == "horse":
        return head + _give_horse(state, content, rng, hold=True)
    return head + _give_pool(state, content, rng, hold=True)
```

```python
def prize_rolls(tianji: int, week: int, faction: str, content: Content) -> tuple[bool, bool]:
    """這一邊這一週有沒有重賞（裝備四欄 6.4）：寶物、良駒各擲一次、分開擲。自己一份亂數（天機＋週次＋陣營；天機是開季時蓋進季裡的
    WorldState.tianji，不然每一季同一週的重賞都一樣）：不碰掛單那一份（bounty|…，同時挑討伐、打探、護送的地點），插進去擲的話
    之後每一張單的地點都會位移。兩個都照抽、不管開關開不開（開關只決定掛不掛上去）。"""
    cfg = content.config.treasures
    rng = random.Random(f"bounty-prize|{tianji}|{week}|{faction}")
    return rng.random() < cfg.bounty_treasure_chance, rng.random() < cfg.bounty_horse_chance


def _hang_prizes(w: WorldState, content: Content, week: int) -> None:
    """重賞掛上去（6.4）：官軍、黃巾這一週新掛的討伐，寶物掛第一張、良駒掛第二張（只中一個就掛第一張；討伐不夠就少掛）。
    那一欄關著的不掛。issue 一週只跑一次，所以「這一週、這一邊的討伐」就是這一批剛掛的。"""
    for faction in ENEMY:
        strikes = [b for b in w.bounties if b.week == week and b.faction == faction and b.kind == "strike"]
        treasure, horse = prize_rolls(w.tianji, week, faction, content)
        prizes = [prize for prize, hit in (("treasure", treasure), ("horse", horse)) if hit and treasures.prize_on(content, prize)]
        for b, prize in zip(strikes, prizes):
            b.prize = prize
```

```python
def challenge_drop(state: GameState, content: Content, figure: str, season: int, record_id: int) -> tuple[Equipment | None, list[str]]:
    """打贏大勢人物本人（Game._challenge 打贏那一支、_rout 之後）：challenge_chance 掉一件掉落池裡你還沒有的寶物（都有了改給銀兩）。
    同一位人物對同一個人每季只掉一次（treasure_drops）；寶物關著、掉過、裝備庫滿了（寶物欄有東西、裝備庫也滿）都不擲，也不記
    「掉過」——騰出空位之後再打贏還有機會。自己一份亂數（季數＋名號＋戰報流水號；流水號每季從 1 起，所以要有季數），不碰 Game.rng。
    回（掉出來的那一件, 江湖紀錄的話）；換成銀兩時那一件是 None。"""
    p, cfg = state.player, content.config.treasures
    if not on(content) or figure in p.treasure_drops or not room_for(state, content, "treasure"):
        return None, []
    rng = random.Random(f"寶|{season}|{p.name}|{record_id}")
    if rng.random() >= cfg.challenge_chance:
        return None, []
    p.treasure_drops.add(figure)
    tid = pick_pool(state, content, rng)
    if tid is None:
        return None, _silver(state, content, ALL_OWNED.format(silver=cfg.dup_silver))
    item = new_treasure(state, content, tid)
    return item, [DROP_LINE.format(name=item.name), *deliver(state, content, item)]
```

```python
def _steer(game, options, rng) -> str | None:

    s, c = game.state, game.content
    ids = {o.id for o in options}
    here = s.player.location
    work = {b.kind for b in bounties.mine(s, c) if b.location == here}
    if "act:train" in ids and ("strike" in work or orders.win_counts(s, c, s.player.faction, here)):

    if "act:explore" in ids and "scout" in work:
        return "act:explore"

        return move
    return "act:train" if "act:train" in ids else None
```
