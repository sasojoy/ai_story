## 二、殼的改法

`web/shell.js` 接在 `registerPage` 後面（shell.js 不進 facade 的比對，註解可以寫）：

```js
  // 點擊分派：包登記自己認的 data-act（registerClicks(mapClick, ["map-home", …])），app.js 的 click 監聽查到就交給它，查不到才走殼自己的 switch
  const CLICKS = Object.create(null); // 沒有原型：data-act 是 constructor 這種字也查不到，跟 switch 一樣什麼都不做

  function registerClicks(fn, acts) {
    for (const act of acts) CLICKS[act] = fn;
  }
```

`web/app.js` 只加兩行，插在 outing 那一行（第 1790 行）與 `switch` 之間，字面照這樣（facade 的放行比字面）：

```js
      const clicked = CLICKS[act];
      if (clicked) return await clicked(act, el, ev); // 包認的按鈕（shell.js）：一定要 await，這個 try 靠它吞 api() 丟的錯
```
