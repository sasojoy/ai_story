# 決戰改版 5：地方豪強第三方 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 豪強的人可以加入三場大戲，自成一方。他們不推官黃的戰局，只推豪強割據；兩軍打得越膠著，豪強收穫越多。兩招：
- 趁亂搶地盤：用奇襲的份量，扣 35 氣血。
- 保存實力：用固守的份量、收穫算一半，扣 10 氣血。

收場時，整場的收穫換成割據的推動，一場最多 +10。

**Architecture:**
- **內容**：`BattleDef.third`（`ThirdParty`）寫明這一場的第三方是哪個陣營、推哪條大勢線、兩招叫什麼。三場大戲（長社、宛城甲乙、廣宗）掛上豪強；舊的黃巾決戰不掛。
- **戰鬥狀態**（`battle_instance`）：
  - 第三方的人在 `participants` 裡，陣營就是豪強。他們的選項是固定的兩招（`third_options`），不走幕裡的選項。
  - `resolve_round` 先另外結算他們（份量、扣血、出手數），不進兩軍的出招比例與推力。
  - 戰局更新之後，照膠著程度累積 `third_gain`；收場時換成 `third_push`。
- **引擎**：能站的每一方（`_sides`）多了第三方；`_apply_battle_outcome` 不論是一般收場還是時刻表收場，都把 `third_push` 推到割據上。
- **假人**：伺服器假人照收穫與氣血替兩招打分數。順手補上計畫一漏掉的三招打分數。

**Tech Stack:** Python 3、pydantic（`tianxia/`）、pytest；網頁不用改（加入與出招都是一般的選項按鈕）。

**Spec:**
- `docs/superpowers/specs/2026-10-03-戰鬥系統-design.md` 第六節（企劃者 2026-10-06 選 A「自成一方、只推割據」；數字【預設】）。
- 第一季設計 4.2、11.2。

**開工條件：** 決戰改版計畫一併進 main 之後才開工（`scores`、`condition`、`option_of`、`CENTER`、`last_result`、`last_mix`、`BattleTuning`、測試的 `three`、`CODES`、`_open_three_move_battle`）。計畫二、三、四先併或後併都可以，見下表。

**執行方式：** 子代理逐步做（superpowers:subagent-driven-development）。每個 Task 由一個新的子代理實作，另一個子代理審過才做下一個。最後整條分支再審一次。

## Global Constraints

- **加入**：
  - 第三方的人（自己的陣營就是 `third.faction`）才能加入，而且要人在那個大區（同兩軍）。
  - 集結時只看得到自己這一方；晚到的人也只補進自己這一方。
  - 集結結束、晚到補人時，都不會被分到兩軍。
- **不推戰局**：第三方不推官黃的戰局，不進出招比例，不吃也不參與剋制，兩軍也打不到他們。戰局、換幕、收場、伏筆鎖定都跟第三方無關。
- **兩招**：
  - 趁亂搶地盤：份量＝這個人「奇襲」的份量 × 氣血狀態；扣氣血 35（`third_grab_damage`）。
  - 保存實力：份量＝「固守」的份量 × 氣血狀態 × 0.5（`third_keep_share`）；扣氣血 10（`third_keep_damage`）。
  - 氣血歸零一樣倒下。
- **膠著程度** ＝ 1 −｜戰局 − 50｜÷ 50，每回合結算完照當下的戰局算。
- **收穫**：
  - 每回合 ＝ Σ份量 ÷ √這回合出手的第三方人數 × 膠著程度。
  - 這一回合兩軍都沒有人出手時，收穫是 0（沒有亂可趁）。
- **收場**：整場收穫加總 ÷ 100，四捨五入，**一場最多 +10**（`third_cap`），推一次 `third.trend`（豪強割據）。季終沒打完收起來的決戰不推。
- **沒人能打**：只看兩軍。場上只剩第三方時，回合一逾時就照保底結果收場（`end_without_fighters`）。
- **逾時沒出手**：代出「保存實力」，記進 `auto_picked`。第三方沒有作戰方針與 AI 代挑，也不能放手一搏。
- **畫面**：第一季開關開著時，割據的增減不寫數字（FB-064），只寫人數與一句話。
- 數字全由規則引擎決定，全部【預設】，放在 `Config.battle`。
- 測試：`.venv/Scripts/python.exe -m pytest -q`。commit 照專案慣例（明列路徑）；push 照 PM 的規矩。

## Review Focus

1. **第三方不動戰局**：同一回合加不加第三方，戰局與兩軍的出招比例都一樣。→ Task 2 `test_the_third_party_never_moves_the_trend`。
2. **一場最多 +10**：收穫再多，割據也只推 10。→ Task 2 `test_the_push_is_capped_at_ten`。
3. **場上只剩第三方**：沒有兩軍的回合不給收穫；回合逾時就照保底收場，不會讓豪強一直刷。→ Task 2 `test_no_armies_no_gain`、`test_only_the_third_party_left_ends_the_battle`。
4. **不會被分到兩軍**：集結結束與晚到補人，都不把豪強塞進官軍或黃巾。→ Task 1 `test_the_third_party_stays_itself_at_muster_and_late`。
5. **季終沒打完**：收起來的決戰不推割據。→ Task 3 `test_an_unfinished_battle_pushes_no_warlords`。

`tianxia/battle_instance.py`：

```python
THIRD_GRAB = "third_grab"  # 第三方的兩招（戰鬥系統第六節）：不在幕的選項裡，由 third_options 給
THIRD_KEEP = "third_keep"


def sides(definition: BattleDef) -> list[str]:
    """這場決戰能站的每一方：交戰的兩軍，加上第三方（有的話）。"""
    ids = [f.id for f in definition.factions]
    return ids + [definition.third.faction] if definition.third is not None else ids


def is_third(definition: BattleDef, p: BattleParticipant) -> bool:
    return definition.third is not None and p.faction == definition.third.faction


def third_options(definition: BattleDef) -> list[BattleOption]:
    """第三方的兩招：趁亂搶地盤（奇襲的份量）、保存實力（固守的份量，收穫一半）。"""
    third = definition.third
    return [
        BattleOption(text=third.grab, tag=THIRD_GRAB, faction=third.faction, move="奇襲"),
        BattleOption(text=third.keep, tag=THIRD_KEEP, faction=third.faction, move="固守"),
    ]


def stalemate(trend: int) -> float:
    """膠著程度（戰鬥系統第六節）：戰局停在 50 是 1，偏到 0 或 100 是 0。"""
    return max(0.0, 1 - abs(trend - CENTER) / CENTER)
```

其他改動：
- `options_for`：`p` 是第三方時回 `third_options(definition)`，不看幕的選項。
- `close_muster`：`faction_ids` 改成 `sides(definition)`，豪強就不會被重新分配。
- `auto_assign_latecomer`：指定的 `faction` 在 `sides(definition)` 裡就照它；沒指定（或不認得）照舊只在兩軍之間補人數少的一邊。

```python
def _third_round(
    instance: BattleInstance, definition: BattleDef, tuning: BattleTuning, msgs: list[str],
) -> tuple[float, int, int]:
    """第三方這一回合（戰鬥系統第六節）：照兩招算份量、扣氣血、記出手；不推戰局、不進出招比例，兩軍也打不到他們。
    回傳（Σ份量 ÷ √出手人數、搶地盤人數、保存實力人數）。膠著程度要等戰局更新完才乘，見 resolve_round。"""
    total, grabs, keeps = 0.0, 0, 0
    for name, tag in instance.round.pending_actions.items():
        p = instance.participants.get(name)
        if p is None or p.eliminated or not is_third(definition, p):
            continue
        if name not in instance.round.auto_picked:
            p.acted_rounds += 1
        grab = tag == THIRD_GRAB
        move = "奇襲" if grab else "固守"
        total += p.scores.get(move, 0.0) * condition(p) * (1.0 if grab else tuning.third_keep_share)  # 份量在扣血之前算
        grabs, keeps = grabs + grab, keeps + (not grab)
        p.neili = max(0.0, p.neili - (tuning.third_grab_damage if grab else tuning.third_keep_damage))
        p.last_result = definition.third.grab if grab else definition.third.keep
        if p.neili <= 0 and not p.eliminated:
            p.eliminated = True
            p.fell_round = instance.round_number + 1
            msgs.append(f"{name}氣血耗盡，倒在戰場上，退出了這場戰鬥（轉為觀戰）。")
    count = grabs + keeps
    return (total / math.sqrt(count) if count else 0.0), grabs, keeps


def settle_third(instance: BattleInstance, definition: BattleDef, tuning: BattleTuning) -> list[str]:
    """收場：第三方整場的收穫 ÷ 100、四捨五入、最多 third_cap，記進 third_push（套到賽季是 engine 的事）。"""
    if definition.third is None:
        return []
    instance.third_push = min(tuning.third_cap, int(instance.third_gain / 100 + 0.5))  # 四捨五入（round 是銀行家進位）
    return ["兩軍相持之際，地方上有人趁亂坐大。"] if instance.third_push > 0 else []
```

```python
    battle = bi.start_muster(definition, now=0)
    third = definition.third.faction
    for side, count in (("guan", guan), ("huang", huang), (third, warlords)):
        for i in range(count):
            power = rng.uniform(0, 150)
            scores = bi.move_scores(tuning, power, rng.choice(ATTRS), rng.choice(ATTRS))
            bi.join_faction(battle, f"{side}{i}", side, neili_cap=400, power=power, scores=scores)
    bi.close_muster(battle, definition, rng, now=0)
    while battle.phase == "active":
        for name, p in battle.participants.items():
            if p.eliminated:
                continue
            if p.faction == third:
                bi.submit_action(battle, name, bi.THIRD_GRAB if p.neili > p.neili_cap / 2 else bi.THIRD_KEEP)
                continue
            best = max(MOVES, key=lambda m: p.scores[m])
            move = best if rng.random() < 0.7 else rng.choice(MOVES)
            bi.submit_action(battle, name, f"{p.faction}_{CODES[move]}")
        bi.resolve_round(battle, definition, rng, now=0, tuning=tuning)
    return battle.third_push


def main() -> None:
    content = load_content(ROOT / "content")
    definition = content.battles["changshe_fire"].model_copy(update={"trend_start": 50})
    tuning = content.config.battle
    for guan, huang in ((20, 20), (40, 10), (200, 200)):
        for warlords in (1, 3, 10, 30, 100):
            pushes = [run(definition, tuning, guan, huang, warlords, seed) for seed in range(20)]
            print(f"官 {guan} 對 黃 {huang}，豪強 {warlords}：割據推 {statistics.median(pushes)}（{min(pushes)}～{max(pushes)}）")


if __name__ == "__main__":
    main()
```

| 第三方的戰報 | 跟兩軍一樣一則，站「地方豪強」，大勢變化列出割據 | 參戰的人都該看得到自己那一方的結果；第一季照 FB-064 不寫數字 |
