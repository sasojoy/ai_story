# 正式季第 1 批：季的骨架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 21 天的季（`season21` 設定）有自己的骨架：季曆就是現實的三週、錨在開季那一週的台灣週一、照現實天排的時刻表、不提前收季、「今天」是現實的一天；週末與 14 天的季一個字都不變。

**Architecture:** 一個 `Config.season21` 開關（預設關，只有 `content/profiles/season21.json` 打開），開季時蓋章進 `WorldState`（`season21`、`cal_offset`）。季曆照舊是「季曆秒＝世界秒×cal_scale」，21 天季的 cal_scale 是 1（`season_weeks` 3、`season_days` 21），另加開季那一刻離台灣週一 00:00 的偏移；`calendar` 是唯一做這個換算的地方。內容裡照週寫的三樣（時刻表、官軍將領出兵、豪強伏筆）各多寫一份照天的，載入時（時刻表）或執行時（人物、條件）照開關挑。

**Tech Stack:** Python 3.14、pydantic、pytest；`C:/Ray/專案/天下大勢/.venv/Scripts/python.exe`。

**Spec:** `docs/superpowers/specs/2026-10-17-正式季整合-design.md`（第一章、10.1、十一章第 1 批、12.3 第 3、41 條）

## Global Constraints

- 開關：`Config.season21` 預設 **關**，只有 `content/profiles/season21.json` 打開；週末與 14 天的季一個字都不變（12.3 第 41 條）。
- 季曆就是現實的三週：季曆一天＝現實一天；「第 1 週・週一 00:00」是開季那一週的台灣週一（`pill_day_utc_offset_hours` 8）；季末是第 3 週週日 24:00，畫面寫 23:59（1.1）。
- 世界秒照舊從開季那一刻算，季曆另加一段偏移（1.1【PM】）。季長倍數、名聲門檻照章上的 21 天算（12.1 第 4 條照 PM 提案）。
- 時刻表（1.2）：一般大事 12:00；決戰週六 20:00；天命之爭第 3 週週日 20:00；第 1 週照舊五件（12.3 第 3 條）；盧植下獄在第 3 週週一，畫面照時間排。
- 不提前收季（1.1）；態勢卡那一句照這一季有沒有蓋天命之季的章挑，另加「這一季不會提前收場」；結局提示另寫 21 天版。
- 「今天」＝台灣 00:00 換日的現實一天，只在 21 天季（1.3）。
- 新手期 48 小時已經上線（`Config.newbie_real_hours` 48），只核對。
- 新寫的字標「待 joy 潤」。測試只跑 `scripts/test_for.py --base origin/feature/formal-season`（tianxia-flow）。

## Review Focus

1. 在週日（週六決戰已過）開季：已經過的一般大事照時間結算、那場決戰照「時間到了卻沒開成」那條路走，不炸（Task 2 補測試）。
2. 用週末設定開著的程式讀到 21 天季蓋的章：啟動時要印設定對不上那一行（Task 1 補測試）。
3. 週三開季時，季末落在第 3 週週日 24:00，不是開季後 21 天（Task 1）。
4. 「每天幾次」的帳在台灣 00:00 換，不是開季那一刻起每 24 小時（Task 4）。
5. 季的事在曆時的整點跑：開季在 10:30 時，12:00 的大事在 12:00 結算，不是 12:30（Task 1）。
