4. **輸出裡的模組名**：類別的 `__module__` 從 `__main__` 變成 `sb.…`。靜態看沒有東西印它（`__module__` 只有 311 行讀 schema 的），真的印了第六節第 3 步會紅；紅了修腳本，不是認差異。
5. **新檔要 LF**：`git ls-files --eol` 要 `i/lf`。工具讀原文先把 `\r\n` 換成 `\n`，寫檔再照工作樹轉。
6. `__pycache__/` 已在 `.gitignore`。`_mutant` 複製時也忽略。父行程先載一次，pyc 就先寫好，子行程不搶。
