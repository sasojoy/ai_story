## 二、設計決定

**玩家看得到的**
- 見聞第八個分頁「攻略」【PM】（企劃者說「見聞或設定」，選見聞：設定抽屜要先點齒輪，找不到）。設定抽屜的「玩法說明」鈕、新手期江湖頁那一行入口，開關開著時都改成打開攻略的「怎麼操作」那一章；關著照舊。八個籤在 375 寬放不放得下，先出 2～3 張對比圖給企劃者挑（照舊規矩）。**同時進行的「天下形勢」計劃（`2026-10-18-AI判斷勢力版圖.md`）也在見聞加一個「形勢」籤（排在大勢後面），兩份都上就是九個籤**：對比圖照九個畫，`NEWS` 兩邊各加一筆，後合的那一邊解衝突。
- 攻略分四章，上面一排章名籤，一次看一章（同榜單的做法）：
  1. **怎麼操作**：就是現在 `howto.page` 那一整頁，一節一個可摺疊的小標題。一打開全看得到。
  2. **怎麼算贏**：一打開全看得到。三段：這一季怎麼收場（`season_page_lines`＋收季規則）、這一季可能的結局（同 `quest_text` 那一塊，抽成共用函式）、自己怎麼留名（七張榜各一句、擂台三個稱號、首創寫進江湖史、季末寫傳）。全部讀 Config 與內容，不寫死。
  3. **小訣竅**：解鎖了的一條一張卡，沒解鎖的只寫「還有 N 條沒碰到」，不露標題【PM】。新解鎖還沒看過的標「新」。
  4. **師父說過**：`hints_seen` 裡每一條，照此刻的 `note_for` 寫（誰說、說什麼），照提示表的順序排。沒說過的不列。開關獨立於 `hints_off`：關了提示，說過的照樣看得到。
- **江湖頁的訣竅小卡**：一個現實的一天（照 `Game._pill_day`，同回體丹與 21 天季的「今天」）最多跳一張【預設 `per_day` 1】。擺在懸賞卡下面，不擠「剛剛」、場景、行動列第一屏【PM】。卡上一行標題＋「翻到攻略 ›」＋「收起」。點了翻到攻略那一條，收起或翻過都算看過。序章裡、決戰、頭目戰、擂台、奪璽單挑打到一半不跳。
- **跳哪一條**：先挑新解鎖還沒看過的（照解鎖先後）；都看過了，這一天照「名號｜第幾天」雜湊擲 `pop_chance`【預設 0.3】，中了從解鎖的挑一條舊的重溫。雜湊是自己的，不碰 `Game.rng`，不讀時鐘（`pill_now`）。

**規則怎麼算**
- 新模組 `tianxia/guidebook.py`（純函式，不 import engine）。內容 `content/guidebook.json`：`tips` 一條一筆 `{id, title, text, unlock}`，`text` 可以寫 `{名字}`（照 `hints.values` 的做法，名字表在 guidebook 自己一份，讀 Config）。
- **解鎖條件**是程式裡一張固定的表（`UNLOCKS`：鍵 → 看 `GameState`、`Content` 的判斷），內容只能寫表裡有的鍵，載入時擋。解鎖了記進 `PlayerState.tips_unlocked`（之後條件不成立也不收回），換季保留（同 `hints_seen`）。存在角色的 JSON 裡，**資料庫結構不動**。
- 第一批訣竅 12 條【預設】，字由我們寫、標待 joy 潤；三類都只指方向：

| 鍵 | 什麼時候解鎖 | 指的方向 |
|---|---|---|
| `fused` | 合成過一門武學 | 意境跟底同屬性或相生較圓融、相剋打散舊功效；不寫哪一組出什麼 |
| `merged` | 合併過一個意境 | 重數越高、越圓融，融進武學越多層 |
| `gen_deep` | 有一門合成的武學境界到「精進」（`depth.gen_of` ≥ 2；不是心得出路的「精研」） | 化境就不能再合，留一門當底要想好 |
| `heard_secret` | 武學譜有一句口訣 | 口訣有說書、人物順口（情誼到 `{talk_affinity}`）、殘譜三種說法，三句湊起來才看得清 |
| `heard_forge` | 鑄譜有一句 | 鐵匠、說書、殘譜各知道一點；每家鐵匠鋪知道的不一樣 |
| `smithed` | 打造過一爐 | 輔料階高、熟手、天時地利會讓品質好 |
| `top_tier` | 背包有最高一階的料 | 神器的料是最高那一階；「最高一階」照素材表算，正式季第 2 批加四階之後自己變 |
| `cultivate_heat` | 有一門火候滿了 | 絕學要契機：打一場比自己強的仗、或決戰出手 |
| `joined` | 投靠了陣營 | 出陣、軍令、晉升怎麼互相帶 |
| `ranger` | 散人有了遊俠名號 | 懸賞與俠名的好處 |
| `figure_win` | 打贏過大勢人物本人 | 越打越難、平手也有收穫、護衛 |
| `arena` | 報名擂台 | 名次只換排在前面的、稱號與俸 |

- **不給答案的守門**【PM】：載入時擋訣竅的字裡出現任何素材名、內容武學名、意境名、隱藏配方與神器的譜名（`content.validate` 加 `check_guidebook`，名字表跟 `naming` 擋重名用的同一批）。企劃者 10/10：不替玩家列出合得出來的組合。
- **開關**：`Config.guidebook`（`GuidebookTuning`：`enabled`、`per_day`、`pop_chance`）。`content/config.json` 開，測試內容關。關著：沒有攻略分頁、沒有小卡、`/api/guidebook` 回空、玩法說明照舊，一個字都不變；`tips_unlocked` 照記也不給人看【PM：記著，開了才不會從零開始】。
- **假人**：解鎖照記（同一條路），不跳卡、沒有畫面，沒有任何地方看得出來。整季機器人不管。

**跟其他系統的接縫**
- 正式季第 3 批改了行動鈕與 howto 的字：攻略直接叫 howto，不另寫一份。第 2 批加四階：`top_tier` 照素材表最高階判，不寫死「三階」。
- 碰到才說照舊在對話框說一次；攻略只是回頭看的地方。

**不做的事**
- 不做搜尋、不做書籤、不叫模型、不做「下一步該做什麼」的推薦（那是 `guide.next_hint`）。
- 不列合得出來的組合、不寫配方、不寫機率表。
- 小訣竅不給獎勵（不是成就）。
