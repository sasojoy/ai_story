> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 派工單定了：開發自己一步一步做（不開子代理），計畫不必給企劃者審。順手修天下圖 QA 開的 FB-630、631、632。

**Goal:** 點一區（或「進入此區」、找地點挑一處）進的是真正的**區圖**：只畫這一區的地點、固定取景、不拖不縮；設色山水當底、州界與三種路的線收掉（路統一成一種淡實線）；每一處一個墨筆小圖、名字裝在印章框裡（框色＝誰的，顏色從劇本讀；大城框粗）、框下一條細進度條（攻方顏色；剛易手灰掉寫冷卻）、朱印「寶」、名字底下最多兩個意境字、你的朱圈與旗、通到鄰區的路畫到邊上寫「→ 南陽」、左下角羅盤；上面一排「‹ 天下・大區名下拉・⏱ 版圖」，一顆「塗層」濾鏡（平常關著，開了多一層照歸屬融成一片的淡彩）。點一處抽屜半開那一處的**卡**（設計 5.3 的一到八段：正在翻、今日產出、下戰書都在），地圖不動。設計 5.4 那一表的東西真的刪掉。領地爭奪關著的季照樣是新畫法，規則與存檔一個位元組都不變。

**Architecture:** 區圖跟天下圖同一張底圖（`mapview.render_base`）換固定取景（`regionFit`），記號畫在 `#mk`／`#mkt`（`regionParts`，純函式），名字框的位置由網頁照螢幕大小挑（`regionLabels`，貪心＋候選位置，不壓字、不壓記號）。路從底圖烤的那張圖裡抽出來留成向量（`<g class="tx-roads">`），天下圖照舊的樣子、區圖用 CSS 換成一種淡實線。卡（`placeCard`）讀疊層（`/api/map/state`）與 `main_view["conquest"]`（翻地那一份畫面資料，`conquest.block_view` 同一個函式）。可以拖縮的那一套（手勢、縮放鈕、看大局、濾鏡、小牌子、⚔、前線鋸齒、中立地虛線、圓盤裡的字、「天下」那一條）整段拿掉。

**Tech Stack:** Python 3（pydantic）、原生 JS（`web/app.js`）、CSS；pytest＋`tests/webharness.py`（node）；實機無頭 Chromium＋CDP。

**Spec:** `docs/superpowers/specs/2026-10-20-輿圖簡化-design.md`（三版 42c4aacc：第一章、3.3、5.2、5.3、5.4、5.5、5.6、第六章、第九章第 5～7、9 條、第十章、第十一章第 4 條、第十二章）；草圖 `docs/superpowers/specs/2026-10-20-輿圖簡化-草圖/`（`方案一-區圖.png`、`定案-清甲加清乙的框.png`、`對照-清甲清乙.png`；產生器 `tools/mock3.py`、`mock5.py`）；開發手冊 `tianxia-map-remake`；上一批計畫 `2026-10-20-輿圖v3-天下圖.md`。

## Global Constraints

- 地理照舊仿真實地形（不動 `content/map.json`、`locations.json`）。

### 1.1 區圖（設計 5.2）

| 記號 | 做法 |
|---|---|
| 底：設色山水、線收掉 | 同一張底圖；區圖那一層把底圖的州界點劃線收掉（大區的淡色留著）、大區名藏起來；路在 `<g class="tx-roads">`（不烤進點陣），區圖照 CSS 換成一種淡實線（官道雙線的芯藏起來） |
| 只畫這一區 | 這一區（`base.places[].region`）的地點才畫；取景框外蓋一層半透明的紙（`.r-mask`，邊緣暈開），鄰區的山水淡淡看得到、路畫到邊上 |
| 墨筆小圖 | 城、營、寺、渡、山、野（底圖給的 `glyph`），線色＝控制方的 `color`、沒人佔的灰（`sideInk`／`unheld`），底是紙色 |
| 印章框 | 名字裝在框裡：框的底色＝控制方的 `tint`、框線＝`color`；沒人佔照底圖的 `unheld` 往紙色淡；大城（`big`）框線粗、字粗 |
| 進度條 | 框下一條細條（框寬）：疊層 `tug` 裡進度最高的那一方（守方自己不算，同天下圖的 `tugOf`），長度＝進度、顏色＝那一方的 `color`；冷卻（`cool`）整條灰、旁邊寫「冷卻 N 分」 |
| 朱印「寶」 | 框右邊一個朱紅小方印（疊層 `rich`：開季中立的區塊，不管此刻誰佔著） |
| 意境字 | 名字底下照意境的顏色寫最濃的在前、最多兩個（底圖 `insights` 已經是最濃的在前；顏色照 `INSIGHT_INK` 的屬性） |
| 朱圈＋旗 | 你在的那一處（在路上畫在路上，同天下圖） |
| → 鄰區 | 一頭在這一區、一頭在別區的路：從這一頭往那一頭的直線碰到取景框邊的那一點，寫「→ 南陽」（框內貼邊） |
| 羅盤 | 地圖框左下角一個小羅盤（`.r-compass`，螢幕上固定，不跟地圖），抽屜拉開時被蓋住 |
| 上面一排 | 「‹ 天下」、大區名下拉（`<select>`，換一區）、「⏱ 版圖」；右邊下面一顆「塗層」 |
| 塗層 | 每一處有控制方的地點一團淡彩（`soft`，半徑大、`feTurbulence`＋`feDisplacementMap`＋`feGaussianBlur` 暈開），整層 `opacity` 0.42，平常關著；開關記在這個瀏覽器（localStorage `tx-map-wash`） |

- 取景（`regionFit`）：這一區地點的外框，四邊照螢幕留邊（名字框多半在右邊、旗在上面、意境字在下面），放進「上面那一排底下、收著的抽屜上面」那一塊；**優先替半開的卡留位子**（卡的高度 `REGION_CARD`），留了之後倍率低於 `REGION_READ` 就不留（短的螢幕、寬的大區照整塊放，卡會蓋到下緣）；倍率最多 `MAP_MAX`。垂直方向靠上。桌機（抽屜是右欄）整塊放。
- 名字的位置（`regionLabels`）：每一處的名字框（＋寶＋進度條＋意境字）有右、左、下、上、右上、右下、左上、左下幾個候選；你那一處先擺，再照「附近地點多的先」擺；每一個挑第一個不壓到已經擺好的框、所有圖示、你的旗、也不出框的位置，都不行挑壓得最少的。框的字級固定（螢幕 px），不跟倍率縮。
- 點一處：抽屜半開那一處的卡（`peek`），**地圖不動**；選了的那一處一圈墨線（`drawSel`）。點空白收回。

### 1.2 卡（設計 5.3）：`placeCard(base, st, id)`

由上往下（在路上：第一行照舊 `journeyHtml`）：

1. 控制方的小印（`ctrlSeal`）、地名（在這裡加「（你）」）、右邊「★高級」（`rich`）與距離（不在這裡：「步行 N 分」）、收起 ✕。
2. 一句話（`placeLine`）：大本營「X大本營」；領地爭奪開著：陣營區塊「X的基礎資源領地」、中立沒人佔「中立・高級資源領地，還沒有人佔」、被佔下「X佔下的高級資源領地」；不是區塊「不在戰線上」；關著的季照控制方寫「X控制」／「無人控制」、廣宗「只照大事易手」；冷卻接「剛易手，N 分後才能再推、加成暫停」。
3. **正在翻**（`flipSection`，讀 `S.main.conquest.blocks[id]`）：領地爭奪開著、搶得下來、而且「看的人推得動（攻）」或「此刻有人在推（有進度）」才有【開發定，見第三節】——每一個攻方一條進度條（名字、顏色、N／100）；「官軍 3 人正在攻（映雪 +12、…）、黃巾 2 人在守」（`pushers` 照邊、攻守分，名字最多三個＋「…」）；集火（`focus` 有一成以上的那一邊）；激戰；被戰書凍結（`frozen`：誰約戰、時刻）。
4. 此地能悟（`insightRow`，照舊）。
5. 此地的對手：站在這裡的隊伍與勝算（`squads`）；人物另一行。
6. 今日產出（疊層新鍵 `yield`，`mapdata.yield_line`）：一句，沒有就不寫。
7. 動作一排（照舊的條件）：在這裡「出陣・攻／守（今日還能 N 次）」與「探索」；不在這裡「步行 N 分」「疾行（體力 M）」；事件擋著照舊；主將（`main.conquest.letter`）而且這一塊在 `ready` 裡：多一顆「下戰書」（`why` 不是空字串時灰著、原因寫在底下），按了先問一次（`ask`），再 `doMain("conquest_letter", {loc})`。
8. 拉高才看：軍令與懸賞、這一季誰佔過（色帶與易手）、地利、此地（醫館鐵匠鋪馬市）、劇情；最底下是輿圖升級設計第五節那三樣（今天去哪裡出陣、戰線的繩、本週大事），只在看你腳下這一處的卡時接在後面。
