# T1 三條戰線與豪強割據：裁決與擱置事項

總計畫：`docs/superpowers/plans/2026-10-04-第一季濃縮版.md` 的 T1。展開計畫：`docs/superpowers/plans/2026-10-04-T1-三條戰線.md`（7 個任務）。版本目標：`docs/superpowers/specs/2026-10-04-第一季濃縮版-版本目標.md`。

## 做了什麼

- 黃巾聲勢改成三條戰線的加權：潁川汝南 ×0.35、南陽 ×0.25、冀州 ×0.40，起始值 40／35／55，所以加權後是 45。
- 新增豪強割據，起始 10：
  - 每有一條戰線在亂局（35～65），每曆日 +1；
  - 三條都穩時，每曆日 −1；
  - 每個曆時算一次。
- 遊歷照陣營推所在戰線：官軍往 0 推，黃巾往 100 推，散人照地點原本的方向。豪強只在亂局的戰線推割據，穩的戰線什麼都不推。
- 狀態列多了「態勢」（官軍 100−黃巾聲勢、黃巾＝黃巾聲勢、豪強＝割據），江湖頁多了三條戰況。
- 假人往己方輸得最多的戰線走。
- 事件效果從推黃巾聲勢改成推所在戰線（`front`）。
- **全部掛在開關後面**：要 `Config.season_one` 開著，而且這一季開季時也蓋了開的章（`calendar.season_one_on`）。開關關著時就是 beta 的規則：戰線 id 和 `front` 都算成黃巾聲勢，存檔與畫面也跟以前一樣。
- 總審查拿開關關著的三整季假人、一季伺服器假人，加上所有畫面的輸出，跟 T1 之前比對，差異是 0。開關開著、但這一季沒蓋章時，差異也是 0。

## 裁決

1. **事件鍵遷移**（PM 同意）：
   - 事件檔裡的 `"huangjin"` 機械地換成 `"front"`，共 17 個檔、107 處。數字不變，文字一個字都沒改，條件也沒動。
   - 這一步單獨一個 commit，排在最後，動手前先 rebase 到 main 最新。
   - 決戰結果、背景人物（波才、皇甫嵩）改推潁川汝南。
   - 洛陽沒有戰況，所以在洛陽發生的效果在開關開著時不推任何戰線。
2. **開關要看這一季的章**：跟 T2 的季曆用同一個條件。開關打開時還在跑的 beta 那一季照舊用 beta 的規則，黃巾聲勢不會從 beta 的值跳成 45。代價是光打開開關不會有任何變化，要等下一季開季。
3. **讀戰線一律用 `rules.trend_value`**：存檔有值就回存值，沒有就回劇本的起始值。T2 的時刻表、T7 的伏筆都改走它；T2 留下的兩個替身（`_front_value` 改成走它、`SEASON_ONE_TRENDS` 拿掉）也一起換掉了。
4. **割據的漲落掛在 T2 的 `season_hour`**，在週初掛鉤與大事之前。開季那一刻只跑 `season_events`，割據不會多算一次。
5. **規劃時定的細節**：
   - 新增 `Trend.season_one` 標記。
   - 洛陽官道、孟津渡的 `train_trend` 寫 `front`。
   - 亂局含兩端（35 ≤ v ≤ 65）。
   - 管理者在開關開著時推黃巾聲勢，只回一句說明。
   - 戰況條放在動作列下面；割據寫在「態勢」那一行，不是第四條戰況條。
6. **路上的捷徑要緊貼選項**：江湖頁照路上設計，順序是選項、捷徑、戰況條。
7. **假人往戰線走**：
   - 開關開著時，離輸的那條戰線還遠的假人，照最短路往前走一步，加分跟原本「回投靠點」的偏好一樣。
   - 這只是偏好，打得贏的遊歷、探索仍然比它優先。假人要多積極，留給 T11 調。
   - 開關關著時，計分一個字都沒變。
8. **戰線與割據的條件先擋掉**：
   - 執行時讀條件還是讀存值，在開關關著或舊季會讀成 0。所以內容檢查先禁止在戰線或割據上寫 `trend_min`／`trend_max`、門檻。
   - 黃巾聲勢與玉璽線索照舊可以寫。
   - 之後要用戰線當條件，要先把讀條件改成走 `trend_value`。
9. **開關打開前的防呆**：`chaos_low` 不能大於 `chaos_high`；割據的兩個速率不能是負的；大勢線的 id 不能叫 `front`。

## 給 PM、企劃者與 T11 的

- **割據會一路漲到頂**：三條戰線的起始值都在亂局裡，所以割據從第一個曆時起就每曆日 +3。總審查開著開關跑了三季，割據最後是 100、65、100。總計畫第五節寫「季末大約 50～70」，但照它自己的數字一季 12 週算不出這個結果。豪強在 85 就是決定性勝利，可能什麼都不做就贏了。要調起始值、亂局範圍或速率，請企劃者決定。
- 開關開著時黃巾聲勢從 45 起算，舊的 `huangjin_50` 門檻會很早觸發。這些門檻照總計畫 7.2 第 10 題之後拿掉。
- 大勢頁的黃巾聲勢說明還是 beta 的文字。
- 開關開著時，在洛陽發生、不推任何戰線的效果不只 3 處，還有：
  - `trend_luoyang_road_cut`；
  - `kou_escort` 在洛陽那一支；
  - 「任何地點」的事件在洛陽觸發時。
- 之後 joy 寫事件，推戰況要寫 `front`，寫 `huangjin` 會被內容檢查擋下。
- 時刻表與伏筆的 `front` 欄位，驗證時當成大區 id、讀值時當成戰線 id。Infra 會等 T1 進 main，改成驗證時就要求寫戰線 id。

## 擱置（小問題，都不擋合併）

- 新的大勢線 API 參數順序不一致：有的 world 在前，有的 content 在前。
- 遲送的上一季決戰戰報，標籤用的是這一季的章（只影響文字）。
- 測試還沒蓋到的地方：
  - 戰線條件 0／100 的夾限、亂局上界 65；
  - 開關開著時的操練；
  - 真實事件效果經過換算的結果；
  - 假人同分時怎麼選、某條戰線沒有地點時怎麼辦。
- 開季時才蓋章的舊季，存下來的黃巾聲勢要等第一次推進時間才重算。
- 江湖頁拿到空的 `fronts` 陣列時沒有擋；戰況條借用了「快」屬性的顏色。
