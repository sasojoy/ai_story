## QA 須知（兩台 QA 踩過的坑，之後的驗收照這些做）

**開伺服器**
- cookie 照 host 分、不分埠：每個驗收用自己的 `<名字>.localhost`。同一個驗收要同時登兩個帳號，也要換 host。
- 在 scratchpad 用 `git archive | tar -x` 解一份複本來跑（PowerShell 的 tar 碰到中文路徑會壞）。
- 用 PowerShell `Start-Process` 加 `-u` 啟動。帳號用 `scripts/set_password.py` 的 `--db`、`--local-dir` 寫到 scratchpad。
- 管理者用環境變數 `TIANXIA_ADMINS`，不改 repo 的設定。
- 關的時候 `taskkill /T`。暫時建的 `content/profiles` 用完就刪。

**API 與瀏覽器**
- API 腳本從 bash 跑，PowerShell 會把 JSON 參數弄壞。
- 管理者的動作走 `POST /api/do/<op>`（例：`fast_forward {hours}`、`schedule`），不是 `/api/admin`。
- 網頁按鈕用 JS 的 `click()`，座標點擊常常沒反應。
- `resize_window` 在窗格寬度一變就會被重設。

**存檔與腳本**
- 換季之後、玩家第一次同步之前改的存檔，會被換季重設洗掉，要等同步完再改。
- 自動選事件的迴圈要排除 `choice:free`。
- `battles` 是最新的在前（`battles[0]`）。腳本移動之前先略過序章（`skip_tutorial` 會重設地點）。
- 出陣的每日次數看現實時間，快轉沒用，要改 `PlayerState.sorties_today`。打贏本人之後的閉門不見記在 `PlayerState.snubbed_until`。
- 決戰的「定結果」只能定還沒開打的。要驗發獎勵就實際打完：用腳本把 `muster_deadline_real` 和 `round.opened_real` 拉到過去。

**只能靠引擎跑才驗得到的**（開暫存資料庫，`Game.new`，必要時 mock `team.fight`）
- 跟開季時刻有關的規則：伺服器開季用真實時間，例如要驗週三開季。
- 沒有設定檔可以切的開關：例如素材四階關掉。
- 機率：例如掉落率，要跑幾千次。
- 滿級換心得、頭目戰、切磋、決戰軍餉、求援傳聞。
- 用自己亂數的掉落（名號＋戰報流水號）：先照種子挑出擲得中的名號建角色，再實打。
- 假人：只在台灣時間 11:30～13 與 19～24 上線。其他時段複製一份資料庫，用帶假時鐘的 BotRunner 跑。
