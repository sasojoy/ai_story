## 3. 確定的違規（照嚴重度排）

### 高

#### 3.1 舊規則的季也跟著變了（#157）

**違反**：新功能要掛開關，開關關著時一個位元組都不能變。出處：v2 設計稿 §一.5、CLAUDE.md 的開關原則。

**證據**：
- **輕身**從前 2 回合改成前 4 回合，沒掛開關（content/traits.json:67-68，e107597f）。同一筆的另外兩項都照季讀，只有這一項沒有。
- **六門新的上品內功**帶了學習地點，舊季也學得到（content/skills.json，590bdc5e）。改之前，帶學習地點的上品武學是 0 門。
- **90 位一般 NPC** 沒看開關，直接併進人物表（tianxia/content.py:190-191）。結果：
  - 舊季在酒肆打聽「強弩射法」，會答出兩位弓手（features/tavern/ask.py:201）；
  - 這 90 個名字不能再拿來取名號（server_bots.py:64、naming.py:111）。
- **存檔多一欄**：擂台、奪璽、決戰的存檔多寫一個空的 card 欄（state.py:523-524、608，world_state.py:214，battle_instance.py:198）。專案平常的做法是預設值不寫進存檔。
- **沒附證明**：PR 沒附 same_behavior 的結果。
- **已經上線**：這張經 #162 上了 main，origin/main 的 traits.json:68 已經是 4 回合；可是 #162 的說明寫「正在跑的季不變」。

**為什麼不算例外**：
- 手冊沒有「平衡調整可以不掛開關」這種例外。
- PR 在退版風險裡自己承認，只算說了，不算准了。
- 提交引的企劃者「可以」，是對「新增內功」點頭；查不到有人同意讓正在跑的季也變。

**怎麼補**：
1. 先問企劃者（第 7 節第 1 題）。
2. 如果不是有意的：
   - 在 develop 改成只在五項屬性的季生效（或撤掉那兩處），照 develop→main 帶上去；
   - 一般 NPC 改放自己的內容欄位，不要塞進人物表；
   - card、dodge 是預設值時不寫進存檔；
   - 以 805993df 為底，補跑一次 same_behavior（所有軌）；
   - 更正 #162 那一句。
3. 線上有沒有部署、正在跑的季有沒有吃到，從 git 看不出來，要問 Joy。

## 4. 反覆出現的模式與改法（只建議，沒有改檔）
